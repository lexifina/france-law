Objet 

Ce jeu de données dresse la liste des Elus au Conseil Municipal sur le mandat en cours à la 
ville de Saint-Paul-lès-Dax. Il consiste en une liste ordonné de membres avec leur 
appartenance aux commissions. 

Ce document décrit les détails de chaque champ. 

Synthèse des données essentielles 

Le jeu de données contient les données essentielles suivantes : 

 Elu 
 Fonction 
 Commission 
 Conseiller communautaire
