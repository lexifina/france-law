ACCORD DU 7 JUIN 2007
PORTANT PROROGATION DE L’ACCORD DU 28 AVRIL 2005
RELATIF AU DIF
NOR : ASET0850196M
Les partenaires sociaux de la branche audiovisuelle conviennent de proro-
ger jusqu’au 31 décembre 2007, sans modification, le protocole d’accord sur
le droit individuel à la formation conclu le 28 avril 2005.
Fait à Paris, le 7 juin 2007.
Suivent les signatures des organisations ci-après :
Organisations patronales :
ACCES ;
API ;
FFRC ;
SNTP ;
USPA.
Syndicats de salariés :
FASAP-FO ;
F3C-CFDT ;
Fédération CFE-CGC des médias ;
Fédération de la communication CFTC ;
SNPCA CFE-CGC.
