Lorsqu’un salarié justifie, pour tout type de contrat de travail, d’une
ancienneté professionnelle bancaire d’au moins 3 ans consécutifs acquise

d’ancienneté dans l’entreprise, le barème figurant dans le tableau précé-
dent lui est applicable.
L’indemnisation s’effectue dès le 1er jour d’absence pour le 1er et 2e arrêt
et dès le 4e jour d’absence pour les arrêts suivants. Pour les absences résul-
tant d’accident de travail, de trajet ou de maladie professionnelle, le salaire
est maintenu dès le 1er jour d’absence dans tous les cas.
La durée et les modalités d’indemnisation de l’arrêt sont appréciées sur
une période de 12 mois glissants. Pour le calcul de cette période, les absen-
ces ne sont pas prises en compte. Toutefois, les absences rémunérées pour
(1) Outre les périodes de présence effective au travail, sont validées les périodes d’absence qui, en
