Un changement de code APE (activité principale exercée, codée selon la
NAF [nomenclature d’activités française]), est introduit le 8 janvier 2008
dans le répertoire pour chaque entreprise et chaque établissement inscrit à
l’INSEE.

A partir du 1er mai 2008, le nouveau code du travail entre en vigueur. La
numérotation du code du travail a changé : les articles de l’ancien code,
comprenant souvent plusieurs alinéas ont été scindés afin que chaque article
exprime un seul principe, le nouveau code du travail contient donc plus d’ar-
ticles que l’ancien et sa numérotation passe de 3 à 4 chiffres.
