# Le droit français en 20 graphiques

[English](README.en.md)

Des graphiques sur le droit de tous les pays, tirés de l’ensemble de global-law : [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). Ici figurent uniquement les graphiques sur la France.

Vingt graphiques sur le droit français, tirés uniquement des données de ce dépôt : l’historique de LEGI, la base de Légifrance, version d’article par version d’article. La Constitution, 77 codes et 118 773 autres textes en vigueur le 28 octobre 2026 (lois, ordonnances, décrets, arrêtés), et pour chacune des 1 528 182 versions d’articles, le jour de son entrée en vigueur et le texte qui l’a écrite.

Ouvrez [`le-droit-francais-en-20-graphiques.html`](le-droit-francais-en-20-graphiques.html) dans un navigateur. La page est un seul fichier qui contient toutes ses données ; elle ne charge du web que la bibliothèque d3 et ses polices. Les boutons en haut à droite choisissent la langue (français ou anglais) et l’affichage (clair ou sombre). Chaque graphique indique sa source dans le dépôt, le nombre d’enregistrements et ses limites, et comporte en dessous un tableau de tous les chiffres. Survolez un élément pour les valeurs exactes.

Les graphiques sont descriptifs : ils montrent ce que les sources enregistrent, pas pourquoi.

## Les graphiques

### I. Le droit en vigueur

#### 1. Le droit en vigueur

Les 692 977 articles en vigueur le 28 octobre 2026, par type de texte : 45 % dans des arrêtés, 24 % dans les 77 codes ; et les plus longs textes hors des codes.

![Le droit en vigueur](stills/fr/01.png)

#### 2. L’inflation des articles

Les articles en vigueur au 1er janvier de chaque année depuis 1990 (298 214 en 2000, 692 977 en octobre 2026), et ceux qui entrent en vigueur ou en sortent chaque année.

![L’inflation des articles](stills/fr/02.png)

#### 3. Les 77 codes

Les codes et leurs parties, lues dans la lettre des numéros d’article : 58 % d’articles R, D ou A ; le Code de la santé publique en compte 13 667.

![Les 77 codes](stills/fr/03.png)

#### 4. L’âge du texte en vigueur

L’année où la rédaction actuelle de chaque article est entrée en vigueur, par type de texte : la moitié en 2015 ou après.

![L’âge du texte en vigueur](stills/fr/04.png)

#### 5. Le Code civil article par article

Les 2 899 articles du Code civil dans l’ordre, colorés selon l’époque de leur rédaction : 596 sans version plus récente que 1803–1804, 949 réécrits depuis 2016.

![Le Code civil article par article](stills/fr/05.png)

### II. Comment le droit change

#### 6. Qui écrit le droit

Les versions d’articles par année, selon le texte qui les a écrites (depuis 2000 : 42 % de décrets, 38 % d’arrêtés, 11 % de lois), et qui écrit les 12 codes les plus modifiés.

![Qui écrit le droit](stills/fr/06.png)

#### 7. Le 1er janvier

Les jours d’entrée en vigueur sur un calendrier : 11,6 % des versions d’articles de 2000 à 2025 le 1er janvier ; le jour de parution au Journal officiel et le jour d’entrée en vigueur.

![Le 1er janvier](stills/fr/07.png)

#### 8. De la signature à l’entrée en vigueur

Le délai entre la signature d’un texte et l’entrée en vigueur de ce qu’il écrit : 2 jours en médiane pour une loi, plus de six mois pour 21 % des versions écrites par ordonnance.

![De la signature à l’entrée en vigueur](stills/fr/08.png)

#### 9. Du texte signé au Journal officiel

Le délai entre la date d’un texte et sa publication, de 1990 à 2026 : de 12 à 5 jours en médiane pour un arrêté, un jour pour une loi.

![Du texte signé au Journal officiel](stills/fr/09.png)

#### 10. Les lois-fleuves

Les 15 lois qui ont écrit le plus de versions d’articles dans les codes, et dans lesquels : 1 091 pour la loi n° 2013-672.

![Les lois-fleuves](stills/fr/10.png)

#### 14. Les articles les plus réécrits

#### 15. Les lois de finances

## Limites

- **LEGI n’est pas tout le Journal officiel.** Le dépôt contient les textes que LEGI consolide ; un texte jamais consolidé, ou abrogé avant de l’être, manque. Les premières années des graphiques 2, 4 et 11 comptent donc moins.
- **Les fiches n’existent que pour les textes encore en vigueur.** Les intitulés, les dates de publication et les numéros (graphiques 9, 15, 17 et 18) ne couvrent pas les textes entièrement abrogés.
- **Les catégories sont lues dans les noms et les intitulés.** Le type de texte (nom de l’auteur du commit), les lois de finances, les mots qui ouvrent un titre, les décrets d’application et la juridiction d’une décision suivent les règles de `src/prep.py`. Ce qu’aucune règle ne reconnaît est compté dans « autres ».
- **Une version est un fichier d’article écrit.** Les versions que LEGI enregistre sans changement de texte (environ 27 000) ne font pas de commit et ne comptent pas.
- **LEGI attribue chaque version au texte qu’elle nomme**, ou à « Légifrance (DILA), version consolidée » quand elle n’en nomme aucun (« non attribué ») ; une décision de justice n’est l’auteur que des changements qu’elle fait elle-même.
- **2026 est incomplet** (jusqu’au 28 octobre) et dessiné plus clair.

## Reconstruire

```sh
python visualisations/src/make.py            # historique, arborescence et fiches -> src/.build/ -> le-droit-francais-en-20-graphiques.html
node visualisations/src/stills.cjs           # les images de ces README (Playwright ; PLAYWRIGHT=<chemin> s’il n’est pas global)
```

`make.py` lit tout dans les objets git : il fonctionne dans un clone sans blobs (`--filter=blob:none`) ou `--no-checkout`, où il ne télécharge que les fiches `index.md`, les articles de la Constitution et le texte des 60 articles de codes qui ont le plus de versions (environ 120 000 petits fichiers). Il lit `origin/main` (ou `HEAD`) par défaut ; `--ref` choisit une autre branche ou un autre commit. Il n’écrit rien dans le dépôt en dehors de la page et du dossier `src/.build/` (que git ignore).

| Fichier | Rôle |
| --- | --- |
| `src/make.py` | extrait l’historique, l’arborescence et les fiches dans `src/.build/`, puis lance `prep.py` et `build.py` |
| `src/prep.py` | calcule tous les chiffres des 20 graphiques et du profil des données dans `src/.build/data.json` |
| `src/page.tpl.html` | la page : les textes dans les deux langues, les graphiques (d3), les tableaux |
| `src/build.py` | insère `data.json` dans le modèle et écrit la page |
| `src/stills.cjs` | dessine chaque graphique en PNG dans `stills/fr/` et `stills/en/` |
