# Anomalie administrative concernant la rédaction des titres d'identité de certains habitants de la commune de Meudon

## Question

M. Hervé Marseille attire l'attention de M. le ministre de l'intérieur, de l'outre-mer, des collectivités territoriales et de l'immigration sur une anomalie administrative concernant la rédaction des titres d'identité de certains habitants de la commune de Meudon. En effet, la ville de Meudon qui a le code postal 92190 comprend un quartier, Meudon-la-Forêt, identifié par un code postal différent (92360). Il se trouve que les cartes d'identité sont établies pour tous les habitants de la commune avec le même code postal 92190. À cause de cette ambiguïté administrative, des correspondances arrivent en retard ou hors délais en certaines circonstances. Ainsi un administré résidant à Meudon-la-Forêt a reçu un avis de contravention avec majoration forfaitaire car les précédents envois recommandés de cette contravention, ayant été faits avec le code postal 92190, ne lui sont jamais parvenus. C'est une anomalie préjudiciable aux habitants de Meudon-la-Forêt. Il lui demande si une mise à jour de l'application informatique des cartes d'identité des services du ministère peut enfin tenir compte du code postal spécifique au quartier de Meudon-la-Forêt pour éviter de tels désagréments qui perdurent depuis près de cinquante ans.
