# Politique de lutte contre les risques d'épidémie de tuberculose

- Nature : Questions écrites
- Numéro : 02101
- Référence : SEQ930702101
- Législature : 10
- Auteur : M. Pierre-Christian Taittinger (Paris, RI)
- Ministère interrogé : Santé
- Rubrique : Santé publique
- Publiée au JO : 1993-07-22, page 1178

## Question

M. Pierre-Christian Taittinger demande à M. le ministre délégué à la santé quelles actions il compte entreprendre pour essayer d'enrayer les risques d'épidémie de tuberculose à germes multirésistants, qui ont tendance à se répandre dans certains pays. Un retour possible de ce fléau en France doit mobiliser tous les responsables de la santé pour que soient évitées les évolutions que nous avons connues dans le passé.
