# Réponse à la question SEQ931203919

- Question : [SEQ931203919](seq931203919.md) — Statut des intervenants extérieurs assurant des cours d'allemand dans les classes bilingues de l'académie de Strasbourg

## Réponse

*Éducation, JO du 1994-02-17, page 375*

Réponse. - Les modalités selon lesquelles peuvent être rémunérés les intervenants extérieurs assurant les cours d'allemand dans les classes bilingues de l'académie de Strasbourg font l'objet d'une étude menée en liaison avec les services du ministre du budget.
