# Organisation des élections professionnelles

- Nature : Questions écrites
- Numéro : 39506
- Référence : SEQ020439506
- Législature : 11
- Auteur : M. André Dulait (Deux-Sèvres, UC)
- Ministère interrogé : Premier ministre
- Rubrique : Élections professionnelles
- Thèmes : Communes
- Publiée au JO : 2002-04-11, page 1017

## Question

M. André Dulait appelle l'attention de M. le Premier ministre sur les charges de travail supplémentaires occasionnées par l'organisation des élections professionnelles pour les communes qui doivent notamment, selon le type d'élection, établir les listes électorales, envoyer les cartes d'électeur, tenir les bureaux de vote et organiser les opérations de vote. Ces contraintes qui se traduisent par la mobilisation du personnel communal apparaissent disproportionnées au regard du faible pourcentage de votants. Face à ces difficultés, il demande si le Gouvernement envisage par exemple de généraliser le vote par correspondance pour les élections professionnelles dont l'organisation par ailleurs pourrait être confiée ultérieurement aux organismes dont elles relèvent.
