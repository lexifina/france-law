# Impôt sur le revenu : partage de la demi-part supplémentaire par enfant

- Nature : Questions écrites
- Numéro : 01962
- Référence : SEQ020801962
- Législature : 12
- Auteur : M. Jean Louis Masson (Moselle, RPR)
- Ministère interrogé : Économie
- Rubrique : Impôt sur le revenu
- Publiée au JO : 2002-08-22, page 1848

## Question

M. Jean-Louis Masson demande à M. le ministre de l'économie, des finances et de l'industrie si, pour le calcul de l'impôt sur le revenu dans le cas de deux parents vivant séparément et partageant l'autorité parentale, il est possible de partager également la demi-part supplémentaire par enfant du quotient familial. Si oui, il souhaiterait connaître sur quelle base de proportionnalité le partage doit être effectué.
