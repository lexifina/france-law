# Réponse à la question SEQ170800979

- Question : [SEQ170800979](seq170800979.md) — Désignation d'un président d'honneur pour un syndicat intercommunal

## Réponse

*Intérieur, JO du 2018-01-18, page 210*

Le titre de président d'honneur n'est ni reconnu, ni, dès lors, régi par le code général des collectivités territoriales (CGCT). Le seul titre honorifique prévu par le CGCT est celui de président honoraire, dont les dispositions relèvent de l'article L. 2122-35 du CGCT.
