# Aide prévue dans le Xe Plan pour la production porcine

- Nature : Questions écrites
- Numéro : 08470
- Référence : SEQ900208470
- Législature : 9
- Auteur : M. Edouard Le Jeune (Finistère, UC)
- Ministère interrogé : Plan
- Rubrique : Plan
- Thèmes : Porcins
- Publiée au JO : 1990-02-22, page 347

## Question

M. Edouard Le Jeune demande à M. le secrétaire d'Etat auprès du Premier ministre, chargé du Plan, si le contrat Xe Plan comporte effectivement une prévision d'appui à la production porcine pour un montant de 110,7 millions de francs (part de l'Etat). Il lui demande, le cas échéant, de bien vouloir lui préciser le détail de l'aide prévue.
