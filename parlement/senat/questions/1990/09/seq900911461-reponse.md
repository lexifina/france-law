# Réponse à la question SEQ900911461

- Question : [SEQ900911461](seq900911461.md) — Exportations agro-alimentaires à destination de l'Irak entre 1980 et 1989

## Réponse

*Commerce extérieur, JO du 1990-11-08, page 2404*

Réponse. - Depuis dix ans, les montants des exportations françaises agro-alimentaires vers l'Irak ont été les suivants (en millions de francs) : 1980 : 728 ; 1981 : 1 084 ; 1982 : 1 115 ; 1983 : 644 ; 1984 : 1 005 ; 1985 : 1 027 ; 1986 : 420 ; 1987 : 360 ; 1988 : 647 ; 1989 : 527. Pour 1989, ces ventes sont essentiellement constituées par quatre produits : viande fraîche (200 MF), blé tendre (94 MF), lait concentré et sec (85 MF), sucre (48 MF).
