# Réponse à la question SEQ070700232

- Question : [SEQ070700232](seq070700232.md) — Statistiques sur les conseillers municipaux de nationalité étrangère

## Réponse

*Intérieur, JO du 2007-08-23, page 1480*

Le tableau ci-dessous indique le nombre des ressortissants de l'Union européenne élus conseillers municipaux à l'issue du scrutin des 21 et 28 mars 2001 par nationalité dans les communes de plus de 3 500 habitants. Les renseignements statistiques ne peuvent être fournis pour les communes de moins de 3 500 habitants, lesquelles ne sont pas soumises aux déclarations de candidature. Allemagne : 17 ; Belgique : 21 ; Danemark : 1 ; Espagne : 23 ; Finlande : 1 ; Grèce : 1 ; Irlande : 2 ; Italie : 28 ; Pays-Bas : 8 ; Portugal : 83 ; Royaume-Uni : 16 ; Suède : 3 ; Total : 204.
