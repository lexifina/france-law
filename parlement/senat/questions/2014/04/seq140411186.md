# Rôle de la table de décharge dans le déroulement des opérations de vote

- Nature : Questions écrites
- Numéro : 11186
- Référence : SEQ140411186
- Législature : 14
- Auteur : M. Christian Namy (Meuse, UDI-UC)
- Ministère interrogé : Intérieur
- Rubrique : Élections
- Publiée au JO : 2014-04-10, page 927

## Question

M. Christian Namy attire l'attention de M. le ministre de l'intérieur sur le déroulement des opérations de vote.

L'article L. 60 du code électoral dispose qu'un bureau de vote doit constater que le nombre des enveloppes correspond exactement à celui des électeurs inscrits.

Il se demande si toutes les enveloppes doivent ensuite être disposées sur la table de décharge à l'ouverture du bureau de vote ou si une partie d'entre elles peut être stockée dans la salle de vote.

Par ailleurs, il se demande dans quelle mesure un assesseur, le secrétaire ou un agent communal peut se positionner, assis, derrière la table de décharge.
