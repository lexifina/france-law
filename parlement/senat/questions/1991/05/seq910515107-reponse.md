# Réponse à la question SEQ910515107

- Question : [SEQ910515107](seq910515107.md) — TVA perçue sur les bateaux de plaisance dans les DOM

## Réponse

*Économie, JO du 1991-12-12, page 2789*

Réponse. - Les renseignements demandés par l'honorable parlementaire ne sont disponibles qu'à partir de 1988 pour la Martinique et la Guadeloupe et 1989 pour la Réunion. Enfin, la T.V.A. n'est pas applicable en Guyane. Les montants annuels (en francs) de la T.V.A. perçue sur les bateaux de plaisance en provenance de métropole pour les D.O.M. sont les suivants : 1988 : Martinique, 3 635 525 ; Guadeloupe, 6 705 475 ; Réunion, néant. 1989 : Martinique, 567 722 ; Guadeloupe, 7 994 205 ; Réunion, 460 311. 1990 : Martinique, 574 435 ; Guadeloupe, 15 418 435 ; Réunion, 472 073.
