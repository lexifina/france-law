# Réponse à la question SEQ910113462

- Question : [SEQ910113462](seq910113462.md) — Personnels de surveillance des musées, monuments et palais nationaux

## Réponse

*Culture, JO du 1991-03-28, page 651*

Réponse. - L'évolution des effectifs des personnels de surveillance des musées nationaux et des monuments historiques appartenant à l'Etat a été la suivante au cours des dix dernières années : 1980 : 1 603 ; 1981 : 1 605 ; 1982 : 1 908 ; 1983 : 1 963 ; 1984 : 1 955 ; 1985 : 1 940 ; 1986 : 2 057 ; 1987 : 2 075 ; 1988 : 2 132 ; 1989 : 2 272 ; 1990 : 2 244 ; 1991 : 2 244. Les grilles indiciaires de ces personnels sont les suivantes (indices majorés) : agent technique de surveillance de 2e classe (échelle 2 de rémunération) : de l'indice 228 à 302 ; agent technique de surveillance de 1re classe (échelle 3 de rémunération) : de l'indice 236 à 322 ; agent chef de 2e classe (échelle 4 de rémunération) : de l'indice 241 à 330 ; agent chef de 1re classe (échelle 5 de rémunération) : de l'indice 248 à 350 ; agent chef principal (nouvel espace indiciaire, en cours de création) : de l'indice 353 à 388 ; inspecteurs de surveillance (catégorie B) : de l'indice 269 à 407.
