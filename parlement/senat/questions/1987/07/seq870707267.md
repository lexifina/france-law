# Orientation de l'épargne vers le foncier agricole

- Nature : Questions écrites
- Numéro : 07267
- Référence : SEQ870707267
- Législature : 8
- Auteur : M. Edouard Le Jeune (Finistère, UC)
- Ministère interrogé : Agriculture
- Rubrique : Exploitants agricoles
- Thèmes : Épargne
- Publiée au JO : 1987-07-30, page 1155

## Question

M.Edouard Le Jeune appelle l'attention de M. le ministre de l'agriculture sur les difficultés économiques que rencontrent les agriculteurs pour l'acquisition des terres agricoles. Il lui demande de bien vouloir lui indiquer les mesures qu'il entend prendre, notamment dans le cadre de la préparation de la loi de modernisation, afin d'orienter l'épargne vers le foncier agricole.
