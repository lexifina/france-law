# Financement du lycée agricole de Roanne-Chervé (loire)

- Nature : Questions écrites
- Numéro : 07348
- Référence : SEQ870807348
- Législature : 8
- Auteur : M. Louis Mercier (Loire, UC)
- Ministère interrogé : Agriculture
- Rubrique : Enseignement agricole
- Publiée au JO : 1987-08-06, page 1207

## Question

M.Louis Mercier attire l'attention de M. le ministre de l'agriculture sur l'importante réduction des crédits de vacation dont bénéficiait jusqu'alors le lycée agricole de Roanne-Chervé. Il souhaiterait connaître les raisons d'une telle décision dont les conséquences vont perturber d'une façon importante le bon fonctionnement du service d'enseignement de cet établissement.
