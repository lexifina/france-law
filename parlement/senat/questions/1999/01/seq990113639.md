# Réduction d'impôt pour les dépenses d'hébergement dans un établissement de long séjour ou une section de cure médicale

- Numéro : 13639
- Référence : SEQ990113639
- Législature : 11

- Ministère interrogé : Économie
- Rubrique : Établissements de long séjour
- Thèmes : Impôt sur le revenu

## Question

M.
