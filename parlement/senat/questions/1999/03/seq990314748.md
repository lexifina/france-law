# Pension uniforme pour les grands invalides de guerre

- Nature : Questions écrites
- Numéro : 14748
- Référence : SEQ990314748
- Législature : 11
- Auteur : M. Georges Gruillot (Doubs, RPR)
- Ministère interrogé : Anciens combattants
- Rubrique : Pensions militaires d'invalidité
- Publiée au JO : 1999-03-18, page 827

## Question

M. Georges Gruillot appelle l'attention de M. le secrétaire d'Etat aux anciens combattants sur le souhait exprimé par la Fédération nationale des plus grands invalides de guerre d'obtenir une valeur du point de pension uniforme pour tous les mutilés. En effet, pour la période 1991-1995, la valeur du point applicable aux pensions dépassant un certain plafond a été gelée, ce qui a lourdement pénalisé les grands invalides de guerre. Le rétablissement de l'indexation en 1995 n'a cependant par permis de compenser le retard accumulé. Il lui demande donc quelles mesures il envisage de prendre afin de rétablir dans les meilleurs délais l'équité de traitement entre mutilés.
