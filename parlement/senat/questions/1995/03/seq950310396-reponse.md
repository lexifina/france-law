# Réponse à la question SEQ950310396

- Question : [SEQ950310396](seq950310396.md) — Mesures en vue de favoriser le développement des greffes

## Réponse

*Santé, JO du 1995-05-04, page 1060*

Réponse. - L'évolution du nombre de transplantation d'organes de 1983 à 1994 est la suivante : 1983 : 967 transplantations ; 1984 : 1070 transplantations ; 1985 : 1360 transplantations ; 1986 : 1769 transplantations ; 1987 : 2405 transplantations ; 1988 : 2884 transplantations ; 1989 : 3334 transplantations ; 1990 : 3572 transplantations ; 1991 : 3512 transplantations ; 1992 : 3220 transplantations ; 1993 : 3180 transplantations ; 1994 : 2871 transplantations. La transplantation d'organes a connu d'abord et jusqu'en 1990, un accroissement continu, puis à partir de 1990, une baisse sensible. L'Etablissement français des greffes mène actuellement une réflexion en vue de développer le don ; il s'agit d'abord de sensibiliser le public à l'intérêt du don d'organes. Cet établisement a pris contact dans ce but avec le Comité français d'éducation pour la santé ; il s'agit également d'améliorer l'accueil des familles dans les hôpitaux et l'organisation actuelle des prélèvements de manière à augmenter le nombre d'organes disponibles pour les milliers de patients en attente de greffe.
