# Renfort des effectifs de gendarmerie dans les départements touristiques

- Nature : Questions écrites
- Numéro : 09831
- Référence : SEQ950209831
- Législature : 10
- Auteur : M. Marcel Vidal (Hérault, SOC)
- Ministère interrogé : Défense
- Rubrique : Gendarmerie
- Thèmes : Tourisme
- Publiée au JO : 1995-02-09, page 303

## Question

M. Marcel Vidal attire l'attention de M. le ministre d'Etat, ministre de la défense, sur les renforts des effectifs de gendarmerie, Depuis plusieurs années, les effectifs de gendarmerie sont renforcés dans les départements touristiques. En 1994, dans le département de l'Hérault, les renforts ont été très faibles et affectés essentiellement dans les communes du littoral alors que la fréquentation touristique est également très importante dans les communes rurales de l'Hérault. Aussi, lui demande-t-il quelles mesures seront les siennes en matière de renforts d'effectifs pour la prochaine saison estivale. Il lui demande également de lui préciser quel sera l'effectif affecté dans le département de l'Hérault.
