# Nouvelle classification du code postal

- Nature : Questions écrites
- Numéro : 06825
- Référence : SEQ891106825
- Législature : 9
- Auteur : M. Georges Treille (Deux-Sèvres, UC)
- Ministère interrogé : Postes
- Rubrique : Postes et télécommunications
- Publiée au JO : 1989-11-02, page 1790

## Question

M. Georges Treille appelle l'attention de M. le ministre des postes, des télécommunications et de l'espace sur la nouvelle classification de l'édition 89 du code postal, assimilant les communes associées à des lieudits dans une troisième partie intitulée " particularités d'adressage ". Cette modification de la présentation du nouveau code postal, outil indispensable, très apprécié du public, peut apparaître discriminatoire, voire choquante, pour nombre de communes associées dont les habitants restent attachés à leur identité locale. Il demande, en conséquence, s'il ne serait pas souhaitable de prendre des dispositions pour 1990 afin de revenir à une distribution mettant sur un pied d'égalité toutes les communes de France.
