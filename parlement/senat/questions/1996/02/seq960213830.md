# Lutte contre l'insécurité dans les établissements scolaires

- Nature : Questions écrites
- Numéro : 13830
- Référence : SEQ960213830
- Législature : 10
- Auteur : M. Alfred Foy (Nord, NI)
- Ministère interrogé : Éducation
- Rubrique : Établissements scolaires
- Thèmes : Sécurité
- Publiée au JO : 1996-02-15, page 304

## Question

M. Alfred Foy attire l'attention de M. le ministre de l'éducation nationale, de l'enseignement supérieur et de la recherche sur la multiplication des actes de violence, dont les médias se font chaque jour l'écho, dans les établissements scolaires. C'est la raison pour laquelle il souhaiterait être informé des mesures qu'il compte prendre pour endiguer cette insécurité.
