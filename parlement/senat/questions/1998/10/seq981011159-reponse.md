# Réponse à la question SEQ981011159

- Question : [SEQ981011159](seq981011159.md) — Détermination des seuils dans le code des marchés publics

## Réponse

*Économie, JO du 1998-12-24, page 4121*

Réponse. - Les seuils de passation et de publication ne figurent pas, en tant que tels, dans le code des marchés publics, mais dans les arrêtés auxquels il renvoie. Dans ces derniers, les seuils communautaires (livre V du code des marchés publics) sont exprimés en HT. Les seuils nationaux (livres Ier à IV du code des marchés publics) sont exprimés en TTC à l'exception du seuil à partir duquel le concours de maîtrise d' uvre est obligatoire (qui est fixé en HT depuis l'arrêté du 16 juin 1998). L'unification de l'expression des seuils figure parmi les mesures de simplification des textes applicables à la commande publique qui sont actuellement étudiées dans le cadre de la réforme du code des marchés publics.
