# Réponse à la question SEQ980306696

- Question : [SEQ980306696](seq980306696.md) — Accès au réseau Internet pour les enseignants

## Réponse

*Éducation, JO du 1998-06-18, page 1944*

Réponse. - Le nombre d'enseignants accédant à Internet dans le cadre d'un projet pédagogique est difficile à évaluer. En effet, tout enseignant travaillant dans un établissement équipé est susceptible d'utiliser le réseau Internet à des fins pédagogiques. Il est possible de fournir le nombre d'enseignants qui se sont manifestés auprès des services académiques pour bénéficier d'une adresse électronique dans le cadre d'un projet pédagogique. Pour la région Rhône-Alpes, ce sont environ 2 700 enseignants qui ont fait cette démarche. Le nombre total d'enseignants utilisant le réseau Internet dans le cadre d'activités pédagogiques est plus important.
