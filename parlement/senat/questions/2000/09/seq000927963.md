# Codification des dispositions réglementaires concernant le code de la santé publique

- Numéro : 27963
- Référence : SEQ000927963

- Ministère interrogé : Emploi

## Question

M. Alain Hethener demande à Mme le ministre de l'emploi et de la solidarité de bien vouloir faire connaître sous quels délais les dispositions réglementaires concernant le code de la santé publique feront l'objet d'une codification.
