# Réglementation relative aux délais de paiement dans les marchés publics

- Nature : Questions écrites
- Numéro : 26707
- Référence : SEQ000726707
- Législature : 11
- Auteur : M. Michel Bécot (Deux-Sèvres, UC)
- Ministère interrogé : Économie
- Rubrique : Marchés publics
- Thèmes : Entreprises
- Publiée au JO : 2000-07-13, page 2455

## Question

M. Michel Bécot souhaite attirer l'attention de M. le ministre de l'économie, des finances et de l'industrie sur les délais de paiement auxquels sont soumises les entreprises, dans le cadre des marchés publics. Si les délais de mandatement sont réglementés, aucune disposition ne vient imposer à l'Etat - les collectivités locales et les établissements publics - un délai de paiement. Cette situation laisse une trop forte latitude à l'Etat, les collectivités locales et les établissements publics, pour régler les entreprises qu'elles engagent. De nombreuses sociétés, principalement dans le secteur du bâtiment et des travaux publics, sont concernées et éprouvent de réelles difficultés de trésorerie. Il lui demande de bien vouloir lui préciser s'il entend introduire dans le code des marchés publics des dispositions réglementant les délais de paiement.
