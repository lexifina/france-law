# Organisation de " rave-party "

- Nature : Questions écrites
- Numéro : 26515
- Référence : SEQ000726515
- Législature : 11
- Auteur : M. Marcel Vidal (Hérault, SOC)
- Ministère interrogé : Intérieur
- Rubrique : Ordre public
- Publiée au JO : 2000-07-06, page 2353

## Question

M. Marcel Vidal attire l'attention de M. le ministre de l'intérieur sur les difficultés que rencontrent les élus de collectivités locales lors de l'organisation de " rave-party ". Ce type de manifestation attire un public très nombreux et entraîne d'importants désagréments pour les populations locales. Aussi lui demande-t-il quelles mesures pourraient être envisagées pour prévenir ce type de manifestation.
