# Organisation d'une table ronde sur les rythmes scolaires

- Nature : Questions écrites
- Numéro : 23460
- Référence : SEQ000323460
- Législature : 11
- Auteur : M. Emmanuel Hamel (Rhône, RPR)
- Ministère interrogé : Enseignement scolaire
- Transmise au ministère : Éducation
- Rubrique : Rythmes scolaires
- Publiée au JO : 2000-03-09, page 839

## Question

M. Emmanuel Hamel attire l'attention de Mme le ministre délégué chargé de l'enseignement scolaire sur l'article paru à la page 7 du quotidien Le Figaro du 23 février 2000 dans lequel la secrétaire générale d'une fédération de parents d'élèves espère que, suite au rapport de l'inspection générale sur l'aménagement des rythmes scolaires dans le primaire présenté le 23 février dernier, " la promesse qui nous a été faite d'organiser une réflexion sur ces rythmes dans le cadre d'une table ronde va être enfin tenue ". Il aimerait savoir si une telle table ronde va être prochainement organisée. Quant le sera-t-elle et qui y participera ?
