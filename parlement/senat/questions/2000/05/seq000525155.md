# Place de l'histoire-géographie dans les programmes des instituts universitaires de formation des maîtres (IUFM)

- Nature : Questions écrites
- Numéro : 25155
- Référence : SEQ000525155
- Législature : 11
- Auteur : M. Emmanuel Hamel (Rhône, RPR)
- Ministère interrogé : Éducation
- Rubrique : Histoire géographie
- Thèmes : Enseignants
- Publiée au JO : 2000-05-11, page 1654

## Question

M. Emmanuel Hamel attire l'attention de M. le ministre de l'éducation nationale sur l'interview du secrétaire général de l'Association des professeurs d'histoire-géographie parue dans le quotidien Le Figaro du 5 avril 2000 au cours de laquelle ce dernier estime que les futurs professeurs d'écoles sont insuffisamment formés pour enseigner l'histoire et la géographie : " la place de l'histoire-géographie est très réduite dans les programmes de certains IUFM... ". Il souhaiterait connaître les mesures envisagées par le Gouvernement pour renforcer l'enseignement de l'histoire-géographie dans les IUFM.
