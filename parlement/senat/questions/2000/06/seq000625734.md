# Politique européenne de stabilisation dans les Balkans occidentaux

- Nature : Questions écrites
- Numéro : 25734
- Référence : SEQ000625734
- Législature : 11
- Auteur : M. Louis Souvet (Doubs, RPR)
- Ministère interrogé : Affaires européennes
- Rubrique : Politique agricole commune (PAC)
- Thèmes : Balkans
- Publiée au JO : 2000-06-01, page 1904

## Question

M. Louis Souvet attire l'attention de M. le ministre délégué aux affaires européennes sur les solutions financières envisagées par la Commission pour réaliser la politique de stabilisation dans les Balkans occidentaux. Il demande si le Gouvernement français entend s'opposer avec détermination à un prélèvement éventuel de 300 millions d'euros sur le budget de la Politique agricole commune.
