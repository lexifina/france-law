# Temps de travail dans le transport urbain

- Nature : Questions écrites
- Numéro : 21975
- Référence : SEQ000121975
- Législature : 11
- Auteur : M. Emmanuel Hamel (Rhône, RPR)
- Ministère interrogé : Équipement
- Rubrique : Transports
- Thèmes : Travail (durée du)
- Publiée au JO : 2000-01-20, page 169

## Question

M. Emmanuel Hamel attire l'attention de M. le ministre de l'équipement, des transports et du logement sur l'information parue dans Le Figaro - Economie du 13 décembre 1999 selon laquelle trois fédérations syndicales lui ont demandé de " les recevoir rapidement ", afin de discuter de l'éventuel changement concernant le temps de travail dans le transport urbain. Il lui demande si, à ce jour, il a bien reçu les trois fédérations syndicales qui le souhaitaient. Dans l'affirmative, quel a été le bilan de cette rencontre, quelles décisions ont été prises et, dans la négative, quand le seront-elles ?
