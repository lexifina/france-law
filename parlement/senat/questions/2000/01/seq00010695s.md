# Test permettant de détecter le prion

- Nature : Questions orales
- Numéro : 0695S
- Référence : SEQ00010695S
- Législature : 11
- Auteur : M. Charles Descours (Isère, RPR)
- Ministère interrogé : Santé
- Rubrique : Élevage
- Thèmes : Santé publique
- Publiée au JO : 2000-01-19, page 81

## Question

M. Charles Descours demande à Mme le secrétaire d'Etat à la santé et à l'action sociale quel test les pouvoirs publics comptent retenir pour détecter dans les cheptels les animaux apparemment sains atteints de maladie à prion.
