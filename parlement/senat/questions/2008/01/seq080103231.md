# Délais de réponse aux questions écrites par groupes politiques

- Nature : Questions écrites
- Numéro : 03231
- Référence : SEQ080103231
- Législature : 13
- Auteur : M. Jean Louis Masson (Moselle, NI)
- Ministère interrogé : Relations avec le Parlement
- Rubrique : Questions parlementaires
- Publiée au JO : 2008-01-31, page 184

## Question

M. Jean Louis Masson attire l'attention de M. le secrétaire d'État chargé des relations avec le Parlement sur le fait que selon les statistiques publiées par les services du Sénat pour 2007, 19,7 % des questions écrites posées par les sénateurs du groupe centriste ont obtenu une réponse dans le délai réglementaire de deux mois. Par contre, ce chiffre n'est que de 11,9 % pour les sénateurs non inscrits et de 10,2 % pour les sénateurs communistes. Il souhaiterait qu'il lui indique s'il ne pense pas qu'il conviendrait de répondre avec la même célérité aux sénateurs de tous les groupes politiques.
