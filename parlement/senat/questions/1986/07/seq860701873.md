# Difficultés de l'élevage bovin dans le département de l'Indre

- Nature : Questions écrites
- Numéro : 01873
- Référence : SEQ860701873
- Législature : 8
- Auteur : M. Jean Benard Mousseaux (Indre, U.R.E.I.)
- Ministère interrogé : Agriculture
- Rubrique : Élevage
- Publiée au JO : 1986-07-03, page 908

## Question

M. Jean Bénard Mousseaux appelle l'attention de M. le ministre de l'agriculture sur les difficultés que connaît l'élevage bovin dans le département de l'Indre. Les conséquences de la sécheresse continuent à se faire sentir. Les prix baissent. Dans la crise communautaire, l'élevage bovin français se trouve de plus en plus menacé par les distorsions de concurrence. Des mesures de sauvegarde s'avèrent indispensables si l'on veut maintenir dans l'Indre une production bovins-viande. En conséquence, il lui demande si des mesures sont envisagées dans un proche avenir pour permettre notamment de maintenir l'élevage dans les zones défavorisées
