# Prise en compte des psycho-névroses de guerre dans le code des pensions

- Nature : Questions écrites
- Numéro : 02081
- Référence : SEQ860702081
- Législature : 8
- Auteur : M. Noël Berrier (Nièvre, SOC)
- Ministère interrogé : Anciens combattants
- Rubrique : Pensions de retraite militaire
- Thèmes : Santé publique
- Publiée au JO : 1986-07-10, page 944

## Question

M.Noël Berrier appelle l'attention de M. le secrétaire d'Etat aux anciens combattants sur les anciens combattants d'Afrique du Nord. Une commission médicale composée de médecins représentant l'administration et les associations a conclu à l'existence des psychonévroses de guerre. Le code des pensions de guerre doit être modifié en conséquence pour permettre aux intéressés de faire valoir leur droit à pension. Il lui demande dans quels délais il compte déposer un projet de loi en ce sens.
