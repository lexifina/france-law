# Révision du code du travail

- Nature : Questions écrites
- Numéro : 02365
- Référence : SEQ860702365
- Législature : 8
- Auteur : M. Pierre-Christian Taittinger (Paris, U.R.E.I.)
- Ministère interrogé : Affaires sociales
- Rubrique : Droit du travail
- Publiée au JO : 1986-07-31, page 1061

## Question

M.Pierre-Christian Taittinger demande à M. le ministre des affaires sociales et de l'emploi s'il juge utile de poursuivre l'idée d'une révision du code du travail pour le simplifier, le clarifier, et en faire un document utilisable par tous.
