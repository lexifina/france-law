# Action à l'encontre d'un maire pour le bornage des chemins communaux

- Nature : Questions écrites
- Numéro : 02058
- Référence : SEQ860702058
- Législature : 8
- Auteur : M. Raymond Soucaret (Lot-et-Garonne, G.D.)
- Ministère interrogé : Intérieur
- Rubrique : Communes
- Publiée au JO : 1986-07-10, page 951

## Question

M.Raymond Soucaret demande à M. le ministre de l'intérieur si un administré peut traduire devant une instance juridique le maire de sa commune pour l'obliger à borner les divers chemins communaux, vicinaux et ruraux.
