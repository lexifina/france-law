# Communication de justificatifs dans le cadre de l'attribution de marchés publics

- Nature : Questions écrites
- Numéro : 05370
- Référence : SEQ180505370
- Législature : 15
- Auteur : Mme Christine Herzog (Moselle, NI)
- Ministère interrogé : Intérieur
- Rubrique : Marchés publics
- Thèmes : Question de rappel
- Publiée au JO : 2018-05-31, page 2596

## Question

Mme Christine Herzog rappelle à M. le ministre d'État, ministre de l'intérieur les termes de sa question n°03963 posée le 22/03/2018 sous le titre : " Communication de justificatifs dans le cadre de l'attribution de marchés publics ", qui n'a pas obtenu de réponse à ce jour. Elle s'étonne tout particulièrement de ce retard important et elle souhaiterait qu'il lui indique les raisons d'une telle carence.
