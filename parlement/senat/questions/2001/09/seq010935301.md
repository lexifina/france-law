# Accueil des enfants de moins de trois ans dans les communes rurales

## Question

M. Jean-Pierre Raffarin attire l'attention de M. le ministre de l'éducation nationale sur l'accueil des enfants âgés de deux à trois ans résidant dans les communes rurales. Il est courant dans la ruralité que les jeunes couples travaillent dans la ville d'à côté. Si la commune de résidence de ces jeunes ménages n'est pas équipée pour accueillir les jeunes enfants avant trois ans, les parents recherchent alors des structures d'accueil dans la ville où ils travaillent. Ils prennent ainsi des habitudes qui les conduisent naturellement à inscrire leur enfant à partir de trois ans dans les écoles urbaines, ce qui a évidemment pour effet de fragiliser les écoles en milieu rural. Cette situation préoccupante inquiète de nombreux maires de la Vienne. Quelles sont les initiatives et les aides que propose le Gouvernement pour promouvoir l'accueil des tout jeunes enfants dans les communes disposant d'une école maternelle ?
