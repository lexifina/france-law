# Français disparus dans les attentats terroristes aux Etats-Unis

- Nature : Questions écrites
- Numéro : 35298
- Référence : SEQ010935298
- Législature : 11
- Auteur : M. Xavier de Villepin (Français établis hors de France, UC)
- Ministère interrogé : Affaires étrangères
- Rubrique : Terrorisme
- Thèmes : États-Unis
- Publiée au JO : 2001-09-27, page 3065

## Question

M. Xavier de Villepin attire l'attention de M. le ministre des affaires étrangères sur la situation des Français disparus dans les attentats terroristes aux Etats-Unis. Il souhaiterait savoir si le département a pu identifier précisément les personnes. En outre, il serait également souhaitable de connaître les formes d'indemnisation prévues pour les familles tant aux Etats-Unis qu'en France.
