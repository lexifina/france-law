# Réponse à la question SEQ011136721

- Question : [SEQ011136721](seq011136721.md) — Equipement des gares en guichets  permettant de recevoir tout type de clientèle

## Réponse

*Équipement, JO du 2002-04-18, page 1120*

A ce jour, près de 200 nouveaux guichets permettant de recevoir tous les types de clientèle, y compris les personnes handicapées, équipent déjà 30 gares SNCF. Dans le courant de l'année 2002, une vingtaine de gares importantes seront rénovées et, dans le cadre de ces travaux de rénovation, seront dotées de ce nouveau concept. De plus, toutes les nouvelles gares sont désormais systématiquement équipées de la sorte.
