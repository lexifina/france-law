# TVA sur les fournitures scolaires

- Nature : Questions écrites
- Numéro : 32064
- Référence : SEQ010332064
- Législature : 11
- Auteur : Mme Marie-Claude Beaudeau (Val-d'Oise, CRC)
- Ministère interrogé : Économie
- Rubrique : Taxe sur la valeur ajoutée (TVA)
- Publiée au JO : 2001-03-22, page 971

## Question

Mme Marie-Claude Beaudeau attire l'attention de M. le ministre de l'économie, des finances et de l'industrie sur la part croissante des dépenses pour les fournitures scolaires dans le budget des familles. Elle lui rappelle que le coût moyen d'une rentrée scolaire pour une famille s'échelonne de 560 francs pour un élève de cours préparatoire à 4 544 francs pour un élève de seconde technologie. Le principe d'égalité devant l'éducation et la formation est loin d'être respecté. Dans le souci de réduire les inégalités existantes, elle lui demande de lui faire connaître les mesures qui pourraient être envisagées pour que, à la rentrée prochaine, le taux de TVA de 19,6 % pour fournitures scolaires soit réduit à 5,5 %.
