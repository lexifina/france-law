# Réponse à la question SEQ940204828

- Question : [SEQ940204828](seq940204828.md) — Application de l'article 1042 du code général des impôts aux communautés de communes

## Réponse

*Budget, JO du 1994-05-19, page 1223*

Réponse. - Il est confirmé à l'honorable parlementaire que les communautés de communes mentionnées à l'article L. 167-1 du code des communes sont éligibles aux dispositions de l'article 1042 du code général des impôts.
