# Codification des décrets pris pour l'application du code civil

- Nature : Questions écrites
- Numéro : 04743
- Référence : SEQ940204743
- Législature : 10
- Auteur : M. Charles de Cuttoli (Français établis hors de France, RPR)
- Ministère interrogé : Justice
- Rubrique : Codes et codification
- Thèmes : Décrets et arrêtés
- Publiée au JO : 1994-02-10, page 287

## Question

M. Charles de Cuttoli expose à M. le ministre d'Etat, garde des sceaux, ministre de la justice, que de nombreux décrets ont été pris en application d'articles du code civil. Il lui demande de bien vouloir lui faire connaître si une codification de ces textes est envisagée dans une partie réglementaire du code civil afin de faciliter l'information juridique des usagers du droit.
