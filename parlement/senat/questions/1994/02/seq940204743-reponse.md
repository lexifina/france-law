# Réponse à la question SEQ940204743

- Question : [SEQ940204743](seq940204743.md) — Codification des décrets pris pour l'application du code civil

## Réponse

*Justice, JO du 1994-05-26, page 1301*

Réponse. - La commission supérieure de codification n'a pas envisagé à ce jour de codifier les textes réglementaires pris en application du code civil. L'instauration dans le code d'une partie réglementaire risquerait de se heurter à de sérieuses difficultés dans la mesure où il conviendrait au préalable de s'assurer que toutes les dispositions actuelles du code civil sont de valeur législative et, le cas échéant, de déclasser celles d'entre elles qui n'auront pas cette valeur. En outre, la partie réglementaire ne permettrait pas d'avoir une vue complète des matières traitées, puisque de nombreux décrets d'application des articles du code civil concernent la procédure applicable à ces matières et sont déjà codifiés dans le nouveau code de procédure civile. Dans ces conditions, et sans méconnaître l'intérêt d'une telle mesure, toute codification ne pourrait être envisagée qu'avec une extrême prudence.
