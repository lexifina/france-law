# Complexité croissante du code général des impôts

- Nature : Questions écrites
- Numéro : 07121
- Référence : SEQ940707121
- Législature : 10
- Auteur : M. Georges Gruillot (Doubs, RPR)
- Ministère interrogé : Budget
- Rubrique : Codes et codification
- Publiée au JO : 1994-07-14, page 1721

## Question

M. Georges Gruillot appelle l'attention de M. le ministre du budget sur la complexité croissante du code général des impôts. Il le remercie de bien vouloir lui préciser les mesures qu'il entend énoncer de manière à rendre ce code plus accessible et plus lisible.
