# Réponse à la question SEQ941209090

- Question : [SEQ941209090](seq941209090.md) — Développement des classes d'intégration accélérée

## Réponse

*Éducation, JO du 1995-02-02, page 268*

Réponse. - Les créations de classes d'intégration scolaires (CLIS) sont du domaine de compétence des inspecteurs d'académie, directeurs des services départementaux de l'éducation nationale qui, seuls, peuvent déterminer le nombre de CLIS qu'il est nécessaire d'ouvrir dans leur département. Ce sont les commissions de l'éducation spéciale (CDES, CCPE) qui déterminent le nombre d'élèves qui peuvent tirer bénéficie d'une scolarisation dans de telles structures, sachant que par ailleurs un certain nombre d'enfants peuvent être intégrés individuellement dans une classe ordinaire. Il convient de remarquer que, d'une année à l'autre, le nombre d'enfants pouvant être admis en CLIS peut fluctuer, notamment en ce qui concerne les enfants déficients visuels.
