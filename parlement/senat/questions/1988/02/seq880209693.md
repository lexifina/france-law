# Notion d'agents salariés ou subventionnés sur les fonds départementaux

- Nature : Questions écrites
- Numéro : 09693
- Référence : SEQ880209693
- Législature : 8
- Auteur : M. Jean Huchon (Maine-et-Loire, UC)
- Ministère interrogé : Intérieur
- Rubrique : Finances locales
- Thèmes : Départements
- Publiée au JO : 1988-02-18, page 221

## Question

M. Jean Huchon demande à M. le ministre de l'intérieur si dans l'article 207 du code électoral, 1er alinéa, les termes " tous les agents salariés ou subventionnés sur les fonds départementaux " s'appliquent aux employés salariés ou au directeur d'une association loi 1901, subventionnée à plus de 50 p. 100 sur fonds départementaux.
