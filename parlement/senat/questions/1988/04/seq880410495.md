# Inscription sur les listes électorales

- Nature : Questions écrites
- Numéro : 10495
- Référence : SEQ880410495
- Législature : 8
- Auteur : M. Jean Cauchon (Eure-et-Loir, UC)
- Ministère interrogé : Intérieur
- Rubrique : Élections
- Publiée au JO : 1988-04-21, page 525

## Question

M. Jean Cauchon demande à M. le ministre de l'intérieur de bien vouloir lui préciser, département par département, et par ordre décroissant, le nombre d'électeurs inscrits sur les listes électorales pour les élections présidentielles.
