# Annuaire électronique : absence d'indication du code postal

- Nature : Questions écrites
- Numéro : 02928
- Référence : SEQ881202928
- Législature : 9
- Auteur : M. Olivier Roux (Français établis hors de France, UC)
- Ministère interrogé : Postes
- Rubrique : Télécommunications
- Thèmes : Postes
- Publiée au JO : 1988-12-29, page 1478

## Question

M. Olivier Roux attire l'attention de M. le ministre des postes, des télécommunications et de l'espace sur l'inconvénient que présente le service de l'annuaire électronique, en ce que l'indication du nom de la commune n'est pas suivie du code postal correspondant. Pour obtenir une adresse complète - c'est-à-dire comportant également le code postal de la localité demandée - l'usager doit donc, soit procéder à une seconde opération sur le Minitel, soit consulter un annuaire téléphonique traditionnel, ce qui entraîne une perte de temps et d'énergie. Il lui demande en conséquence s'il ne lui paraît pas souhaitable de perfectionner le système actuellement en vigueur, en permettant l'inscription simultanée du nom et du code postal des communes ; cette simple modification ne pourrait que mieux aider les usagers dans leur recherche sur le Minitel.
