# Réponse à la question SEQ881202928

- Question : [SEQ881202928](seq881202928.md) — Annuaire électronique : absence d'indication du code postal

## Réponse

*Postes, JO du 1989-02-16, page 289*

Réponse. - Bien que l'objet principal d'un annuaire téléphonique soit de permettre de trouver le numéro d'appel du correspondant, il est certain qu'on peut utiliser ce support à d'autres fins, et notamment à l'indication des codes postaux. C'est d'ailleurs ce qui est fait, tant sur l'annuaire papier (sous les intitulés de localité) que sur l'annuaire électronique où l'on accède au code postal à partir de la touche " sommaire ". Dans un avenir proche, le code postal des localités dotées d'un unique code apparaîtra en tête d'écran. Pour les localités dotées de plusieurs codes, les importantes modifications nécessaires contraindront à attendre durant deux ans environ.
