# Réponse à la question SEQ190309708

- Question : [SEQ190309708](seq190309708.md) — Pièces à fournir pour une demande de permis de construire

## Réponse

*Cohésion des territoires et relations avec les collectivités territoriales, JO du 2019-12-26, page 6390*

Les articles R.* 431-5 à R.* 431-33-2 du Code de l'urbanisme pour les constructions et les articles R.* 441-1 à R.* 441-8-1 pour les projets d'aménagement listent de manière exhaustive les informations et pièces qui peuvent être demandées aux pétitionnaires au titre de l'instruction de l'autorisation d'urbanisme. Aucune autre information ou pièce ne peut être exigée par l'autorité compétente (articles R.* 431-4 et R.* 441-8-2 du Code de l'urbanisme). Toute demande de pièce supplémentaire est donc illégale.
