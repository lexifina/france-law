# Amendement n° 831 — Art. L. 1112-20 du code générale des collectivités territoriales

- Texte : n° 4 (2003-2004) : Responsabilités locales — relatif aux responsabilités locales
- Nature du texte : Projet de loi
- Dossier : pjl03-004
- Division visée : Art. L. 1112-20 du code générale des collectivités territoriales
- Auteurs : Mme Josiane MATHON, Mme Nicole BORVO, M. Robert BRET
- Déposé le : 2003-10-28
- Sort : Tombé
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 18158

## Dispositif

Dans la première phrase du texte proposé par cet article pour l'article L. 1112‑20 du code général des collectivités territoriales, remplacer le mot :

électeurs

par les mots :

habitants ayant leur domicile fiscal dans la commune au sens de l'article 4 B du code général des impôts

## Objet

Amendement de conséquence.
