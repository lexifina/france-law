# Amendement n° 394 — Art. L. 1112-16 du code générale des collectivités territoriales

- Texte : n° 4 (2003-2004) : Responsabilités locales — relatif aux responsabilités locales
- Nature du texte : Projet de loi
- Dossier : pjl03-004
- Division visée : Art. L. 1112-16 du code générale des collectivités territoriales
- Auteurs : M. Yves DÉTRAIGNE
- Déposé le : 2003-10-24
- Sort : Retiré
- Avis de la commission : Défavorable
- Avis du Gouvernement : Néant
- Identifiant : 17394

## Dispositif

Dans le premier alinéa du texte proposé par le I de cet article pour l'article L. 1112-16 du code générale des collectivités territoriales, remplacer les mots :

le conseil de la collectivité

par les mots

l'assemblée délibérante de la collectivité

## Objet

Il s'agit d'un amendement rédactionnel
