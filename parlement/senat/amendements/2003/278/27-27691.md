# Amendement n° 27 — Article 44

- Texte : n° 278 (2003-2004) : Politique de santé publique — relatif à la politique de santé publique
- Nature du texte : Projet de loi
- Dossier : pjl03-019
- Division visée : Article 44
- Auteurs : M. Jacques BLANC, M. Paul BLANC
- Déposé le : 2004-07-02
- Sort : Non soutenu
- Identifiant : 27691

## Dispositif

Dans le I de cet article, après les mots :

des personnes

insérer les mots :

dans la recherche

## Objet

L'intitulé adopté dans le projet de loi est trop vague et ne reflète pas les véritables missions de ces comités. Il convient donc de préciser que leur rôle s'exerce dans la recherche.
