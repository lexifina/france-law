# Amendement n° 271 — Art. L. 121-91 du code de la consommation

- Texte : n° 215 (2003-2004) : Communications électroniques — relatif aux communications électroniques et aux services de communication audiovisuelle
- Nature du texte : Projet de loi
- Dossier : pjl03-215
- Division visée : Art. L. 121-91 du code de la consommation
- Auteurs : M. René TRÉGOUËT
- Déposé le : 2004-04-09
- Sort : Non soutenu
- Identifiant : 23354

## Dispositif

Dans le deuxième alinéa du texte proposé par cet amendement pour l'article L. 121‑91 du code de la consommation, après les mots :

une modification contractuelle ou de clause

supprimer les mots :

d'indexation

## Objet

Les contrats des opérateurs de télécommunications ne comportent généralement pas de clause d'indexation de prix mais uniquement des clauses de modification de prix.
