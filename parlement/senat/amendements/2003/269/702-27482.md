# Amendement n° 702 — Art. L. 1112-20 du code général des collectivités territoriales

- Texte : n° 269 (2003-2004) : Responsabilités locales — relatif aux libertés et responsabilités locales
- Nature du texte : Projet de loi
- Dossier : pjl03-004
- Division visée : Art. L. 1112-20 du code général des collectivités territoriales
- Auteurs : Mme Josiane MATHON, Mme Nicole BORVO COHEN-SEAT, M. Robert BRET
- Déposé le : 2004-06-29
- Sort : Tombé

- Avis du Gouvernement : Défavorable
- Identifiant : 27482

## Dispositif

Au début du texte proposé par cet article pour l'article L. 1112‑20 du code général des collectivités territoriales, remplacer le mot :

électeurs

par les mots :

habitants ayant leur domicile fiscal dans la commune au sens de l'article 4 B du code général des impôts.

## Objet

Amendement de conséquence.
