# Amendement n° COM-20 — Article 15

- Texte : n° 630 (2020-2021) : PJL Confiance dans l'institution judiciaire — pour la confiance dans l'institution judiciaire
- Nature du texte : Projet de loi
- Dossier : pjl20-630
- Division visée : Article 15
- Auteurs : Mme Valérie BOYER
- Déposé le : 2021-09-09
- Sort : Rejeté
- Identifiant : 1204031

## Dispositif

Supprimer cet article.

## Objet

L’article 15 habilite le Gouvernement à adopter par voie d’ordonnance la partie législative d’un futur code pénitentiaire.

La rédaction d'un code pénitentiaire constitue une prérogative importante du Parlement. Le présent amendement propose par conséquent de supprimer cette habilitation.
