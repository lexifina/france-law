# Amendement n° COM-7 — Article 3

- Texte : n° 164 (2020-2021) : Lutte contre le plastique — Proposition de loi visant à lutter contre le plastique
- Nature du texte : Proposition de loi
- Dossier : ppl20-164
- Division visée : Article 3
- Auteurs : Mme Martine FILLEUL
- Déposé le : 2021-03-01
- Sort : Adopté
- Identifiant : 1182892

## Dispositif

Alinéa 2

Après le mot :

procéder

insérer le mot :

intentionnellement

## Objet

L’article 3 vise à assimiler le lâcher de ballons de baudruche en plastique à l’abandon de déchets dans l’environnement, passible des sanctions prévues à cet effet par le code de l’environnement.

Cet amendement rédactionnel vise à préciser que les lâchers de ballon ne sont soumis à ce régime juridique que dans les cas où le lâcher est intentionnel.
