# Amendement n° 102 — Article 2

- Texte : n° 387 (2000-2001) : Autorité parentale — relative à l'autorité parentale
- Nature du texte : Proposition de loi
- Dossier : ppl00-387
- Division visée : Article 2
- Auteurs : Mme Nelly OLIN, M. Alain GOURNAC
- Déposé le : 2001-11-21
- Sort : Retiré
- Avis de la commission : Défavorable
- Identifiant : 1796

## Dispositif

Dans le deuxième alinéa du texte proposé par cet article pour l'article 371-1 du code civil, après le mot :

appartient

insérer le mot :

paritairement

## Objet

Il convient d'insérer dans le code civil la notion de parité dans l'exercice de l'autorité parentale.
