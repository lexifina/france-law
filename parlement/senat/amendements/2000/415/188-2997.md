# Amendement n° 188 — Art. L. 121-7 du code de l'environnement

- Texte : n° 415 (2000-2001) : Démocratie de proximité — relatif à la démocratie de proximité
- Nature du texte : Projet de loi
- Dossier : pjl00-415
- Division visée : Art. L. 121-7 du code de l'environnement
- Auteurs : M. Patrick LASSOURD
- Déposé le : 2001-12-21
- Sort : Retiré
- Identifiant : 2997

## Dispositif

Rédiger comme suit la seconde phrase du deuxième alinéa du II du texte proposé par cet article pour l'article L. 121-7 à insérer dans le code de l'environnement :

La saisine de la commission doit intervenir dans un délai de deux mois à compter de la date à laquelle le projet est rendu public.
