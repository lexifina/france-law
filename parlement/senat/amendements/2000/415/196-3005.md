# Amendement n° 196 — Art. L. 121-11 du code de l'environnement

- Texte : n° 415 (2000-2001) : Démocratie de proximité — relatif à la démocratie de proximité
- Nature du texte : Projet de loi
- Dossier : pjl00-415
- Division visée : Art. L. 121-11 du code de l'environnement
- Auteurs : M. Patrick LASSOURD
- Déposé le : 2001-12-21
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Défavorable
- Identifiant : 3005

## Dispositif

Rédiger comme suit la dernière phrase du texte proposé par cet article pour l'article L. 121-11 à insérer dans le code de l'environnement.

Au-delà de ce délai, la commission ne peut décider de relancer la concertation avec le public, que si l'économie générale du projet est profondément modifiée.
