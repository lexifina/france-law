# Amendement n° 143 — Art. L. 121-11 du code de l'environnement

- Texte : n° 415 (2000-2001) : Démocratie de proximité — relatif à la démocratie de proximité
- Nature du texte : Projet de loi
- Dossier : pjl00-415
- Division visée : Art. L. 121-11 du code de l'environnement
- Auteurs : M. Daniel HOEFFEL
- Déposé le : 2001-12-19
- Sort : Retiré
- Avis de la commission : Néant
- Avis du Gouvernement : Néant
- Identifiant : 2879

## Dispositif

Compléter le texte proposé par cet article pour l'article L. 121-11 du code de l'environnement par une phrase ainsi rédigée :

La Commission nationale du débat public ne peut décider de rouvrir un débat public que si l'économie générale du projet a été altérée.
