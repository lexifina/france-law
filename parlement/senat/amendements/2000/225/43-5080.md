# Amendement n° 43 — Article 7

- Texte : n° 225 (2000-2001) : Nom patronymique — relative au nom patronymique
- Nature du texte : Proposition de loi
- Dossier : ppl00-225
- Division visée : Article 7
- Auteurs : N
- Déposé le : 2002-02-20
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 5080

## Dispositif

Dans le texte proposé par l'amendement n° 25 pour compléter le premier alinéa de l'article 363 du code civil, après les mots :

de l'adopté est

insérer les mots :

à la demande des adoptants

## Objet

Il appartient aux adoptants qui saisissent le tribunal en vue du prononcé de l'adoption de choisir le nom conféré à l'adopté.
