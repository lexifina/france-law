# Amendement n° 21 — Article 7

- Texte : n° 634 (2015-2016) : Statut général des AAI et des API — portant statut général des autorités administratives indépendantes et des autorités publiques indépendantes
- Nature du texte : Proposition de loi
- Dossier : ppl15-225
- Division visée : Article 7
- Auteurs : M. Alain RICHARD
- Déposé le : 2016-06-01
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 1088221

## Dispositif

Alinéa 3, première phrase

Après le mot :

légales

insérer les mots :

ou une incapacité définitive

## Objet

L'amendement complète les cas dans lesquels un mandat de membre d'une AAI ou API peut être interrompu pour y intégrer celui d'incapacité définitive.
