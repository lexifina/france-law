## Dispositif

Alinéa 97

Remplacer le mot :

rénovées

par le mot :

restaurées

## Objet

Le terme « rénovées » implique, comme l’indique le code de l’urbanisme, une destruction‑reconstruction. Le terme « restaurées » lui est préféré.
