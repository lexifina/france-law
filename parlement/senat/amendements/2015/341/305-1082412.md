## Dispositif

Alinéa 97

Remplacer le mot :

rénovées

par le mot :

restaurées

## Objet

le terme "rénovées" implique, comme l'indique le code de l'urbanisme, un destruction-reconstruction. Le terme "restaurées" lui est préféré.
