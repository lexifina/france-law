# Amendement n° COM-53 — Article 54

- Texte : n° 790 (2013-2014) : simplification du code de commerce — de simplification, de clarification et d'actualisation du code de commerce
- Nature du texte : Proposition de loi
- Dossier : ppl13-790
- Division visée : Article 54
- Auteurs : M. André REICHARDT
- Déposé le : 2016-05-30
- Sort : Adopté
- Identifiant : 1088123

## Dispositif

Alinéa 2

Remplacer le mot :

un

par le mot :

deux

## Objet

Amendement de cohérence, s’agissant du nombre minimal de commissaires aux comptes devant être désignés par les entités publiant des comptes combinés, par assimilation avec les entités publiant des comptes consolidés (notamment les groupes coopératifs ou mutualistes, sans liens capitalistiques).
