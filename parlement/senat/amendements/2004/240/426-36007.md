# Amendement n° 426 — Art. L. 213-10-8 du code de l'environnement

- Texte : n° 240 (2004-2005) : eau et milieux aquatiques — sur l'eau et les milieux aquatiques
- Nature du texte : Projet de loi
- Dossier : pjl04-240
- Division visée : Art. L. 213-10-8 du code de l'environnement
- Auteurs : Mme Évelyne DIDIER, M. Michel BILLOUT, M. Yves COQUELLE, Mme Michelle DEMESSINE, M. Gérard LE CAM, M. Bernard VERA
- Déposé le : 2005-04-04
- Sort : Tombé
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 36007

## Dispositif

Dans le III du texte proposé par cet article pour l'article L. 213-10-8 du code de l'environnement, remplacer les mots :

, dans la limite de 1,2 €

par les mots :

dans une fourchette allant de 1,2 à 1,7 €

## Objet

Cet amendement a pour objet d'encadrer et de relever le coefficient de la redevance sur les produits phytosanitaires.
