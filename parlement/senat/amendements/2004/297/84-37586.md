# Amendement n° 84 — Art. L. 712-8 du code de commerce

- Texte : n° 297 (2004-2005) : petites et moyennes entreprises — en faveur des petites et moyennes entreprises
- Nature du texte : Projet de loi
- Dossier : pjl04-297
- Division visée : Art. L. 712-8 du code de commerce
- Auteurs : M. Gérard CORNU
- Déposé le : 2005-05-10
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 37586

## Dispositif

I. - Au début du texte proposé par cet article pour l'article L. 712-8 du code de commerce, remplacer les mots :

Dans les cas où

par le mot :

Lorsque

II. - Dans le même texte, après les mots :

excédents disponibles,

remplacer le mot :

où

par le mot :

que

III. - Dans le même texte, après les mots :

été mandatées,

remplacer les mots :

ou bien lorsque

par les mots :

ou que

IV. - Dans le même texte, remplacer les mots :

la chambre

par les mots :

l'établissement

V. - A la fin du même texte, supprimer les mots :

de l'établissement
