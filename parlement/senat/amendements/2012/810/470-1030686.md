# Amendement n° 470 — Article 11

- Texte : n° 810 (2012-2013) : Consommation — relatif à la consommation
- Nature du texte : Projet de loi
- Dossier : pjl12-725
- Division visée : Article 11
- Auteurs : M. Gérard LE CAM, Mme Évelyne DIDIER, Mme Mireille SCHURCH
- Déposé le : 2013-09-12
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 1030686

## Dispositif

Alinéa 26

Remplacer les mots :

vingt‑quatre

par les mots :

quarante-huit

## Objet

Les auteurs de cet amendement considèrent que le délai de vingt‑quatre heures n’est pas suffisant pour protéger le consommateur dans ce type d’opération.
