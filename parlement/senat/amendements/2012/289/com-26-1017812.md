# Amendement n° COM-26 — Article 1er

- Texte : n° 289 (2012-2013) : Contrat de génération — portant création du contrat de génération
- Nature du texte : Projet de loi
- Dossier : pjl12-289
- Division visée : Article 1er
- Auteurs : Mme Christiane DEMONTÈS
- Déposé le : 2013-01-25
- Sort : Adopté
- Identifiant : 1017812

## Dispositif

Alinéa 62

Remplacer les mots :

« en vue »

par les mots :

« dans la perspective »

## Objet

L'amendement reprend le mot "perspective", déjà utilisé dans le document d'orientation du 4 septembre 2012 pour évoquer la transmission des entreprises de moins de 50 salariés.
