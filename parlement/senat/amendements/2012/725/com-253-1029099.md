# Amendement n° COM-253 — Article 22 bis (nouveau)

- Texte : n° 725 (2012-2013) : Consommation — relatif à la consommation
- Nature du texte : Projet de loi
- Dossier : pjl12-725
- Division visée : Article 22 bis (nouveau)
- Auteurs : Mme Michèle ANDRÉ
- Déposé le : 2013-07-23
- Sort : Adopté
- Identifiant : 1029099

## Dispositif

Alinéa 60

Remplacer les mots :

les concernant

par les mots :

concernant les emprunteurs

## Objet

Le présent amendement vise à préciser que les informations inscrites dans le registre ne portent que sur les emprunteurs et non sur les personnes qui se portent caution.
