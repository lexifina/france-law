# Amendement n° COM-3 — Article 4

- Texte : n° 156 (2012-2013) : vote blanc — visant à reconnaître le vote blanc aux élections
- Nature du texte : Proposition de loi
- Dossier : ppl12-156
- Division visée : Article 4
- Auteurs : Mme Hélène LIPIETZ
- Déposé le : 2013-02-07
- Sort : Rejeté
- Identifiant : 1018205

## Dispositif

Après l’article 4 est ajouté un article additionnel ainsi rédigé :

“Il est institué un chapitre préliminaire au code électoral intitulé “Du décompte des suffrages””.

## Objet

Afin de pouvoir préciser, pour toutes les élections et tous les votes, le décompte des suffrages exprimés de manière uniforme, il est nécessaire de créer un chapitre préliminaire dans le code électoral : "Du décompte des suffrages".
