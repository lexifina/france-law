# Amendement n° COM-5 — Article 2 bis

- Texte : n° 69 (2012-2013) : Programmation des finances publiques — Projet de loi de programmation des finances publiques pour les années 2012 à 2017.
- Nature du texte : Projet de loi
- Dossier : pjl12-069
- Division visée : Article 2 bis
- Auteurs : M. François MARC
- Déposé le : 2012-10-29
- Sort : Adopté
- Identifiant : 1014163

## Dispositif

Alinéa 2, tableau, première ligne

Après les mots :

points de produit intérieur brut

ajouter le mot :

potentiel

## Objet

Amendement de précision.

L’effort structurel, comme le solde structurel, est exprimé dans le projet de loi (et en particulier dans le rapport annexé) en points de PIB potentiel.
