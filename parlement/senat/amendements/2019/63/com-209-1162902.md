# Amendement n° COM-209 — Article 20

- Texte : n° 63 (2019-2020) : Bioéthique — relatif à la bioéthique
- Nature du texte : Projet de loi
- Dossier : pjl19-063
- Division visée : Article 20
- Auteurs : M. Bernard JOMIER
- Déposé le : 2020-01-02
- Sort : Adopté
- Identifiant : 1162902

## Dispositif

Alinéa 5, première phrase

Après le mot :

avis

insérer le mot :

consultatif

## Objet

Cet amendement d'harmonisation rédactionnelle permet de rappeler que l’avis de l’équipe pluridisciplinaire chargée d’examiner la demande de réduction embryonnaire ou fœtale est consultatif, comme c’est le cas pour les demandes d’IMG pour motif maternel ou fœtal.
