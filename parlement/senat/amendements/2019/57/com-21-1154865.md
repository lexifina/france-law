# Amendement n° COM-21 — Article 7

- Texte : n° 57 (2019-2020) : Agir contre les violences au sein de la famille — visant à agir contre les violences au sein de la famille
- Nature du texte : Proposition de loi
- Dossier : ppl19-057
- Division visée : Article 7
- Auteurs : Mme Marie MERCIER
- Déposé le : 2019-10-28
- Sort : Adopté
- Identifiant : 1154865

## Dispositif

Alinéa 3

1° Remplacer les mots :

la caution locative

par les mots :

le dépôt de garantie

2° Supprimer les mots :

par une décision du juge prise en application de l’article 257 du code civil ou

3° Remplacer les mots :

même code

par les mots :

code civil

## Objet

Amendement de précision rédactionnelle

Et suppression de la référence à l'article 257 du code civil qui va être abrogé d'ici la fin de l'année dans le cadre de l'application de la loi du 23 mars 2019 de programmation 2018-2022 et de réforme pour la justice.
