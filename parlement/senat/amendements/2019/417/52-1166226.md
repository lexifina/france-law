# Amendement n° 52 — Intitulé du projet de loi

- Texte : n° 417 (2019-2020) : État d'urgence sanitaire — prorogeant l'état d'urgence sanitaire et complétant ses dispositions
- Nature du texte : Projet de loi
- Dossier : pjl19-414
- Division visée : Intitulé du projet de loi
- Auteurs : Mme Samia GHALI, Mme Marie-Françoise PEROL-DUMONT, M. Olivier JACQUIN, Mme Hélène CONWAY-MOURET, M. Maurice ANTISTE
- Déposé le : 2020-05-04
- Sort : Non soutenu
- Identifiant : 1166226

## Dispositif

Après le mot :

sanitaire

insérer les mots :

et social

## Objet

S’il est incontestable que la crise que nous traversons est sanitaire, il est essentiel de rappeler que les retombées seront aussi sociales. Cet amendement vise donc à élargir le périmètre de ce projet de loi.
