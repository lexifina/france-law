# Amendement n° 57 — Article 462-11 du code pénal

- Texte : n° 308 (2006-2007) : Cour pénale internationale — portant adaptation du droit pénal à l'institution de la cour pénale internationale
- Nature du texte : Projet de loi
- Dossier : pjl06-308
- Division visée : Article 462-11 du code pénal
- Auteurs : Mme Nicole BORVO COHEN-SEAT, Mme Josiane MATHON-POINAT, Mme Éliane ASSASSI
- Déposé le : 2008-05-28
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 65343

## Dispositif

Supprimer le texte proposé par cet article pour l'article 462-11 du code pénal.

## Objet

Les auteurs de cet amendement ne souhaitent pas que la légitime défense constitue un principe absolu d'immunité pénale, quelle que soit l'arme utilisée.
