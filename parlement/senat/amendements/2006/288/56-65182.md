# Amendement n° 56 — Art. L. 162-12 du code de l'environnement

- Texte : n° 288  (2006-2007) : responsabilité environnementale — relatif à la responsabilité environnementale
- Nature du texte : Projet de loi
- Dossier : pjl06-288
- Division visée : Art. L. 162-12 du code de l'environnement
- Auteurs : Mme Évelyne DIDIER, M. Michel BILLOUT, M. Jean-Claude DANGLOT, M. Gérard LE CAM, Mme Odette TERRADE
- Déposé le : 2008-05-26
- Sort : Tombé
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 65182

## Dispositif

Dans la dernière phrase du texte proposé par cet article pour l'article L. 162‑12 du code de l'environnement, remplacer les mots :

peut également les mettre

par les mots :

les met

## Objet

Les auteurs de cet amendement au regard des enjeux en cause considèrent qu'il est essentiel de garantir la publicité des propositions pour réparer le dommage environnemental.
