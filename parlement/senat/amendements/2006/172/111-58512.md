# Amendement n° 111 — Art. 436 du code civil

- Texte : n° 172  (2006-2007) : Protection juridique des majeurs — portant réforme de la protection juridique des majeurs
- Nature du texte : Projet de loi
- Dossier : pjl06-172
- Division visée : Art. 436 du code civil
- Auteurs : Mme Bernadette DUPONT
- Déposé le : 2007-02-12
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 58512

## Dispositif

Dans le premier alinéa du texte proposé par cet article pour l'article 436 du code civil, remplacer les mots :

soit révoqué

par les mots :

ne soit révoqué ou suspendu
