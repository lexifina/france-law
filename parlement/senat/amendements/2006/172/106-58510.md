# Amendement n° 106 — Art. 431 du code civil

- Texte : n° 172  (2006-2007) : Protection juridique des majeurs — portant réforme de la protection juridique des majeurs
- Nature du texte : Projet de loi
- Dossier : pjl06-172
- Division visée : Art. 431 du code civil
- Auteurs : Mme Bernadette DUPONT
- Déposé le : 2007-02-12
- Identifiant : 58510

## Dispositif

Compléter le second alinéa du texte proposé par cet article pour l'article 431 du code civil par une phrase ainsi rédigée :

Il est pris en charge par l'Etat pour les personnes dont les ressources sont inférieures à un plafond fixé par ce même décret.
