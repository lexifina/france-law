# Amendement n° 6 — Art. L. 439-61 du code du travail

- Nature du texte : Projet de loi
- Dossier : pjl06-437
- Division visée : Art. L. 439-61 du code du travail
- Auteurs : M. Louis SOUVET
- Déposé le : 2007-10-10
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 60350

## Dispositif

Dans le septième alinéa du texte proposé par cet article pour l'article L. 439-61 du code du travail, après les mots :

consiste en l'élection

insérer les mots :

de membres du conseil d'administration ou, le cas échéant, du conseil de surveillance
