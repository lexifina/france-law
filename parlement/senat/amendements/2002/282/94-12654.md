# Amendement n° 94 — Art. L. 322-4-15-1 du code du travail

- Texte : n° 282 (2002-2003) : décentralisation revenu minimum d'insertion et revenu minimum d'activité — portant décentralisation en matière de revenu minimum d'insertion et créant un revenu minimum d'activité
- Nature du texte : Projet de loi
- Dossier : pjl02-282
- Division visée : Art. L. 322-4-15-1 du code du travail
- Auteurs : M. Alain VASSELLE
- Déposé le : 2003-05-27
- Sort : Retiré
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 12654

## Dispositif

Dans le deuxième alinéa (1°) du texte proposé par cet article pour l'article L.322-4-15-1, après les mots:

établissements publics administratifs,

insérer les mots:

les établissements publics de coopération intercommunale à fiscalité propre,

## Objet

Cet amendement a simplement pour but d'intégrer les groupements à fiscalité propre à la liste de ceux qui peuvent conclure une convention avec le département.
