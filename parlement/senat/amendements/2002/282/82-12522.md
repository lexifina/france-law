# Amendement n° 82 — Art. L.322-4-15-5 du code du travail

- Texte : n° 282 (2002-2003) : décentralisation revenu minimum d'insertion et revenu minimum d'activité — portant décentralisation en matière de revenu minimum d'insertion et créant un revenu minimum d'activité
- Nature du texte : Projet de loi
- Dossier : pjl02-282
- Division visée : Art. L.322-4-15-5 du code du travail
- Auteurs : M. Gilbert CHABROUX, Mme Marie-Christine BLANDIN, M. Bernard CAZEAU
- Groupe :  et apparenté
- Déposé le : 2003-05-23
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 12522

## Dispositif

Supprimer le dernier alinéa du texte proposé par cet article pour l'article L. 322‑4‑15‑5 du code du travail.

## Objet

Cette disposition revient sur les formules d'intéressement mises en place avec succès par ailleurs.
