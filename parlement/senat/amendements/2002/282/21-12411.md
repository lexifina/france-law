# Amendement n° 21 — Art. L. 322-4-15 du code du travail

- Texte : n° 282 (2002-2003) : décentralisation revenu minimum d'insertion et revenu minimum d'activité — portant décentralisation en matière de revenu minimum d'insertion et créant un revenu minimum d'activité
- Nature du texte : Projet de loi
- Dossier : pjl02-282
- Division visée : Art. L. 322-4-15 du code du travail
- Auteurs : M. Bernard SEILLIER
- Déposé le : 2003-05-21
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 12411

## Dispositif

Compléter le texte proposé par cet article pour l'article L. 322-4-15 du code du travail par une phrase ainsi rédigée :

Ce contrat s'inscrit dans le cadre du parcours d'insertion visé à l'article L. 262-38 du code de l'action sociale et des familles.
