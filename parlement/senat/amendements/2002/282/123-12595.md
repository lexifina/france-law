# Amendement n° 123 — Art. L.322-4-15-5 du code du travail

- Texte : n° 282 (2002-2003) : décentralisation revenu minimum d'insertion et revenu minimum d'activité — portant décentralisation en matière de revenu minimum d'insertion et créant un revenu minimum d'activité
- Nature du texte : Projet de loi
- Dossier : pjl02-282
- Division visée : Art. L.322-4-15-5 du code du travail
- Auteurs : M. Roland MUZEAU, Mme Michelle DEMESSINE, M. Guy FISCHER
- Déposé le : 2003-05-26
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 12595

## Dispositif

Supprimer le dernier alinéa du texte proposé par cet article pour l'article L. 322-4-15-5 du code du travail.

## Objet

Considérant que l'incitation financière à rechercher un emploi est faible, que le nouveau contrat n'améliore pas le revenu et les droits des personnes concernées par le RMA, les auteurs de cet amendement proposent de supprimer les dispositions interdisant le cumul avec une autre activité salariée.
