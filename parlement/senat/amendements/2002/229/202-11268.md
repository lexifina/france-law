# Amendement n° 202 — Art. L. 916-1 du code de l'éducation

- Texte : n° 229 (2002-2003) : Assistants d'éducation — relatif aux assistants d'éducation
- Nature du texte : Projet de loi
- Dossier : pjl02-229
- Division visée : Art. L. 916-1 du code de l'éducation
- Auteurs : Mme Annie DAVID, M. Ivan RENAR, M. Jack RALITE, M. François AUTAIN
- Déposé le : 2003-04-07
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 11268

## Dispositif

Supprimer le troisième alinéa du texte proposé par le I de cet article pour l'article L. 916-1 du code de l'éducation.

## Objet

Cet amendement vise à supprimer, dans un souci d'efficacité, la possibilité que les assistants d'éducation exercent dans plusieurs établissements.
