# Amendement n° 212 — Art. L. 916-2 du code de l'éducation

- Texte : n° 229 (2002-2003) : Assistants d'éducation — relatif aux assistants d'éducation
- Nature du texte : Projet de loi
- Dossier : pjl02-229
- Division visée : Art. L. 916-2 du code de l'éducation
- Auteurs : Mme Annie DAVID, M. Ivan RENAR, M. Jack RALITE, M. François AUTAIN
- Déposé le : 2003-04-07
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 11306

## Dispositif

Supprimer le texte proposé par le I de cet article pour l'article L. 916‑2 du code de l'éducation.

## Objet

Les auteurs de cet amendement s'opposent catégoriquement à toute possibilité d'utilisation du personnel d'un établissement par une collectivité territoriale pour des fonctions autres que celles pour lesquelles il a été recruté.
