# Amendement n° 101 — Art. L. 3132-25-2 du code du travail

- Texte : n° 562 (2008-2009) : Repos dominical — réaffirmant le principe du repos dominical et visant à adapter les dérogations à ce principe dans les communes et zones touristiques et thermales ainsi que dans certaines grandes agglomérations pour les salariés volontaires
- Nature du texte : Proposition de loi
- Dossier : ppl08-557
- Division visée : Art. L. 3132-25-2 du code du travail
- Auteurs : Mme Annie DAVID, Mme Gélita HOARAU, Mme Isabelle PASQUET, M. François AUTAIN, M. Guy FISCHER
- Déposé le : 2009-07-20
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 80157

## Dispositif

Dans le cinquième alinéa du texte proposé par le II de cet article pour l'article L. 3132‑25‑2 du code du travail, après le mot :

consultation

insérer les mots :

des organisations professionnelles et syndicales concernées ainsi que

## Objet

Les auteurs de cet amendement estiment que le Préfet, doit, pour délimiter les périmètres d'usage de consommation exceptionnelle, consulter les organisations syndicales. Tel est le sens de cet amendement.
