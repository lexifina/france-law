# Amendement n° 87 — Art. L. 3132-25 du code du travail

- Texte : n° 562 (2008-2009) : Repos dominical — réaffirmant le principe du repos dominical et visant à adapter les dérogations à ce principe dans les communes et zones touristiques et thermales ainsi que dans certaines grandes agglomérations pour les salariés volontaires
- Nature du texte : Proposition de loi
- Dossier : ppl08-557
- Division visée : Art. L. 3132-25 du code du travail
- Auteurs : Mme Annie DAVID, Mme Gélita HOARAU, Mme Isabelle PASQUET, M. François AUTAIN, M. Guy FISCHER
- Déposé le : 2009-07-20
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 80135

## Dispositif

Dans le premier alinéa du texte proposé par le II de cet article pour l'article L. 3132‑25 du code du travail, après les mots :

ou d'animation culturelle permanente

insérer les mots :

dont l'objet social est en lien direct avec l'activité touristique

## Objet

Les auteurs de cet amendement considèrent que l'ouverture des établissements de commerce de détail dans les zones ou communes touristiques n'est justifiée que pour les seuls établissements concernés par la vente de produits touristiques.
