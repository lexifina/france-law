# Amendement n° 95 — Art. L. 3132-25 du code du travail

- Texte : n° 562 (2008-2009) : Repos dominical — réaffirmant le principe du repos dominical et visant à adapter les dérogations à ce principe dans les communes et zones touristiques et thermales ainsi que dans certaines grandes agglomérations pour les salariés volontaires
- Nature du texte : Proposition de loi
- Dossier : ppl08-557
- Division visée : Art. L. 3132-25 du code du travail
- Auteurs : Mme Annie DAVID, Mme Gélita HOARAU, Mme Isabelle PASQUET, M. François AUTAIN, M. Guy FISCHER
- Déposé le : 2009-07-20
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 80148

## Dispositif

Compléter le premier alinéa du texte proposé par le II de cet article pour l'article L. 3132‑25 du code du travail par une phrase ainsi rédigée :

Seuls les salariés volontaires, ayant donné leur accord par écrit à leur employeur peuvent travailler le dimanche.

## Objet

Les auteurs de cet amendement considèrent que le volontariat doit être le fondement du travail dominical, sans distinction quant à la nature de la dérogation qui est pratiquée, c'est pourquoi ils proposent d'appliquer ce volontariat pour le travail dominical effectué dans les commerces situés dans les communes touristiques ou thermales.
