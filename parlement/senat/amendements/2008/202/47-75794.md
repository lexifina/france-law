# Amendement n° 47 — Article 47

- Texte : n° 202 (2008-2009) : pénitentiaire — pénitentiaire

- Division visée : Article 47

- Déposé le : 2009-02-20
- Sort : Retiré
- Identifiant : 75794

## Dispositif

Dans le troisième alinéa du 1° de cet article, après le mot :

temporaire

insérer les mots :

ou saisonnier

## Objet

Le bénéfice d'une libération conditionnelle doit également pouvoir être justifiée par l'exercice d'un emploi saisonnier.
