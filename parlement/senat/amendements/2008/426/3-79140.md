# Amendement n° 3 — Art. L. 123-3 du code de justice administrative

- Texte : n° 426 (2008-2009) : Modification de l'ordonnance de 1958 — tendant à modifier l'ordonnance n°58-1100 du 17 novembre 1958 relative au fonctionnement des assemblées parlementaires et à compléter le code de justice administrative
- Nature du texte : Proposition de loi
- Dossier : ppl08-373
- Division visée : Art. L. 123-3 du code de justice administrative
- Auteurs : Mme Nicole BORVO COHEN-SEAT, Mme Éliane ASSASSI, Mme Josiane MATHON-POINAT
- Déposé le : 2009-05-28
- Sort : Rejeté
- Avis de la commission : Demande de retrait
- Avis du Gouvernement : Défavorable
- Identifiant : 79140

## Dispositif

Rédiger comme suit le texte proposé par le 2° du II de cet article pour l'article L. 123‑3 du code de justice administrative :

« Art. L. 123‑3. - L'avis du Conseil d'État est public. ».

Amendement de coordination.
