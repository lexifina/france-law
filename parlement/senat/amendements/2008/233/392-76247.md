# Amendement n° 392 — Article 5

- Texte : n° 233 (2008-2009) : Outre-mer — pour le développement économique de l'outre-mer
- Nature du texte : Projet de loi

- Division visée : Article 5
- Auteurs : N
- Déposé le : 2009-03-04

## Dispositif

Supprimer le C bis de cet article.

## Objet

Cette obligation de consultation préalable pour les investissements réalisés de plein droit est remplacée par des amendements de réduction de seuils d'agrément.
