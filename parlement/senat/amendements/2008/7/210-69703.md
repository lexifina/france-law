# Amendement n° 210 — Art. L. 5134-30-1 du code du travail

- Texte : n° 7 (2008-2009) : Revenu de solidarité active — généralisant le revenu de solidarité active et réformant les politiques d'insertion
- Nature du texte : Projet de loi
- Dossier : pjl08-007
- Division visée : Art. L. 5134-30-1 du code du travail
- Auteurs : Mme Annie DAVID, M. Guy FISCHER, M. François AUTAIN, Mme Gélita HOARAU
- Déposé le : 2008-10-20
- Sort : Rejeté
- Avis de la commission : Défavorable
- Avis du Gouvernement : Défavorable
- Identifiant : 69703

## Dispositif

Supprimer la seconde phrase du texte proposé par le 11° de cet article pour l'article L. 5134‑30‑1 du code du travail.

## Objet

Les auteurs de cet amendement proposent de supprimer cette disposition d'exonération fiscale qu'ils estiment trop importante et participe de la déresponsabilisation des employeurs.
