# Amendement n° 296 — Art. L. 5134-72-2 du code du travail

- Texte : n° 7 (2008-2009) : Revenu de solidarité active — généralisant le revenu de solidarité active et réformant les politiques d'insertion
- Nature du texte : Projet de loi
- Dossier : pjl08-007
- Division visée : Art. L. 5134-72-2 du code du travail
- Auteurs : Mme Bernadette DUPONT
- Déposé le : 2008-10-22
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 69678

## Dispositif

Dans le texte proposé par le 8° du II de cet article pour l'article L. 5134-72-2 du code du travail, remplacer les mots :

revenu minimum garanti dû

par les mots :

montant forfaitaire mentionné au 2° de l'article L. 262-2 du code de l'action sociale et des familles applicable
