## Objet

Cet amendement assure la bonne coordination entre le code civil et le code de l’action sociale et de la famille. Il déplace ainsi les dispositions relatives au contenu du rapport sur la situation de l’enfant qui avaient été introduites dans le code civil, au sein du code de l’action sociale et des familles. Il supprime, en outre, les dispositions de nature réglementaire contenues dans l’article 1er.
