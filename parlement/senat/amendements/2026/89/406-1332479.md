## Dispositif

I. - Alinéa 2

Après les mots :

même I C

insérer les mots :

, le cas échéant, des traitements de données prévus au 5° du même I C

II. - Après l’alinéa 22

Insérer un alinéa ainsi rédigé :

5° Lorsqu’une collectivité locale a mis en place un traitement de données recensant les signalements pour violences sur mineurs dont elle a eu connaissance, de ce traitement de données.

## Objet

L’amendement a pour objet d’indiquer que, dans les collectivités qui ont mis en place un traitement de données pour assurer la traçabilité dans le temps des signalements pour violence sexuelle sur mineur, pour éviter qu’un agent ayant été signalé dans le passé pour de tels faits puisse de nouveau travailler en contact avec des mineurs, le contrôle d’honorabilité suppose que la collectivité consulte, outre les fichiers évoqués plus haut dans l’article 5, ce traitement de données spécifique.
