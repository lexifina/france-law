# Amendement n° 660 — Art. L. 253-8 du code rural

- Texte : n° 26 (2005-2006) : d'orientation agricole — d'orientation agricole
- Nature du texte : Projet de loi
- Dossier : pjl05-026
- Division visée : Art. L. 253-8 du code rural
- Auteurs : M. Bruno RETAILLEAU, M. Philippe DARNICHE
- Déposé le : 2005-11-02
- Sort : Non soutenu
- Identifiant : 41134

## Dispositif

Dans le texte proposé par le II de cet article pour l'article L. 253‑8 du code rural, remplacer les mots :

l'autorité administrative compétente

par les mots :

l'Agence française de sécurité sanitaire des aliments

## Objet

Cet amendement se justifie par son texte même.
