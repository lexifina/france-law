## Dispositif

I. Dans le texte proposé par cet article pour l'article L. 533-11 du code de l'environnement, après les mots :

est tenu de prendre

insérer le mot :

immédiatement

II. Dans le même texte, après les mots :

d'informer

insérer le mot :

immédiatement

## Objet

Amendement d'harmonisation avec l'amendement n° 174.
