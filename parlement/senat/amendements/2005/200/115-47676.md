# Amendement n° 115 — Art. L. 531-5 du code de l'environnement

- Nature du texte : Projet de loi
- Dossier : pjl05-200
- Division visée : Art. L. 531-5 du code de l'environnement
- Auteurs : M. Gérard LE CAM, Mme Évelyne DIDIER, M. Michel BILLOUT, M. Yves COQUELLE, Mme Michelle DEMESSINE
- Déposé le : 2006-03-20
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Sagesse du Sénat
- Identifiant : 47676

## Dispositif

Dans le texte proposé par cet article pour l'article L. 531‑5 du code de l'environnement, après les mots :

un décret

insérer les mots :

en Conseil d'Etat

## Objet

Amendement de précision. Un décret en Conseil d'Etat offre davantage de garanties d'indépendance et d'expertise qu'un décret simple.
