# Amendement n° 188 — Art. L. 663-14 du code rural

- Texte : n° 200 (2005-2006) : organismes génétiquement modifiés — relatif aux organismes génétiquement modifiés
- Nature du texte : Projet de loi
- Dossier : pjl05-200
- Division visée : Art. L. 663-14 du code rural
- Auteurs : M. Jean DESESSARD, Mme Marie-Christine BLANDIN, Mme Alima BOUMEDIENE-THIERY, Mme Dominique VOYNET

- Sort : Rejeté

- Avis du Gouvernement : Défavorable
- Identifiant : 47756

## Dispositif

1° Dans le texte proposé par cet article pour l'article L. 663‑14 du code rural, remplacer les mots :

du préjudice mentionné au II

par les mots :

de son préjudice économique

2° Compléter le même texte par les mots :

sous réserve du II de l'article L. 663‑10

## Objet

Amendement d'harmonisation avec l'amendement n° 33.
