# Amendement n° 9 — Art. L. 222-5 du code du sport

- Texte : n° 310 (2007-2008) : Agents sportifs — visant à encadrer la profession d'agent sportif et modifiant le code du sport
- Nature du texte : Proposition de loi
- Dossier : ppl07-310
- Division visée : Art. L. 222-5 du code du sport
- Auteurs : M. Jean-François VOGUET, Mme Brigitte GONTHIER-MAURIN, M. Ivan RENAR, M. Jack RALITE
- Déposé le : 2008-06-04
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 65382

## Dispositif

Dans le deuxième alinéa du texte proposé par cet article pour l'article L. 222‑5 du code du sport, après les mots :

au bénéfice d'une personne

insérer les mots :

physique ou morale

## Objet

La loi actuelle précise ces autres cas.

Les auteurs de cet amendement souhaitent les réintroduire dans la réécriture de l'article L. 222‑5 prévue dans cette proposition de loi.

Ils ne voient aucune raison motivant ce retrait du texte d'origine.
