# Amendement n° 239 — Art. L. 531-4 du code de l'environnement

- Nature du texte : Projet de loi
- Dossier : pjl07-149

- Auteurs : N
- Déposé le : 2008-02-05
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 64113

## Dispositif

I. - Au deuxième alinéa de l'amendement n° 13, après les mots :

se rapportant

insérer le mot :

notamment

II. - Au troisième alinéa du même amendement, après le mot :

composé

insérer le mot :

notamment

## Objet

La composition des comités ne doit pas être trop figée dans la loi. L'introduction du mot notamment permet la souplesse nécessaire.
