# Amendement n° 19 — Art. L. 663-8 du code rural

- Texte : n° 149 (2007-2008) : Organismes génétiquement modifiés — relatif aux organismes génétiquement modifiés
- Nature du texte : Projet de loi
- Dossier : pjl07-149
- Division visée : Art. L. 663-8 du code rural
- Auteurs : M. Jean BIZET
- Déposé le : 2008-01-29
- Sort : Adopté
- Avis de la commission : Favorable
- Avis du Gouvernement : Favorable
- Identifiant : 63622

## Dispositif

Dans le second alinéa du texte prévu par cet article pour l'article L. 663-8 du code rural, remplacer les mots :

l'autorité administrative, selon des modalités définies par décret

par les mots :

arrêté du ministre chargé de l'agriculture, pris après avis du comité scientifique du Haut conseil institué à l'article L. 531-3 du code de l'environnement
