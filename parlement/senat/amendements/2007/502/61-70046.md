# Amendement n° 61 — Article 1er

- Texte : n° 502 (2007-2008) : Revenus du travail — en faveur des revenus du travail
- Nature du texte : Projet de loi
- Dossier : pjl07-502

- Déposé le : 2008-10-27
- Sort : Retiré
- Avis de la commission : Demande de retrait
- Avis du Gouvernement : Demande de retrait
- Identifiant : 70046

## Dispositif

Supprimer les VI et VII de cet article.

## Objet

Ces dispositions prévoyant la possibilité d'un versement exceptionnel d'intéressement n'ont pas d'utilité puisqu'elles sont déjà prévues dans le code du travail, de manière pérenne à l'article L 3314-10 du Code du travail.
