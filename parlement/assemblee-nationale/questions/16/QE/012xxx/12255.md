# Question n° 12255 — Protocoles vaccinaux antirabiques pour les chiens

- Type : Question écrite
- Législature : 16
- Auteur : Mme Anne-Laure Babault (Démocrate (MoDem et Indépendants))
- Ministère interrogé : Ministère de l’agriculture et de la souveraineté alimentaire
- Rubrique : pharmacie et médicaments
- Analyse : Protocoles vaccinaux antirabiques pour les chiens
- Identifiant : QANR5L16QE12255

## Question

*JO du 2023-10-17, page 9106*

Mme Anne-Laure Babault interroge M. le ministre de l'agriculture et de la souveraineté alimentaire sur les modalités de validation des protocoles vaccinaux antirabiques. Il apparaît en effet que le protocole vaccinal varie d'un laboratoire à l'autre. En effet, dans tous les cas, un premier rappel est effectué un 1 an après la primo-vaccination mais ensuite les rappels ultérieurs sont prévus tous les ans ou tous les 3 ans, en fonction du type de vaccin. Ces différences de protocole interrogent légitimement certains concitoyens, qui par ailleurs se demandent si cette différence est définie par les laboratoires eux-mêmes ou par une instance indépendante. Elle l'interroge donc sur la procédure et sur les rapports entre l'expertise sanitaire publique et l'expertise sanitaire privée dans la définition de ces protocoles vaccinaux.
