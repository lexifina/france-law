# Question n° 5096 — Nombre d'étrangers sous OQTF dans les Bouches-du-Rhône

- Type : Question écrite
- Législature : 16
- Auteur : Mme Gisèle Lelouis (Rassemblement National)
- Ministère interrogé : Ministère de l’intérieur et des outre-mer
- Rubrique : étrangers
- Analyse : Nombre d'étrangers sous OQTF dans les Bouches-du-Rhône
- Identifiant : QANR5L16QE5096

## Question

*JO du 2023-01-31, page 823*

Mme Gisèle Lelouis attire l'attention de M. le ministre de l'intérieur et des outre-mer sur le nombre d'étrangers sous OQTF dans les Bouches-du-Rhône et en particulier dans la ville de Marseille. Elle souhaiterait disposer d'un rapport détaillé des OQTF exécutées ou non sur l'année passée dans son département.
