# Question n° 5939 — Congés exceptionnels des professeurs dans l'enseignement libre sous contrat

- Type : Question écrite
- Législature : 16
- Auteur : M. Michel Herbillon (Les Républicains)
- Ministère interrogé : Ministère de l’éducation nationale et de la jeunesse
- Rubrique : enseignement privé
- Analyse : Congés exceptionnels des professeurs dans l'enseignement libre sous contrat
- Identifiant : QANR5L16QE5939

## Question

*JO du 2023-02-28, page 1873*

M. Michel Herbillon interroge M. le ministre de l'éducation nationale et de la jeunesse sur les congés attribués en cas de perte d'un proche (parents, beaux-parents, famille...) pour les professeurs qui enseignent dans l'enseignement libre sous contrat. Il voudrait savoir le nombre de jours qui sont accordés pour permettre l'absence d'un professeur dans ces circonstances particulières.
