# Question n° 9391 — Nombre d'avions Rafale exportés

- Type : Question écrite
- Législature : 16
- Auteur : M. Charles Sitzenstuhl (Renaissance)
- Ministère interrogé : Ministère des armées
- Rubrique : industrie
- Analyse : Nombre d'avions Rafale exportés
- Identifiant : QANR5L16QE9391

## Question

*JO du 2023-06-27, page 5673*

M. Charles Sitzenstuhl interroge M. le ministre des armées sur le nombre d'avions Rafale exportés depuis sa mise en service dans les armées françaises. Il souhaiterait également connaître les pays vers lesquels ces avions ont été exportés.
