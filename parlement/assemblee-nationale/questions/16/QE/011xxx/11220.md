# Question n° 11220 — Nombre de boursiers sur critères sociaux

- Type : Question écrite
- Législature : 16
- Auteur : M. Charles Sitzenstuhl (Renaissance)
- Ministère interrogé : Ministère de l’enseignement supérieur et de la recherche
- Rubrique : enseignement supérieur
- Analyse : Nombre de boursiers sur critères sociaux
- Identifiant : QANR5L16QE11220

## Question

*JO du 2023-09-12, page 8054*

M. Charles Sitzenstuhl interroge Mme la ministre de l'enseignement supérieur et de la recherche sur le nombre de boursiers sur critères sociaux dans l'enseignement supérieur. Il souhaite également connaître le nombre de boursiers pour chacun des huit échelons, ainsi que le coût global pour le budget de l'État.
