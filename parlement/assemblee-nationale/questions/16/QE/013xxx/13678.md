# Question n° 13678 — Données chiffrées sur les quinze nationalités recevant le plus de visas

- Type : Question écrite
- Législature : 16
- Auteur : M. Kévin Pfeffer (Rassemblement National)
- Ministère interrogé : Ministère de l’intérieur et des outre-mer
- Rubrique : immigration
- Analyse : Données chiffrées sur les quinze nationalités recevant le plus de visas
- Identifiant : QANR5L16QE13678

## Question

*JO du 2023-12-12, page 11090*

M. Kévin Pfeffer interroge M. le ministre de l'intérieur et des outre-mer sur la publication des données portant sur les quinze nationalités auxquelles sont délivrés le plus grand nombre de visas pour l'année 2022 (données définitives) et pour l'année 2023 (données provisoires). Les chiffres complets et définitifs les plus récents remontent à 2021. Or le nombre de visas délivrés en 2021 a été fortement affecté par la pandémie de la covid-19. Par ailleurs, bien que l'année 2023 soit sur le point de se terminer, les données publiées pour l'année 2022 sur les quinze premières nationalités demeurent provisoires. Dans le contexte de l'étude du projet de loi sur l'immigration, il apparaît pertinent d'avoir les données récentes. Il souhaite donc connaître les statistiques définitives de 2022 et les statistiques provisoires de 2023 pour les quinze nationalités qui se sont vu délivrer le plus de visas.
