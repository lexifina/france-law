# Question n° 18086 — Expérimentation d'une option santé dans les lycées de Normandie

- Type : Question écrite
- Législature : 16
- Auteur : M. Timothée Houssin (Rassemblement National)
- Ministère interrogé : Ministère de l’éducation nationale et de la jeunesse
- Rubrique : enseignement secondaire
- Analyse : Expérimentation d'une option santé dans les lycées de Normandie
- Identifiant : QANR5L16QE18086

## Question

*JO du 2024-05-28, page 4160*

M. Timothée Houssin attire l'attention de Mme la ministre de l'éducation nationale et de la jeunesse sur l'expérimentation visant à encourager les lycéens issus de déserts médicaux vers les études de santé prévue par la loi du 27 décembre 2023 visant à améliorer l'accès aux soins par l'engagement territorial des professionnels. Il lui demande sur quels critères se fera le choix des trois académies volontaires dans lesquelles les lycées pourront bénéficier d'une option santé pour les élèves des classes de première et de terminale. Il lui demande également par quel biais les académies peuvent se porter volontaires. Il lui demande enfin que l'académie de Normandie compte parmi les trois académies test tant il est urgent que des jeunes Normands, issus des déserts médicaux, se dirigent vers les études de médecine.
