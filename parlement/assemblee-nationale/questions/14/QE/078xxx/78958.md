# Question n° 78958 — gaspillage alimentaire; rapport; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : Mme Véronique Louwagie (Union pour un Mouvement Populaire)
- Ministère interrogé : Premier ministre
- Rubrique : agriculture
- Tête d'analyse : produits alimentaires
- Analyse : gaspillage alimentaire; rapport; perspectives
- Identifiant : QANR5L14QE78958

## Question

*JO du 2015-05-05*

Mme Véronique Louwagie attire l'attention de M. le Premier ministre sur la lutte contre le gaspillage alimentaire. Guillaume Garot, député de la Mayenne, ancien ministre délégué à l'agroalimentaire, a récemment établi un rapport intitulé « Lutte contre le gaspillage alimentaire : propositions pour une politique publique ». Dans ce rapport, il est recommandé de « mesurer le gaspillage alimentaire ». Au regard de cette recommandation, elle souhaite connaître l'avis du Gouvernement.
