# Question n° 78031 — investissements étrangers; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'économie, de l'industrie et du numérique
- Rubrique : politique économique
- Tête d'analyse : investissements
- Analyse : investissements étrangers; perspectives
- Identifiant : QANR5L14QE78031

## Question

*JO du 2015-04-14*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'économie, de l'industrie et du numérique sur les investissements étrangers. Les investissements étrangers créateurs d'emplois ont augmenté de 8 % en 2014. Il souhaiterait savoir comment le Gouvernement entend soutenir ces investissements.
