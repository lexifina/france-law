# Question n° 12995 — statistiques

- Type : Question écrite

- Ministère interrogé : Ministère de l'intérieur
- Rubrique : cultes
- Tête d'analyse : lieux de culte
- Analyse : statistiques
- Identifiant : QANR5L14QE12995

## Question

*JO du 2012-12-11*

M. Éric Ciotti attire l'attention de M. le ministre de l'intérieur sur le nombre d'édifices religieux recensés dans notre pays. Il lui demande de préciser le nombre d'églises, de synagogues et de mosquées dénombrées sur le territoire national.
