# Question n° 56449 — publications; droit d'expression; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : conseils municipaux
- Analyse : publications; droit d'expression; réglementation
- Identifiant : QANR5L14QE56449

## Question

*JO du 2014-06-03*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le cas où le règlement intérieur d'un conseil municipal prévoit un volume d'expression dans le bulletin municipal. Elle lui demande dans ces conditions si ce droit d'expression peut être réparti par groupe d'élus ou s'il est individuel, un conseiller municipal même appartenant à un groupe pouvant demander à s'exprimer séparément. Par ailleurs, si un volume d'expression est attribué à un groupe, elle lui demande si ce groupe peut décider de remplacer le texte par des photos du groupe.
