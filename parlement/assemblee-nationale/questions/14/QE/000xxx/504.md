# Question n° 504 — régies; institution; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : coopération intercommunale
- Tête d'analyse : syndicats intercommunaux
- Analyse : régies; institution; réglementation
- Identifiant : QANR5L14QE504

## Question

*JO du 2012-07-10*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur de bien vouloir lui préciser si un syndicat intercommunal gérant un équipement touristique installé sur trois communes peut, pour l'exploitation de cet équipement, créer plusieurs régies dotées de l'autonomie financière, chacune intervenant séparément sur le territoire de l'une des communes.
