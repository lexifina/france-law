# Question n° 545 — statut; conséquences; concurrence

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Christine Dalloz (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère du redressement productif
- Rubrique : entreprises
- Tête d'analyse : auto-entrepreneurs
- Analyse : statut; conséquences; concurrence
- Identifiant : QANR5L14QE545

## Question

*JO du 2012-07-10*

Mme Marie-Christine Dalloz alerte M. le ministre du redressement productif sur le champ du régime de l'auto-entreprenariat. Elle lui demande de bien vouloir lui indiquer les raisons pour lesquelles les métiers qualifiés du BTP ne peuvent être exclus de ce champ au même titre que les agriculteurs ou les agents immobiliers.
