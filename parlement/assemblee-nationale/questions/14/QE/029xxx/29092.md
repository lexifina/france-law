# Question n° 29092 — cendres; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : mort
- Tête d'analyse : crémation
- Analyse : cendres; réglementation
- Identifiant : QANR5L14QE29092

## Question

*JO du 2013-06-11*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur la problématique de l'inhumation d'une urne funéraire dans une propriété privée. À l'appui de la réponse ministérielle n° 14500 publiée le 23 avril 2013, il lui demande de lui préciser si la saisine du préfet doit être impérativement sollicitée pour l'installation d'une urne dans une propriété privée.
