# Question n° 66058 — élus; droit d'expression

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes

## Question

*JO du 2014-10-14*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si le maire peut refuser de donner la parole à un conseiller municipal sous prétexte qu'un membre de son groupe s'est déjà exprimé sur le même sujet.
