# Question n° 86024 — radicalisation; rapport; propositions

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : ordre public
- Tête d'analyse : terrorisme
- Analyse : radicalisation; rapport; propositions
- Identifiant : QANR5L14QE86024

## Question

*JO du 2015-07-28*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur le rapport sur « la déradicalisation, outil de lutte contre le terrorisme ». Ce dernier préconise de mettre en place des équipes mobiles d'intervention « laïcité » venant apporter leur aide aux équipes enseignantes. Il souhaiterait connaître son avis sur le sujet.
