# Question n° 86017 — radicalisation; rapport; propositions

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : ordre public
- Tête d'analyse : terrorisme
- Analyse : radicalisation; rapport; propositions
- Identifiant : QANR5L14QE86017

## Question

*JO du 2015-07-28*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur le rapport sur « la déradicalisation, outil de lutte contre le terrorisme ». Ce dernier préconise de mettre en place une task force de community managers pour identifier et combattre le discours djihadiste sur le web. Il souhaiterait connaître son avis sur le sujet.
