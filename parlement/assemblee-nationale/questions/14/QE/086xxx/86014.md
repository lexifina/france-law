# Question n° 86014 — radicalisation; rapport; propositions

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : ordre public
- Tête d'analyse : terrorisme
- Analyse : radicalisation; rapport; propositions
- Identifiant : QANR5L14QE86014

## Question

*JO du 2015-07-28*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur le rapport sur « la déradicalisation, outil de lutte contre le terrorisme ». Ce dernier préconise d'améliorer la coopération entre les autorités et les entreprises du numérique, en matière de lutte contre l'apologie du terrorisme. Il souhaiterait connaître son avis sur le sujet.
