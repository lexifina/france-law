# Question n° 17236 — absentéisme scolaire

- Type : Question écrite
- Législature : 14

- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement

## Question

*JO du 2013-02-05*

M. Christophe Guilloteau interroge M. le ministre de l'éducation nationale sur les pourcentages d'absentéisme scolaire par niveau dans le département du Rhône pour l'année scolaire 2011-2012. Il lui demande de bien vouloir lui communiquer ces chiffres.
