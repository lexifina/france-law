# Question n° 17046 — réglementation

- Type : Question écrite
- Législature : 14
- Auteur : M. Jean-Luc Warsmann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : assurances
- Tête d'analyse : assurance scolaire
- Analyse : réglementation
- Identifiant : QANR5L14QE17046

## Question

*JO du 2013-02-05*

M. Jean-Luc Warsmann attire l'attention de M. le ministre de l'éducation nationale sur l'assurance scolaire. En effet, à chaque rentrée, il est proposé aux parents d'élèves des assurances pour leurs enfants scolarisés. Il lui demande s'il est fait obligation de souscrire à ce type d'assurance.
