# Question n° 17289 — données statistiques; publication

- Type : Question écrite
- Législature : 14
- Auteur : M. Christophe Castaner (Socialiste, républicain et citoyen)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : étrangers
- Tête d'analyse : naturalisation
- Analyse : données statistiques; publication
- Identifiant : QANR5L14QE17289

## Question

*JO du 2013-02-05*

M. Christophe Castaner attire l'attention de M. le ministre de l'intérieur sur les données statistiques relatives aux demandes de naturalisation. La ventilation des demandes ainsi que les ajournements et refus par origine nationale ne sont pas publiés officiellement. Ces données seraient pourtant intéressantes à étudier. Il lui demande donc si le Gouvernement entend publier ces données officiellement.
