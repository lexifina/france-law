# Question n° 17855 — agressions; lutte et prévention

- Type : Question écrite
- Législature : 14
- Auteur : M. François Baroin (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : commerce et artisanat
- Tête d'analyse : débits de tabac
- Analyse : agressions; lutte et prévention
- Identifiant : QANR5L14QE17855

## Question

*JO du 2013-02-12*

M. François Baroin alerte M. le ministre de l'intérieur sur le sentiment d'insécurité qui se généralise parmi les buralistes. En effet, les agressions se multiplient sur le territoire de sa circonscription et les débiteurs de tabac se sentent démunis pour se protéger. Il souhaite connaître les mesures d'urgence que le Gouvernement prévoit de prendre pour protéger les buralistes, assorties de leur calendrier.
