# Question n° 17154 — procès verbaux d'infraction; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : urbanisme
- Analyse : procès verbaux d'infraction; réglementation
- Identifiant : QANR5L14QE17154

## Question

*JO du 2013-02-05*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si les procès-verbaux d'infraction dressés en matière d'urbanisme par les agents de police municipale agissant sur le fondement de l'article L. 480-1 du code de l'urbanisme peuvent être adressés, directement par ces agents, au procureur de la République ou s'ils doivent l'être par l'intermédiaire du maire de la commune qui est leur supérieur hiérarchique.
