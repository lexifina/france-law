# Question n° 60191 — code de l'environnement; mise en application

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'écologie, du développement durable et de l'énergie
- Rubrique : animaux
- Tête d'analyse : oiseaux
- Analyse : code de l'environnement; mise en application
- Identifiant : QANR5L14QE60191

## Question

*JO du 2014-07-15*

M. Pierre Morel-A-L'Huissier attire l'attention de Mme la ministre de l'écologie, du développement durable et de l'énergie sur l'obligation prévue à l'article L. 411-6 du code de l'environnement pour le Gouvernement de déposer un rapport au Parlement sur les actions entreprises en application de la directive sur les oiseaux sauvages ainsi que les dérogations accordées au titre de l'article 9 de cette directive. Il souhaiterait savoir combien de rapports ont été déposés depuis l'entrée en vigueur de cet article du code de l'environnement adopté lors de la loi sur la chasse n° 2000-698 du 26 juillet 2000.
