# Question n° 60475 — monnaie virtuelle; risques; contrôle

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : moyens de paiement
- Tête d'analyse : monnaie électronique
- Analyse : monnaie virtuelle; risques; contrôle
- Identifiant : QANR5L14QE60475

## Question

*JO du 2014-07-15*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur le trafic de monnaie virtuelle « bitcoin ». Alors que les gendarmes de la région Midi-Pyrénées viennent de démanteler le premier trafic de ce type sur le sol européen, il souhaiterait savoir quelles sont les intentions du Gouvernement pour parer à ces nouveaux phénomènes.
