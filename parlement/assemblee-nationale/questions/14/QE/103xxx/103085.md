# Question n° 103085 — djihadistes; retour en France; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Gérard Menuel (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : ordre public
- Tête d'analyse : terrorisme
- Analyse : djihadistes; retour en France; perspectives
- Identifiant : QANR5L14QE103085

## Question

*JO du 2017-02-28*

M. Gérard Menuel attire l'attention de M. le ministre de l'intérieur sur les risques liés aux retours de djihadistes sur le sol national. Les renseignements chiffrent à plus de 700 le nombre de Français partis dans le Moyen-Orient pour combattre aux côtés d'organisations terroristes, notamment Daech. Leur retour possible en France représente une menace pour la sécurité nationale. Il lui demande les mesures prises par le Gouvernement pour répondre à cette situation.
