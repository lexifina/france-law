# Réponse à la question n° 90619

- Question : [90619](90619.md) — Question n° 90619 — code de déontologie; décret; publication

## Réponse

*JO du 2016-12-06*

Le code de déontologie des infirmiers a été publié au Journal officiel du 27 novembre 2016. Il s'agit du décret no 2016-1605 du 25 novembre 2016 portant code de déontologie des infirmiers. Ce code est entré en vigueur le lendemain de sa publication.
