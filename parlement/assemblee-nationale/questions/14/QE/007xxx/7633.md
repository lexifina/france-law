- Type : Question écrite
- Législature : 14
- Auteur : M. Jean-Luc Warsmann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : départements
- Tête d'analyse : finances
- Analyse : dotations de l'État; statistiques

## Question

*JO du 2012-10-23*
