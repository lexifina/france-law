# Question n° 7640 — redevance; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : eau
- Tête d'analyse : assainissement
- Analyse : redevance; réglementation
- Identifiant : QANR5L14QE7640

## Question

*JO du 2012-10-23*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le cas d'une commune où la station d'épuration est hors service et où le lagunage qui doit la remplacer n'est pas encore réalisé. Elle lui demande si dans cette hypothèse il est possible de maintenir la perception de la redevance d'assainissement qui avait été instituée lorsque la station d'épuration fonctionnait normalement.
