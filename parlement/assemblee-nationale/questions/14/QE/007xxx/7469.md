# Question n° 7469 — procédure contradictoire; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : administration
- Tête d'analyse : rapports avec les administrés
- Analyse : procédure contradictoire; réglementation
- Identifiant : QANR5L14QE7469

## Question

*JO du 2012-10-23*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si les procédures visées aux articles L. 2213-25 du code général des collectivités territoriales (CGCT), L. 131-11 et L. 134-17 du nouveau code forestier, L. 541-3 du code de l'environnement doivent être précédées de la procédure contradictoire prévue à l'article 24 de la loi du 12 avril 2000.
