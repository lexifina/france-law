# Question n° 13736 — décrochage scolaire; mesures; perspsectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Gérald Darmanin (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement
- Tête d'analyse : élèves
- Analyse : décrochage scolaire; mesures; perspsectives
- Identifiant : QANR5L14QE13736

## Question

*JO du 2012-12-18*

M. Gérald Darmanin interroge M. le ministre de l'éducation nationale sur le plan de lutte contre le décrochage scolaire. Le 4 décembre 2012, il a annoncé le lancement du plan de lutte contre le décrochage scolaire qui a pour objectif la création d'un accompagnement personnalisé de chaque jeune « décrocheur ». Il souhaiterait donc connaître les mesures concrètes contenues dans ce plan ainsi que leur calendrier éventuel.
