# Question n° 13659 — simplification; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Gérald Darmanin (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : collectivités territoriales
- Tête d'analyse : normes
- Analyse : simplification; perspectives
- Identifiant : QANR5L14QE13659

## Question

*JO du 2012-12-18*

M. Gérald Darmanin interroge M. le ministre de l'intérieur sur les normes qui pèsent sur les collectivités territoriales. Plusieurs personnalités politiques et élus locaux ont récemment dénoncé le nombre démesuré de normes auxquelles sont soumises les collectivités territoriales. Ainsi, il lui demande de bien vouloir lui indiquer le nombre exact de normes qui pèsent sur les collectivités territoriales.
