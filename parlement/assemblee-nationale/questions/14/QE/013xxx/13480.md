# Question n° 13480 — recours; modalités

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : contraventions
- Analyse : recours; modalités
- Identifiant : QANR5L14QE13480

## Question

*JO du 2012-12-11*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur les contraventions injustement attribuées. De nombreux citoyens reçoivent des contraventions pécuniaires pour des véhicules qui ne leur appartiennent pas ou plus. Il lui demande de lui indiquer les mesures qu'il entend prendre pour lutter contre cette nouvelle forme de délinquance.
