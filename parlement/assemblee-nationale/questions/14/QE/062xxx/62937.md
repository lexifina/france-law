# Question n° 62937 — agent contractuel; délégation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Sophie Rohfritsch (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : état civil
- Tête d'analyse : activités
- Analyse : agent contractuel; délégation
- Identifiant : QANR5L14QE62937

## Question

*JO du 2014-08-12*

Mme Sophie Rohfritsch attire l'attention de M. le ministre de l'intérieur sur la possibilité pour un agent contractuel dans un service d'état-civil d'obtenir une délégation d'officier d'état-civil. Il semblerait en effet que cela soit actuellement impossible pénalisant bien souvent la bonne marche du service. Elle lui demande sa position sur ce sujet.
