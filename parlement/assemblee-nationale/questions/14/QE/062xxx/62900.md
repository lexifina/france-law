# Question n° 62900 — numérisation de signature; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : maires
- Analyse : numérisation de signature; réglementation
- Identifiant : QANR5L14QE62900

## Question

*JO du 2014-08-12*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si, afin de réduire le nombre de documents qu'il doit signer, un maire peut demander à son secrétariat de scanner sa signature pour l'apposer ensuite sur les factures, les attestations, les délibérations et autres documents qui doivent être revêtus de sa signature.
