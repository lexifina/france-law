# Question n° 62360 — indemnités; statistiques

- Type : Question écrite
- Législature : 14
- Auteur : M. René Dosière (Socialiste, républicain et citoyen)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : conseillers municipaux
- Analyse : indemnités; statistiques
- Identifiant : QANR5L14QE62360

## Question

*JO du 2014-08-05*

M. René Dosière demande à M. le ministre de l'intérieur de lui faire connaître, pour l'année 2013, le montant global des indemnités perçues par les élus municipaux (maires, adjoints, conseillers délégués...) telles qu'elles figurent dans les documents budgétaires correspondants.
