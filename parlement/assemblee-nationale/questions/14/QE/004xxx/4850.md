# Question n° 4850 — milieu scolaire; diagnostic; amélioration

- Type : Question écrite
- Législature : 14
- Auteur : M. Philippe Meunier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : santé
- Tête d'analyse : autisme
- Analyse : milieu scolaire; diagnostic; amélioration
- Identifiant : QANR5L14QE4850

## Question

*JO du 2012-09-18*

M. Philippe Meunier interroge M. le ministre de l'éducation nationale sur les problèmes que rencontrent les familles d'enfants autistes en ce qui concerne le diagnostic de ce handicap par les différents professionnels amenés à côtoyer ces enfants dans le cadre scolaire. En effet, il lui demande ce qu'il compte mettre en œuvre afin d'améliorer le diagnostic de l'autisme dans le cadre de l'école.
