# Question n° 52752 — cendres; lieux d'épandage; création; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : mort
- Tête d'analyse : crémation
- Analyse : cendres; lieux d'épandage; création; réglementation
- Identifiant : QANR5L14QE52752

## Question

*JO du 2014-03-25*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si la création d'un site cinéraire isolé pour épandre les cendres des défunts visé à l'article L. 2223-40 du CGCT est assujettie à une procédure administrative particulière.
