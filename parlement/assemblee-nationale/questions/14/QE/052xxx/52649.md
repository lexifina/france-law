# Question n° 52649 — formations paramédicales; rapport; préconisations

- Type : Question écrite
- Législature : 14
- Auteur : M. Denis Jacquat (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement supérieur
- Tête d'analyse : professions de santé
- Analyse : formations paramédicales; rapport; préconisations
- Identifiant : QANR5L14QE52649

## Question

*JO du 2014-03-25*

M. Denis Jacquat attire l'attention de M. le ministre de l'éducation nationale sur les recommandations exprimées dans le rapport relatif aux « formations paramédicales ». Le rapporteur recommande d'associer la direction générale de l'offre de soins (DGOS) à la réflexion sur le grade universitaire devant être reconnu. Il le remercie de bien vouloir lui faire part de son avis à ce sujet.
