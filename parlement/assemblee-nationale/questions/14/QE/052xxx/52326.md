# Question n° 52326 — structures publiques d'ingéniérie; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère du redressement productif
- Rubrique : marchés publics
- Tête d'analyse : maîtrise d'ouvrage
- Analyse : structures publiques d'ingéniérie; réglementation
- Identifiant : QANR5L14QE52326

## Question

*JO du 2014-03-18*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre du redressement productif sur l'ingénierie. De nombreuses structures publiques d'ingénierie sous des formes variées se développent. Ces dernières s'ajoutent aux multiples entités publiques et parapubliques déjà existantes. Il souhaiterait savoir comment le Gouvernement entend réguler la concurrence de ces entités avec les professionnels privés.
