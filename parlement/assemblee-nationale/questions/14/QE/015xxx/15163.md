# Question n° 15163 — sites pollués; recensement; base de données

- Type : Question écrite
- Législature : 14
- Auteur : M. Patrick Hetzel (Rassemblement - Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'écologie, du développement durable et de l'énergie
- Rubrique : environnement
- Tête d'analyse : protection
- Analyse : sites pollués; recensement; base de données
- Identifiant : QANR5L14QE15163

## Question

*JO du 2013-01-08*

M. Patrick Hetzel attire l'attention de Mme la ministre de l'écologie, du développement durable et de l'énergie sur la classification du site Basol. La base de données Basol concerne les sites et sols pollués ou potentiellement pollués, appelant une action des pouvoirs publics, à titre préventif ou curatif. Cependant, la portée concrète de cette classification reste aujourd'hui à déterminer. Il lui demande de bien vouloir lui indiquer quelle est la portée de cette classification Basol.
