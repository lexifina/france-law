# Question n° 8850 — usoirs; domaine public; incorporation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : voirie
- Tête d'analyse : réglementation
- Analyse : usoirs; domaine public; incorporation
- Identifiant : QANR5L14QE8850

## Question

*JO du 2012-10-30*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le régime de droit coutumier applicable aux usoirs dans le département de la Moselle. Ce régime est souvent une source d'incertitude juridique et de difficultés de gestion pour les municipalités. De ce fait, certaines communes souhaitent intégrer les parcelles correspondantes dans leur domaine public en supprimant ainsi leur statut d'usoir. Pour cela, elle lui demande quelle est la procédure juridique à suivre et notamment s'il est nécessaire de réaliser une enquête publique.
