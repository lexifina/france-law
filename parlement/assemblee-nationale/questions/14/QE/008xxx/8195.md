# Question n° 8195 — recours; modalités

- Type : Question écrite
- Législature : 14
- Auteur : M. Marcel Bonnot (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : contraventions
- Analyse : recours; modalités
- Identifiant : QANR5L14QE8195

## Question

*JO du 2012-10-23*

M. Marcel Bonnot appelle l'attention de M. le ministre de l'intérieur sur les contraventions injustement attribuées. Force est de constater que de nombreux citoyens reçoivent des contraventions pécuniaires pour des véhicules qui ne leur appartiennent pas. Il lui demande de lui indiquer les mesures qu'il entend prendre pour lutter contre cette nouvelle forme de délinquance car la contestation de ces contraventions est malheureusement très compliquée.
