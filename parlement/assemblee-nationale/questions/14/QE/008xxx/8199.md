# Question n° 8199 — communes; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : limitations de vitesse
- Analyse : communes; réglementation
- Identifiant : QANR5L14QE8199

## Question

*JO du 2012-10-23*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si un maire peut décider librement des limitations de vitesse dans sa commune. Sinon elle lui demande quelles sont les contraintes administratives qu'il doit respecter.
