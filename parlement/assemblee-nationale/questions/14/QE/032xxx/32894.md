# Question n° 32894 — véhicules sans permis

- Type : Question écrite
- Législature : 14
- Auteur : Mme Isabelle Le Callennec (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : réglementation
- Analyse : véhicules sans permis
- Identifiant : QANR5L14QE32894

## Question

*JO du 2013-07-16*

Mme Isabelle Le Callennec attire l'attention de M. le ministre de l'intérieur sur les conditions de conduite d'une voiture sans permis. Il semblerait que les personnes nées avant 1988 puissent conduire une voiture sans permis sans l'obtention du code de la route préalablement. Elle souhaiterait que le Gouvernement indique quelles sont ses intentions en la matière, et si une évolution de la réglementation est prévue.
