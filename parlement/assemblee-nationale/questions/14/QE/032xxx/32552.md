# Question n° 32552 — statistiques

- Type : Question écrite
- Législature : 14
- Auteur : M. Éric Straumann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : étrangers
- Tête d'analyse : reconduite aux frontières
- Analyse : statistiques
- Identifiant : QANR5L14QE32552

## Question

*JO du 2013-07-16*

M. Éric Straumann interroge M. le ministre de l'intérieur sur le nombre d'arrêtés de reconduite à la frontière prononcés par le préfet du Haut-Rhin pour les années 2010, 2011 et 2012. Il souhaite également connaître le nombre d'arrêtés réellement exécutés pour ces mêmes années.
