# Question n° 32893 — véhicules sans permis

- Type : Question écrite
- Législature : 14
- Auteur : Mme Isabelle Le Callennec (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : réglementation
- Analyse : véhicules sans permis
- Identifiant : QANR5L14QE32893

## Question

*JO du 2013-07-16*

Mme Isabelle Le Callennec attire l'attention de M. le ministre de l'intérieur sur les conditions de conduite des voitures sans permis. Elle souhaiterait que le Gouvernement indique quels sont les droits et les devoirs des conducteurs de véhicules sans permis.
