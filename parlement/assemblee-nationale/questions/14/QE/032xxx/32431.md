# Question n° 32431 — effectifs; statistiques

- Type : Question écrite
- Législature : 14
- Auteur : Mme Isabelle Le Callennec (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement : personnel
- Tête d'analyse : enseignants
- Analyse : effectifs; statistiques
- Identifiant : QANR5L14QE32431

## Question

*JO du 2013-07-16*

Mme Isabelle Le Callennec attire l'attention de M. le ministre de l'éducation nationale sur l'évolution des effectifs de professeurs. Il semblerait que certaines disciplines pâtissent d'un manque de professeurs. Le cas des enseignants d'allemand a été évoqué dans le cadre de la mission d'évaluation sur les emplois d'avenirs professeurs. Le Gouvernement peut-il indiquer le nombre total de professeurs, la variation depuis six ans et confirme-t-il cette pénurie ?
