# Question n° 58259 — infractions; police municipale; commissionnement

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : urbanisme
- Tête d'analyse : communes
- Analyse : infractions; police municipale; commissionnement
- Identifiant : QANR5L14QE58259

## Question

*JO du 2014-06-24*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si un policier municipal qui constate une infraction en matière d'urbanisme doit être obligatoirement commissionné à cet effet, dans les conditions prévues par le code de l'urbanisme.
