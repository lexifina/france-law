# Question n° 58352 — droits de l'opposition

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : conseils municipaux
- Analyse : droits de l'opposition
- Identifiant : QANR5L14QE58352

## Question

*JO du 2014-07-01*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si un règlement intérieur d'un conseil municipal peut interdire, pour les droits d'expression de l'opposition ou des groupes représentés au sein du conseil municipal, les photographies, les dessins ou les caricatures.
