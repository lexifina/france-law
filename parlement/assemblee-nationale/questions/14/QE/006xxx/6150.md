# Question n° 6150 — signalisation; aménagements

- Type : Question écrite
- Législature : 14
- Auteur : M. Philippe Meunier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : limitations de vitesse
- Analyse : signalisation; aménagements
- Identifiant : QANR5L14QE6150

## Question

*JO du 2012-10-02*

M. Philippe Meunier attire l'attention de M. le ministre de l'intérieur sur l'indication des limitations de vitesse sur les routes françaises. Il lui demande de bien vouloir lui indiquer comment il entend assurer une meilleure lisibilité des limitations de vitesse sur les routes de notre pays.
