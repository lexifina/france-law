# Question n° 6989 — groupes de l'opposition; collaborateurs

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : conseils municipaux
- Analyse : groupes de l'opposition; collaborateurs
- Identifiant : QANR5L14QE6989

## Question

*JO du 2012-10-16*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le fait que dans les grandes villes, les groupes d'opposition des conseils municipaux peuvent disposer de collaborateurs mis à disposition par la commune. Elle lui demande si le maire à un droit de regard sur l'embauche de ces collaborateurs. Par ailleurs, dans le cas où un collaborateur est titulaire d'un contrat à durée déterminée de trois ans, elle lui demande si ce contrat peut être interrompu en cas de dissolution du conseil municipal.
