# Question n° 71139 — locaux commerciaux; construction; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : coopération intercommunale
- Tête d'analyse : bâtiments
- Analyse : locaux commerciaux; construction; réglementation
- Identifiant : QANR5L14QE71139

## Question

*JO du 2014-12-16*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si une communauté de communes peut décider de construire des locaux commerciaux destinés à la location alors que localement, l'initiative privée n'est pas défaillante.
