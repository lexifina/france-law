# Question n° 71502 — prévention; moyens

- Type : Question écrite
- Législature : 14
- Auteur : M. Charles-Ange Ginesy (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité publique
- Tête d'analyse : inondations
- Analyse : prévention; moyens
- Identifiant : QANR5L14QE71502

## Question

*JO du 2014-12-16*

M. Charles-Ange Ginesy attire l'attention de M. le ministre de l'intérieur sur les difficultés rencontrées dans le département des Alpes-Maritimes suite aux pluies diluviennes qui se sont abattues au mois de novembre 2014. Il souhaiterait savoir ce que le Gouvernement entend faire pour réduire ces risques d'inondation aussi bien sur le plan local que national.
