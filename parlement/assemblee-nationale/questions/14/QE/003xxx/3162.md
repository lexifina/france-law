# Question n° 3162 — voies privées; intégration dans le domaine public communal; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : voirie
- Analyse : voies privées; intégration dans le domaine public communal; réglementation
- Identifiant : QANR5L14QE3162

## Question

*JO du 2012-08-21*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si une commune peut user des dispositions de l'article L. 318-3 du code de l'urbanisme pour incorporer dans son domaine public routier communal, le sol d'une voie privée située en coeur de village ou si elle doit utiliser une procédure d'expropriation de droit commun.
