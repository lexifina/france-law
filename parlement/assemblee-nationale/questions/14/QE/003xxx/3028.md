# Question n° 3028 — accès; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement
- Tête d'analyse : cantines scolaires
- Analyse : accès; réglementation
- Identifiant : QANR5L14QE3028

## Question

*JO du 2012-08-14*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'éducation nationale si un maire peut réserver l'accès d'une cantine scolaire aux enfants dont les deux parents travaillent et exclure à ce titre les enfants de chômeurs.
