# Question n° 3790 — autorités administratives indépendantes; statistiques

- Type : Question écrite
- Législature : 14
- Auteur : M. Gérald Darmanin (Union pour un Mouvement Populaire)
- Ministère interrogé : Premier ministre
- Rubrique : administration
- Tête d'analyse : organisation
- Analyse : autorités administratives indépendantes; statistiques
- Identifiant : QANR5L14QE3790

## Question

*JO du 2012-09-11*

M. Gérald Darmanin interroge M. le Premier ministre sur les autorités administratives indépendantes (AAI) françaises. Depuis plusieurs années, le nombre d'autorités administratives indépendantes est en croissance constante. C'est pourquoi il lui demande de bien vouloir lui indiquer, sous forme de tableau, la liste complète des autorités administratives indépendantes, le nombre de personnels, leurs budgets et leurs champs d'intervention respectifs.
