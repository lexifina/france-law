# Question n° 3072 — carrés confessionnels; Alsace-Moselle

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : mort
- Tête d'analyse : cimetières
- Analyse : carrés confessionnels; Alsace-Moselle
- Identifiant : QANR5L14QE3072

## Question

*JO du 2012-08-14*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si, en Alsace-Moselle, les communes peuvent créer des carrés confessionnels dans les cimetières au profit de religions qui ne sont pas reconnues.
