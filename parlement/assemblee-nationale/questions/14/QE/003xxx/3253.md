# Question n° 3253 — statistiques

- Type : Question écrite
- Législature : 14
- Auteur : M. Guillaume Larrivé (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : étrangers
- Tête d'analyse : titres de séjour
- Analyse : statistiques
- Identifiant : QANR5L14QE3253

## Question

*JO du 2012-08-21*

M. Guillaume Larrivé appelle l'attention de M. le ministre de l'intérieur sur l'immigration en provenance des Seychelles. Il le prie de bien vouloir lui préciser, pour ce pays, les données les plus récentes, concernant l'exercice 2010 et si possible l'exercice 2011 : le nombre de ressortissants détenteurs d'un titre de séjour en France ; le nombre de ressortissants ayant sollicité un visa de court séjour et le nombre de ressortissants en ayant bénéficié ; le nombre de ressortissants ayant sollicité un visa de long séjour et le nombre de ressortissants en ayant bénéficié ; le nombre de ressortissants ayant sollicité une carte de séjour et le nombre de ressortissants en ayant bénéficié ; le nombre de ressortissants ayant sollicité leur naturalisation et le nombre de ressortissants en ayant bénéficié ; le nombre de ressortissants en situation irrégulière ayant été éloignés.
