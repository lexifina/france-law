# Question n° 54749 — sécurité civile; base de Marignane; transfert

- Type : Question écrite
- Législature : 14
- Auteur : M. Christian Estrosi (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité publique
- Tête d'analyse : incendies
- Analyse : sécurité civile; base de Marignane; transfert
- Identifiant : QANR5L14QE54749

## Question

*JO du 2014-04-29*

M. Christian Estrosi interroge M. le ministre de l'intérieur sur la base d'avions de la sécurité civile (BASC). Il avait été annoncé le 14 janvier 2013 son déménagement depuis Marignane, où elle était installée depuis sa création en 1963, à Nîmes-Garons pour la saison des feux 2017. Il souhaite connaître les crédits de paiement prévus sur les exercices budgétaires 2014 à 2016 de son ministère (programme n° 161) pour mener à bien cette opération.
