# Question n° 54530 — seuils de population; harmonisation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : réglementation
- Analyse : seuils de population; harmonisation
- Identifiant : QANR5L14QE54530

## Question

*JO du 2014-04-29*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le fait que le mode de scrutin proportionnel, avec prime majoritaire pour les élections municipales, s'applique dorénavant dans les communes à partir de 1 000 habitants. Toutefois, diverses dispositions continuent à s'appliquer seulement à partir de 3 500 habitants, ce qui semble assez illogique car, si on change le mode de scrutin, il faut en tirer les conséquences. Elle lui demande donc s'il ne faudrait pas remédier à la multiplication des seuils de population qui existent dans le code électoral et dans le CGCT.
