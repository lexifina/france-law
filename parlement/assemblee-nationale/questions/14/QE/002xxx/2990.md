# Question n° 2990 — délibérations; votes à bulletins secrets; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : conseils municipaux
- Analyse : délibérations; votes à bulletins secrets; réglementation
- Identifiant : QANR5L14QE2990

## Question

*JO du 2012-08-14*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si, lorsqu'un vote à bulletins secrets est décidé par les membres d'un conseil municipal, la mise en place d'un isoloir est obligatoire lorsqu'un au moins un des élus le réclame.
