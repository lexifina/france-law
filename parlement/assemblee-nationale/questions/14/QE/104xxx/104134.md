# Question n° 104134 — radars embarqués; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : Mme Véronique Louwagie (Les Républicains)
- Ministère interrogé : Ministère de l’intérieur
- Rubrique : sécurité routière
- Tête d'analyse : radars
- Analyse : radars embarqués; perspectives
- Identifiant : QANR5L14QE104134

## Question

*JO du 2017-06-13*

Mme Véronique Louwagie interroge M. le ministre d'État, ministre de l'intérieur, sur l'externalisation des voitures-radars à des sociétés privées. Cette mesure fait l'objet d'une expérimentation jusqu'au 1er septembre 2017. Des associations de conducteurs s'interrogent sur les suites qui seront réservées à cette expérimentation. Elle lui demande si le Gouvernement peut indiquer un point d'étape de cette expérimentation et le périmètre pour lequel celle-ci est conduite.
