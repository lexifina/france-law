# Question n° 44301 — licences; attribution; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : hôtellerie et restauration
- Tête d'analyse : débits de boissons
- Analyse : licences; attribution; réglementation
- Identifiant : QANR5L14QE44301

## Question

*JO du 2013-12-03*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur une commune qui acquiert une licence de débit de boissons pour ouvrir occasionnellement un café. Elle lui demande qui parmi les élus ou les fonctionnaires territoriaux, doit détenir le permis d'exploitation de licence de débit de boissons délivré à l'issue d'une formation obligatoire.
