# Question n° 26333 — circonscriptions; statistiques

- Type : Question écrite
- Législature : 14
- Auteur : M. Jean-Luc Warsmann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : élections et référendums
- Tête d'analyse : élections législatives
- Analyse : circonscriptions; statistiques
- Identifiant : QANR5L14QE26333

## Question

*JO du 2013-05-14*

M. Jean-Luc Warsmann interroge M. le ministre de l'intérieur sur les éléments synthétiques suivants. Il souhaite connaître pour chaque département ou territoire d'outre-mer le nombre de députés, le nombre d'habitants en fonction du dernier recensement connu, le nombre d'habitants de chaque circonscription électorale de député, le nombre moyen d'habitants pour chaque département d'une circonscription législative, le nombre d'électeurs en fonction des derniers chiffres connus par le ministère de l'intérieur pour chaque circonscription législative et le nombre moyen d'électeurs par circonscription législative pour chaque département ou territoire d'outre-mer.
