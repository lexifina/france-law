# Question n° 81689 — gaspillage alimentaire; rapport parlementaire; propositions

- Type : Question écrite
- Législature : 14
- Auteur : M. Charles-Ange Ginesy (Les Républicains)
- Ministère interrogé : Ministère de l'économie, de l'industrie et du numérique
- Rubrique : agriculture
- Tête d'analyse : produits alimentaires
- Analyse : gaspillage alimentaire; rapport parlementaire; propositions
- Identifiant : QANR5L14QE81689

## Question

*JO du 2015-06-23*

M. Charles-Ange Ginesy attire l'attention de M. le ministre de l'économie, de l'industrie et du numérique sur le gaspillage alimentaire. Dans le rapport « Lutte contre le gaspillage alimentaire : proposition pour une politique publique », il est recommandé d'inscrire dans la loi une hiérarchie des actions de lutte contre le gaspillage alimentaire. Il souhaiterait connaître la position du Gouvernement sur cette recommandation.
