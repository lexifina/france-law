# Question n° 21713 — code des bonnes pratiques; valeur juridique

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : publications
- Analyse : code des bonnes pratiques; valeur juridique
- Identifiant : QANR5L14QE21713

## Question

*JO du 2013-03-26*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le fait que de très nombreuses communes ont, sous des appellations diverses (code des bonnes pratiques, charte, règlement d'installation), adopté des règles (couleurs, matériaux, aspect...) relatives à l'installation sur le domaine public de terrasses commerciales. Elle lui demande si l'approbation d'un tel document appartient au conseil municipal ou au maire. Elle lui demande également quelle est la valeur juridique contraignante de ce type de règle.
