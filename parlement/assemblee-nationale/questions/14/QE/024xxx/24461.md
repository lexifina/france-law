# Question n° 24461 — propriétés adjacentes; arbres et plantations; élagage; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : voirie
- Tête d'analyse : routes
- Analyse : propriétés adjacentes; arbres et plantations; élagage; réglementation
- Identifiant : QANR5L14QE24461

## Question

*JO du 2013-04-16*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le cas d'une propriété implantée à un carrefour et sur laquelle sont implantés des arbres et des arbustes qui respectent les distances d'éloignement et les critères de hauteur imposés par le code civil. Elle lui demande si, dans le but d'améliorer la visibilité pour les automobilistes, le maire peut malgré tout exiger que le propriétaire taille ses végétaux.
