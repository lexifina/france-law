# Question n° 24459 — libre circulation; préservation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : voirie
- Tête d'analyse : chemins ruraux
- Analyse : libre circulation; préservation
- Identifiant : QANR5L14QE24459

## Question

*JO du 2013-04-16*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur les difficultés de circulation parfois constatées sur les chemins ruraux. Il peut ainsi arriver qu'un agriculteur incorpore l'emprise d'un chemin rural à l'intérieur de la clôture d'un pré ou qu'il laboure l'emprise d'un chemin rural situé dans le prolongement de sa parcelle. Dans ces deux types de situation, elle lui demande quels sont les moyens concrets dont dispose le maire pour préserver la liberté de circulation.
