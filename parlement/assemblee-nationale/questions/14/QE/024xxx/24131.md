# Question n° 24131 — réserve parlementaire; montant

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : finances publiques
- Tête d'analyse : lois de finances
- Analyse : réserve parlementaire; montant
- Identifiant : QANR5L14QE24131

## Question

*JO du 2013-04-16*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur la dissociation qui existe entre les crédits « réserve parlementaire » qui sont affectés sur plusieurs chapitres ministériels et la ligne budgétaire n° 122-01 qui est du ressort du ministère de l'intérieur. Il lui demande de bien vouloir lui faire connaître les montants concernés par ces deux dispositifs.
