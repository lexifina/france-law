# Question n° 24055 — voyages scolaires; dépenses; imputation budgétaire

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement
- Tête d'analyse : établissements
- Analyse : voyages scolaires; dépenses; imputation budgétaire
- Identifiant : QANR5L14QE24055

## Question

*JO du 2013-04-16*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'éducation nationale sur le calcul des frais de fonctionnement des écoles. Il lui demande si, au vu de l'article L. 212-8 du code de l'éducation nationale, les voyages scolaires effectués pendant le temps scolaire peuvent être intégrés en tout ou partie auxdits frais de fonctionnement et, dans l'affirmative, selon quelles modalités.
