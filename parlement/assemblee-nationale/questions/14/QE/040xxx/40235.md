# Question n° 40235 — catégories; âge minimal; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : M. Lucien Degauchy (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : permis de conduire
- Analyse : catégories; âge minimal; réglementation
- Identifiant : QANR5L14QE40235

## Question

*JO du 2013-10-15*

M. Lucien Degauchy interroge M. le ministre de l'intérieur sur les conditions d'obtention du permis de conduire dans les catégories C et D. En effet alors qu'il faut être âgé de 18 ans minimum pour être autorisé à conduire des véhicules de marchandise de plus de 3,5 tonnes, le code de la route exige pour l'obtention du permis D, un âge minimun de 21 ans. Il souhaiterait savoir s'il est possible d'harmoniser les règles d'obtention des permis.
