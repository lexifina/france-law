# Question n° 40136 — baux; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Lucien Degauchy (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'égalité des territoires et du logement
- Rubrique : logement
- Tête d'analyse : réglementation
- Analyse : baux; perspectives
- Identifiant : QANR5L14QE40136

## Question

*JO du 2013-10-15*

M. Lucien Degauchy appelle l'attention de Mme la ministre de l'égalité des territoires et du logement sur le projet de loi pour l'accès au logement et un urbanisme rénové (ALUR). Ce projet prévoit de nouvelles clauses obligatoires dans le contrat de location; ainsi le bailleur devra indiquer le loyer de référence médian majoré correspondant au type de logement, et défini par le représentant de l'État dans le département. Cependant dans le cas où le loyer fixé dans le bail est supérieur à ce loyer de référence, le projet prévoit bien de contester le supplément de loyer, mais faute d'accord amiable avec le bailleur, le locataire devra faire appel à la juridiction compétente pour obtenir une diminution de loyer. Il lui demande quels moyens réellement efficaces elle peut envisager afin de simplifier les procédures d'encadrement des loyers.
