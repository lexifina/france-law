# Question n° 48568 — inscription; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : élections et référendums
- Tête d'analyse : listes électorales
- Analyse : inscription; réglementation
- Identifiant : QANR5L14QE48568

## Question

*JO du 2014-02-04*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le fait qu'en application de l'article L. 11 du code électoral peuvent être inscrits sur la liste électorale "tous les électeurs qui ont leur domicile réel dans la commune ou y habitent depuis six mois au moins". Elle lui demande si la contrainte de six mois s'applique uniquement aux électeurs qui sont simplement habitants ou si elle s'applique également à ceux qui ont leur domicile réel.
