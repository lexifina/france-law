- Type : Question écrite
- Législature : 14
- Auteur : Mme Isabelle Le Callennec (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement technique et professionnel
- Tête d'analyse : LP
- Analyse : élèves; effectifs
- Identifiant : QANR5L14QE48637

## Question

*JO du 2014-02-04*

Mme Isabelle Le Callennec attire l'attention de M. le ministre de l'éducation nationale sur le nombre de places vacantes dans les lycées professionnels. Il semblerait que 40 000 places seraient vacantes dans les lycées professionnels. Elle lui demande comment le Gouvernement entend lutter contre ces 40 000 places vacantes.
