# Question n° 65568 — code informatique; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Charles-Ange Ginesy (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale, de l'enseignement supérieur et de la recherche
- Rubrique : enseignement
- Tête d'analyse : programmes
- Analyse : code informatique; perspectives
- Identifiant : QANR5L14QE65568

## Question

*JO du 2014-10-07*

M. Charles-Ange Ginesy attire l'attention de Mme la ministre de l'éducation nationale, de l'enseignement supérieur et de la recherche sur l'enseignement du code informatique à l'école. Le précédent ministre de l'éducation nationale souhaitait favoriser l'enseignement du langage informatique dès l'école primaire. Il souhaiterait connaître les intentions du Gouvernement sur ce sujet et savoir comment sera financée cette mesure, avec quel matériel et quel contenu pédagogique.
