# Question n° 65164 — code informatique; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : Mme Isabelle Le Callennec (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale, de l'enseignement supérieur et de la recherche
- Rubrique : enseignement
- Tête d'analyse : programmes
- Analyse : code informatique; perspectives
- Identifiant : QANR5L14QE65164

## Question

*JO du 2014-09-30*

Mme Isabelle Le Callennec attire l'attention de Mme la ministre de l'éducation nationale, de l'enseignement supérieur et de la recherche sur l'enseignement à l'école du code informatique. Le précédent Gouvernement avait annoncé vouloir enseigner le code informatique à l'école. Elle lui demande de bien vouloir préciser où en sont les intentions du Gouvernement en la matière et selon quel calendrier il entend agir.
