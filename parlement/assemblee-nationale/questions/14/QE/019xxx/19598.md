# Question n° 19598 — réglementation; évolution; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Gérald Darmanin (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'écologie, du développement durable et de l'énergie
- Rubrique : mines et carrières
- Tête d'analyse : droit minier
- Analyse : réglementation; évolution; perspectives
- Identifiant : QANR5L14QE19598

## Question

*JO du 2013-02-26*

M. Gérald Darmanin interroge Mme la ministre de l'écologie, du développement durable et de l'énergie sur la réforme du code minier. À l'occasion du conseil des ministres du 6 février 2013, la ministre de l'écologie, avec le ministre du redressement productif, a présenté les grands axes de la future réforme du code minier. Cette réforme a pour objectif de mettre en conformité le code minier avec la Charte de l'environnement. Ainsi, il lui demande de bien vouloir lui préciser quelles sont les mesures contenues dans cette réforme ainsi que le calendrier prévisionnel de cette dernière.
