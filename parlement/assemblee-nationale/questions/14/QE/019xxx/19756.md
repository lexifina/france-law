# Question n° 19756 — alcoolémie; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : risques professionnels
- Tête d'analyse : contrôle
- Analyse : alcoolémie; réglementation
- Identifiant : QANR5L14QE19756

## Question

*JO du 2013-02-26*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur de lui indiquer si une collectivité peut opérer des contrôles inopinés d'alcoolémie auprès de ses agents et dans l'affirmative sous quelles conditions.
