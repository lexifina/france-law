# Question n° 19678 — infractions; constatation; prérogatives

- Type : Question écrite

- Ministère interrogé : Ministère de l'intérieur
- Rubrique : police
- Tête d'analyse : police municipale
- Analyse : infractions; constatation; prérogatives
- Identifiant : QANR5L14QE19678

## Question

*JO du 2013-02-26*

Mme Marie-Jo Zimmermann expose à M. le ministre de l'intérieur le cas d'une commune disposant de deux parkings publics payants. L'un aménagé par elle sur un terrain appartenant à son domaine privé. L'autre existant sur un terrain privé et pris à bail par la commune. Le stationnement étant anarchique sur ces deux parkings, elle lui demande si la police municipale peut verbaliser les contrevenants sur chacun de ces deux parkings.
