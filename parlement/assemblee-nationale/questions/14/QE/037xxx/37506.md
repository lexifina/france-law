# Question n° 37506 — vols; sanctions

- Type : Question écrite
- Législature : 14
- Auteur : Mme Isabelle Le Callennec (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de la justice
- Rubrique : matières premières
- Tête d'analyse : métaux
- Analyse : vols; sanctions
- Identifiant : QANR5L14QE37506

## Question

*JO du 2013-09-17*

Mme Isabelle Le Callennec attire l'attention de Mme la garde des sceaux, ministre de la justice, sur les vols de cuivre dans les bâtiments vides. Un certain nombre de propriétaires de bâtiments vides dans lesquels il y a de l'électricité se plaignent de vols de fils de cuivre. Elle lui demande de préciser les peines encourues pour ce genre d'infractions.
