# Question n° 96713 — Alsace-Moselle; trottoirs; entretien; responsabilité

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : voirie
- Analyse : Alsace-Moselle; trottoirs; entretien; responsabilité
- Identifiant : QANR5L14QE96713

## Question

*JO du 2016-06-21*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur les problèmes d'entretien des trottoirs et des caniveaux dans les communes. Dans le cas général et dans le cas spécifique du droit local d'Alsace-Moselle, elle lui demande selon quelles modalités la commune peut demander aux riverains de se charger de leur déneigement, de leur balayage et éventuellement de leur désherbage.
