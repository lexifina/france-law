# Question n° 61982 — blocages; sites internet; pertinence

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : ordre public
- Tête d'analyse : terrorisme
- Analyse : blocages; sites internet; pertinence
- Identifiant : QANR5L14QE61982

## Question

*JO du 2014-07-29*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur les mécanismes de lutte contre le terrorisme. Le Conseil national du numérique déplore le dispositif de blocage des sites internet dans la mesure où il est aisément contournable par les recruteurs comme les internautes. En effet le blocage ne permet pas de supprimer le contenu à la source. Il lui demande son avis quant aux moyens permettant d'améliorer l'efficacité de ce dispositif.
