# Question n° 35679 — réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : collectivités territoriales
- Tête d'analyse : délégations de service public
- Analyse : réglementation
- Identifiant : QANR5L14QE35679

## Question

*JO du 2013-08-13*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur quelle est la durée d'amortissement des compteurs d'eau mis en place dans le cas d'une délégation de service public. Cet élément est en effet indispensable pour en connaître la valeur en fin de contrat.
