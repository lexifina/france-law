# Question n° 49934 — égalité hommes-femmes; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : Mme Virginie Duby-Muller (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement maternel et primaire
- Tête d'analyse : programmes
- Analyse : égalité hommes-femmes; perspectives
- Identifiant : QANR5L14QE49934

## Question

*JO du 2014-02-18*

Alors que des parents d'élève inquiets du contenu des ABCD de l'égalité ont demandé leur retrait, Mme Virginie Duby-Muller interroge M. le ministre de l'éducation nationale sur cette requête. Par ailleurs, le ministère ayant évoqué une évaluation de cette expérimentation - à ce jour 600 classes réparties dans 275 écoles sont concernées par ce programme - elle lui demande des éléments d'information sur cette phase d'évaluation prévue pour le printemps, mais aussi, dans le cas de leur généralisation, avec quelles modalités tant matérielles que financières. Elle l'interroge aussi sur la possibilité d'imposer de fait aux enseignants une formation continue quelle qu'elle soit.
