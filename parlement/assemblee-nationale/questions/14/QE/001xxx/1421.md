# Question n° 1421 — listes; homonymie

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : élections et référendums
- Tête d'analyse : élection présidentielle
- Analyse : listes; homonymie
- Identifiant : QANR5L14QE1421

## Question

*JO du 2012-07-24*

Mme Marie-Jo Zimmermann rappelle à M. le ministre de l'intérieur le fait que, dans les départements qui élisent plus de trois sénateurs, le scrutin est proportionnel et les candidats doivent indiquer le nom de leur liste. Or il semble qu'aucune disposition n'interdise à deux listes de porter le même nom, ce qui peut être source d'incertitude d'autant qu'une liste peut se déclarer rapidement dans le but essentiel d'usurper le nom d'une autre qui était déjà annoncée mais pas encore déposée en préfecture. Elle lui demande en conséquence quelles sont les solutions en la matière.
