# Question n° 1749 — éthylotest; tracteurs agricoles

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : alcoolémie
- Analyse : éthylotest; tracteurs agricoles
- Identifiant : QANR5L14QE1749

## Question

*JO du 2012-07-24*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le fait que dorénavant les conducteurs d'un véhicule à moteur doivent disposer d'un éthylotest. Or certains organismes professionnels agricoles s'inquiètent dans la mesure où il semblerait que cette obligation concerne également les tracteurs agricoles. Elle lui demande donc si dans le cas d'un tracteur, la règle susvisée s'applique également.
