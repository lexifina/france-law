# Question n° 82853 — migrants; accueil; réforme; coût

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : étrangers
- Tête d'analyse : immigration
- Analyse : migrants; accueil; réforme; coût
- Identifiant : QANR5L14QE82853

## Question

*JO du 2015-06-30*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur les pressions migratoires. Le Gouvernement a dévoilé son plan pour accueillir les migrants. Il souhaiterait connaître l'impact budgétaire de l'ensemble des mesures proposées dans ce plan.
