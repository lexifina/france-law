# Question n° 59618 — concessions funéraires; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : mort
- Tête d'analyse : chambres funéraires et pompes funèbres
- Analyse : concessions funéraires; réglementation
- Identifiant : QANR5L14QE59618

## Question

*JO du 2014-07-08*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le cas d'une concession funéraire collective pour laquelle les deux époux sont nommément désignés dans l'acte d'achat, le titulaire de la concession étant cependant le mari. En cas de divorce, elle lui demande si l'épouse peut être inhumée dans la concession malgré l'opposition de son ex-mari.
