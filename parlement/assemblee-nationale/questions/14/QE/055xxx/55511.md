# Question n° 55511 — réforme; propositions

- Type : Question écrite
- Législature : 14
- Auteur : M. Martial Saddier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : permis de conduire
- Analyse : réforme; propositions
- Identifiant : QANR5L14QE55511

## Question

*JO du 2014-05-13*

M. Martial Saddier attire l'attention de M. le ministre de l'intérieur sur la réforme du permis de conduire. Pour réduire, entre autres, les délais d'obtention du permis et diminuer "l'accidentalité" des jeunes conducteurs, le rapport préconise notamment : de permettre la conduite accompagnée dès quinze ans ; de passer l'examen pratique dès dix-sept ans et demi ; de créer une « période probatoire » avant la délivrance définitive du permis ; d'augmenter le nombre de places pour repasser le permis et de recruter de nouveaux inspecteurs. Il souhaite connaître les intentions du Gouvernement quant aux propositions de ce rapport.
