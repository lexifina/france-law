# Question n° 46646 — signature; légalisation; compétences

- Type : Question écrite
- Législature : 14
- Auteur : M. Philippe Meunier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : mairies
- Analyse : signature; légalisation; compétences
- Identifiant : QANR5L14QE46646

## Question

*JO du 2013-12-24*

M. Philippe Meunier interroge M. le ministre de l'intérieur sur la légalisation de signature. Seule la mairie du domicile de la personne requérant la légalisation de sa signature est compétente pour procéder à cette authentification. Il lui demande pour quelles raisons cette compétence n'appartient pas à toutes les mairies françaises dès lors que cette légalisation n'a aucun rapport avec le domicile du demandeur.
