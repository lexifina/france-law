# Question n° 46794 — connaissances de base; acquisition

- Type : Question écrite
- Législature : 14
- Auteur : M. Claude de Ganay (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement maternel et primaire
- Tête d'analyse : pédagogie
- Analyse : connaissances de base; acquisition
- Identifiant : QANR5L14QE46794

## Question

*JO du 2013-12-24*

M. Claude de Ganay attire l'attention de M. le ministre de l'éducation nationale sur les résultats du classement international Program for international student assessment (Pisa), publié par l'OCDE. Ce rapport souligne, pour la France, une augmentation du nombre d'élèves en situation d'échec scolaire. Il lui demande ce que le Gouvernement compte faire pour enrayer cette hausse.
