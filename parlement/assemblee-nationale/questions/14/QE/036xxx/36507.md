# Question n° 36507 — autorisation d'occupation; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : domaine public
- Analyse : autorisation d'occupation; réglementation
- Identifiant : QANR5L14QE36507

## Question

*JO du 2013-09-03*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si une personne qui souhaite vendre des fruits et légumes sur un terrain privé accessible depuis la voie publique, est tenue de disposer d'une autorisation d'occuper le domaine public dès lors que la desserte de ce terrain se fait depuis la voie publique communale.
