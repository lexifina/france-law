# Question n° 72868 — redécoupage; circonscriptions législatives; conséquences

- Type : Question écrite
- Législature : 14
- Auteur : M. Jean-François Mancel (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : administration
- Tête d'analyse : cantons
- Analyse : redécoupage; circonscriptions législatives; conséquences
- Identifiant : QANR5L14QE72868

## Question

*JO du 2015-01-27*

M. Jean-François Mancel interroge M. le ministre de l'intérieur sur les conséquences de la loi du 17 mai 2013 définissant un redécoupage des cantons. Il souhaiterait savoir quelles peuvent être les conséquences de ce texte sur les circonscriptions législatives actuelles.
