# Question n° 75271 — droit de préemption; communes

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : urbanisme
- Tête d'analyse : réglementation
- Analyse : droit de préemption; communes
- Identifiant : QANR5L14QE75271

## Question

*JO du 2015-03-03*

Mme Marie-Jo Zimmermann expose à M. le ministre de l'intérieur le cas d'une commune ayant délégué au maire, pour la durée du mandat, la possibilité d'exercer pour le compte de la collectivité le droit de préemption urbain. Si une propriété visée par une déclaration d'intention d'aliéner appartient à un proche du maire, elle lui demande si celui-ci doit s'abstenir. Dans l'affirmative, elle lui demande si le conseil municipal retrouve automatiquement le pouvoir d'exercer le droit de préemption pour le compte de la collectivité.
