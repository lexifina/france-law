# Question n° 47155 — délivrance; délais

- Type : Question écrite
- Législature : 14
- Auteur : M. Dominique Tian (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : permis de conduire
- Analyse : délivrance; délais
- Identifiant : QANR5L14QE47155

## Question

*JO du 2013-12-24*

M. Dominique Tian attire l'attention de M. le ministre de l'intérieur sur les difficultés majeures de la délivrance du nouveau permis de conduire sécurisé. Le tout nouveau permis de conduire est apparu le 16 septembre 2013. Les professionnels de la route - les transporteurs de voyageurs mais aussi de marchandises - se plaignent aujourd'hui des retards dans la délivrance de ces nouveaux titres réalisés par l'Imprimerie nationale qui empêchent les employés concernés de prendre le volant. Il n'est plus délivré d'attestations provisoires. Même lorsque les entreprises anticipent, certains salariés doivent attendre plusieurs semaines, ce qui est très pénalisant pour l'économie. Aussi, il lui demande de lui présenter les mesures qu'il compte prendre pour y remédier.
