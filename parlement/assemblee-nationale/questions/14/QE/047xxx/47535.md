# Question n° 47535 — classes préparatoires; horaires

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Christine Dalloz (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement supérieur : personnel
- Tête d'analyse : enseignants
- Analyse : classes préparatoires; horaires
- Identifiant : QANR5L14QE47535

## Question

*JO du 2014-01-14*

Mme Marie-Christine Dalloz attire l'attention de M. le ministre de l'éducation nationale sur son intention de modifier le décret qui réglemente actuellement les horaires de professeurs en classes préparatoires de Besançon. Elle lui demande quelle sera sa ligne de conduite sachant que le temps et la charge de travail seront considérablement alourdis, le tout pour une perte sèche de 10 % à 20 % pour les professeurs.
