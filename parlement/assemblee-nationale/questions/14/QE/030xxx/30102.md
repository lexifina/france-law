# Question n° 30102 — emprunt citoyen; perspectives

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'économie et des finances
- Rubrique : collectivités territoriales
- Tête d'analyse : finances
- Analyse : emprunt citoyen; perspectives
- Identifiant : QANR5L14QE30102

## Question

*JO du 2013-06-25*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'économie et des finances sur la mise en place d'emprunt citoyen par des collectivités locales (communes, départements, régions). Ce type d'emprunt permet d'associer les citoyens aux projets économiques de leurs collectivités. Il lui demande de bien vouloir lui indiquer s'il entend favoriser le développement de ce type de dispositif par les collectivités locales.
