# Question n° 51702 — annulation; demande de recours gracieux

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : marchés publics
- Tête d'analyse : réglementation
- Analyse : annulation; demande de recours gracieux
- Identifiant : QANR5L14QE51702

## Question

*JO du 2014-03-11*

Mme Marie-Jo Zimmermann expose à M. le ministre de l'intérieur le cas d'une commune qui dans le cadre d'une procédure de marché public est rendue destinataire d'une demande de candidat évincé, intitulée « recours gracieux. Ce recours demande l'annulation de la procédure et la résiliation du marché public octroyé. Elle souhaite connaître les conséquences attachées à cette demande et à une absence de réponse.
