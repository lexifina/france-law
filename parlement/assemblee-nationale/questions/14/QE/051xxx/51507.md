# Question n° 51507 — barres de hauteur; installation; réglementation

- Type : Question écrite
- Législature : 14
- Auteur : M. Jean-Luc Warsmann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : communes
- Tête d'analyse : voiries
- Analyse : barres de hauteur; installation; réglementation
- Identifiant : QANR5L14QE51507

## Question

*JO du 2014-03-11*

M. Jean-Luc Warsmann attire l'attention de M. le ministre de l'intérieur quant à l'installation des portiques combinés à un panneau de pré signalisation d'un danger, installation tendant à se répandre dans les communes. Cette utilisation de portiques permet d'interdire implicitement l'accès aux véhicules de grand gabarit notamment les camping-cars dans les communes. Toutefois l'article 36 de l'instruction interministérielle sur la signalisation routière précise que les barres de hauteur ne peuvent être utilisées que pour la signalisation d'un danger. Il lui demande donc de préciser les conditions d'emploi de ces portiques par les communes.
