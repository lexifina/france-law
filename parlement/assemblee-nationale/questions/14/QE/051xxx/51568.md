# Question n° 51568 — CNDP; Cour des comptes; rapport; préconisations

- Type : Question écrite
- Législature : 14
- Auteur : M. Claude de Ganay (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'éducation nationale
- Rubrique : enseignement
- Tête d'analyse : fonctionnement
- Analyse : CNDP; Cour des comptes; rapport; préconisations
- Identifiant : QANR5L14QE51568

## Question

*JO du 2014-03-11*

M. Claude de Ganay attire l'attention de M. le ministre de l'éducation nationale sur les recommandations du rapport public annuel 2014 de la Cour des comptes concernant le Centre national de documentation pédagogique. Ce rapport préconise de définir une offre éditoriale selon les besoins des enseignants. Il lui demande si le Gouvernement prévoit de suivre cette préconisation.
