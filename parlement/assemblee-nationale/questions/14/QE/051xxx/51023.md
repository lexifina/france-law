# Question n° 51023 — réglementation

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : élections et référendums
- Tête d'analyse : élections municipales
- Analyse : réglementation
- Identifiant : QANR5L14QE51023

## Question

*JO du 2014-03-04*

Mme Marie-Jo Zimmermann attire l'attention de M. le ministre de l'intérieur sur le cas où un candidat aux élections municipales a érigé un panneau d'affichage sur un terrain privé avec l'accord du propriétaire de celui-ci. Ce terrain est situé en bordure d'un axe routier important et le candidat utilise ce panneau pour y apposer ses affiches. Elle lui demande si une telle pratique est légale.
