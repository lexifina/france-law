# Question n° 10139 — pose de ralentisseurs

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : voirie
- Tête d'analyse : gestion
- Analyse : pose de ralentisseurs
- Identifiant : QANR5L14QE10139

## Question

*JO du 2012-11-13*

Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si la pose de ralentisseurs sur une voie départementale traversante d'une agglomération doit faire l'objet d'une permission de voirie délivrée par le gestionnaire de la voie.
