# Réponse à la question n° 10423

- Question : [10423](10423.md) — Question n° 10423 — statistiques

## Réponse

*JO du 2013-04-23*

En 2011, selon le Haut Commissariat des Nations Unies aux réfugiés (HCR) 876 100 demandes d'asile ont été présentées dans le monde entier. La demande d'asile dans les quarante-quatre pays dits industrialisés s'est élevée quant à elle à 441 300 demandes, en hausse de 20 % par rapport à 2010 (368 000 demandes). Outre la France qui se situe en deuxième position, les cinq principaux pays d'accueil et les principales nationalités des demandeurs sont les suivants : États-Unis : 74 020 demandes (Chine : 12 850 ; Mexique : 4 225 ; Russie : 817) Allemagne : 47 740 demandes (Serbie-Kosovo : 6 546 ; Afghanistan : 5 905 ; Irak : 5 555) Italie : 34 120 demandes (Nigéria : 1 385 ; Pakistan : 929 ; Afghanistan : 873) Suède : 29 650 demandes (Serbie-Kosovo : 7 907 ; Somalie : 5 560 ; Afghanistan : 2 397) Belgique : 25 980 demandes (Serbie-Kosovo : 4 545 ; Irak : 1 637 ; Guinée : 1 455). Les cinq premières nationalités des demandeurs en France ( à comparer avec les demandeurs de même nationalité dans les autres principaux pays d'accueil)sont les suivants : Bangladesh : France : 3 140 ; Grèce : 987 ; Royaume Uni : 495 ; Italie : 222 République démocratique du Congo : France : 3 395 ; Belgique : 813 ; Canada : 314 ; Royaume Uni : 215 Arménie : France : 1 766 ; Belgique : 1 266 ; Pays Bas : 611 ; Allemagne : 296 Sri Lanka : France : 2 827 ; Royaume Uni : 1 625 ; Canada : 1 203 ; Suisse : 892 Russie : France : 4 302 ; Pologne : 4 796 ; Autriche : 2 322 ; Allemagne : 1 199. Ces chiffres peuvent être complétés à partir des données du HCR disponible sur Internet (http ://www. unhcr. org).
