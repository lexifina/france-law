# Question n° 10424 — statistiques

- Type : Question écrite
- Législature : 14
- Auteur : M. Gérald Darmanin (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : étrangers
- Tête d'analyse : demandeurs d'asile
- Analyse : statistiques
- Identifiant : QANR5L14QE10424

## Question

*JO du 2012-11-20*

M. Gérald Darmanin interroge M. le ministre de l'intérieur sur le nombre de demandes d'asile dans les pays étrangers. Il souhaiterait obtenir, en effet, un tableau comparatif dans lequel est établi le nombre de demandes en 2012 enregistrées en faisant apparaître la nationalité du demandeur.
