# Question n° 10435 — festivités; débordements

- Type : Question écrite
- Législature : 14
- Auteur : M. Thierry Lazaro (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : famille
- Tête d'analyse : mariage
- Analyse : festivités; débordements
- Identifiant : QANR5L14QE10435

## Question

*JO du 2012-11-20*

M. Thierry Lazaro interroge M. le ministre de l'intérieur sur les mesures qu'il compte prendre pour que cessent les troubles à l'ordre public constatés lors de certaines manifestations festives, tels les mariages, qui dépassent de loin les pratiques traditionnelles autorisées en pareilles circonstances.
