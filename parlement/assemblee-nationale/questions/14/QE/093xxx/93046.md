# Question n° 93046 — opérations funéraires; modalités

- Type : Question écrite
- Législature : 14
- Auteur : M. Jacques Valax (Socialiste, républicain et citoyen)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : mort
- Tête d'analyse : réglementation
- Analyse : opérations funéraires; modalités
- Identifiant : QANR5L14QE93046

## Question

*JO du 2016-02-09*

M. Jacques Valax attire l'attention de M. le ministre de l'intérieur sur certaines opérations funéraires. Des familles du Tarn l'ont alerté sur les difficultés de déplacer les cendres et les os d'arrières-grands-parents, grand-tantes vers un autre cimetière. Aujourd'hui, ce type d'opérations doit donner lieu à une attestation de l'ensemble des ayants droits ce qui génère, avec le temps, des difficultés pour les personnes souhaitant réaliser ce type d'opération. Il serait donc souhaitable d'étudier la possibilité de simplifier ce type de formalité administrative. Il désirerait donc connaître les intentions du Gouvernement sur ce dossier.
