# Question n° 38751 — agent contractuel; délégation

- Type : Question écrite
- Législature : 14
- Auteur : M. Jean-Luc Warsmann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : état civil
- Tête d'analyse : activités
- Analyse : agent contractuel; délégation
- Identifiant : QANR5L14QE38751

## Question

*JO du 2013-10-01*

M. Jean-Luc Warsmann attire l'attention de M. le ministre de l'intérieur quant à la possibilité pour un agent contractuel dans un service d'état-civil d'obtenir une délégation d'officier d'état-civil. Il semble en effet que cela soit actuellement impossible pénalisant bien souvent la bonne marche de ces services. Il lui demande sa position sur ce sujet.
