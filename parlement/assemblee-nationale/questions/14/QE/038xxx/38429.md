# Question n° 38429 — présentation aux épreuves; délais

- Type : Question écrite
- Législature : 14
- Auteur : M. Patrick Hetzel (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère du redressement productif
- Rubrique : sécurité routière
- Tête d'analyse : permis de conduire
- Analyse : présentation aux épreuves; délais
- Identifiant : QANR5L14QE38429

## Question

*JO du 2013-09-24*

M. Patrick Hetzel attire l'attention de M. le ministre du redressement productif sur le manque criant d'inspecteurs du permis de conduire qui entraîne un allongement du temps d'attente entre chaque passage d'examen pour les candidats. Cette situation, qui est extrêmement dommageable pour les candidats, a pour conséquence une démotivation générale de ces derniers. Tout ceci n'est évidemment pas sans répercussion sur l'activité des moniteurs d'auto-écoles qui s'inquiètent de la pérennité de leur profession. Par ailleurs, nombre de jeunes ayant besoin de permis de conduire pour pouvoir entrer dans la vie active, ces retards pour passer le permis de conduire ont aussi une incidence sur l'emploi des jeunes. Face à cette situation, il souhaite que lui soient précisées les actions qui pourraient être mises en oeuvre pour retrouver les effectifs initiaux d'inspecteurs du permis de conduire.
