# Question n° 91215 — mosquées; fermetures

- Type : Question écrite
- Législature : 14
- Auteur : M. Philippe Meunier (Les Républicains)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : cultes
- Tête d'analyse : lieux de culte
- Analyse : mosquées; fermetures
- Identifiant : QANR5L14QE91215

## Question

*JO du 2015-11-24*

M. Philippe Meunier appelle l'attention de M. le ministre de l'intérieur sur sa promesse de fermer certaines mosquées radicales en France. Il lui demande sur quelle base juridique il entend se fonder pour prononcer la fermeture de ces lieux de culte.
