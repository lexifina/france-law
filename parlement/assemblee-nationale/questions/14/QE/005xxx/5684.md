# Question n° 5684 — contractuel; recrutement; modalités

- Type : Question écrite
- Législature : 14
- Auteur : Mme Marie-Jo Zimmermann (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : collectivités territoriales
- Tête d'analyse : communes
- Analyse : contractuel; recrutement; modalités
- Identifiant : QANR5L14QE5684

## Question

*JO du 2012-10-02*

Sa question écrite du 13 mars 2012 n'ayant pas obtenu de réponse sous la précédente législature, Mme Marie-Jo Zimmermann demande à M. le ministre de l'intérieur si lorsqu'une commune recrute un employé contractuel, elle doit obligatoirement procéder à un appel de candidatures préalable.
