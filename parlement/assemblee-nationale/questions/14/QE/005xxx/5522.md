# Question n° 5522 — réorganisation; modalités

- Type : Question écrite
- Législature : 14
- Auteur : M. Olivier Marleix (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère des outre-mer
- Rubrique : transports aériens
- Tête d'analyse : ligne Paris-Papeete
- Analyse : réorganisation; modalités
- Identifiant : QANR5L14QE5522

## Question

*JO du 2012-09-25*

M. Olivier Marleix appelle l'attention de M. le ministre des outre-mer sur la situation de la ligne Air France Papeete-Los Angeles-Paris. Air France, au-delà du plan Transform 2015, envisagerait un plan d'économies pour cette desserte. Il s'inquiète de ce que pourraient être les conséquences de ces modifications sur l'économie, notamment le tourisme, de l'archipel.
