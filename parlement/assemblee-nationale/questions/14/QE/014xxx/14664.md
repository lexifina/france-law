# Question n° 14664 — éthylotests; mise en oeuvre

- Type : Question écrite
- Législature : 14
- Auteur : M. Pierre Morel-À-L'Huissier (Union pour un Mouvement Populaire)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité routière
- Tête d'analyse : alcoolémie
- Analyse : éthylotests; mise en oeuvre
- Identifiant : QANR5L14QE14664

## Question

*JO du 2012-12-25*

M. Pierre Morel-A-L'Huissier attire l'attention de M. le ministre de l'intérieur sur le nouveau report de verbalisation dans le cadre de l'obligation de présence d'éthylotests dans les véhicules. Il lui demande de bien vouloir lui préciser les raisons de ce nouveau report et ses intentions en la matière.
