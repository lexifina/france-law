# Réponse à la question n° 5033

- Question : [5033](5033.md) — Question n° 5033 — Homologation des boitiers flexfuel pour les deux-roues motorisés

## Réponse

*JO du 2026-09-15, page 8574*

Une étude sur la performance environnementale des boîtiers de conversion E85 installés sur les motos a été publiée par l'IFPEN : https://www.ifpenergiesnouvelles.fr/article/etude-dgec-ifpen-realise-etude-dimpact-lutilisation-du-carburant-e85-les-deux-roues. Le ministère engagera une concertation avec les parties prenantes concernant l'évolution du cadre réglementaire relatif aux boîtiers de conversion E85 : une réunion de lancement des travaux de modification de l'arrêté de 2017 sur les boitiers E85 pour introduire les 2RM est planifiée à cette fin.
