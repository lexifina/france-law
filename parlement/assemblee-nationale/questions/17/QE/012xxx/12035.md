# Question n° 12035 — Sécurité dans les transports en commun franciliens

- Type : Question écrite
- Législature : 17
- Auteur : M. Thierry Frappé (Rassemblement National)
- Ministère interrogé : Ministère de l'intérieur
- Rubrique : sécurité des biens et des personnes
- Analyse : Sécurité dans les transports en commun franciliens
- Identifiant : QANR5L17QE12035

## Question

*JO du 2025-12-23, page 10466*

M. Thierry Frappé attire l'attention de M. le ministre de l'intérieur sur les chiffres récemment publiés concernant les agressions sexuelles commises dans les transports en commun franciliens. Selon les données rendues publiques, 62 % des personnes mises en cause seraient des étrangers. M. le député souhaite connaître les mesures que le Gouvernement entend prendre pour prévenir ces faits, renforcer la sécurité des usagers et lutter plus efficacement contre les auteurs d'agressions sexuelles dans les transports. Il lui demande également de lui préciser les modalités d'analyse de ces données afin d'adapter la réponse policière et judiciaire face à une hausse préoccupante des violences sexuelles dans les réseaux de transport.
