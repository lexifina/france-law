## Dispositif

Supprimer les alinéas 7 à 10.

## Exposé sommaire

Dès lors que l’article 122‑8 du code pénal renvoie aux "conditions fixées par le Code de la justice pénale des mineurs" pour engager la responsabilité pénale des mineurs, il n'apparait pas juridiquement nécessaire de modifier cet article.

Il est donc proposé de supprimer les alinéas modifiant l'article 122-8 du code pénal.
