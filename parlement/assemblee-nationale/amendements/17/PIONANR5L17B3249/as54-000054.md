## Dispositif

Après le mot :

« rédigée : »,

rédiger ainsi la fin de l’alinéa 6 :

« Le département identifie, en lien avec le service public départemental de l’autonomie, un guichet intégré pour les aidants, chargé de les accueillir, de les accompagner et de les orienter vers les services sociaux, médicaux et administratifs. »

## Exposé sommaire

L’article 5 propose, entre autres, de créer un guichet unique pour les aidants dans chaque département.

Sans contester l’échelle départemental pour ces dispositifs, il n’apparaît pour autant pas utile de multiplier les dispositifs, d’autant plus que les départements font montre d’une très grande hétérogénéité quant à leur organisation locale pour accompagner les aidants. Certains se servent déjà du service département de l’autonomie, d’autres, comme dans la Loire, disposent d’une structure, comme l’Escale des aidants, permettant déjà de les orienter.

C’est la raison pour laquelle, cet amendement propose de remplacer la création d’un tel guichet unique pour les aidants, par l’identification d’un guichet intégré dans chaque département.
