# Amendement n° 38

- Texte : PIONANR5L17BTC1029
- Article visé : Article PREMIER
- Auteur : Mme Sylvie Bonnet
- Déposé le : 2025-03-06
- Publié le : 2025-03-10
- Sort : Rejeté
- Identifiant : AMANR5L17PO838901BTC1029P0D1N000038

## Dispositif

À l’alinéa 6, après le mot :

« prescription »,

insérer les mots :

« orale ou écrite ».

## Exposé sommaire

Cet amendement vise à préciser que les actes peuvent aussi être réalisés sur demande orale d’un prescripteur pour tenir compte des différentes situations de travail, notamment pour les actes préopératoires.
