# Assemblée nationale

Données ouvertes de l'Assemblée nationale (Licence Ouverte) : les dossiers législatifs (XVIe et XVIIe législatures), chaque étape datée, et les amendements de la XVIIe législature tels que déposés (dispositif, exposé sommaire, auteur, sort). Un fichier et un commit par dossier ou amendement, à sa date.

Assemblée nationale open data (Licence Ouverte): legislative files (16th and 17th legislatures), each step dated, and the amendments of the 17th legislature as tabled. One file and one commit per file or amendment, on its date.

6,371 files and 148,715 amendments, 1986-10-29 to 2026-11-17.
