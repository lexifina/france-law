## Documents

- [Communiqué de presse du Conseil des ministres du 7 juin 2006](http://archives.gouvernement.fr/villepin/acteurs/gouvernement/conseils_ministres_35/conseil_ministres_7_juin_821/codification_dispositions_relatives_juridictions_56170.html) Le Garde des sceaux, ministre de la Justice, a présenté une ordonnance portant refonte du code de l’organisation judiciaire et modifiant le code de commerce, le code rural et le code de procédure pénale. Cette ordonnance, prise sur le fondement de la loi du 9 décembre 2004 de simplification du droit, a procédé à une nouvelle codification à droit constant des dispositions qui organisent les juridictions de l’ordre judiciaire. Répondant aux critiques émises par le Conseil d’État dans son rapport pour l’année 1984-1985, l’ordonnance rétablit la hiérarchie des normes en déclassant de nombreuses dispositions de la partie législative vers la partie réglementaire du code de l’organisation judiciaire. En outre, elle exclut de ce code les dispositions relatives aux conseils des prud’hommes, aux juridictions sociales, aux tribunaux de commerce et aux tribunaux paritaires des baux ruraux, pour les introduire dans les codes regroupant les dispositions procédurales ou de fond (code du commerce et code rural) ou les y maintenir (code du travail et code de la sécurité sociale). La refonte du code de l’organisation judiciaire a également été l’occasion d’harmoniser l’état du droit, de remédier à quelques erreurs et d’abroger des dispositions devenues sans objet.
