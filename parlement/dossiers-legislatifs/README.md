# Dossiers législatifs

Les dossiers législatifs de Légifrance (base DOLE de la DILA, Licence Ouverte 2.0) : pour chaque loi, les étapes, les textes adoptés par chaque assemblée, l'étude d'impact, l'avis du Conseil d'État et l'échéancier des mesures d'application. Un fichier par dossier, par législature.

Légifrance's legislative files (DILA DOLE base, Licence Ouverte 2.0): for each law, its steps, the texts each chamber adopted, the impact study, the Conseil d'État opinion and the schedule of implementing measures. One file per legislative file, by legislature.

3,605 files, opened 1997-07-16 to 2026-11-10.
