# Parlement

- `assemblee-nationale/` : Assemblée nationale (données ouvertes, archives 1958-2002, comptes rendus du JO Débats 2011-2017 dans `comptes-rendus/jo-<année>/`)
- `senat/` : Sénat (textes Akoma Ntoso, questions, amendements, débats ; comptes rendus intégraux du JO Débats depuis 2011 dans `comptes-rendus/`)
- `dossiers-legislatifs/` : dossiers législatifs de Légifrance (DILA DOLE)

Les comptes rendus du JO Débats viennent des données ouvertes DILA (Licence Ouverte) : un fichier et un commit par numéro du JO, à la date de la séance.

Parliament: Assemblée nationale, Sénat and Légifrance legislative files. The JO Débats verbatim records (DILA open data, Licence Ouverte) are one file and one commit per JO issue, on the day of the sitting.
