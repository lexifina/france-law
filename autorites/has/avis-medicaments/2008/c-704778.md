Posologie : cf. R.C.P.

Données de  prescriptions  :  selon  les  données IMS  (cumul mobile  annuel  février  2008), il  a
été observé 42 000 prescriptions de FONGAREX 900 mg. La posologie moyenne observée
est  conforme  au  R.C.P.  FONGAREX  900  mg  a  été  majoritairement  prescrit  dans  les
candidoses (45,4 %) et les mycoses (20,7%).
