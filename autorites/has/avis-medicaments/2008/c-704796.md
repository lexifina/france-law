Données de  prescriptions  :  selon  les  données IMS  (cumul mobile  annuel février  2008),  il  a
été observé 473 000 prescriptions de GYNOPEVARYL (dont 82,8 % de GYNOPEVARYL LP
150  mg  et  17,2  %  de  GYNOPEVARYL  150  mg).  La  posologie  moyenne  observée  est
conforme au R.C.P. GYNOPEVARYL LP a été majoritairement prescrit dans les candidoses
(48,2 %) et les mycoses (15,8 %). GYNOPEVARYL a été majoritairement prescrit dans les
candidoses (63,4 %) et les mycoses (9 %).
