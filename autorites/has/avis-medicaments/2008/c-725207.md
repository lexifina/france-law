Données d’utilisation : (IMS / CMA août 2008)
Il a été observé 491 000 prescriptions de NERISONE : 6% dans la dermatite atopique, 4%
dans le prurit, 2% dans le prurigo, 2% dans les varices des membres inférieurs, 2% dans la
dermite  allergique  de  contact,  2%  après  contact  avec  un  animal  venimeux.  La  durée  de
prescription est en moyenne de 16 jours.

Réévaluation du Service Médical Rendu :

Transparence.

Le SMR de ces spécialités reste important dans les indications de l’AMM.
