Plan de minimisation du risque :
Dans chaque état membre de l’Union Européenne où VOLIBRIS est commer-cialisé, le titulaire de l’AMM veille à ce que tous les patients susceptibles d’uti-liser VOLIBRIS reçoivent une brochure disponible sur le site de l’ANSM incluant les informations suivantes :
− VOLIBRIS est tératogène chez les animaux ;
− Les femmes enceintes ne doivent pas prendre VOLIBRIS ;
− Les femmes en âge de procréer doivent utiliser une contraception fiable avec nécessité de tests de grossesse mensuels ;
− La nécessité d’un contrôle régulier de la fonction hépatique car VOLIBRIS peut provoquer une atteinte hépatique
