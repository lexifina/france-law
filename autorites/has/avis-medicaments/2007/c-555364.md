Indication Thérapeutique :
Gel : Traitement local de l’acné vulgaire.
Crème : Acné de sévérité moyenne, particulièrement indiqué dans l’acné rétentionnelle.

Posologie : cf. RCP

Données d’utilisation : (IMS / CMA février 2007)
DIFFERINE a fait l’objet de 467 000 prescriptions par an, dans 97% des cas dans l’acné. La
posologie moyenne a été de 1 application par jour.
