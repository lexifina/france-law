Données de prescriptions :
Selon  les  données  IMS  (cumul  mobile  annuel  février  2007),  249.000  prescriptions
d’OPTICRON ont été observées. La posologie moyenne est de 6,4 gouttes/j. OPTICRON a
été majoritairement prescrit dans les conjonctivites (34,5%), dans l’allergie (23%) ou dans la
rhinite allergique ou vasomotrice (15%).
