Renouvellement conjoint de la spécialité :

FIXICAL VITAMINE D3 1000 mg/800 UI, comprimé à sucer
B/30 (CIP : 364 247-2)

Indications Thérapeutiques :
-  Correction des carences vitamino-calciques chez les sujets âgés,
-  Apport vitamino-calcique associé aux traitements spécifiques de l’ostéoporose, chez les

patients carencés ou à haut risque de carence vitamino D-calcique.

Posologie : cf. R.C.P.

Données d’utilisation :
Selon  les  données  IMS  (cumul  mobil  annuel  été  2006),  l’ostéoporose  représente  plus  de
60% des motifs de prescription des spécialités FIXICAL vitamine D3.
Les posologies journalières moyennes ont été les suivantes :
-  FIXICAL VITAMINE D3 500 mg/400 UI : 1,5 comprimés/jour
-  FIXICAL VITAMINE D3 1000 mg/800 UI : 1 comprimé/jour
Les durées moyennes de prescription ont été de 73,8 jours avec FIXICAL VITAMINE D3 500
mg/400 UI  et 65,7 jours avec FIXICAL VITAMINE D3 1000 mg/800 UI.
