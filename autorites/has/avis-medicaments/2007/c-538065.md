Indications Thérapeutiques :

PRETERAX : hypertension artérielle essentielle

BIPRETERAX : traitement de l’hypertension artérielle essentielle. Bipreterax est indiqué chez
les patients pour lesquels la pression artérielle est insuffisamment contrôlée par périndopril
seul.

Posologie : cf. R.C.P.

Données  de  prescriptions :  selon  les  données  IMS  (cumul  mobile  annuel  février  2007),  il  a
été  observé  696  000  prescriptions  de  PRETERAX  et  688  000  prescriptions  de
BIPRETERAX.  Ces  spécialités  ont  été  majoritairement  prescrites  dans  le  traitement  de
l’hypertension artérielle (94,1% pour PRETERAX et 95,1% pour BIPRETERAX)
