# Décision DE-2011-056 autorisant DIAVERUM SWEDEN AB à mettre en œuvre un traitement de données de santé à caractère personnel ayant pour finalité études statistiques de données anomymisées pour tous les patients traités dans les centres Diaverum afin de suivre certains indicateurs de qualité dans tous les centres de dialyse Diaverum et d'assurer le meilleur soin possible aux patients mais aussi d'identifier les points d'amélioration des traitements médicaux.
