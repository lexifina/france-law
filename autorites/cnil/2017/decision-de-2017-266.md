# Décision DE-2017-266 autorisant le CHU DIJON-BOURGOGNE à mettre en œuvre un traitement de données de santé à caractère personnel ayant pour finalité l’analyse de la base de données SNIIRAM pour les années 2007 à 2016 afin d’étudier le suivi glycémique, dans 3 populations à haut risque de présenter un diabète : les femmes ayant présenté un diabète gestationnel, les patients non diabétiques ayant présenté un IDM ou un AVC.
