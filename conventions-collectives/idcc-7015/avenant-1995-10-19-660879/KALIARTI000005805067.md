L'indemnité mensuelle d'occupation d'un logement de fonction est fixée comme suit à compter du 1er mai 1996 :

Logement

- une pièce cuisine : 61,79 F ;

- une pièce supplémentaire : 59,97 F ;

- eau courante : :7,80 F ;

- électricité (en l'absence de compteur) : 94,45 F

Chauffage

1. Garde bénéficiant du chauffage central :

- retenue mensuelle de : 228,30 F ;

2. Garde bénéficiant de bois déjà façonné :

- retenue de 2/3, soit : 151,86 F ;

3. Garde bénéficiant de bois à façonner lui-même :

- retenue de 1/3, soit : 75,59 F ;

4. Garde n'ayant ni chauffage central ni bois :

- reçoit une indemnité mensuelle de : 228,30 F
