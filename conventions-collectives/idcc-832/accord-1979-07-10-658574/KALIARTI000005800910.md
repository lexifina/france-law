# Article KALIARTI000005800910

Dessin technologique :

A partir de pièces réelles ou d'ensembles simples :

- relevés des cotes ;

- élaboration de croquis cotés ;

- lecture de plans d'ensemble.

Analyse fonctionnelle et technologique :

Electro-vannes.

Servo-moteur :

- limiteur de course ;

- limiteur de couple.

Electro-freins.

Détecteurs :

- cotation ;

- positionnement.

Moteurs électriques, moto-réducteurs.

Organes de transformation et transmission du mouvement.

Diagnostic, intervention, réglage sur systèmes électromécaniques simples (systèmes couramment rencontrés en cimenterie, commande de volets, mécanisation des mouvements sur encamionneur, palettiseur, etc.) :

Recherche méthodique de panne mécanique pouvant entraîner des répercussions au niveau électrique.

Analyse de démontage :

- lecture et interprétation des documents :

- fiches techniques ;

- plans : ensemble et détail ;

- gamme de démontage :

- phases chronologiques ;

- repérage ;

- outillage nécessaire ;

- précautions ;

- sécurité.

Interventions :

- démontage ;

- réparation, montage ;

- réglage.
