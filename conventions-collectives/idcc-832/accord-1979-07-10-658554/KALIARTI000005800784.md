# Article KALIARTI000005800784

PROGRAMME

Physique et notions de thermodynamique :

Unités légales ;

Correspondance des unités de pression ;

L'air atmosphérique (composition, poids, pression) ;

Lois physiques (énoncé, formule) :

- lois de compression et de détente des gaz parfaits ;

L'air humide :

- degré hygrométrique, point de rosée ;

Cycle de compression dans un compresseur à piston (notions élémentaires) :

- cycle théorique ;

- travail, puissance, rendement ;

- cycle réel.

Cycle frigorifique (principe appliqué à ce type de réfrigérant).

Technologie. - Equipements de production :

Compresseurs : à piston, à vis, à palettes :

- conception, domaines d'emplois ;

- clapets ;

- graissage et refroidissement des compresseurs ;

- dispositifs de réglage du débit ;

- dispositifs de sécurité.

Appareils d'épuration de l'air et des gaz comprimés :

- filtres d'aspiration ;

- réfrigérants, séparateurs ;

- séparateurs de condensats ;

- purgeurs.

Autres accessoires :

- silencieux ;

- tuyauteries d'aspiration, de refoulement, de régularisation.

Réservoirs.

Travaux pratiques sur équipements réels :

Entretien préventif, opérations systématiques ;

Anomalies de fonctionnement ;

Recherche de pannes, dépannage ;

Aspect sécurité propre aux équipements de production-distribution de l'air comprimé.

EPREUVES

Epreuve orale (devant jury) :

Technologie : question relative à l'appareil de production ou à ses accessoires.

Exemple : rôle et description des clapets.

Epreuve pratique (devant jury) :

Recherche d'une panne, dépannage, réglage.

Exemple : dépannage et réglage sur circuit de régulation du compresseur.
