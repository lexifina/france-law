# Article KALIARTI000005800783

PROGRAMME

Théorie :

Rappels de notions générales :

- force, moment, couple, travail, puissance.

Hydrostatique et hydrodynamique : définitions.

Hydrostatique :

- pression, débit : unités, symboles ;

- incompressibilité des liquides : principe de Pascal ;

- puissance " hydraulique ", couple " hydraulique " ;

- rendement ;

- propriétés des liquides (fluidité, viscosité) ;

- notions de perte de charge.

Technologie :

Principaux composants hydrauliques :

- générateurs :

- pompes (caractéristiques, types) ;

- récepteurs :

- vérins (caractéristiques, types) ;

- moteurs hydrauliques (caractéristiques, types) ;

- soupapes de sûreté, de réduction de pression ;

- limiteurs de débit ;

- clapets antiretour ;

- distributeurs (types et utilisations) ;

- réservoir, crépine, filtre ;

- jonctions et raccords hydrauliques.

Huile hydraulique (caractéristiques, classification).

Travaux pratiques :

Réalisation de circuits hydrauliques simples :

- circuit vérin simple effet ;

- circuit vérin double effet ;

- transmissions en circuits " ouvert " ou " fermé " à vitesse constante.

Schéma (symbolisation, représentation).

Recherche méthodique de pannes, dépannage :

- application de l'étude de ces circuits aux systèmes courants de cimenterie : vérins (butées de four, mouvements sur engins...).

Aspect sécurité propre aux circuits sous pression.

ÉPREUVES

Epreuve écrite :

Schéma. - Réalisation d'un circuit simple d'après données (constituants, fonctionnement).

Exemple : mouvement de " montée-descente " d'un godet d'engin.

Epreuve orale (devant jury) :

Technologie (2 questions), composant :

- constitution ;

- fonction.

Exemple : soupape de sûreté.

Epreuve pratique (devant jury) :

Sur circuit de commande simple.

Exemple : commande de vérins à double effet avec ses sécurités :

- recherche de panne ;

- dépannage ;

- réglage des composants.
