# Article KALIARTI000005800970

Description :

Recevoir en établissement des visiteurs ou se présenter à l'extérieur pour le compte de l'entreprise ; donner ou demander des indications sur la configuration des lieux ou l'utilisation des installations.

Richesse :

Il faut une expression orale courante pour des interlocuteurs variés.

Importance :

La mission influence la satisfaction des correspondants.

Niveau : 1.

Description :

Accueillir les chauffeurs de camions.

Richesse :

Les rapports avec les chauffeurs demandent une expression orale courante pour des interlocuteurs variés.

Importance :

La qualité des contacts, entretenue malgré les incidents, peut éviter des réclamations limitées des transporteurs et des clients.
