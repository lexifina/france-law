# Article KALIARTI000005800791

PROGRAMME

Théorie :

Notions d'algèbre de Boole et études des fonctions logiques :

- fonctions logiques ;

- identités logiques, opérations ;

- mise en équation d'un circuit ;

- simplification.

Méthodes de réalisation d'un schéma logique.

Technologie :

Symbolisation.

Organes de puissance :

- cylindres pneumatiques :

- simple et double effet ;

- à action différentielle.

Organes de commande :

- distributeurs ;

- valves ;

- électrovalves ;

- électrodistributeurs.

Organes de réglage :

- régulateur de débit.

Organes de fonction :

- valve de séquence ;

- sélecteur de circuit ;

- clapet anti-retour.

Travaux pratiques ;

Réalisation de montages divers d'après énoncé :

- détermination du cycle ;

- équations, simplification ;

- schémas ;

- réalisations pratiques sur simulateur ou sur équipements (genre cimenterie) ;

- dépannage.

ÉPREUVES

Epreuve écrite (devant jury)

Schéma : étude fonctionnelle d'une installation pneumatique classique de cimenterie.

Exemple : commande séquentielle d'un système de soufflage (décolmatage).

Epreuve pratique (devant jury)

Recherche d'une panne, dépannage, réglage ; sur un type d'installation classique en cimenterie.

Exemple : système séquentiel de soufflage dans cuves " homogénéisation ".
