# Article 32

Compte tenu de l'état actuel de la législation, les congés payés sont augmentés du fait de l'ancienneté des intéressés dans l'entreprise, dans les conditions suivantes :

- à partir de quinze ans d'ancienneté : un jour ouvrable ;

- à partir de vingt ans d'ancienneté : deux jours ouvrables ;

- à partir de vingt-cinq ans d'ancienneté : quatre jours ouvrables ;

- à partir de trente ans d'ancienneté : six jours ouvrables.
