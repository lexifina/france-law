# Article 3

L'article 53 est ainsi modifié :

– le 1er alinéa est abrogé (intégré dans l'article 48) ;

– dans le 2e alinéa le membre de phrase suivant :

– « … Si le conseil de discipline… réuni à nouveau » est abrogé ;

– le 3e alinéa est abrogé ;

– 4e alinéa : sans changement ;

– 5e alinéa : le membre de phrase « les conclusions du conseil de discipline… faite à l'agent intéressé » est abrogé (intégré dans l'article 48).
