# Article KALIARTI000005768138

1re catégorie (coefficient 100) :

- Manutention ; gardiennage sans ronde ; balayage ; essuyage ; frottage de pieds.

2e catégorie (coefficient 118) :

- Manutention de chariots de moules et vaisselle ; gardiennage avec rondes ; alimentation de machine automatique sans contrôle de fonctionnement ; préparation de pâte à gazettes ; alimentation de désaéreuse ; alimentation en pâte de roller automatique ; démoulage sur séchoir ; alimentation de machine à faire les bords en cru ; coupage d'anses sans ajustage ; finition de coulage de pièces petites et faciles ; époussetage (espassage) avec contrôle ; entretien de gazetterie et de matériel d'enfournement ; décastage ; déglobage ; sablage main ou touret ; découpage de chromo ; estampillage chromo ; estampillage tampon ; polissage de pieds et de bords sur machine ; pliage sans vérification.

3e catégorie (coefficient 122) :

- Filtres, presses ; tasses à la boulette sans démoulage ; finition de bords unis ; grattage et ajustage d'anses ; coulage d'anses pleines de tasses entre deux plâtres ; finition de pièces moyennes ; époussetage de grand creux avec contrôle ; émaillage main de pièces faciles ; bouchetonnage de tasses (capage) ; désémaillage au tapis avec contrôle et retouche émail ; encastage avec contrôle ; aide moufletier répartiteur ; préparation des chromos ; chromos centre et jetés toutes pièces ; tampon semis positionnés ; roulette tampon non raccordé ; remplissage incrustation vernis ; bord or au rouleau ; anses lamées or ; aérographe sur dégourdi ; approvisionnement de magasin de blanc ; pré-triage sortie de four ; conditionnement et pliage avec contrôle.

4e catégorie (coefficient 127) :

- Mélange et préparation de pâtes ; coulage de moules à la chape métallique avec finition ; calibrage roller sans réglage (jusqu'à l'assiette 6° 1/2) ; tasse à la boulette avec démoulage ; finition de bords festons ; garnissage d'anses courantes de tasses ; coulage de pièces moyennes entre deux plâtres ; coulage en creux de petites pièces ; coulage sur machine ; garnissage de pièces moyennes ; finition de toutes pièces émaillage main pièces moyennes ; paraffinage ; montage de wagons émail en gazettes ; trempage d'incrustation ; détache décor ou tour ; chromos jetés placés et bordures simples ; roulette tampon bordure avec raccord ; anses lamées couleurs ; aérographe de décor ; délaquage ; choisissage de blanc ; polissage des bords à la main sur tour vertical ; blanchissage de grains ; pliage avec contrôle de la composition des commandes ; choisissage et triage de décor ; emballage cartons et conteneurs.

5e catégorie (coefficient 133) :

- Cariste non mécanicien ; entretien simple ; coulage de moules en deux pièces avec finition et ajustage ; calibrage roller sans réglage ; assiette au-dessus de la 6e demi ; calibrage main sans réglage ; tasse à la boulette avec démoulage et tournasage des bords ; tournasage sur machine avec réglage ; finition avec découpage ; garnissage d'anses délicates ; coulage entre deux plâtres toutes pièces ; coulage en creux de pièces moyenne ; garnissage de toutes pièces ; finition avec découpage ; émaillage main pièces courantes ; retouche émail avec débridage ; montage de wagons émail sur plaques ; conduite de four sans réglage ; moufletier ; englobage ; bordures à raccord toutes largeurs sur toutes pièces ; incrustation slide-off ; roulette simili couleur ; tous tampons bordure et arrangement or brillant et or mat ; filets or et platine sur forme unie ; anses détaillées or ; aérographe couleur pièces isolées ; préparation des commandes ; rabotage de grains ; préparation des commandes (magasin de décor) ; choisissage et vérification des commandes de décor incrustation ; emballage toutes catégories.

6e catégorie (coefficient 139) :

- Conduite d'une machine automatique avec réglage ; conduite permis C et D non mécanicien ; entretien simple et dépannage courant ; coulage de moules à pièces multiples avec finition et ajustage ; calibrage roller avec réglage ; calibrage en creux de grandes pièces à la boulette avec réglage ; calibrage à la main en bosse avec réglage ; calibrage à la housse de tasses sans pied avec réglage ; finition avec découpage de pièces ajourées ; garnissage de deux anses minces ; coulage à la table de pièces grandes et difficiles entre deux plâtres ; coulage en creux de toutes pièces ; pressage à la main avec réglage ; garnissage de pièces délicates ; émaillage main pièces délicates ; retouche émail au tour avec débridage de pièces délicates ; gazettes au tour ; conduite de décors composés comprenant des raccords de bordures multiples ; four émail avec plan de cuisson ; incrustation toutes largeurs ; tampon sur bande foncée avec retouche au pinceau ; filets or et platine sur toutes formes et toutes pièces ; filets couleurs sur pièces simples ; anses détaillées couleur ; retouche décor et incrustations, repique ; aérographe couleurs claires sur service de table ; brunissage tous travaux ; choisissage d'incrustation blanc ; coupage avec blanchissage de grains ; polissage des bords à la main sur tour horizontal ; emballage tonneau.

7e catégorie (coefficient 145) :

- Conduite d'un ensemble de machines automatiques avec réglage ; conduite permis C et D mécanicien ; professionnel d'atelier d'entretien très qualifié ; coulage de tous moules avec noyautage de toutes matrices en plâtre ; calibrage main en brosse de pièces très délicates avec tournage et réglage du calibre ; calibrage main en creux avec tournasage au tour anglais et réglage du calibre ; calibrage à la housse de tasses à pied avec réglage ; coulage en creux de pièces délicates (verseuse 12 T et soupière) ; émaillage bicolore toutes pièces ; chromos bleus de four aile pleine avec raccord ; découpage et positionnement des anses ; décors composés comportant des filets incorporés sur toutes pièces ; tous filets et toutes bandes couleur sur toutes formes et toutes pièces ; cernés d'incrustation or et vernis ; pose de fonds au putois sur pièces isolées ; décoration garniture couleur ; enluminage ; aérographe couleurs foncées sur service de table ; brunissage à effets ; fondage de grains avec expérience.

8e catégorie (coefficient 179) :

- Professionnel d'entretien capable d'exécuter des modifications sur plan ; modelage sur plan ; noyautage de toutes matrices à composition plastique ; établissement de premiers moules ; calibrage de grands creux à la housse avec réglage ; filages de bandes avec pose de fonds au putois sur toutes les pièces d'un ensemble ; reproduction de décor main ; or en relief à la main ; aérographe très confirmé sachant faire ses pochoirs.

9e catégorie (coefficient 201) :

- Electronicien et automaticien ; modelage (création) ; tournage anglais (création) ; conduite de four continu avec compétences pour les réglages d'ensemble ; création de décors sur porcelaine.
