# Article 3

Le congé du 1er Mai est accordé dans les conditions prévues par les dispositions légales.

Les jours fériés sont les suivants :

- 1er janvier ;

- lundi de Pâques ;

- 8 Mai ;

- Ascension ;

- lundi de Pentecôte ;

- 14 Juillet ;

- 15 août ;

- 1er novembre ;

- 11 Novembre ;

- 25 décembre.
