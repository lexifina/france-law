# Article 39

Les bulletins de paie seront établis conformément à l'article R. 143-2 du code du travail.

Les différents éléments suivants devront apparaître clairement, à savoir :

-la qualification professionnelle ;

-le coefficient hiérarchique de base ;

-le salaire horaire ou mensuel de base ;

-le nombre des heures de travail et, le cas échéant, le nombre des heures effectuées au-delà de la durée légale du travail ;

-les primes diverses, les heures du dimanche, les heures de nuit exceptionnelles ;

-les acomptes.
