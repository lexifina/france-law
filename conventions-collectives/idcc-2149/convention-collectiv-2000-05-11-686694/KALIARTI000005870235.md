# Article KALIARTI000005870235

Emploi : agent d'études, de développement

Activité dominante : il recueille les données.

Missions principales :

Exécution :

- recueillir et synthétiser tous types d'informations nécessaires ;

- effectuer l'exploitation des données et utiliser les résultats ;

- participer à la préparation de dossiers d'appel d'offres :

conception de dossiers, assistance technique... ;

- participer à la veille technologique et réglementaire ;

- respecter la confidentialité.

Sécurité :

- se conformer aux règles de l'exploitation et aux règles de sécurité.

Qualité :

- adapter son action aux niveaux de qualité prescrits pour l'activité, selon les procédures notifiées.
