# Conventions collectives (KALI)

Les conventions et accords collectifs nationaux consolidés par la DILA (base KALI, Licence Ouverte 2.0), un fichier par article, un commit par texte qui a écrit des versions, au jour de leur entrée en vigueur. Un dossier par conteneur (`idcc-<IDCC>` pour une convention collective), puis un dossier par texte (texte de base, avenants, accords, salaires). Les signataires ne sont pas reproduits.

National collective agreements as consolidated by DILA (KALI base, Licence Ouverte 2.0): one file per article, one commit per agreement that wrote versions, on the day they took effect. One folder per container (`idcc-<IDCC>` for a convention collective), then one per text. Signatories are not reproduced.

1162 containers, 31242 texts and 191503 articles in force on 2026-11-01; 304149 article versions in the history.
