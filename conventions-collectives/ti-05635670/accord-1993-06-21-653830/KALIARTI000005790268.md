# Article KALIARTI000005790268

Article 1er.

Le salaire minimum national professionnel prévu à la convention collective nationale de la pharmacie d'officine est fixé à 17,40 francs de l'heure sur la base de référence du coefficient 100.

Article 2.

Le salaire mensuel garanti au coefficient 100, excluant toutes primes, est fixé à 5 950 F bruts sur la base de trente-neuf heures de travail hebdomadaire.

Article 3.

Il est créé une courbe de raccordement pour les coefficients 100 à 210 inclus s'établissant comme suit :

100 : 5.950,00 F ;

115 : 5.980,72 F ;

125 : 6.001,20 F ;

130 : 6.011,44 F ;

135 : 6.021,68 F ;

140 : 6.031,92 F ;

145 : 6.042,16 F ;

150 : 6.052,40 F ;

155 : 6.062,64 F ;

160 : 6.072,88 F ;

165 : 6.083,12 F ;

170 : 6.093,36 F ;

175 : 6.103,60 F ;

200 : 6.154,80 F ;

210 : 6.175,26 F.

Article 4.

Le présent accord entrera en vigueur à compter du 1er juillet 1993.
