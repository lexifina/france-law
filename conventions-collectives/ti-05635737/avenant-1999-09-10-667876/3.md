# Article 3

Les fonctions définies dans la convention collective nationale sont affectées dans les différentes catégories INSEE de la façon suivante :

Catégorie ouvriers :

- les peseurs ;

- les agents d'exécution de catégorie A.

Catégories employés :

- les employés de bureau ;

- les sténodactylographes ;

- les secrétaires.

Catégories professions intermédiaires :

- les contrôleurs laitiers agents techniques de catégorie B ;

- les contrôleurs laitiers-conseillers d'élevage de catégories C et D ;

- les comptables ;

- les assistantes et secrétaires de direction.

Catégories cadres et assimilés cadres :

- les encadreurs-animateurs de catégorie D ;

- les assistantes et les secrétaires de direction dirigeant un secrétariat ;

- les chefs de service ;

- les chefs comptables.
