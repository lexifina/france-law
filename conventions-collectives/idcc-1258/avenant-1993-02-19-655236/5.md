# Article 5

Chacune des catégories situées à l'article 4 ci-dessus comporte les groupes de postes suivants :

Exécution - Intervention

Groupe 1 : Aide à domicile non titulaire du CAFAD ; agent de service niveau 1.

Groupe 2 : Agent d'entretien ; aide à domicile titulaire du CAFAD ; agent de service administratif niveau 2 ; aide-cuisinier(e) ; chauffeur : porteur de repas.

Groupe 3 : Chauffeur ; secrétaire niveau 1 ; aide-comptable niveau 1.

Groupe 3 bis :

Secrétaire niveau 2 ; aide-comptable niveau 2.

Maîtrise

Groupe 4 : Responsable de secteur ; comptable niveau 1 ; animateur(trice) ; maître(tresse) de maison ; chef cuisinier(e).

Groupe 4 bis : Secrétaire de direction ; assistante(e) social(e).

Cadres et direction

Groupe 5 : Cadre de secteur ; cadre administratif ; comptable niveau 2.

Groupe 6 : Directeur(trice), responsable d'un ou plusieurs services de : 50 salariés équivalent temps plein, 50 à 249 salariés équivalent temps plein, 250 à 500 salariés équivalent temps plein, au-delà de 500 salariés équivalent temps plein : directeur(trice) général(e).

Personnels soignants

Groupe 7 : Aide soignant(e) (intervention) ; infirmier(e) D.E. (maîtrise) ; infirmière coordonnateur(trice), 50 places (cadre) ; infirmier(e) coordonnateur(trice) + 50 places (cadre).
