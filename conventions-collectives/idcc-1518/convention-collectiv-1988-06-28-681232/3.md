# Article 3

Les emplois du personnel pédagogique s'intègrent dans la grille de classification définie à l'annexe I dans les groupes suivants :

Animateur.

Assistant sanitaire.

Groupe II.

Coefficient 225.

Directeur adjoint/économe.

Groupe III.

Coefficient 250.

Directeur.

Groupe IV.

Coefficient 280.
