# Article 1

La présente convention conclue entre :

L'union syndicale des rouisseurs-teilleurs de lin de France,

D'une part, et

Les organisations syndicales de salariés signataires :

S.N.C.E.A. - C.G.C. ;

F.S.C.O.P.A. - C.F.T.C. ;

F.G.T.A. - F.O. ;

F.G.A. - C.F.D.T.,

D'autre part,

règle les rapports entre :

"- d'une part, les employeurs ayant pour activité principale le rouissage-teillage de lin, le peignage, l'affinage, le cardage ou une autre transformation agro-industrielle du lin sur le territoire national. Le code A.P.E. de ces entreprises est le 17.1 H..

et

- d'autre part, les salariés de ces entreprises.
