# Article 3

En référence à l'article 11 de la convention collective nationale (Rupture du contrat par l'employeur) :

Le deuxième alinéa du paragraphe b (Indemnités de licenciement) est remplacé par :

" Pour les employés de maison à temps complet, logés, nourris, cette indemnité sera calculée comme suit :

" - pour deux ans d'ancienneté : deux dixièmes de mois ;

" - pour trois ans d'ancienneté : trois dixièmes de mois ;

" - pour quatre ans d'ancienneté : quatre dixièmes + un quinzième de mois ;

" - pour cinq ans d'ancienneté : cinq dixièmes + deux quinzièmes de mois ;

" - pour six ans d'ancienneté : cinq dixièmes + trois quinzièmes de mois ;

" - pour sept ans d'ancienneté : sept dixièmes + quatre quinzièmes de mois ;

" - à partir de huit ans d'ancienneté : un cinquième de mois par an de présence, soit huit cinquièmes. "

Le troisième alinéa du paragraphe c (Heures de liberté) est le suivant :

" S'ils ont plus de deux ans de présence, à deux heures par jour pendant quinze jours ouvrables. "
