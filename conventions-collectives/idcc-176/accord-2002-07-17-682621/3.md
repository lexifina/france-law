# Article 3

Le compte épargne-temps est alimenté à l'initiative du salarié par les éléments suivants :

-un report de jours " de réduction du temps de travail ", dans la limite de 25 % par an des jours de " réduction du temps de travail " accordés dans l'entreprise ;

-un report de congés payés, dans la limite maximum de 5 jours par an, pour les salariés ne bénéficiant pas de jours " de réduction de temps de travail ".

Un accord d'entreprise peut prévoir d'autres sources d'alimentation autorisées par la loi (art. L. 227-1 du code du travail).

Avant une date limite qui sera déterminée dans l'entreprise, le salarié indiquera par écrit, chaque année, à l'employeur les droits susceptibles d'alimenter le compte épargne-temps qu'il entendra affecter à son compte.
