# Article 3

Un programme de référence, faisant l'objet de l'annexe I du présent accord, constitué de modules d'enseignements, porte sur les matières suivantes.

I. Enseignements scientifiques :

- biologie générale ;

- anatomie-physiologie ;

- pathologie générale ;

- pathologie des appareils ;

- thérapeutique.

II. Enseignements professionnels :

- économie de la santé et marché pharmaceutique ;

- système de santé en France ;

- médicament ;

- information médico-pharmaceutique ;

- visite médicale ;

- législation du travail ;

- communication.

Ce programme constitue le niveau de connaissances professionnelles requis pour les nouveaux visiteurs médicaux. Il est complété par des stages dans les milieux professionnels où évoluent les visiteurs médicaux.
