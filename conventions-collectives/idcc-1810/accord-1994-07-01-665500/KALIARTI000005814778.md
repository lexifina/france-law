# Article KALIARTI000005814778

Rémunérations minimales hiérarchiques pour 169 heures.

Valeurs des points

A compter du 1er janvier 1995, sous réserve de l'entrée en vigueur du présent accord :

- la valeur du point de base (pour les 150 premiers points) est fixée à : 41,90 ;

- la valeur du point complémentaire (applicable au-delà de 150) est fixée :

- pour la filière exploitation à : 18,790 ;

- pour la filière administrative à : 21,689 ;

- pour la filière cadre à : 21,332.
