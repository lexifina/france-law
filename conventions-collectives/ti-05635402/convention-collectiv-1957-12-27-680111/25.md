# Article 25

Les bulletins de paie sont établis conformément à l'article 44 du livre Ier du code du travail.

Les différents éléments de la somme versée devront apparaître clairement, à savoir :

- la qualification professionnelle ;

- le coefficient hiérarchique de base ;

- le salaire horaire ou mensuel de base ;

- le nombre des heures de travail normal et, le cas échéant, le nombre des heures effectuées au-delà de la durée légale du travail ;

- les heures au rendement, les primes diverses, les heures du dimanche, les heures de nuit exceptionnelles ;

- les acomptes.
