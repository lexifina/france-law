# Article 34-201

Les congés d'ancienneté, prévus dans le cadre du chapitre XIV Congés, sont les suivants :

- un jour pour huit ans d'ancienneté dans la profession ;

- deux jours pour treize ans d'ancienneté dans la profession ;

- trois jours pour dix-huit ans d'ancienneté dans la profession ;

Si, compte tenu des campagnes sucrières, l'intéressé travaille en continu (régime qui conduit le salarié à prendre, suivant un rythme prévu, son repos hebdomadaire un autre jour que le dimanche), ces congés d'ancienneté deviennent :

- un jour pour cinq ans de travail en continu ;

- deux jours pour dix ans de travail en continu ;

- trois jours pour quinze ans de travail en continu ;

- quatre jours pour vingt ans de travail en continu.
