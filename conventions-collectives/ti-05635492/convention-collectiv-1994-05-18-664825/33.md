# Article 33

A l'issue des négociations qui se poursuivent sur les salaires minima conventionnels, les classifications de la convention collective se présenteront de la manière suivante :

Catégories / Niveau :

Niveau I

Ouvriers : échelons.

Employés : échelons.

Catégories / Niveau :

Niveau II

Ouvriers : échelons.

Employés : échelons.

Catégories / Niveau :

Niveau III

Ouvriers : échelons.

Employés : échelons.

Techniciens, agents de maîtrise : échelons.

Catégories / Niveau :

Niveau IV

Techniciens, agents de maîtrise : échelons.

Catégories / Niveau :

Niveau V

Techniciens, agents de maîtrise : échelons.

Cadres : échelons.

Catégories / Niveau :

Niveau VI

Cadres : échelons.

Catégories / Niveau :

Niveau VII

Cadres : échelons.

Les minima salariaux catégoriels font l'objet d'un avenant donnant les montants par niveau.
