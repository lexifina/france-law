# Article 4

La prime d'ancienneté sera calculée de la manière suivante pour 169 heures de travail mensuel :

[C x VPS] x TMS = PA

Elle est calculée pro rata temporis pour une durée de travail mensuel différente.

C = Coefficient ;

VPS = Valeur point salaire ;

TMS = Taux de majoration de salaire pour ancienneté ;

PA = Prime d'ancienneté.
