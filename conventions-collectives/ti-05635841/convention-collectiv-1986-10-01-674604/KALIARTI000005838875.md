# Article KALIARTI000005838875

NIVEAU : III.

EMPLOI :

Emploi correspondant à l'exécution de tâches simples, analogues ou répétitives nécessitant des connaissances élémentaires et une adaptation préalable.

NIVEAU III.

ECHELON : 3 a.

COEFFICIENT : 125.

EMPLOI :

Travaux ne nécessitant qu'une mise au courant sommaire et une formation pratique très courte.

Mise en oeuvre de moyens connus et habituels entrant dans le cadre de consignes simples expliquées par voie démonstrative ou orale.

Production :

- agent de conditionnement ;

- agent de transformation ;

- agent de manutention.

Tertiaire :

- employé administratif.

NIVEAU : III.

ECHELON : 3 b.

COEFFICIENT : 135.

EMPLOI :

Travaux nécessitant une formation pratique courte sans connaissances générales du métier.

Mise en oeuvre de moyens connus et habituels dans le cadre de consignes permanentes ou précises écrites ou orales.

Production :

- agent de transformation ;

- agent de magasinage, cariste ;

- préparateur 1er degré ;

- chauffeur-livreur V.L.3,5 tonnes.

Technique :

- agent d'entretien.

NIVEAU : III

ECHELON : 3 c

COEFFICIENT : 145.

EMPLOI :

Travaux ne nécessitant pas un enseignement professionnel particulier mais pouvant exiger une part d'initiative au niveau du choix entre les solutions connues et usuelles.

Mise en oeuvre de moyens connus et habituels pouvant être variés, dans le cadre de consignes précises et détaillées fixant les modes opératoires donnés par voie orale ou écrite.

Production :

- agent de production ;

- agent de magasinage, cariste ;

- préparateur.

Tertiaire :

- employé administratif.
