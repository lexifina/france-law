# Article KALIARTI000005838927

Article 1er

Salaire minimum professionnel (SMP)

A compter du 1er décembre 1994, la base de calcul des primes d'ancienneté est portée, au coefficient 100, à 18,54 F par heure, soit, pour 169 h 65/100, à 3 145,13 F par mois.

Le barème des primes d'ancienneté est calculé dans un tableau annexe.

Article 2

Salaire minimum garanti (SMG)

A compter du 1er décembre 1994, les valeurs données à chaque point A, B, C et D sont les suivantes :

Point A : K 115 = 35,56 F par heure ;

Point B : K 145 = 36,60 F par heure ;

Point C : K 190 = 42,29 F par heure ;

Point D : K 880 = 166,62 F par heure.

1. Détermination de la valeur du point complémentaire entre A B :

K145 - K115 / 30 points = 36,60 - 35,56 / 30 =0,0347 F.

Point A :

- K 115 = 35,56 F par heure ;

- K 125 : (0,0347 X 10) + 35,56 = 35,91 F par heure ;

- K 135 : (0,0347 X 20) + 35,56 = 36,25 F par heure.
