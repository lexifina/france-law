# Article KALIARTI000005838924

Article 1er Salaire minimum professionnel (S.M.P. ) A compter du 1er juillet 1994, la base de calcul des primes d'ancienneté est portée, au coefficient 100, à 18,48 F par heure, soit, pour 169 h 65/100, à 3.135,13 F par mois.

Le barème des primes d'ancienneté est calculé dans un tableau annexe.

Article 2 Salaire minimum garanti (S.M.G.).

A compter du 1er juillet 1994, les valeurs données à chaque point A, B, C et D sont les suivantes :

Point A : K 115 = 35,42 F par heure ;

Point B : K 145 = 36,45 F par heure ;

Point C : K 190 = 42,12 F par heure ;

Point D : K 880 = 163,19 F par heure.

1. Détermination de la valeur du point complémentaire entre A et B :

K145 - K115 / 30 points = 36,45 -35,42 / 30 =0,034 F.

Point A :

- K 115 = 35,42 F par heure ;

- K 125 : (0,034 X 10) + 35,42 = 35,76 F par heure ;

- K 135 : (0,034 X 20) + 35,42 = 36,10 F par heure.

2. Détermination de la valeur du point complémentaire entre B et C :

K 190 - K 145 / 45 points = 42,12 - 36,45 / 45 = 0,126 F.

Point B :

- K145 = 36,45 F par heure ;

- K 155 : (0,126 x 10) + 36,45 = 37,71 F par heure ;

- K 165 : (0,126 x 20) + 36,45 = 38,97 F par heure ;

- K 180 : (0,126 x 35) + 36,45 = 40,86 F par heure.

3. Détermination de la valeur du point complémentaire entre C et D :

K 880 - K 190 / 690 points = 163,19 - 42,12 / 690 = 0,175 F.

- K190 = 42,12 F par heure ;

- K 205 : (0,175 X 15) + 42,12 = 44,74 F par heure ;

- K 215 : (0,175 X 25) + 42,12 = 46,49 F par heure ;

- K 230 : (0,175 X 40) + 42,12 = 49,12 F par heure ;

- K 250 : (0,175 X 60) + 42,12 = 52,62 F par heure ;

- K 265 : (0,175 X 75) + 42,12 = 55,24 F par heure ;

- K 295 : (0,175 X 105) + 42,12 = 60,49 F par heure ;

- K 315 : (0,175 X 125) + 42,12 = 63,99 F par heure ;

- K 330 : (0,175 X 140) + 42,12 = 66,62 F par heure ;

- K 345 : (0,175 X 155) + 42,12 = 69,24 F par heure ;

- K 390 : (0,175 X 200) + 42,12 = 77,12 F par heure ;

- K 440 : (0,175 X 250) + 42,12 = 85,87 F par heure ;

- K 550 : (0,175 X 360) + 42,12 = 105,12 F par heure ;

- K 660 : (0,175 X 470) + 42,12 = 124,37 F par heure.

Point D :

- K 880 = 163,19 F par heure.
