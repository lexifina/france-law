# Article KALIARTI000005855835

- L'usage est de régler les frais sur la base de conditions convenables agréées par les parties sur la présentation d'éléments justificatifs.

Il est toutefois précisé que la valeur du repas remboursable s'établit sur la base de deux fois le salaire horaire de la catégorie la mieux payée dans l'entreprise.
