# Article KALIARTI000005844119

La zone côtière dite à vocation balnéaire est constituée par les communes suivantes :

- Oye-Plage ;

- Calais ;

- Escalles ;

- Sangatte ;

- Ambleteuse ;

- Audinghem ;

- Audresselles ;

- Tardinghem ;

- Wissant ;

- Boulogne-sur-Mer ;

- Wimereux ;

- Equihen-Plage ;

- Hardelot ;

- Le Portel ;

- Camiers (plages de Sainte-Cécile et Saint-Gabriel) ;

- Cucq (Stella Plage) ;

- Etaples ;

- Le Touquet ;

- Berck ;

- Groffliers ;

- Merlimont.
