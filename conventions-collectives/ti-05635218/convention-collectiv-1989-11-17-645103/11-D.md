# Article 11 D

Le délai de préavis est fixé comme suit :

Employés

Avant deux ans de présence dans l'étude :

- un mois pour le licenciement.

Entre deux et dix ans de présence dans l'étude :

- deux mois pour le licenciement.

Après dix ans de présence dans l'étude :

- trois mois pour le licenciement.

Techniciens

Avant deux ans de présence dans l'étude :

- deux mois pour le licenciement.

Entre deux et dix ans de présence dans l'étude :

- trois mois pour le licenciement.

Après dix ans de présence dans l'étude :

- quatre mois pour le licenciement.

Cadres

Avant trois ans de présence dans l'étude :

- trois mois pour le licenciement.

Entre trois et sept ans de présence dans l'étude :

- quatre mois pour le licenciement.

Entre sept et douze ans de présence dans l'étude :

- cinq mois pour le licenciement.

Après douze ans de présence dans l'étude :

- six mois pour le licenciement.

Le délai de préavis est augmenté de 50 p. 100, avec majoration minimale de deux mois, si le licenciement intervient dans les six mois précédant ou dans l'année suivant le changement du titulaire ou d'un associé de l'office, la mise en société de l'office ou sa suppression.
