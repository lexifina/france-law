# Article KALIARTI000005790339

Les informations relatives aux :

- produits : nature, présentation, stockage ;

- prix ;

- conditions d'achat et de vente.

Les moyens classiques à la disposition des employés :

- rôle ;

- présentation générale ;

- différentes formes ;

- classement : les imprimés, les fichiers, les dossiers, les registres, les catalogues, les tarifs, les autres moyens de traitement de l'information.
