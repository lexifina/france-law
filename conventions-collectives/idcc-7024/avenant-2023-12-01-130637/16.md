# Article 16

Une prime d'ancienneté est attribuée aux salariés non-cadre dans les conditions suivantes :

– après 2 ans de service dans une même exploitation ou pour le compte d'un même exploitant : prime correspondant à une majoration du salaire de base de 1 % ;

– après 4 ans de service dans une même exploitation ou pour le compte d'un même exploitant : prime correspondant à une majoration du salaire de base de 3 % ;

– après 6 ans de service dans une même exploitation ou pour le compte d'un même exploitant : prime correspondant à une majoration du salaire de base de 5 % ;

– après 8 ans de service dans une même exploitation ou pour le compte d'un même exploitant : prime correspondant à une majoration du salaire de base de 7 %.
