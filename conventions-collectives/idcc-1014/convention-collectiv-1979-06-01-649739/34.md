# Article 34

Le traitement comprend pour l'ensemble du personnel :

a) Le salaire se composant des éléments suivants :

- le salaire de base ;

- la rémunération des heures supplémentaires (pour le personnel d'exécution et de maîtrise).

b) Les éléments accessoires ci-après :

- la prime de gestion ;

- le 13e mois ;

- les majorations ;

- les primes spéciales ;

- les indemnités diverses représentatives de sujétions particulières à certaines catégories d'emploi.
