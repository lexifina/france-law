# Article KALIARTI000005769267

A compter du 1er juillet 2002, la valeur du point est fixée à 6,10 euros. Toutefois, pour les coefficients 140, 145, 155, 170, 180 et 190, les minima ainsi obtenus seront majorés de :

- 35,5 % pour le coefficient 140, soit 1 157 euros ;

- 34 % pour le coefficient 145, soit 1 185 euros ;

- 27 % pour le coefficient 155, soit 1 200 euros ;

- 17 % pour le coefficient 170, soit 1 213 euros ;

- 13,5 % pour le coefficient 180, soit 1 246 euros ;

- 9 % pour le coefficient 190, soit 1 263 euros.

Ces salaires minima s'entendent pour une durée légale de 151,67 heures de travail effectif.

La valeur du point " cadre " est fixée suivant le coefficient de raccordement ci-dessous :

Valeur du point " collaborateur " x 4,2.

La valeur du point " collaborateur " étant de 6,10 euros, la valeur du point " cadre " est de 25,62 euros.
