# Article 2

Outre les dispositions prévues au chapitre VII de l'annexe I, pour les entreprises ayant signé un accord de modulation, seront rémunérées, selon le taux applicable pour le paiement des heures supplémentaires, les heures effectuées dans le contingent au-delà de :

- 130 heures pour une modulation comprise entre 0 et 46 heures ;

- 90 heures pour une modulation comprise entre 0 et 48 heures pour l'ensemble du personnel exception faite des chauffeurs.

Pour les entreprises n'ayant pas signé d'accord de modulation, seront rémunérées, selon le taux applicable pour le paiement des heures supplémentaires, les heures effectuées dans le contingent au-delà de :

- 150 heures pour le personnel de l'élevage, de maintenance et des couvoirs ;

- 90 heures pour le personnel administratif, exception faite pour les chauffeurs.
