# Article 3

Les 10 jours fériés conventionnels, outre le 1er Mai, sont les suivants :

- 1er janvier ;

- lundi de Pâques ;

- 8 Mai ;

- Ascension ;

- lundi de Pentecôte ;

- 14 Juillet ;

- Assomption ;

- Toussaint ;

- 11 Novembre ;

- Noël.

Si un de ces jours fériés est travaillé, le salaire reçu pour cette journée de travail sera doublé.
