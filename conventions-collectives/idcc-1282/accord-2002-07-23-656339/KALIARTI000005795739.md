# Article KALIARTI000005795738

La cotisation est de 1,65 % du salaire annuel de référence pour la tranche A.

La répartition entre les employeurs et les salariés est de :

Tranche A :

- 1,50 % pour l'employeur ;

- 0,15 % pour le salarié,

y compris les 0,10 % pour le fonds collectif de rente pour soutien scolaire.

Pour les salariés à temps partiel, l'assiette de cotisation est celle du salaire à temps complet reconstitué avec la même répartition que pour les temps complets.

Tranche B-C (1 %) :

La cotisation de la tranche B et C est ainsi répartie :

- 30 % pour l'employeur ;

- 70 % pour le salarié.
