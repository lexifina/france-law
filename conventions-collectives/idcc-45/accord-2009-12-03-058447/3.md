# Article 3

Les indicateurs visés dans le présent accord seront examinés annuellement dans le cadre de la CPNE. Ils figureront, ainsi que l'évolution de leurs résultats, dans le rapport annuel de branche prévu à l'article D. 2241-1 du code du travail.

Un bilan général sera dressé dans le courant de l'année 2012 afin d'examiner la situation au regard des objectifs fixés.

Les parties examineront à cette occasion les conditions de renouvellement du présent accord.
