# Article 36

Les salariés bénéficient de congés supplémentaires en raison de leur ancienneté dans l'entreprise, dans les conditions suivantes :

- deux jours supplémentaires après cinq ans d'ancienneté ;

- trois jours supplémentaires après dix ans d'ancienneté ;

- quatre jours supplémentaires après quinze ans d'ancienneté ;

- cinq jours supplémentaires après vingt ans d'ancienneté ;

- six jours supplémentaires après vingt-cinq ans d'ancienneté.
