# Article 1

La présente convention règle sur le territoire métropolitain et dans les départements et territoires d'outre-mer les rapports entre employeurs et salariés travaillant dans les entreprises ayant, selon la Nomenclature d'activités françaises (N.A.F.), les références suivantes :

Sous-section :

- division 15, groupe 15-1, classes 15-1-A, 15-1-C, 15-1-E et 15-1 F.

Sous-section GG :

- division 51, groupe 51-3, classe 51-3-C ;

- division 52, groupe 52-1, classes 52-1-B et 52-1-C :

- groupe 52-2, classe 52-2-C ;

- groupe 52-6, classe 52-6-D.

Sous-section HH :

- division 55, groupe 55-3, groupe 55-5, classe 55-5-D.
