# Article KALIARTI000005825328

A partir du 1er janvier 1993 les salaires horaires sont les suivants :

- le coefficient 105 est augmenté de 1,7 % ;

- le coefficient 110 est augmenté de 2,3 % ;

- le coefficient 125 est augmenté de 0,5 % ;

- les coefficients 135 à 420 sont augmentés de 0,3 %.
