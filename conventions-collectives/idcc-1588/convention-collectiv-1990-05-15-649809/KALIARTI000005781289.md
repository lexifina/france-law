# Article KALIARTI000005781289

Classe I : 450 points :

- attaché de direction ;

- secrétaire de direction 2 ;

- gérant d'immeuble ;

- chargé de mission ;

- informaticien.

Classe II : 500 points :

- attaché de direction 2 ;

- responsable de service ;

- monteur d'opérations ;

- chef comptable 1.

Classe III : 550 points :

- secrétaire général ;

- sous-directeur ;

- directeur adjoint ;

- chef comptable 2 ;

- responsable des ressources humaines ;

- responsable de département.

Classe IV : 650 points : directeur.

Il est précisé que les fonctions de direction générale exercées en vertu d'un mandat social ne sont pas visées par la présente classification.
