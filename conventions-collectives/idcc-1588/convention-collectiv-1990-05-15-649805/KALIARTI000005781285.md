# Article KALIARTI000005781284

Classe I : salaire minimum professionnel garanti.

Agent sans qualification ou sans expérience professionnelle. Cette catégorie s'adresse exclusivement aux débutants et ne pourra excéder un an après la période d'essai.

Le salaire minimum professionnel garanti est égal au S.M.I.C., constante incluse.

Classe II : 260 points.

Sténodactylo 1er échelon.

Dactylo 1er échelon.

Agent de bureau 1er échelon.

Classe III : 270 points.

Agent ayant un C.A.P., ou B.E.P. ou une expérience professionnelle confirmée.

Dessinateur 1er échelon.

Dactylo 2e échelon.

Sténodactylo 2e échelon.

Agent de bureau 2e échelon.

Opérateur de saisie 1er échelon.

Hôtesse.

Aide-comptable 1er échelon.

Classe IV : 300 points.

Agent ayant un niveau brevet de technicien ou baccalauréat ou une formation équivalente.

Secrétaire administratif 1er échelon.

Aide-comptable 2e échelon.

Opérateur de saisie 2e échelon, opérateur sur ordinateur ou micro.

Surveillant de chantier 1er échelon.

Dessinateur 2e échelon.

Agent d'enquêtes, agent de recouvrement.

Téléphoniste, standardiste.

Pupitreur 1er échelon.

Classe V : 340 points.

Agent ayant un brevet de technicien ou baccalauréat + une année d'enseignement supérieur ou une formation équivalente avec une expérience professionnelle confirmée.

Secrétaire administratif 2e échelon.

Comptable 1er échelon.

Caissier-comptable (majoration de 20 points) : agent de formation comptable qui a la responsabilité d'une caisse.

Surveillant de chantier 2e échelon.

Agent de gérance.

Secrétaire commercial.

Programmeur qualifié.

Métreur-vérificateur 1er échelon.

Conseiller social 1er échelon.

Pupitreur 2e échelon.
