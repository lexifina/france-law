# Article KALIARTI000005770503

Pour chaque activité, les filières font application des définitions générales, lesquelles sont dans tous les cas l'élément essentiel servant de base pour déterminer le classement minimum des ETAM de l'ensemble des branches professionnelles des carrières et matériaux de construction.

Ces filières sont les suivantes :

1. Filière : sténodactylo, secrétariat.

2. Filière : administration.

3. Filière : comptabilité.

4. Filière : laboratoire.

5. Filière : informatique.

6. Filière : commerce.

7. Filière : dessin.

8. Filière : appareillage, métrage, calepinage.

9. Filière : planning.

10. Filière : exploitation.

11. Filière : services généraux.

12. Filière : méthodes exploitation.

Les filières sont annexées au présent accord.
