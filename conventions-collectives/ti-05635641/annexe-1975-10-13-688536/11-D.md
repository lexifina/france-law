# Article 11 D

Le délai de préavis est fixé comme suit :

Employés :

- avant deux ans de présence dans l'étude (un mois pour le licenciement) ;

- entre deux et dix ans de présence dans l'étude (deux mois pour le licenciement) ;

- après deix ans de présence dans l'étude (trois mois pour le licenciement).

Techniciens :

- avant deux ans de présence dans l'étude (deux mois pour le licenciement) ;

- entre deux et dix ans de présence dans l'étude (trois mois pour le licenciement) ;

- entre dix ans de présence dans l'étude (quatre mois pour le licenciement) ;

Cadres :

- avant trois ans de présence dans l'étude (trois mois pour le licenciement) ;

- entre trois et sept ans de présence dans l'étude (quatre mois pour le licenciement) ;

- entre sept et douze ans de présence dans l'étude (cinq mois pour le licenciement) ;

- après douze ans de présence dans l'étude (six mois pour le licenciement) ;

Le délai de préavis est augmenté de 50 p. 100, avec majoration minimale de deux mois, si le licenciement intervient dans les six premiers mois précédents ou dans l'année suivant le changement du titulaire ou d'un associé de l'office, la mise en société de l'office ou sa suppression.
