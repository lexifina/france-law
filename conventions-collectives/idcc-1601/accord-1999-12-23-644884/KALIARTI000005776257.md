# Article KALIARTI000005776257

Il est déterminé par application du calcul suivant :

J - jt - WE - CP - jf - jc

J = nombre de jours compris dans l'année civile.

jt = nombre annuel de jours de travail applicable dans l'entreprise pour les cadres concernés (au maximum 214).

WE = nombre de jours correspondant aux week-end et/ou aux jours non ouvrés dans le cadre de l'horaire hebdomadaire habituel.

CP = nombre de jours correspondant à 5 semaines de congés payés.

jf = jours fériés tombant un jour ouvré (ou jour de remplacement).

jc = jours compensatoires pour dépassement du forfait de l'année précédente.
