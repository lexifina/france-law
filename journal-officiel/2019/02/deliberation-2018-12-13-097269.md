# Délibération du 13 décembre 2018 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2018-12-13
- Publication : 2019-02-06
- JO n° : 0031
- NOR : CSAR1903391X
- Origine : JORF n°0031 du 6 février 2019
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000038097269

## Article

Par délibération en date du 13 décembre 2018, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 25 février au 14 juillet 2019.

Site : SAINT-GENIS-L'ARGENTIERE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : SAINT-SYMPHORIEN-SUR-COISE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
