# Délibération du 1er juillet 2019 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2019-07-01
- Publication : 2019-08-08
- JO n° : 0183
- NOR : CSAR1923111X
- Origine : JORF n°0183 du 8 août 2019
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000038896029

## Article

Par délibération en date du 1er juillet 2019, le comité territorial de l'audiovisuel de Nancy a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Radio Campus Lorraine à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Campus Lorraine, pour la période du 16 septembre 2019 au 16 juin 2020 (*).

Site : 6, rue d'Aquitaine, bâtiment Lavoisier, 54500 Vandœuvre-lès-Nancy.

Puissance : 100 W.

Fréquence : 99,6 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.

Site : résidence Saulcy, Ile du Saulcy, 57010 Metz.

Puissance : 100 W.

Fréquence : 106,1 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.

(*) Sous réserve d'un aboutissement favorable des procédures de coordination internationale en ce qui concerne le site de Metz.

---

Fait à Nancy, le 1er juillet 2019.

Pour le comité territorial de l'audiovisuel de Nancy :

La présidente,
