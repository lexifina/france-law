# Délibération du 1er juillet 2019 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2019-07-01
- Publication : 2019-07-27
- JO n° : 0173
- NOR : CSAR1921848X
- Origine : JORF n°0173 du 27 juillet 2019
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000038828202

## Article

Par délibération en date du 1er juillet 2019, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 19 août au 31 décembre 2019.

Site : Saint-Genis-l'Argentière (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : Saint-Symphorien-sur-Coise (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
