# Délibération du 28 mars 2019 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2019-03-28
- Publication : 2019-04-27
- JO n° : 0099
- NOR : CSAR1912114X
- Origine : JORF n°0099 du 27 avril 2019
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000038424029

## Article

Par délibération en date du 28 mars 2019, le comité territorial de l'audiovisuel de Bordeaux a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Port Albret FM à diffuser un service de radio par voie hertzienne terrestre dénommé Port d'Albret FM, pour la période du 20 mai 2019 au 3 novembre 2019.

Site : Vieux Boucau (40)

Puissance : 30 W

Fréquence : 95,1 MHz

RDS Code PI : F3D1

RDS Code PS : PAFM

Fait à Bordeaux, le 28 mars 2019.
