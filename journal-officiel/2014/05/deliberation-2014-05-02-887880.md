# Délibération relative à une autorisation temporaire

- Nature : Deliberation
- Publication : 2014-05-02
- JO n° : 0102
- NOR : CSAR1409707X
- Origine : JORF n°0102 du 2 mai 2014
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000028887880

## Article

Par délibération en date du 25 mars 2014, le comité territorial de l'audiovisuel de Bordeaux a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Starcom à diffuser un service de radio par voie hertzienne terrestre dénommé Surf FM pour la période du 1er avril au 31 octobre 2014.

Site : Seignosse (40).

Puissance : 100 W.

Fréquence : 102,3 MHz.

RDS Code PI : F3D9.

RDS Code PS : SURF FM.
