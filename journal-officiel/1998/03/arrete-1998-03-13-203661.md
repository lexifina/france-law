# Arrêté du 13 mars 1998 fixant le nombre d'étudiants admis en première année d'études conduisant au diplôme d'Etat d'infirmier

- Date du texte : 1998-03-13
- Publication : 1998-03-21

- NOR : MESP9820945A
- Ministère : MINISTERE DE L'EMPLOI ET DE LA SOLIDARITE
- Origine : JORF n°68 du 21 mars 1998

## Article

Par arrêté de la ministre de l'emploi et de la solidarité et du secrétaire d'Etat à la santé en date du 13 mars 1998, le nombre d'étudiants admis à entrer en première année d'études conduisant au diplôme d'Etat d'infirmier pour l'année scolaire 1998-1999 (rentrées de septembre 1998 et de février 1999) est fixé dans les différentes régions comme suit :

Alsace : 550 ;

Aquitaine : 780 ;

Auvergne : 364 ;

Bourgogne : 450 ;

Bretagne : 610 ;

Centre : 650 ;

Champagne-Ardenne : 352 ;

Corse : 38 ;

Franche-Comté : 392 ;

Ile-de-France : 3 702 ;

Languedoc-Roussillon : 566 ;

Limousin : 291 ;

Lorraine : 812 ;

Midi-Pyrénées : 540 ;

Nord - Pas-de-Calais : 1 580 ;

Basse-Normandie : 412 ;

Haute-Normandie : 540 ;

Pays de la Loire : 650 ;

Picardie : 650 ;

Poitou-Charentes : 414 ;

Provence-Alpes-Côte d'Azur :

1 037 ;

Rhône-Alpes : 1 700 ;

Antilles-Guyane : 65 ;

Réunion : 91.
