# Décisions du 8 avril 1998 autorisant l'établissement et l'exploitation de réseaux indépendants

- Nature : Decision
- Date du texte : 1998-04-08
- Publication : 1998-05-28
- JO n° : 0122
- NOR : ARTL9800119S
- Origine : JORF n°122 du 28 mai 1998
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000755375

## Article

Par décision no 98-234 en date du 8 avril 1998, rendue par l'Autorité de régulation des télécommunications, les canaux du plan 1,5 D, tel que défini à l'annexe 4 de l'arrêté du 7 octobre 1994 modifié fixant les conditions générales d'autorisation des réseaux radioélectriques indépendants du service fixe, sont attribués à la société Autoroutes du sud de la France, dans le cadre de l'autorisation qui lui a été délivrée par la décision no 97-78 du 2 avril 1997 de l'Autorité :

- le canal no 1 est attribué pour les quatre liaisons suivantes : Saint-Romain-de-Lerps (07)-Bourg-lès-Valences (26) ; Saint-Palais-de-Phiolin (17)-Saint-Georges-des-Coteaux (17) ; Poulx (30)-Lunel-Viel (34) ; Nespouls (19)-Lachapelle-Auzac (46) ;

- le canal no 2 est attribué pour les cinq liaisons suivantes : Beausemblant (26)-Saint-Romain-de-Lerps (07) ; Saint-Georges-des-Coteaux (17)-Lozay (17) ; Lachapelle-Auzac (46)-Souillac (46) ; Labastide-Murat (46)-Montpezat-de-Quercy (82) ; Fournes-Cabardès (11)-Avignonet-Lauragais (31) ;

- le canal no 3 est attribué pour les cinq liaisons suivantes : Saint-Romain-en-Gal (69)-Beausemblant (26) ; Lozay (17)- Gript (79) ; Courpignac (17)-Saint-Palais-de-Phiolin (17) ; Lachapelle-Auzac (46)-Labastide-Murat (46) ; Narbonne (11)- Fournes-Cabardès (11) ;

- le canal no 4 est attribué pour la liaison à Souillac (46).
