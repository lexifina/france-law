# Arrêté du 26 janvier 2010 portant agrément des repères d'identification des animaux des espèces bovine, ovine et caprine

- Nature : Arrete
- Date du texte : 2010-01-26
- Publication : 2010-02-14
- JO n° : 0038
- NOR : AGRG1002438A
- Ministère : Ministère de l'alimentation, de l'agriculture et de la pêche
- Origine : JORF n°0038 du 14 février 2010
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000021824061

Le ministre de l'alimentation, de l'agriculture et de la pêche,

Vu le règlement (CE) n° 1760/2000 du Parlement européen et du Conseil du 17 juillet 2000 établissant un système d'identification et d'enregistrement des bovins et concernant l'étiquetage de la viande bovine et ses produits à base de viande bovine, et abrogeant le règlement (CE) n° 820/97 du Conseil ;

Vu le règlement (CE) n° 21/2004 du Conseil du 17 décembre 2003 établissant un système d'identification des animaux des espèces ovine et caprine et modifiant le règlement (CE) n° 1782/2003 et les directives n° 92/102/CEE et n° 64/432/CEE ;

Vu le règlement (CE) n° 911/2004 de la Commission du 29 avril 2004 portant disposition d'exécution du règlement (CE) n° 1760/2000 du Parlement européen et du Conseil en ce qui concerne les marques auriculaires, les passeports et les registres d'exploitation ;

Vu le code rural, et notamment son article L. 212-8 ;

Vu l'arrêté du 19 décembre 2005 modifié relatif à l'identification des animaux des espèces ovine et caprine ;

Vu l'arrêté du 9 mai 2006 relatif aux modalités d'identification du cheptel bovin,

Arrête :

## Article 1

Dans le cadre de l'identification des animaux des espèces bovine, ovine et caprine, les modalités de délivrance et de suppression de l'agrément des repères officiels sont fixées dans le cahier des charges relatif à l'agrément des repères officiels validé par le ministre chargé de l'agriculture, consultable auprès de l'Institut de l'élevage et du bureau de l'identification et du contrôle des mouvements des animaux à la direction générale de l'alimentation du ministère en charge de l'agriculture.

## Article 2

Dans le cadre de l'identification des animaux des espèces ovine et caprine, le ministre chargé de l'agriculture agrée, pour l'identification des animaux de ces espèces destinés à être abattus avant l'âge de deux mois, les repères auriculaires de type barrette rigide suivants :

― le modèle « Tiptag », de la société Chevillot, de code d'agrément « FR 50 » ;

― le modèle « Ovibag », de la société Néodis, de code d'agrément « FR 51 » ;

― le modèle « Reytag », de la société Reyflex, de code d'agrément « FR 52 ».

## Article 3

Dans le cadre de l'identification des animaux des espèces ovine et caprine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de ces espèces, les repères auriculaires conventionnels de type pendentif suivants :

Pour la société Reyflex :

― la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « Supermini » de code d'agrément « FR 85 » ;

― la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « MPLC » de code d'agrément « FR 83 » ;

― la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « MG » de code d'agrément « FR 84 ».

Pour la société Néodis :

― la combinaison suivante : partie femelle « Oviflex » de code d'agrément « FR 87 » et partie mâle « Oviflex » de code d'agrément « FR 87 ».

Pour la société Chevillot :

― la combinaison suivante : partie femelle « Axaflex Couple 16 » de code d'agrément « FR 92 » et partie mâle « Axaflex Couple 16 » de code d'agrément « FR 92 » ;

― la combinaison suivante : partie femelle « Axaflex Couple 14 » de code d'agrément « FR 94 » et partie mâle « Axaflex Couple 14 » de code d'agrément « FR 94 ».

― la combinaison suivante : partie femelle « Sheep Ultra » de code d'agrément « FR 95 » et partie mâle « Senior » de code d'agrément « FR 96 ».

Pour la société Agid :

Pour la société Ardes :

― le modèle « Ov'Ardes » de code d'agrément « FR 99 ».

## Article 4

Dans le cadre de l'identification des animaux des espèces ovine et caprine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de ces espèces, les repères auriculaires de type barrette souple suivants :

― le modèle « Strip tag », de la société AGID, de code d'agrément « FR 64 » ;

― le modèle « Cheviflex », de la société Chevillot, de code d'agrément « FR 60 » ;

― le modèle « Fba/Mba », de la société Reyflex, de code d'agrément « FR 62 » ;

― le modèle « Orimark » de la société Néodis, de code d'agrément « FR 61 ».

## Article 5

Dans le cadre de l'identification électronique des animaux de l'espèce ovine, le ministre chargé de l'agriculture agrée, pour l'identification des animaux de cette espèce, les repères auriculaires de type bouton/pendentif électroniques suivants :

Pour la société Allflex :

― la combinaison suivante : partie femelle « Sheep air tag » de code d'agrément « FR 75 » et partie mâle « Axaflex couple 16 » de code d'agrément « FR 92 ».

Pour la société Chevillot :

― la combinaison suivante : partie femelle « Sheep air tag » de code d'agrément « FR 75 » et partie mâle « Axaflex Ovina » de code d'agrément « FR 91 ».

Pour la société Reyflex :

― la combinaison suivante : partie femelle « bouton FRCE FDX » de code d'agrément « FR 72 » et partie mâle « Reyflex Mini » de code d'agrément « FR 85 ».

Pour la société Néodis :

― la combinaison suivante : partie femelle « bouton FDX - Ovitronic » de code d'agrément « FR 74 » et partie mâle « Oviflex » de code d'agrément « FR 87 ».

Pour la société OS ID distribuée par la société Allflex :

― la combinaison suivante : partie femelle « Combi E23 » de code d'agrément « FR 76 » et partie mâle « Combi Mini 2000 » de code d'agrément « FR 98 ».

## Article 6

Dans le cadre de l'identification des animaux de l'espèce ovine de race « Mouton d'Ouessant » et « Soay » et les animaux de l'espèce caprine dont la hauteur au garrot à l'âge adulte ne dépasse pas 55 centimètres, le ministre de l'agriculture agrée les repères auriculaires suivants :

― le modèle « Quick », de la société Chevillot, de code d'agrément « FR 81 ».

## Article 7

Dans le cadre de l'identification électronique des animaux de l'espèce caprine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de cette espèce, les bagues de paturon suivantes :

― le modèle « A. Raymond - version 2 », de la société A. Raymond, de code d'agrément « FR 54 » ;

― le modèle « CAPRITAG », de la société Chevillot, de code d'agrément « FR 55 ».

## Article 8

Dans le cadre de l'identification des animaux de l'espèce bovine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de cette espèce, les repères auriculaires de type pendentif-pendentif conventionnel suivants :

― le modèle « Axaflex », de la société Chevillot, de code d'agrément « FR 15 » ;

― le modèle « Allflex », de la société Allflex Europe, de code d'agrément « FR 18 » ;

― le modèle « Ultra », de la société Allflex Europe, de code d'agrément « FR 27 » ;

― le modèle « Reyflex », de la société Reyflex, de code d'agrément « FR 29 » ;

― le modèle « Zeetag Z 3 laser » de la société Zeetag, de code d'agrément « FR 30 ».

## Article 9

Dans le cadre de l'identification des animaux de l'espèce bovine destinés à des événements culturels et sportifs au sens de l'article 1er de l'arrêté du 9 mai 2006, le ministre chargé de l'agriculture agrée le repère auriculaire suivant :

― le modèle « Brassite », de la société Vétal, de code d'agrément « FR 12 ».

## Article 10

Dans le cadre de l'identification électronique des animaux de l'espèce bovine, le ministre chargé de l'agriculture délivre, pour la mise en œuvre des projets qu'il a approuvés, pour les animaux des exploitations qui participent aux tests sur les repères auriculaires de type pendentif/pendentif électronique et dans la limite des besoins pour lesdits tests dans les départements pilotes, un agrément transitoire comme second marquage tel que prévu dans le règlement (CE) n° 911/2004 susvisé, aux repères auriculaires suivants :

Pour la société Reyflex :

― le modèle « ReyFID COMBO », de code d'agrément « FR 40 ».

Pour la société Allflex :

― le modèle « SELECT ULTRA HDX », de code d'agrément « FR 43 ».

## Article 11

L'arrêté du 26 juin 2006, modifié par les arrêtés du 1er août 2006, du 26 octobre 2006, du 3 juillet 2007 et du 24 décembre 2009, portant agrément des marques auriculaires d'identification des animaux des espèces ovine, caprine et bovine est abrogé.

## Article 12

La directrice générale de l'alimentation au ministère de l'alimentation, de l'agriculture et de la pêche et les préfets sont chargés, chacun en ce qui le concerne, de l'application du présent arrêté, qui sera publié au Journal officiel de la République française.
