# Arrêtés du 4 mars 1997 portant homologation de cahiers des charges de labels et agrément d'organismes certificateurs

- Nature : Arrete
- Date du texte : 1997-03-04
- Publication : 1997-03-20
- JO n° : 0067
- NOR : AGRG9700499A
- Ministère : MINISTERE DE L'AGRICULTURE, DE LA PECHE ET DE L'ALIMENTATION
- Origine : JORF n°67 du 20 mars 1997
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000564621

## Article

Par arrêté du ministre de l'agriculture, de la pêche et de l'alimentation et du ministre délégué aux finances et au commerce extérieur en date du 4 mars 1997 :

Sont homologués, pour une période probatoire s'achevant le 30 juin 1997, les cahiers des charges des labels agricoles suivants, détenus par Qualité-Bretagne, immeuble Orchis, Rennes Atalante Apigné, 35650 Le Rheu :

- no 02-75 << poulet noir fermier >> ;

- no 02-82 << poulet blanc fermier >> ;

- no 19-89 << poulet noir fermier surgelé >> ;

- no 14-90 << poulet blanc fermier surgelé >> ;

- no 11-86 << dinde fermière de Noël >> ;

- no 28-88 << chapon fermier >> ;

- no 59-88 << pintade fermière >> ;

- no 14-91 << chapon fermier surgelé >> ;

- no 06-92 << pintade fermière surgelée >> ;

- no 13-92 << poularde fermière >> ;

- no 14-92 << poularde fermière surgelée >> ;

- no 05-94 << dinde fermière à rôtir surgelée >> ;

- no 08-95 << chapon de pintade fermier >> ;

- no 20-88 << porc fermier >> ;

- no 21-89 << porc fermier >> ;

- no 22-89 << veau de boucherie nourri au lait entier >> ;

- no 01-93 << viande bovine de race charolaise >> ;

- no 04-71 << charcuteries, salaisons et conserves de viande de Bretagne >> ;

- no 04-71 << pâté de campagne >> ;

<< pâté de foie >> ;

<< pâté de chair >> ;

<< saucisson cuit >> ;

<< andouillettes >> ;

- no 21-88 << jambon cuit de porc fermier >> ;

- no 39-89 << charcuteries fraîches et cuites de porc fermier >> ;

<< saucisse >> ;

<< saucisse cuite >>.

Ces homologations entreront en vigueur à compter de la date de parution du présent arrêté au Journal officiel.

Les cahiers des charges des labels précités peuvent être consultés au siège de l'organisme certificateur ou au ministère de l'agriculture, de la pêche et de l'alimentation.

Est prolongé, pour une période probatoire s'achevant le 30 juin 1997,

l'agrément de l'organisme certificateur Qualité-Bretagne (no LA 26),

Qualité-Bretagne, immeuble Orchis, Rennes Atalante Apigné, 35650 Le Rheu,

pour la certification de labels agricoles concernant les produits suivants : - << poulet et poulet surgelé >> ;

- << chapon et chapon surgelé >> ;

- << dinde et dinde surgelée >> ;

- << pintade et pintade surgelée >> ;

- << poularde et poularde surgelée >> ;

- << porc fermier >> ;

- << salaisons et conserves de viande >> ;

- << charcuteries fraîches et cuites de porc fermier >> ;

- << viande bovine >> ;

- << veau de boucherie >>.

Cette prolongation de période probatoire d'agrément entrera en vigueur à compter de la date de parution du présent arrêté au Journal officiel.

La certification des cahiers des charges des labels précités est assurée par Qualité-Bretagne (no LA 26).
