# Arrêté du 30 décembre 1996 portant attribution du diplôme de l'Ecole nationale supérieure des officiers de sapeurs-pompiers aux capitaines de sapeurs-pompiers professionnels (promotion interne)

- Nature : Arrete
- Date du texte : 1996-12-30
- Publication : 1997-01-28
- JO n° : 0023
- NOR : INTE9700029A
- Ministère : MINISTERE DE L'INTERIEUR
- Origine : JORF n°23 du 28 janvier 1997
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000746660

## Article

Par arrêté du ministre de l'intérieur en date du 30 décembre 1996, le diplôme de l'Ecole nationale supérieure des officiers de sapeurs-pompiers est décerné aux capitaines de sapeurs-pompiers professionnels (promotion interne) dont les noms suivent :

Blanchard (Michel) (Meurthe-et-Moselle) ;

Daubioul (Guy) (Pas-de-Calais) ;

Daucourt (Lionel) (Seine-et-Marne) ;

Gallina (Jacques) (Savoie) ;

Halter (Alain) (Moselle) ;

Héral (Jean-Pierre) (Haute-Garonne) ;

Kostus (Alain) (Ardennes) ;

Le Guen (Paul) (Ille-et-Vilaine) ;

Mailhe (Alain) (Tarn) ;

Marty (Georges) (Savoie) ;

Métivet (Jean-Paul) (Cher) ;

Montillet (Marc) (Rhône) ;

Parnin (Camille) (Vaucluse) ;

Queguiner (Loïc) (Morbihan) ;

Sabathier (Jean-Claude) (Aveyron) ;

Smith (Patrick) (Creuse) ;

Squillari (Jean-Pierre) (Bouches-du-Rhône) ;

Thiélin (Bernard) (Indre-et-Loire) ;

Vachier (Jacques) (Vaucluse) ;

Vermeulen (Jean-Guy) (Essonne) ;

Viguier (Philippe) (Sarthe).
