# Arrêté du 15 avril 1997 fixant le nombre d'étudiants admis en première année d'études conduisant au diplôme d'Etat d'infirmier

- Nature : Arrete
- Date du texte : 1997-04-15
- Publication : 1997-04-23
- JO n° : 0095
- NOR : TASP9721405A
- Ministère : MINISTERE DU TRAVAIL ET DES AFFAIRES SOCIALES
- Origine : JORF n°95 du 23 avril 1997
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000748727

## Article

Par arrêté du ministre du travail et des affaires sociales en date du 15 avril 1997, le nombre d'étudiants admis à entrer en première année d'études conduisant au diplôme d'Etat d'infirmier pour l'année scolaire 1997-1998 (rentrées de septembre 1997 et de février 1998) est fixé dans les différentes régions comme suit :

Alsace : 506 ;

Aquitaine : 700 ;

Auvergne : 327 ;

Bourgogne : 420 ;

Bretagne : 590 ;

Centre : 621 ;

Champagne-Ardenne : 326 ;

Corse : 36 ;

Franche-Comté : 368 ;

Ile-de-France : 3 604 ;

Languedoc-Roussillon : 539 ;

Limousin : 280 ;

Lorraine : 755 ;

Midi-Pyrénées : 528 ;

Nord - Pas-de-Calais : 1 437 ;

Basse-Normandie : 387 ;

Haute-Normandie : 502 ;

Pays de la Loire : 598 ;

Picardie : 615 ;

Poitou-Charentes : 378 ;

Provence-Alpes-Côte d'Azur : 1 007 ;

Rhône-Alpes : 1 566 ;

Antilles-Guyane : 61 ;

Réunion : 85.
