## Article

Par arrêté du secrétaire d'Etat à l'industrie en date du 22 juillet 1997, la validité du permis exclusif de recherches d'hydrocarbures liquides ou gazeux dit << Permis de Grand-Villandraut >>, attribué par décret du 18 septembre 1991 aux sociétés Texas Crude France et Compagnie et Francep Inc., conjointes et solidaires, est prolongée jusqu'au 24 septembre 1999 sur une superficie de 787 kilomètres carrés environ, portant sur partie des départements de la Gironde et des Landes, compte tenu d'un engagement financier minimal de 12,420 MF.

Conformément à l'extrait de carte au 1/200 000 annexé audit arrêté, le nouveau périmètre de ce permis est constitué par les arcs de méridien et de parallèle joignant successivement les sommets définis ci-après par leurs coordonnées géographiques, le méridien origine étant celui de Paris :

A 3,50 gr 0 49,80 gr N B 3,50 gr 0 49,70 gr N C 3,40 gr 0 49,70 gr N D 3,40 gr 0 49,60 gr N E 3,30 gr 0 49,60 gr N F 3,30 gr 0 49,50 gr N G 3,20 gr 0 49,50 gr N H 3,20 gr 0 49,40 gr N I 3,30 gr 0 49,40 gr N J 3,30 gr 0 49,30 gr N K 3,40 gr 0 49,30 gr N L 3,40 gr 0 49,20 gr N M 3,50 gr 0 49,20 gr N N 3,50 gr 0 49,50 gr N O 3,60 gr 0 49,50 gr N P 3,60 gr 0 49,80 gr N
