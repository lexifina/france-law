# Délibération du 23 mai 2018 relative à une autorisation temporaire

- Nature : Deliberation
- Date du texte : 2018-05-23
- Publication : 2018-07-07
- JO n° : 0155
- NOR : CSAR1818913X
- Origine : JORF n°0155 du 7 juillet 2018

## Article

Par délibération en date du mercredi 23 mai 2018, le comité territorial de l'audiovisuel de Caen a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Papa's Production à diffuser un service de radio par voie hertzienne terrestre dénommé Ouest Track Radio, pour la période du 15 juin au 23 septembre 2018.

Site : 55, rue du 329°-RI, 76620 Le Havre.

Puissance : 20 W.

Fréquence : 95.9 MHz.

RDS Code PI : F3B6.

RDS Code PS : Ouesttra.

---

Fait à Caen, le 23 mai 2018.

Pour le comité territorial de l'audiovisuel de Caen :

Le président,

M. Dufour
