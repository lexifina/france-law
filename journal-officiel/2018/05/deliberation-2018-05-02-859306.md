# Délibération relative à une autorisation temporaire

- Nature : Deliberation
- Publication : 2018-05-02
- JO n° : 0101
- NOR : CSAR1811926X
- Origine : JORF n°0101 du 2 mai 2018
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000036859306

## Article

Par délibération en date du 2 mars 2018, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Stichting Alpes d'HuZes à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Alpe d'HuZes, pour la période du 3 au 8 juin 2018.

Site : L'ALPE D'HUEZ (38).

Puissance : 50 W.

Fréquence : 107,6 MHz.

Code PI : F380.

Code PS : RADIOAD6.
