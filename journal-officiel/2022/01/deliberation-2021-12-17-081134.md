# Délibération du 17 décembre 2021 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2021-12-17
- Publication : 2022-01-28
- JO n° : 0023
- NOR : CSAR2202355X
- Origine : JORF n°0023 du 28 janvier 2022
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000045081134

## Article

Par délibération en date du 17 décembre 2021, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 28 février au 17 juillet 2022.

Site : Saint-Genis-l'Argentière (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : Saint-Symphorien-sur-Coise (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
