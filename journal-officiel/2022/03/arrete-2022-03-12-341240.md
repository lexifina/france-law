# Arrêté du 12 mars 2022 modifiant l'arrêté du 7 juin 2021 identifiant les zones de circulation de l'infection du virus SARS-CoV-2

- Nature : Arrete
- Date du texte : 2022-03-12
- Publication : 2022-03-13
- JO n° : 0061
- NOR : SSAZ2208135A
- Ministère : Ministère des solidarités et de la santé
- Origine : JORF n°0061 du 13 mars 2022
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000045341240

Le ministre des solidarités et de la santé,

Vu le code de la santé publique, notamment ses articles L. 3131-15 et L. 3131-17 ;

Vu la loi n° 2021-689 du 31 mai 2021 modifiée relative à la gestion de la sortie de crise sanitaire ;

Vu le décret n° 2021-699 du 1er juin 2021 modifié prescrivant les mesures générales nécessaires à la gestion de la sortie de crise sanitaire ;

Vu l'arrêté du 7 juin 2021 modifié identifiant les zones de circulation de l'infection du virus SARS-CoV-2,

Arrête :

## Article 1

Le 1° de l'article 1er de l'arrêté du 7 juin 2021 susvisé est ainsi modifié :

1° Après l'alinéa : «-le Bangladesh ; », est inséré l'alinéa suivant :

«-le Belize ; »

2° Après l'alinéa : «-le Bénin ; », sont insérés deux alinéas ainsi rédigés :

«-le Bhoutan ;

«-la Birmanie ; »

3° Après l'alinéa : «-le Botswana ; », sont insérés trois alinéas ainsi rédigés :

«-le Brésil ;

«-le Burkina Faso ;

«-le Burundi ; »

4° Après l'alinéa : «-le Cambodge ; », est inséré l'alinéa suivant :

«-le Cameroun ; »

5° Après l'alinéa : «-les Comores ; », est inséré l'alinéa suivant :

«-le Congo ; »

6° Après l'alinéa : «-Djibouti ; », est inséré l'alinéa suivant :

«-l'Egypte ; »

7° Après l'alinéa : «-l'Eswatini ; », sont insérés deux alinéas ainsi rédigés :

«-les Etats-Unis ;

«-l'Ethiopie ; »

8° Après l'alinéa : «-le Lesotho ; », sont insérés deux alinéas ainsi rédigés :

«-Madagascar ;

«-le Malawi ; »

9° Après l'alinéa : «-la Mauritanie ; », est inséré l'alinéa suivant :

«-le Mozambique ; »

10° Après l'alinéa : «-le Nicaragua ; », sont insérés deux alinéas ainsi rédigés :

«-le Niger ;

«-le Nigeria ; »

11° Après l'alinéa : «-le Pakistan ; », est inséré l'alinéa suivant :

«-le Panama ; »

12° Après l'alinéa : «-le Qatar ; », est inséré l'alinéa suivant :

«-la République démocratique du Congo ; »

13° Après l'alinéa : «-le Sénégal ; », sont insérés trois alinéas ainsi rédigés :

«-les Seychelles ;

«-le Soudan ;

«-le Soudan du Sud ; »

14° Après l'alinéa : «-le Tchad ; », est inséré l'alinéa suivant :

«-le Timor oriental ; »

15° Après l'alinéa : «-le Togo ; », est inséré l'alinéa suivant :

«-la Tunisie ; ».

## Article 2

Le présent arrêté sera publié au Journal officiel de la République française.

Fait le 12 mars 2022.
