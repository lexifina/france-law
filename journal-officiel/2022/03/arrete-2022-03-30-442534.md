# Arrêté du 30 mars 2022 modifiant l'arrêté du 7 juin 2021 identifiant les zones de circulation de l'infection du virus SARS-CoV-2

- Nature : Arrete
- Date du texte : 2022-03-30
- Publication : 2022-03-31
- JO n° : 0076
- NOR : SSAZ2209551A
- Ministère : Ministère des solidarités et de la santé
- Origine : JORF n°0076 du 31 mars 2022
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000045442534

Le ministre des solidarités et de la santé,

Vu le code de la santé publique, notamment ses articles L. 3131-15 et L. 3131-17 ;

Vu la loi n° 2021-689 du 31 mai 2021 modifiée relative à la gestion de la sortie de crise sanitaire ;

Vu le décret n° 2021-699 du 1er juin 2021 modifié prescrivant les mesures générales nécessaires à la gestion de la sortie de crise sanitaire ;

Vu l'arrêté du 7 juin 2021 modifié identifiant les zones de circulation de l'infection du virus SARS-CoV-2,

Arrête :

## Article 1

Le 1° de l'article 1er de l'arrêté du 7 juin 2021 susviséest ainsi modifié :

1° Après l'alinéa : «-l'Afrique du Sud ; », est inséré l'alinéa suivant :

«-l'Albanie ; »

2° Après l'alinéa : «-l'Angola ; », est inséré l'alinéa suivant :

«-Antigua-et-Barbuda ; »

3° Après l'alinéa : «-l'Arabie-Saoudite ; », est inséré l'alinéa suivant :

«-Aruba ; »

4° Après l'alinéa : «-l'Argentine ; », est inséré l'alinéa suivant :

«-l'Azerbaïdjan ; »

5° Après l'alinéa : «-le Bangladesh ; », est inséré l'alinéa suivant :

«-la Barbade ; »

6° Après l'alinéa : «-la Bolivie ; », sont insérés deux alinéas ainsi rédigés :

«-Bonaire, Saint-Eustache et Saba ;

«-la Bosnie-Herzégovine ; »

7° Après l'alinéa : «-le Canada ; », est inséré l'alinéa suivant :

«-le Chili ; »

8° Après l'alinéa : «-la Corée du Sud ; », est inséré l'alinéa suivant :

«-le Costa Rica ; »

9° Après l'alinéa : «-Cuba ; », est inséré l'alinéa suivant :

«-le Curaçao ; »

10° Après l'alinéa : «-le Gabon ; », est inséré l'alinéa suivant :

«-la Gambie ; »

11° Après l'alinéa : «-le Ghana ; », sont insérés trois alinéas ainsi rédigés :

«-Grenade ;

«-le Groenland ;

«-le Guatemala ; »

12° Après l'alinéa : «-Hong Kong ; », est inséré l'alinéa suivant :

«-les Iles Féroé ; »

13° Après l'alinéa : «-l'Ile Maurice ; », est inséré l'alinéa suivant :

«-les Iles Salomon ; »

14° Après l'alinéa : «-les Iles Samoa ; », sont insérés trois alinéas ainsi rédigés :

«-les Iles Turques-et-Caïques ;

«-les Iles Vierges britanniques ;

«-les Iles Vierges des Etats-Unis ; »

15° Après l'alinéa : «-le Japon ; », est inséré l'alinéa suivant :

«-la Jordanie ; ».

16° Après l'alinéa : «-le Kenya ; », sont insérés deux alinéas ainsi rédigés :

«-Kiribati ;

«-le Kosovo ; »

17° Après l'alinéa : «-le Lesotho ; », sont insérés trois alinéas ainsi rédigés :

«-le Liban ;

«-le Liberia ;

«-la Macédoine du Nord ; ».

18° Après l'alinéa : «-Madagascar ; », est inséré l'alinéa suivant :

«-la Malaisie ; »

19° Après l'alinéa : «-le Malawi ; », est inséré l'alinéa suivant :

«-les Maldives ; »

20° Après l'alinéa : «-la Mauritanie ; », sont insérés cinq alinéas ainsi rédigés :

«-le Mexique ;

«-la Moldavie ;

«-la Mongolie ;

«-le Monténégro ;

«-Montserrat ; »

21° Après l'alinéa : «-le Panama ; », est inséré l'alinéa suivant :

«-la Papouasie-Nouvelle-Guinée ; »

22° Après l'alinéa : «-les Philippines ; », est inséré l'alinéa suivant :

«-Porto Rico ; »

23° L'alinéa : «-le Rwanda ; », est remplacé par l'alinéa suivant :

«-la République dominicaine ; »

24° L'alinéa : «-la République dominicaine ; », est remplacé par deux alinéas ainsi rédigés :

«-le Royaume-Uni ;

«-le Rwanda ; »

25° Après l'alinéa : «-Saint-Christophe-et-Niévès ; », sont insérés deux alinéas ainsi rédigés :

«-Sainte Lucie ;

«-Saint-Vincent-et-les-Grenadines ; »

26° Après l'alinéa : «-le Salvador ; », est inséré l'alinéa suivant :

«-Sao Tomé-et-Principe ; »

27° Après l'alinéa : «-le Sénégal ; », est inséré l'alinéa suivant :

«-la Serbie ; »

28° Après l'alinéa : «-le Togo ; », est inséré l'alinéa suivant :

«-Trinité-et-Tobago ; »

29° Après l'alinéa : «-la Tunisie ; », sont insérés trois alinéas ainsi rédigés :

«-la Turquie ;

«-l'Ukraine ;

«-l'Uruguay ; ».

## Article 2

Le présent arrêté sera publié au Journal officiel de la République française.
