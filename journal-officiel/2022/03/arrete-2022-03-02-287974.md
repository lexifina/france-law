# Arrêté du 2 mars 2022 modifiant l'arrêté du 7 juin 2021 identifiant les zones de circulation de l'infection du virus SARS-CoV-2

- Nature : Arrete
- Date du texte : 2022-03-02
- Publication : 2022-03-03
- JO n° : 0052
- NOR : SSAZ2207241A
- Ministère : Ministère des solidarités et de la santé
- Origine : JORF n°0052 du 3 mars 2022
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000045287974

Le ministre des solidarités et de la santé,

Vu le code de la santé publique, notamment ses articles L. 3131-15 et L. 3131-17 ;

Vu la loi n° 2021-689 du 31 mai 2021 modifiée relative à la gestion de la sortie de crise sanitaire ;

Vu le décret n° 2021-699 du 1er juin 2021 modifié prescrivant les mesures générales nécessaires à la gestion de la sortie de crise sanitaire ;

Vu l'arrêté du 7 juin 2021 modifié identifiant les zones de circulation de l'infection du virus SARS-CoV-2,

Arrête :

## Article 1

Le 1° de l'article 1er de l'arrêté du 7 juin 2021 susvisé est ainsi modifié :

1° Après le deuxième alinéa, sont insérés deux alinéas ainsi rédigés :

«-l'Afrique du Sud ;

«-l'Angola ; »

2° Après l'alinéa : «-l'Arabie saoudite ; », sont insérés deux alinéas ainsi rédigés :

«-l'Argentine ;

«-les Bahamas ; »

3° Après l'alinéa : «-Bahreïn ; », sont insérés quatre alinéas ainsi rédigés :

«-le Bangladesh ;

«-le Bénin ;

«-la Bolivie ;

«-le Botswana ; »

4° Après l'alinéa : «-le Cambodge ; », est inséré l'alinéa suivant :

«-le Canada ; »

5° Après l'alinéa : «-la Colombie ; », est inséré l'alinéa suivant :

«-les Comores ; »

6° Après l'alinéa : «-Cuba ; », est inséré l'alinéa suivant :

«-Djibouti ; »

7° Après l'alinéa : «-l'Equateur ; », est inséré l'alinéa suivant :

«-l'Eswatini ; »

8° Après l'alinéa : «-les Iles Samoa ; », est inséré l'alinéa suivant :

«-l'Inde ; »

9° Après l'alinéa : «-l'Indonésie ; », sont insérés deux alinéas ainsi rédigés :

«-l'Irak ;

«-la Jamaïque ; »

10° Après l'alinéa : «-le Japon ; », sont insérés deux alinéas ainsi rédigés :

«-le Kazakhstan ;

«-le Kenya ; »

11° Après l'alinéa : «-le Laos ; », est inséré l'alinéa suivant :

«-le Lesotho ; » ;

12° Après l'alinéa : «-la Mauritanie ; », est inséré l'alinéa suivant :

«-la Namibie ; »

13° Après l'alinéa : «-la Nouvelle-Zélande ; », est inséré l'alinéa suivant :

«-Oman ; »

14° Après l'alinéa : «-l'Ouganda ; », sont insérés quatre alinéas ainsi rédigés :

«-le Pakistan ;

«-le Paraguay ;

«-le Pérou ;

«-les Philippines ; »

15° Après l'alinéa : «-le Rwanda ; », sont insérés trois alinéas ainsi rédigés :

«-la République dominicaine ;

«-Saint-Christophe-et-Niévès ;

«-le Salvador ; »

16° Le 1° est complété par deux alinéas ainsi rédigés :

«-la Zambie ;

«-le Zimbabwe. »

## Article 2

Le présent arrêté sera publié au Journal officiel de la République française.

Fait le 2 mars 2022.
