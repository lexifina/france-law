# Délibération du 3 juin 2022 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2022-06-03
- Publication : 2022-07-07
- JO n° : 0156
- NOR : RCAR2219672X
- Origine : JORF n°0156 du 7 juillet 2022

## Article

Par délibération en date du 3 juin 2022, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 15 août au 31 décembre 2022.

Site : SAINT-GENIS-L'ARGENTIERE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : SAINT-SYMPHORIEN-SUR-COISE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
