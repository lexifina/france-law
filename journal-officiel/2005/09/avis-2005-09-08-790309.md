# Avis de publication de la liste des organismes certificateurs déclarés relative à la certification des produits industriels et des services (art. R. 115-5 du code de la consommation)

- Nature : Avis
- Publication : 2005-09-08
- JO n° : 0209
- NOR : INDI0505671V
- Ministère : MINISTERE DE L'ECONOMIE, DES FINANCES ET DE L'INDUSTRIEINDUSTRIE
- Origine : JORF n°209 du 8 septembre 2005
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000790309

## Article

La liste des organismes certificateurs déclarés parue au Journal officiel de la République française décrite ci-dessous :

ACERBOIS ; ACERMI ; ACQPA ; ADAL ; ADF ; AFAQ AFNOR Certification ; AFAQ-ASCERT international ; AFCAB ; AFG ; AOQC Moody France ; ASQUAL ; AUCERT ; Bureau Veritas SA ; BVQI ; CEBTP ; CEKAL ; CERTIFER ; CERTIQUAL ; CETEHOR ; CNPP ; CSTB ; CTBA ; CTC ; DWS ; ECOCERT SAS ; EXCEL Certification ; FIB ; GQS ; INERIS ; ITR ; Label qualité ; LNE ; LRQA France ; OCMS ; OFC ; OGBTP ; OPHIS ; Phare hôtels ; PROMOTELEC ; QUALITE-FRANCE SA ; QUALITEL ; SGS ICS SAS ; SNJF ; UTAC,

est complétée par un nouvel organisme certificateur, à compter du 29 août 2005, sous l'appellation CERQUAL, 136, boulevard Saint-Germain, 75006 Paris.

Cette publication, qui n'a aucune valeur de reconnaissance officielle, n'engage pas la responsabilité de l'Etat (art. R. 115-5 du code de la consommation).
