# Avis de publication de la liste des organismes certificateurs déclarés relative à la certification des produits industriels et des services (art. R. 115-5 du code de la consommation)

- Nature : Avis
- Publication : 2005-04-05
- JO n° : 0079
- NOR : INDI0504880V
- Ministère : MINISTERE DE L'ECONOMIE, DES FINANCES ET DE L'INDUSTRIEINDUSTRIE
- Origine : JORF n°79 du 5 avril 2005
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000239453

## Article

L'AFAQ-AFNOR Certification, 116, avenue Aristide-Briand, BP 40, 92224 Bagneux Cedex, devient organisme certificateur à compter du 1er janvier 2005 et complète la liste des organismes certificateurs déclarés parue au Journal officiel de la République française, décrite ci-dessous.

L'ensemble des activités de certification de services de l'AFAQ (Association française pour le management et l'amélioration de la qualité) a été transféré, à compter du 1er janvier 2005, à la société par actions simplifiée AFAQ-AFNOR Certification.

Liste des organismes certificateurs déclarés à ce jour :

ACERBOIS ; ACERMI ; ACQPA ; ADAL ; ADF ; AFAQ-ASCERT International ; AFCAB ; AFG ; AFNOR Certification ; AOQC Moody France ; ASQUAL ; AUCERT ; bureau Veritas SA ; BVQI ; CEBTP ; CEKAL ; CERTIFER ; CERTIQUAL ; CETEHOR ; CNPP ; CSTB ; CTBA ; CTC ; DWS ; ECOCERT SAS ; Excel Certification ; FIB ; GQS ; INERIS ; ITR ; Label qualité ; LNE ; OCMS ; OFC ; OGBTP ; OPHIS ; PHARE Hôtels ; PROMOTELEC ; Qualité-France SA ; QUALITEL ; SGS ICS SAS ; SNJF ; UTAC.

Cette publication, qui n'a aucune valeur de reconnaissance officielle, n'engage pas la responsabilité de l'Etat.
