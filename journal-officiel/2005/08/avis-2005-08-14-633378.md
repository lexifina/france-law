# Avis de publication de la liste des organismes certificateurs déclarés relative à la certification des produits industriels et des services (art. R. 115-5 du code de la consommation)

- Nature : Avis
- Publication : 2005-08-14
- JO n° : 0189
- NOR : INDI0505430V
- Ministère : MINISTERE DE L'ECONOMIE, DES FINANCES ET DE L'INDUSTRIEINDUSTRIE
- Origine : JORF n°189 du 14 août 2005
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000633378

## Article

La liste des organismes certificateurs déclarés parue au Journal officiel de la République française, décrite ci-dessous :

ACERBOIS ; ACERMI ; ACQPA ; ADAL ; ADF ; AFAQ-AFNOR Certification ; AFAQ-ASCERT International ; AFCAB ; AFG ; AOQC MOODY France ; ASQUAL ; AUCERT ; Bureau VERITAS SA ; BVQI ; CEBTP ; CEKAL ; CERTIFER ; CERTIQUAL ; CETEHOR ; CNPP ; CSTB ; CTBA ; CTC ; DWS ; ECOCERT SAS ; Excel Certification ; FIB ; GQS ; INERIS ; ITR ; Label Qualité ; LNE ; OCMS ; OFC ; OGBTP ; OPHIS ; PHARE Hôtels ; PROMOTELEC ; Qualité-France SA ; QUALITEL ; SGS ICS SAS ; SNJF ; UTAC,

est complétée par un nouvel organisme certificateur, à compter du 8 juillet 2005, sous l'appellation :

LRQA France, tour Société suisse, 1, boulevard Vivier-Merle, 69003 Lyon.

Cette publication, qui n'a aucune valeur de reconnaissance officielle, n'engage pas la responsabilité de l'Etat (art. R. 115-5 du code de la consommation).
