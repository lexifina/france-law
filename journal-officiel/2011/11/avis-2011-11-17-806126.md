# Avis relatif aux jeux de loterie instantanée de La Française des jeux

- Nature : Avis
- Publication : 2011-11-17
- JO n° : 0266
- NOR : BCRZ1199132V
- Ministère : Ministère du budget, des comptes publics et de la réforme de l'Etat
- Origine : JORF n°0266 du 17 novembre 2011
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000024806126

## Article

L'émission n° 02, code jeu 477, des tickets du jeu « Cash 500 000 € » ;

L'émission n° 01, code jeu 501, des tickets du jeu « Crescendo » ;

L'émission n° 01, code jeu 502, des tickets du jeu « XV de France » ;

L'émission n° 01, code jeu 503, des tickets du jeu « Poker » ;

L'émission n° 01, code jeu 499, des tickets du jeu « Roland Garros »,

L'émission n° 05, code jeu 451, des tickets du jeu « Dédé » ;

L'émission n° 03, code jeu 430, des tickets du jeu « Goal », et

L'émission n° 01, code jeu 452, des tickets du jeu « Banco Plus »,

sont clôturées le 25 novembre 2011.

En conséquence, le droit de revendication des lots au titre de ces émissions pourra s'exercer jusqu'au dimanche 25 décembre 2011 inclus.
