# Avis relatif aux jeux de loterie instantanée de La Française des jeux

- Nature : Avis
- Publication : 2011-09-21
- JO n° : 0219
- NOR : BCRZ1199111V
- Ministère : Ministère du budget, des comptes publics et de la réforme de l'Etat
- Origine : JORF n°0219 du 21 septembre 2011
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000024574949

## Article

L'émission n° 01, code jeu 488, des tickets du jeu « Banco Plus » ;

L'émission n° 02, code jeu 478, des tickets du jeu « 2011 Année de rêve » ;

L'émission n° 01, code jeu 444, des tickets du jeu « Vegas » ;

L'émission n° 01, code jeu 429, des tickets du jeu « Goal » ;

L'émission n° 01, code jeu 431, des tickets du jeu « Morpion » ;

L'émission n° 03, code jeu 451, des tickets du jeu « Dédé », et

L'émission n° 01, code jeu 401, des tickets du jeu « Bingo »,

sont clôturées le 30 septembre 2011.

En conséquence, le droit de revendication des lots au titre de ces émissions pourra s'exercer jusqu'au dimanche 30 octobre 2011 inclus.
