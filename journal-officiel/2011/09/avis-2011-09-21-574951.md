# Avis relatif aux jeux de loterie instantanée de La Française des jeux

- Nature : Avis
- Publication : 2011-09-21
- JO n° : 0219
- NOR : BCRZ1199112V
- Ministère : Ministère du budget, des comptes publics et de la réforme de l'Etat
- Origine : JORF n°0219 du 21 septembre 2011
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000024574951

## Article

L'émission n° 03, code jeu 397, des tickets du jeu « Numéro Fétiche » ;

Les émissions n°s 01 à 08, code jeu 443, des tickets du jeu « 7 Extra » ;

L'émission n° 01, code jeu 493, des tickets du jeu « Vegas Brandon & Brenda » ;

L'émission n° 01, code jeu 459, des tickets du jeu « Black Jack » ;

L'émission n° 01, code jeu 433, des tickets du jeu « Astro » ;

L'émission n° 02, code jeu 430, des tickets du jeu « Goal », et

L'émission n° 04, code jeu 451, des tickets du jeu « Dédé »,

sont clôturées le 28 octobre 2011.

En conséquence, le droit de revendication des lots au titre de ces émissions pourra s'exercer jusqu'au dimanche 27 novembre 2011 inclus.
