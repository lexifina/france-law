# Arrêté du 16 mars 1993 fixant le nombre d'élèves admis à entreprendre des études de masso-kinésithérapie en application de l'article L. 510-9 du code de la santé

- Nature : Arrete
- Date du texte : 1993-03-16
- Publication : 1993-03-27
- JO n° : 73
- NOR : SANP9300872A
- Origine : JORF n°73 du 27 mars 1993
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000361710

## Article

Par arrêté du ministre de la santé et de l’action humanitaire en date du 16 mars 1993, le nombre d’élèves admis à entrer en première année d’études préparatoires au diplôme d’Etat de masseur-kinésithérapeute (session de 1992) est fixé comme suit (compte non tenu des écoles pour déficients visuels) :

Alsace : 59 ;

Aquitaine : 35 ;

Auvergne : 44 ;

Bourgogne : 32 ;

Bretagne : 68 ;

Centre : 25 ;

Franche-Comté : 18 ;

Ile-de-France : 454 ;

Languedoc-Roussillon : 60 ;

Limousin : 20 ;

Lorraine : 62 ;

Midi-Pyrénées : 67 ;

Nord - Pas-de-Calais : 147 ;

Haute-Normandie : 28 ;

Pays de la Loire : 73 ;

Picardie : 30 ;

Poitou-Charentes : 23 ;

Provence-Alpes-Côte d’Azur : 96 ;

Rhône-Alpes : 125.
