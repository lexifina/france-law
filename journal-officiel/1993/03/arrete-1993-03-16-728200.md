# Arrêté du 16 mars 1993 fixant le nombre d'étudiants admis en première année d'études préparatoires au diplôme d'Etat d'infirmier et d'infirmière

- Nature : Arrete
- Date du texte : 1993-03-16
- Publication : 1993-03-27
- JO n° : 73
- NOR : SANP9300870A
- Origine : JORF n°73 du 27 mars 1993
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000728200

## Article

Par arrêté du ministre de la santé et de l’action humanitaire en date du 16 mars 1993, le nombre d’étudiants admis à entrer en première année d’études préparatoires au diplôme d’Etat d’infirmier et d’infirmière pour l’année 1993-1994 (rentrées septembre 1993 et février 1994) est fixé dans les différentes régions comme suit :

Alsace : 619 ;

Aquitaine : 800 ;

Auvergne : 384 ;

Basse-Normandie : 435 ;

Bourgogne : 498 ;

Bretagne : 650 :

Centre : 660 ;

Champagne-Ardenne : 420 ;

Corse : 60 ;

Franche-Comté : 470 ;

Haute-Normandie : 540 ;

Ile-de-France : 4 500 ;

Languedoc-Roussillon : 660 ;

Limousin : 334 ;

Lorraine : 914 ;

Midi-Pyrénées : 708 ;

Nord-Pas-de-Calais : 1 300 ;

Pays de la Loire : 657 ;

Picardie : 595 ;

Poitou-Charentes : 450 ;

Provence-Alpes-Côte d’Azur : 1 235 ;

Rhône-Alpes : 1 700 ;

Antilles-Guyane : 65 ;

Réunion : 90.
