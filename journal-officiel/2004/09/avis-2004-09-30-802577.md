## Article

Les Editions du point vétérinaire, sises 9, rue Alexandre, BP 233, 94702 Maisons-Alfort Cedex (téléphone : 01-45-17-02-25, fax : 01-45-17-02-74), et identifiées sous le code PV ;

La société Berger-Levrault éditions, sise 3, rue Ferrus, 75014 Paris (téléphone : 01-40-64-42-32, fax : 01-40-64-42-30), et identifiée sous le code BL.
