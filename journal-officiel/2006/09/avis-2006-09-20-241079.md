# Avis de publication de la liste des organismes certificateurs déclarés relative à la certification des produits industriels et des services (art. R. 115-5 du code de la consommation)

- Nature : Avis
- Publication : 2006-09-20
- JO n° : 0218
- NOR : INDI0608298V
- Ministère : MINISTERE DE L'ECONOMIE, DES FINANCES ET DE L'INDUSTRIEINDUSTRIE
- Origine : JORF n°218 du 20 septembre 2006
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000241079

## Article

La liste des organismes certificateurs déclarés parue au Journal officiel de la République française, décrite ci-dessous :

ACERBOIS ; ACERMI ; ACQPA ; ADAL ; ADF ; AFAQ AFNOR Certification ; AFAQ-ASCERT International ; AFCAB ; AFG ; AOQC Moody France ; ASQUAL-AUCERT ; Bureau Veritas SA ; BVQI ; CEBTP ; CEKAL ; CERQUAL ; CERTIFER ; CERTIQUAL ; CETEHOR ; CNPP ; CSTB ; CTBA ; CTC ; DWS ; ECOCERT SAS ; Excel Certification ; FIB ; GQS ; INERIS ; ITR ; Label Qualité ; LNE ; LRQA France ; OCMS ; OFC ; OGBTP ; OPHIS ; Phare Hôtels ; PROMOTELEC ; Qualité-France SA ; QUALITEL ; SGS ICS SAS ; SNJF ; UTAC,

est complétée par un nouvel organisme certificateur à compter du 8 septembre 2006 sous l'appellation :

CERTISUD : 6, avenue Louis-Sallenave, 64000 Pau.

Cette publication, qui n'a aucune valeur de reconnaissance officielle, n'engage pas la responsabilité de l'Etat (art. R. 115-5 du code de la consommation).
