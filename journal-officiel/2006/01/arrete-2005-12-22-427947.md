# Arrêté du 22 décembre 2005 portant agrément des marques auriculaires d'identification des animaux des espèces ovine, caprine et bovine

- Nature : Arrete
- Date du texte : 2005-12-22
- Publication : 2006-01-18
- JO n° : 0015
- NOR : AGRG0600030A
- Ministère : MINISTERE DE L'AGRICULTURE ET DE LA PECHE
- Origine : JORF n°15 du 18 janvier 2006
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000427947

Le ministre de l'agriculture et de la pêche,

Vu le code rural ;

Vu le règlement n° 21/2004/CE du Conseil du 17 décembre 2003 établissant un système d'identification des animaux des espèces ovine et caprine et modifiant le règlement (CE) n° 1782/2003 et les directives 92/102/CEE et 64/432/CEE ;

Vu le règlement (CE) n° 911/2004 de la Commission du 29 avril 2004 portant disposition d'exécution du règlement (CE) n° 1760/2000 du Parlement européen et du Conseil en ce qui concerne les marques auriculaires, les passeports et les registres d'exploitation ;

Vu le règlement (CE) n° 1760/2000 du Parlement européen et du Conseil du 17 juillet 2000 établissant un système d'identification et d'enregistrement des bovins et concernant l'étiquetage de la viande bovine et les produits à base de viande bovine, et abrogeant le règlement (CE) n° 820/97 du Conseil ;

Vu l'arrêté du 3 septembre 1998 relatif aux modalités d'identification du cheptel bovin ;

Vu l'arrêté du 19 décembre 2005 relatif à l'identification des animaux des espèces ovine et caprine,

Arrête :

## Article 1

Dans le cadre de l'identification des animaux des espèces ovine et caprine, le ministre chargé de l'agriculture agrée, pour l'identification des animaux de ces espèces destinés à être abattus avant l'âge de deux mois et pour une durée de sept mois à compter de la date de parution du présent arrêté, les repères auriculaires de type barrette rigide suivants :

- le modèle « Tiptag », de la société Chevillot, de code d'agrément « FR 50 » ;

- le modèle « Ovibag », de la société Néodis, de code d'agrément « FR 51 » ;

- le modèle « Reytag », de la société Reyflex, de code d'agrément « FR 52 ».

## Article 2

Dans le cadre de l'identification des animaux des espèces ovine et caprine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de ces espèces et pour une durée de sept mois à compter de la date de parution du présent arrêté, les repères auriculaires de type pendentif suivants :

Pour la société Reyflex :

- la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « Supermini » de code d'agrément « FR 85 » ;

- la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « Mini » de code d'agrément « FR 86 » ;

- la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « MPLC » de code d'agrément « FR 83 » ;

- la combinaison suivante : partie femelle « Supermini » de code d'agrément « FR 85 » et partie mâle « MG » de code d'agrément « FR 84 ».

Pour la société Néodis Elvagri :

La combinaison suivante : partie femelle « Oviflex » de code d'agrément « FR 87 » et partie mâle « Oviflex » de code d'agrément « FR 87 ».

Pour la société Chevillot :

- la combinaison suivante : partie femelle « Axaflex Ovina » de code d'agrément « FR 91 » et partie mâle « Axaflex Ovina » de code d'agrément « FR 91 » ;

- la combinaison suivante : partie femelle « Axaflex Ovina » de code d'agrément « FR 91 » et partie mâle « Axaflex Couple 16 » de code d'agrément « FR 92 » ;

- la combinaison suivante : partie femelle « Axaflex Ovina » de code d'agrément « FR 91 » et partie mâle « Junior » de code d'agrément « FR 95 » ;

- la combinaison suivante : partie femelle « Axaflex Ovina » de code d'agrément « FR 91 » et partie mâle « Senior » de code d'agrément « FR 96 » ;

- la combinaison suivante : partie femelle « Axaflex Couple 16 » de code d'agrément « FR 92 » et partie mâle « Axaflex Couple 16 » de code d'agrément « FR 92 » ;

- la combinaison suivante : partie femelle « Axaflex Couple 16 » de code d'agrément « FR 92 » et partie mâle « Axaflex Ovina » de code d'agrément « FR 91 » ;

- la combinaison suivante : partie femelle « Axaflex Couple 16 » de code d'agrément « FR 92 » et partie mâle « Junior » de code d'agrément « FR 95 » ;

- la combinaison suivante : partie femelle « Axaflex Couple 16 » de code d'agrément « FR 92 » et partie mâle « Senior » de code d'agrément « FR 96 ».

## Article 3

Dans le cadre de l'identification des animaux des espèces ovine et caprine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de ces espèces et pour une durée de sept mois à compter de la date de parution du présent arrêté, les repères auriculaires de type barrette souple suivants :

- le modèle « Strip Tag », de la société AGID, de code d'agrément « FR 64 » ;

- le modèle « Cheviflex », de la société Chevillot, de code d'agrément « FR 60 ».

## Article 4

Dans le cadre de l'identification des animaux de l'espèce ovine de race « Mouton d'Ouessant » et « Soay » et les animaux de l'espèce caprine dont la hauteur au garrot à l'âge adulte ne dépasse pas 55 centimètres, le ministre chargé de l'agriculture agrée les repères auriculaires suivants :

- le modèle « Brassite petit modèle aluminium », de la société Vétal, de code d'agrément « FR 82 » ;

- le modèle « Quick », de la société Chevillot, de code d'agrément « FR 81 ».

## Article 5

Dans le cadre de l'identification des animaux de l'espèce bovine, le ministre chargé de l'agriculture agrée, pour l'identification de tous les animaux de cette espèce, les repères auriculaires suivants :

- le modèle « Axaflex », de la société Chevillot, de code d'agrément « FR 15 » ;

- le modèle « Allflex », de la société Allflex Europe, de code d'agrément « FR 18 » ;

- le modèle « Ultra », de la société Allflex Europe, de code d'agrément « FR 27 » ;

- le modèle « Reyflex », de la société Reyflex, de code d'agrément « FR 29 ».

## Article 6

Dans le cadre de l'identification des animaux de l'espèce bovine destinés à des événements culturels et sportifs au sens de l'article 1er de l'arrêté du 3 septembre 1998 susvisé, le ministre chargé de l'agriculture agrée le repère auriculaire suivant :

- le modèle « Brassite », de la société Vétal, de code d'agrément « FR 12 ».

## Article 7

Dans le cadre de l'identification des animaux de l'espèce bovine, le ministre chargé de l'agriculture délivre, pour l'identification de tous les animaux de cette espèce et dans la limite annuelle de 20 % des besoins d'un département, un agrément provisoire au repère auriculaire suivant :

- le modèle « Z3 », de la société AGID, de code d'agrément provisoire « FR 30 ».

## Article 8

La directrice générale de l'alimentation au ministère de l'agriculture et de la pêche et les préfets sont chargés, chacun en ce qui le concerne, de l'exécution du présent arrêté, qui sera publié au Journal officiel de la République française.

---

Fait à Paris, le 22 décembre 2005.
