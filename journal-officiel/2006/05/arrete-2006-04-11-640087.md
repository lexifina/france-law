## Article

Par arrêtés du ministre de l'agriculture et de la pêche en date du 11 avril 2006, les organismes ci-dessous sont reconnus en qualité d'organisation de producteurs.

Elevage bovin

Société d'intérêt collectif agricole Bretagne Viande Bio

« SICA BVB » (Morbihan)

La société d'intérêt collectif agricole Bretagne Viande Bio « SICA BVB », dont le siège social est situé au Faouët (Morbihan), est reconnue en qualité d'organisation de producteurs dans le secteur des bovins certifiés issus de l'agriculture biologique sous le numéro 56-04-2225, à compter du 1er février 2006, sur la zone de reconnaissance suivante :

- la région Bretagne ;

- le canton de Blain (Loire-Atlantique) ;

- le canton de Derval (Loire-Atlantique) ;

- le canton de Guémené-Penfao (Loire-Atlantique) ;

- le canton de Nozay (Loire-Atlantique) ;

- le canton de Rougé (Loire-Atlantique) ;

- le canton de Mortain (Manche) ;

- le canton de Saint-Hilaire-du-Harcouët (Manche) ;

- le canton de Saint-James (Manche) ;

- le canton de Loiron (Mayenne).

Aviculture

Société coopérative agricole « Poitou Lapins »

(Deux-Sèvres)

La société coopérative agricole « GRELAP », reconnue en qualité d'organisation de producteurs dans le secteur des lapins de chair, dont le siège social est situé à Bressuire (Deux-Sèvres), prend la dénomination « Poitou Lapins ».

A compter du 8 avril 2006, la coopérative est reconnue sous le numéro 79-64-1408 sur la zone de reconnaissance suivante :

- le département d'Indre-et-Loire ;

- le département de Maine-et-Loire ;

- le département de la Mayenne ;

- le département de la Sarthe ;

- le département des Deux-Sèvres ;

- le département de la Vienne ;

- le canton de La Châtaigneraie (Vendée) ;

- le canton de Fontenay-le-Comte (Vendée) ;

- le canton de Maillezais (Vendée) ;

- le canton de Pouzauges (Vendée) ;

- le canton de Sainte-Hermine (Vendée) ;

- le canton de Saint-Hilaire-des-Loges (Vendée) ;

- le canton de Chantonnay (Vendée) ;

- le canton des Essarts (Vendée) ;

- le canton des Herbiers (Vendée) ;

- le canton de Mortagne-sur-Sèvre (Vendée) ;

- le canton de Saint-Fulgent (Vendée).
