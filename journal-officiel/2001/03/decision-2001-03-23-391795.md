## Article

Peugeot, Citroën Automobiles SA, Hagondange (57) ;

Marant Maxime, Narbonne (11) ;

Helilagon, Saint-Paul (97) ;

Atofina, Jarrie (38) ;

Mairie du Barcarès (66) ;

Hervé, Rambouillet (78) ;

Société assistance gardiennage, Mahault (97) ;

Coopérateurs Normandie Picardie, Le Grand-Quevilly (76) ;

SARL Centurions, Vaulx-en-Velin (69) ;

SAEP, Paris (75) ;

Compagnie générale des eaux, Toul (54) ;

Direction des services pénitentiaires de Paris, Orléans (45) ;

Total Gaz SNC, Hauconcourt (57) ;

Carrefour France SA, Quetigny (21) ;

Semeva, Aix-en-Provence (13) ;

Mairie de Cavaillon (84) ;

Paris Saint-Germain Football, Paris (75) ;

Crystal Holidays France, Saint-Bon-Tarentaise (73) ;

ISS France, Morzine (74).

Les fréquences qui leur sont attribuées sont consultables sur le site internet de l'Autorité : www.art.telecom.fr.
