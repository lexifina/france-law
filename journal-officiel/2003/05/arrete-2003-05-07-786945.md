# Arrêté du 7 mai 2003 fixant le nombre d'étudiants admis en première année d'études préparatoires au diplôme d'Etat d'infirmier

- Nature : Arrete
- Date du texte : 2003-05-07
- Publication : 2003-05-15
- JO n° : 0112
- NOR : SANP0321650A
- Ministère : MINISTERE DE LA SANTE, DE LA FAMILLE ET DES PERSONNES HANDICAPEES
- Origine : JORF n°112 du 15 mai 2003
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000786945

## Article

Par arrêté du ministre de la santé, de la famille et des personnes handicapées en date du 7 mai 2003, le nombre d'étudiants admis à entrer en première année d'études préparatoires au diplôme d'Etat d'infirmier pour l'année scolaire 2003-2004 (rentrées de septembre 2003 et de février 2004) est fixé dans les différentes régions comme suit :

Alsace : 885 ;

Aquitaine : 1 375 ;

Auvergne : 610 ;

Bourgogne : 800 ;

Bretagne : 1 200 ;

Centre : 1 137 ;

Champagne-Ardenne : 632 ;

Corse : 120 ;

Franche-Comté : 570 ;

Ile-de-France : 6 540 ;

Languedoc-Roussillon : 960 ;

Limousin : 480 ;

Lorraine : 1 400 ;

Midi-Pyrénées : 855 ;

Nord - Pas-de-Calais : 2 600 ;

Basse-Normandie : 702 ;

Haute-Normandie : 930 ;

Pays de la Loire : 1 200 ;

Picardie : 1 161 ;

Poitou-Charentes : 730 ;

Provence-Alpes-Côte d'Azur : 1 740 ;

Rhône-Alpes : 2 880 ;

Guadeloupe : 122 ;

Guyane : 50 ;

Martinique : 84 ;

Réunion : 220 ;

Mayotte : 17.
