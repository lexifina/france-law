## Article

Par décision de la ministre de la défense en date du 7 février 2003 :

1. Les vingt-cinq chefs d'escadron de gendarmerie dont les noms suivent sont déclarés admis par ordre de mérite à suivre le cycle d'enseignement 2003-2004 du collège interarmées de défense :

Arviset (Bruno, Michel, Marie) ;

Hubscher (Edouard) ;

Lettermann (Jean-Valéry) ;

Bitouzet (Laurent, Jean, Marie) ;

Blériot (Nicolas, Henri) ;

Ducept (Xavier, Jean-Marie) ;

François (Bertrand, Michel) ;

Bonneval (Frédéric, Didier) ;

Dumez (Yves, Pierre) ;

Bonneau (Hubert, Charles, Aimé) ;

Guichard (Philippe) ;

Guérin (Jean-Philippe) ;

Brice (Francis, Louis, Eugène) ;

Mabrier (Patrick, Jean-Louis) ;

De Tarle (Marc, Henri, Marie) ;

Gleyzon (Joël, Georges) ;

Saulnier (Frédéric) ;

Teissier (Jean-Marc, François) ;

Razafindranaly (Jacques, Aimé) ;

Kletzel (Philippe, René, Gaston) ;

Poveda (Christian, Claude) ;

Grandi (Fabrice, Dominique) ;

Fohrer (Régis, Ronald, Léon) ;

Cédé (Jean-Michel, Richard) ;

Rémond (Didier, Pierre).

2. Les chefs d'escadron de gendarmerie dont les noms suivent sont inscrits sur la liste complémentaire d'admission et sont susceptibles, dans l'ordre de leur classement, d'être admis à suivre le cycle d'enseignement 2003-2004 du collège interarmées de défense, en cas de vacances éventuelles :

Delapierre (Philippe, Raphaël) ;

Ignatovitch (Etienne, Jacques).
