dispositions de l'article R. 5121-123du code de la santé publique

Spécialité dénommée : ARIMIDEX 1 mg, comprimé pelliculé ; code identifiant de spécialité : 6 803 175 3.

Pays de provenance : Italie.

BB FARMA SRL.

Composition : anastrozole 1,00 mg, pour un comprimé. ― Code(s) identifiant(s) de présentation : 490 175-7 ou 34009 490 175 7 7 : 28 comprimés sous plaquettes thermoformées (PVC-aluminium).

Date de la décision d'autorisation d'importation parallèle : 18 février 2013.
