# Arrêté du 13 décembre 2000 modifiant les taux de cotisation des employeurs de main-d'oeuvre docker à la Caisse nationale de garantie des ouvriers dockers

- Nature : Arrete
- Date du texte : 2000-12-13
- Publication : 2000-12-20
- JO n° : 0294
- NOR : EQUK0001962A
- Ministère : MINISTERE DE L'EQUIPEMENT, DES TRANSPORTS ET DU LOGEMENT
- Origine : JORF n°294 du 20 décembre 2000
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000587530

Le ministre de l'économie, des finances et de l'industrie, la ministre de l'emploi et de la solidarité et le ministre de l'équipement, des transports et du logement,

Vu le code des ports maritimes, et notamment ses articles L. 521-6 et R. 521-5 ;

Vu l'arrêté du 16 juin 2000 modifiant les taux de cotisation des employeurs de main-d'oeuvre docker à la Caisse nationale de garantie des ouvriers dockers ;

Vu la consultation des bureaux centraux de la main-d'oeuvre ;

Vu l'avis du conseil d'administration de la Caisse nationale de garantie des ouvriers dockers du 19 octobre 2000 ;

Sur proposition du président de la Caisse nationale de garantie des ouvriers dockers du 20 octobre 2000,

Arrêtent :

## Article

## Article

Art. 1er. - Les taux de la cotisation versée à la Caisse nationale de garantie des ouvriers dockers et due par les employeurs de dockers professionnels intermittents et de dockers occasionnels, afin d'assurer l'équilibre financier des comptes ouverts par ladite caisse pour chaque bureau central de la main-d'oeuvre visé à l'article L. 521-6, sont modifiés comme suit :

Ajaccio : 0 % ;

Bastia : 8 % ;

Bayonne : 0 % ;

Bordeaux-Le Verdon : 0 % ;

Boulogne : 0 % ;

Brest : 3 % ;

Caen : 0 % ;

Calais : 0 % ;

Cherbourg : 0 % ;

Concarneau : 0 % ;

Dieppe : 0 % ;

Douarnenez : 6 % ;

Dunkerque : 0 % ;

Fécamp : 0 % ;

Le Havre : 0 % ;

Honfleur : 0 % ;

Lorient : 15 % ;

Marseille-Est : 3 % ;

Marseille-Ouest : 7 % ;

Nantes : 1,50 % ;

Nice : 0 % ;

Port-la-Nouvelle : 0 % ;

Port-Vendres : 0 % ;

La Rochelle : 0 % ;

Roscoff : 0 % ;

Rouen : 4,50 % ;

Saint-Malo : 0 % ;

Saint-Nazaire : 3 % ;

Sète : 0 % ;

Toulon : 0 % ;

Le Tréport : 0 %.

## Article

Art. 2. - L'arrêté du 16 juin 2000 relatif au même objet est abrogé.

## Article

Art. 3. - Ces taux sont applicables à compter du 1er janvier 2001.

## Article

Art. 4. - Le directeur du transport maritime, des ports et du littoral, la déléguée générale à l'emploi et à la formation professionnelle et la directrice du budget sont chargés, chacun en ce qui le concerne, de l'exécution du présent arrêté, qui sera publié au Journal officiel de la République française.
