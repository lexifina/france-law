# Délibération du 18 décembre 2020 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2020-12-18
- Publication : 2021-01-19
- JO n° : 0016
- NOR : CSAR2101227X
- Origine : JORF n°0016 du 19 janvier 2021
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000043005625

## Article

Par délibération en date du 18 décembre 2020, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 1er mars au 11 juillet 2021.

Site : Saint-Genis-l'Argentière (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : Saint-Symphorien-sur-Coise (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
