## Article

Par arrêté du ministre de l'intérieur en date du 20 septembre 2021, le décret du 7 octobre 2004 fixant l'étendue des zones et les servitudes applicables au voisinage de centres radioélectriques contrôlés par le ministère de l'intérieur, de la sécurité intérieure et des libertés locales pour la protection des réceptions radioélectriques contre les perturbations électromagnétiques, est abrogé pour les centres de :

- Prix-lès-Mézières - CODIS 08 (Ardennes, code ANFR : 008 014 0056) ;

- Bogny-sur-Meuse-La Robillarde (Ardennes, code ANFR : 008 014 0066) ;

- Revin-Mont-Malgré-Tout (Ardennes, code ANFR : 008 014 0002) ;

- Aubrives-Mont-des-Haies (Ardennes, code ANFR : 008 014 0067).
