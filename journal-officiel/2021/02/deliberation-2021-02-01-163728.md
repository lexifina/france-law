# Délibération du 1er février 2021 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2021-02-01
- Publication : 2021-02-21
- JO n° : 0045
- NOR : CSAR2105844X
- Origine : JORF n°0045 du 21 février 2021
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000043163728

## Article

Par délibération en date du 1er février 2021, le comité territorial de l'audiovisuel de Clermont-Ferrand a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association La radio associative Argentat Corrèze Xaintrie à diffuser un service de radio par voie hertzienne terrestre dénommé ACX, pour la période du 1er mars au 30 septembre 2021.

Site : Le château d'eau, Lieu-dit Longour, 19400 Argentat-sur-Dordogne.

Puissance : 100 W.

Fréquence : 107.5 MHz.

RDS CODE PI : F3F3.

RDS CODE PS : ACX 19

Site : Rue du Puy du bassin, 19220 Saint-Privat.

Puissance : 50 W.

Fréquence : 98.7 MHz.

RDS CODE PI : F3F3.

RDS CODE PS : ACX 19.

---

Fait à Clermont-Ferrand, le 1er février 2021.
