# Délibération du 22 novembre 2021 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2021-11-22
- Publication : 2021-12-16
- JO n° : 0292
- NOR : CSAR2137138X
- Origine : JORF n°0292 du 16 décembre 2021
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000044501890

## Article

Par délibération en date du 22 novembre 2021, le comité territorial de l'audiovisuel de Clermont-Ferrand a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association La radio associative Argentat Corrèze Xaintrie à diffuser un service de radio par voie hertzienne terrestre dénommé ACX, pour la période du 6 décembre 2021 au 6 juillet 2022.

Site : le château d'eau, lieu-dit Longour, 19400 Argentat-sur-Dordogne.

Puissance : 100 W.

Fréquence : 107,5 MHz.

RDS CODE PI : F3F3.

RDS CODE PS : ACX 19.

Site : rue du Puy-du-Bassin, 19220 Saint-Privat.

Puissance : 50 W.

Fréquence : 98,7 MHz.

RDS CODE PI : F3F3.

RDS CODE PS : ACX 19.

---

Fait à Clermont-Ferrand, le 22 novembre 2021.
