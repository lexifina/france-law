# Avis de vacance d'un emploi de directeur de projet (administration territoriale : région Hauts-de-France) (modificatif)

- Nature : Avis
- Publication : 2021-07-28
- JO n° : 0173
- NOR : PRMG2123247V
- Ministère : Premier ministre
- Origine : JORF n°0173 du 28 juillet 2021
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000043862828

## Article

L'avis de vacance d'un emploi de directeur de projet (administration territoriale : région Hauts-de-France) publié au Journal officiel de la République française du 24 juillet 2021, texte n° 92, est modifié comme suit :

Dans le paragraphe : « conditions d'emploi », les mots : « cet emploi est classé dans le groupe III » sont remplacés par les mots : « cet emploi est classé dans le groupe II ».
