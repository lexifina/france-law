# Délibération du 28 mai 2021 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2021-05-28
- Publication : 2021-06-25
- JO n° : 0146
- NOR : CSAR2119101X
- Origine : JORF n°0146 du 25 juin 2021
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000043699970

## Article

Par délibération en date du 28 mai 2021, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 16 août au 31 décembre 2021.

Site : SAINT-GENIS-L'ARGENTIERE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : SAINT-SYMPHORIEN-SUR-COISE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
