# Décision n° 2008-0517 du 22 avril 2008 fixant les conditions techniques d'utilisation des fréquences par les systèmes de radiocommande de modèles réduits (rectificatif)

- Nature : Decision
- Numéro : 2008-0517
- Date du texte : 2008-04-22
- Publication : 2009-04-11
- JO n° : 0086
- NOR : ARTL0800045Z
- Origine : JORF n°0086 du 11 avril 2009

## Article

Rectificatif au Journal officiel du 16 septembre 2008, édition électronique, texte n° 82, l'annexe est modifiée comme suit :

Dans le 1er tableau « Spécification d'interface radioélectrique », à la 4e ligne « Type d'application » :

Au lieu de : « Systèmes de radiocommande de modèles réduits aériens. Flying Model control. »,

Lire : « Systèmes de radiocommande de modèles réduits. Model control. ».

Dans le 4e tableau « Spécification d'interface radioélectrique », à la 4e ligne « Type d'application » :

Au lieu de : « Systèmes de radiocommande de modèles réduits aériens. Flying Model control. »,

Lire : « Systèmes de radiocommande de modèles réduits. Model control. ».
