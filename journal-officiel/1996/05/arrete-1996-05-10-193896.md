# Arrêté du 10 mai 1996 fixant le nombre d'étudiants admis en première année d'études préparatoires au diplôme d'Etat d'infirmier

- Nature : Arrete
- Date du texte : 1996-05-10
- Publication : 1996-05-16
- JO n° : 0114
- NOR : TASP9621467A
- Ministère : MINISTERE DU TRAVAIL ET DES AFFAIRES SOCIALES
- Origine : JORF n°114 du 16 mai 1996
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000193896

## Article

Par arrêté du ministre du travail et des affaires sociales en date du 10 mai 1996, le nombre d'étudiants admis à entrer en première année d'études préparatoires au diplôme d'Etat d'infirmier pour l'année scolaire 1996-1997 (rentrées de septembre 1996 et de février 1997) est fixé dans les différentes régions comme suit :

Alsace : 562 ;

Aquitaine : 800 ;

Auvergne : 363 ;

Basse-Normandie : 435 ;

Bourgogne : 470 ;

Bretagne : 655 ;

Centre : 675 ;

Champagne-Ardenne : 360 ;

Corse : 40 ;

Franche-Comté : 410 ;

Haute-Normandie : 540 ;

Ile-de-France : 4 135 ;

Languedoc-Roussillon : 634 ;

Limousin : 334 ;

Lorraine : 844 ;

Midi-Pyrénées : 625 ;

Nord - Pas-de-Calais : 1 520 ;

Pays de la Loire : 664 ;

Picardie : 630 ;

Poitou-Charentes : 418 ;

Provence-Alpes-Côte d'Azur : 1 227 ;

Rhône-Alpes : 1 740 ;

Antilles-Guyane : 65 ;

Réunion : 90.
