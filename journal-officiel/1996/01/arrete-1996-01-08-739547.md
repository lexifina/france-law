# Arrêtés du 8 janvier 1996 portant prolongation de la période probatoire d'agrément d'organismes certificateurs de labels agricoles

- Nature : Arrete
- Date du texte : 1996-01-08
- Publication : 1996-01-17
- JO n° : 0014
- NOR : AGRG9600046A
- Ministère : MINISTERE DE L'AGRICULTURE, DE LA PECHE ET DE L'ALIMENTATION
- Origine : JORF n°14 du 17 janvier 1996
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000739547

## Article

Par arrêté du ministre de l'agriculture, de la pêche et de l'alimentation et du ministre délégué aux finances et au commerce extérieur en date du 8 janvier 1996 :

Est prolongée, pour une durée d'un an à compter de la date de parution au Journal officiel, la période probatoire d'agrément, sous le numéro LA 11,

comme organisme certificateur de labels agricoles de l'Association avicole du Gers, route d'Auch, 32300 Mirande, pour les produits suivants :

- << dinde fermière de Noël >> ;

- << pintade fermière >> ;

- << canard de Barbarie fermier >> ;

- << poulet fermier et découpe >> ;

- << chapon fermier >> ;

- << foie gras cru et produits de découpe de canard mulard fermier gavé >> ; - << foie gras cru et produits de découpe d'oie grasse fermière >> ;

- << poulet fermier surgelé >> ;

- << poularde fermière >> ;

- << chapon de pintade fermier >>.

Est prolongée, pour une durée d'un an à compter de la date de parution au Journal officiel, la période probatoire d'homologation des règlements techniques des labels :

- no 06-71 << dinde fermière de Noël >> ;

- no 10-77 << pintade fermière >> ;

- no 11-77 << canard fermier >> ;

- no 12-77 << poulet gris fermier >> ;

- no 01-81 << poulet roux fermier et découpe >> ;

- no 08-85 << poulet noir fermier >> ;

- no 07-86 << poulet blanc fermier et découpe >> ;

- no 14-88 << chapon fermier >> ;

- no 16-89 << foie gras cru et produits de découpe de canard mulard fermier gavé >> ;

- no 17-89 << foie gras cru et produits de découpe d'oie grasse fermière >> ; - no 03-91 << poulet blanc fermier surgelé >> ;

- no 04-91 << poulet jaune fermier surgelé >> ;

- no 10-91 << poularde fermière >> ;

- no 16-94 << chapon de pintade fermier >>.
