# Arrêtés du 8 janvier 1996 portant prolongation de la période probatoire d'agrément d'organismes certificateurs de labels agricoles

- Nature : Arrete
- Date du texte : 1996-01-08
- Publication : 1996-01-17
- JO n° : 0014
- NOR : AGRG9600045A
- Ministère : MINISTERE DE L'AGRICULTURE, DE LA PECHE ET DE L'ALIMENTATION
- Origine : JORF n°14 du 17 janvier 1996
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000190340

## Article

Par arrêté du ministre de l'agriculture, de la pêche et de l'alimentation et du ministre délégué aux finances et au commerce extérieur en date du 8 janvier 1996 :

Est prolongée, pour une durée d'un an à compter de la date de parution au Journal officiel, la période probatoire d'agrément, sous le numéro LA 22,

comme organisme certificateur de labels agricoles de l'association Auvergne certificateur (Aucert), chambre régionale d'agriculture, 12, rue Marx-Dormoy, 63000 Clermont-Ferrand, pour les produits suivants :

- << poulet fermier et découpe >> ;

- << dinde fermière de Noël >> ;

- << canette et canard de Barbarie fermiers et découpe >> ;

- << pintade fermière et découpe >> ;

- << chapon fermier >> ;

- << poularde fermière >> ;

- << salaisons >> :

<< saucisson sec >> ;

<< saucisse sèche >> ;

<< jambon sec >> ;

- << viande bovine >> ;

- << agneau fermier >> ;

- << porc fermier >>.

Est prolongée, pour une durée d'un an à compter de la date de parution au Journal officiel, la période probatoire d'homologation des règlements techniques de ses labels :

- no 08-80 << poulet blanc fermier et découpe >> ;

- no 08-84 << dinde fermière de Noël >> ;

- no 15-87 << poulet blanc fermier >> ;

- no 29-88 << chapon fermier >> ;

- no 02-89 << poulet noir fermier >> ;

- no 23-90 << chapon fermier >> ;

- no 15-91 << poularde fermière >> ;

- no 10-84 << salaisons d'Auvergne >> :

<< saucisson sec >> ;

<< saucisse sèche >> ;

<< jambon sec >> ;

- no 02-74 << viande bovine de race charolaise >> ;

- no 01-80 << viande bovine de race charolaise >> ;

- no 31-90 << agneau fermier >> ;

- no 08-89 << porc fermier >>.
