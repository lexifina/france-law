# Arrêté du 29 mai 2012 modifiant l'arrêté du 12 avril 2012 portant création d'offices de notaire et réouverture des délais de dépôt de candidatures à un office notarial déjà créé (officiers publics et ministériels)

## Article

Par arrêté de la garde des sceaux, ministre de la justice, en date du 29 mai 2012, l'arrêté du 12 avril 2012 portant création d'offices de notaire et réouverture des délais de dépôt de candidatures à un office notarial déjà créé est modifié comme suit :

Il est créé vingt et un offices de notaire aux résidences de :

La Ciotat (Bouches-du-Rhône), dans le ressort du tribunal d'instance d'Aubagne ;

Roquebrune-sur-Argens (Var), dans le ressort du tribunal d'instance de Fréjus ;

Gujan-Mestras (Gironde), dans le ressort du tribunal d'instance d'Arcachon ;

Eysines (Gironde), dans le ressort du tribunal d'instance de Bordeaux ;

Passy (Haute-Savoie), dans le ressort du tribunal d'instance de Bonneville ;

Saint-Jorioz (Haute-Savoie), dans le ressort du tribunal d'instance d'Annecy ;

Halluin (Nord), dans le ressort du tribunal d'instance de Tourcoing ;

Wattrelos (Nord), dans le ressort du tribunal d'instance de Roubaix ;

Chaponost ou Brindas (Rhône), dans le ressort du tribunal d'instance de Lyon ;

Amilly (Loiret), dans le ressort du tribunal d'instance de Montargis ;

Paris, dans le ressort des tribunaux d'instance de Paris ;

Moissy-Cramayel (Seine-et-Marne), dans le ressort du tribunal d'instance de Melun ;

Ivry-sur-Seine (Val-de-Marne), dans le ressort du tribunal d'instance d'Ivry-sur-Seine ;

Pantin ou Le Pré-Saint-Gervais (Seine-Saint-Denis), dans le ressort du tribunal d'instance de Pantin ;

Saint-Herblain (Loire-Atlantique), dans le ressort du tribunal d'instance de Nantes ;

Royat (Puy-de-Dôme), dans le ressort du tribunal d'instance de Clermont-Ferrand ;

Fonsorbes (Haute-Garonne), dans le ressort du tribunal d'instance de Muret ;

Toulouse (Haute-Garonne), dans le ressort du tribunal d'instance de Toulouse ;

Achères (Yvelines), dans le ressort du tribunal d'instance de Saint-Germain-en-Laye ;

Antony (Hauts-de-Seine), dans le ressort du tribunal d'instance d'Antony ;

Argenteuil (Val-d'Oise), dans le ressort du tribunal d'instance de Sannois.
