## Article

Rectificatif au Journal officiel du 23 mars 2012, édition électronique, texte n° 22, et édition papier, page 5269, article 2, dans la nomenclature du code 1103720 :

Au lieu de :

« Forfait hebdomadaire 44 associant les forfaits 6 (de ventilation assistée inférieure à 12 heures, code 1196270) et Ultrafill (d'oxygénothérapie à long terme, code 118415). »,

Lire :

« Forfait hebdomadaire 44 associant les forfaits 6 (de ventilation assistée inférieure à 12 heures, code 1196270) et Ultrafill (d'oxygénothérapie à long terme, code 1184315). »
