# Délibération du 28 février 2023 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2023-02-28
- Publication : 2023-03-28
- JO n° : 0074
- NOR : RCAR2308123X
- Origine : JORF n°0074 du 28 mars 2023
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000047351605

## Article

Par délibération en date du 28 février 2023, le comité territorial de l'audiovisuel de Caen a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Maison des lycéens du lycée Jacques Prévert à diffuser un service de radio par voie hertzienne terrestre dénommé Jacques a dit !, pour la journée du 13 avril 2023.

Site : 3, place Jacques-Prévert, 27500 Pont-Audemer.

Puissance : 50 W.

Fréquence : 96.2 MHz.

RDS Code PI : F3B3.

RDS Code PS : JACQUES.

---

Fait à Caen, le 28 février 2023.

Pour le comité territorial de l'audiovisuel de Caen :

Le président,
