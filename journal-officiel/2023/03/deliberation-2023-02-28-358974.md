# Délibération du 28 février 2023 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2023-02-28
- Publication : 2023-03-29
- JO n° : 0075
- NOR : RCAR2308210X
- Origine : JORF n°0075 du 29 mars 2023
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000047358974

## Article

Par délibération en date du mardi 28 février 2023, le comité territorial de l'audiovisuel de Caen a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Zones d'ondes - Agence associative : Normandie Média à diffuser un service de radio par voie hertzienne terrestre dénommé Radio EDM, pour la journée du 11 mai 2023.

Site : Lycée Gabriel.

6, place Robert-Dugué, 61200 Argentan.

Puissance : 50 W.

Fréquence : 90,1 MHz.

RDS Code PI : F3B3.

RDS Code PS : EDM.

---

Fait à Caen, le 28 février 2023.
