# Arrêté du 22 juin 2020 modifiant l'arrêté du 20 février 2019 relatif aux aides financières mentionnées au II de l'article 183 de la loi n° 2018-1317 du 28 décembre 2018 de finances pour 2019

- Nature : Arrete
- Date du texte : 2020-06-22
- Publication : 2020-06-24
- JO n° : 0155
- NOR : TRER2011600A
- Ministère : Ministère de la transition écologique et solidaire
- Origine : JORF n°0155 du 24 juin 2020
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000042028755

Le Premier ministre,

Vu le code de l'énergie, notamment son article L. 432-13 ;

Vu la loi n° 2018-1317 du 28 décembre 2018 de finances pour 2019, notamment son article 183 ;

Vu l'arrêté du 20 février 2019 relatif aux aides financières mentionnées au II de l'article 183 de la loi n° 2018-1317 du 28 décembre 2018 de finances pour 2019 ;

Vu l'avis du Conseil supérieur de l'énergie en date du 19 mai 2020 ;

Vu l'avis de la Commission de régulation de l'énergie en date du 28 mai 2020,

Arrête :

## Article 1

Le 1° de l'article 1er de l'arrêté du 20 février 2019 susvisé est ainsi modifié :

1° Après le mot : « Bourbourg, », est inséré le mot : « Brouckerque, » ;

2° Après le mot : « Herzeele, », est inséré le mot : « Holque, » ;

3° Après les mots : « Loon-Plage, », est inséré le mot : « Nieurlet, » ;

4° Après les mots : « Saint-Georges-sur-l'Aa, », sont insérés les mots : « Saint-Momelin, » ;

5° Après le mot : « Warhem, », est inséré le mot : « Watten, ».

## Article 2

Le 2° de l'article 1er de l'arrêté du 20 février 2019 susvisé est ainsi modifié :

1° Après les mots : « Pas-de-Calais, », sont insérés les mots : « Andres, Ardres, Arques, Audruicq, Autingues, » ;

2° Après les mots : « Auxi-le-Château, », sont insérés les mots : « Balinghem, Blendecques, Brêmes, Caffiers, Calais, Campagne-lès-Wardrecques, Clairmarais, Coquelles, Coulogne, Ecques, Elnes, Eperlecques, Esquerdes, » ;

3° Après les mots : « Gauchin-Verloingt, », sont insérés les mots : « Guînes, Hallines, Hames-Boucres, Helfaut, » ;

4° Après le mot : « Hernicourt, », sont insérés les mots : « Heuringhem, Les Attaques, Leulinghem, Longuenesse, Louches, Lumbres, Marck, Muncq-Nieurlet, » ;

5° Après les mots : « Oye-Plage, », sont insérés les mots : « Polincove, Ruminghem, Saint-Augustin, » ;

6° Après les mots : « Saint-Folquin, », sont insérés les mots : « Saint-Martin-lez-Tatinghem, » ;

7° Après les mots : « Saint-Michel-sur-Ternoise, », sont insérés les mots : « Saint-Omer, » ;

8° Après les mots : « Saint-Pol-sur-Ternoise, », sont insérés les mots : « Sangatte, Salperwick, Setques, Tilques, » ;

9° Après les mots : « Vieille-Eglise, », sont insérés les mots : « Wavrans-sur-L'Aa, Wisques, Wizernes, Zutkerque. ».

## Article 3

Le présent arrêté sera publié au Journal officiel de la République française.
