# Délibération du 15 mai 2020 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2020-05-15
- Publication : 2020-06-14
- JO n° : 0145
- NOR : CSAC2014845X
- Origine : JORF n°0145 du 14 juin 2020
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000041991794

## Article

Par délibération en date du 15 mai 2020, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 17 août au 31 décembre 2020.

Site : SAINT-GENIS-L'ARGENTIERE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : SAINT-SYMPHORIEN-SUR-COISE (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
