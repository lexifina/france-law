# Délibération du 7 juillet 2020 relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Date du texte : 2020-07-07
- Publication : 2020-08-13
- JO n° : 0198
- NOR : CSAR2021229X
- Origine : JORF n°0198 du 13 août 2020
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000042231615

## Article

Par délibération en date du 7 juillet 2020, le comité territorial de l'audiovisuel de Nancy a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Radio Campus Lorraine à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Campus Lorraine, pour la période du 14 septembre 2020 au 14 juin 2021 (*).

Site : 6, rue d'Aquitaine, bâtiment Lavoisier, 54500 Vandœuvre-lès-Nancy.

Puissance : 100 W.

Fréquence : 99,6 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.

Site : résidence Saulcy, Ile du Saulcy, 57010 Metz.

Puissance : 100 W.

Fréquence : 106,1 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.

---

Fait à Nancy, le 7 juillet 2020.

Pour le comité territorial de l'audiovisuel de Nancy :

La présidente,

C. Ledamoisel

(*) Sous réserve d'un aboutissement favorable des procédures de coordination internationale en ce qui concerne le site de Metz.
