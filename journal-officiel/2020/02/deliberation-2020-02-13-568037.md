# Délibération relative à une autorisation temporaire pour l'exploitation d'un service de radio

- Nature : Deliberation
- Publication : 2020-02-13
- JO n° : 0037
- NOR : CSAR2002073X
- Origine : JORF n°0037 du 13 février 2020
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000041568037

## Article

Par délibération en date du 20 décembre 2019, le comité territorial de l'audiovisuel de Lyon a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Modul FM à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Modul, pour la période du 2 mars au 12 juillet 2020.

Site : Saint-Genis-l'Argentière (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.

Site : Saint-Symphorien-sur-Coise (69).

Puissance : 50 W.

Fréquence : 98,7 MHz.

Code PI : F387.

Code PS : MODUL.
