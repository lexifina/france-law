# Délibération relative à une autorisation temporaire

- Nature : Deliberation
- Publication : 2017-08-02
- JO n° : 0179
- NOR : CSAR1722118X
- Origine : JORF n°0179 du 2 août 2017
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000035342686

## Article

Par délibération en date du 3 juillet 2017, le comité territorial de l'audiovisuel de Nancy a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Radio Campus Lorraine à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Campus Lorraine, pour la période du 15 septembre 2017 au 15 juin 2018.

Site : 6, rue d'Aquitaine, bâtiment Lavoisier, 54500 Vandœuvre-lès-Nancy.

Puissance : 100 W.

Fréquence : 99,6 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.

Site : résidence Saulcy, Ile du Saulcy, 57 010 Metz.

Puissance : 100 W.

Fréquence : 106,1 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.
