# Délibération relative à une autorisation temporaire

- Nature : Deliberation
- Publication : 2017-06-27
- JO n° : 0149
- NOR : CSAR1718156X
- Origine : JORF n°0149 du 27 juin 2017
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000035014262

## Article

Par délibération en date du 7 avril 2017, le comité territorial de l'audiovisuel de Marseille a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Imagine l'Association à diffuser un service de radio par voie hertzienne terrestre dénommé « Gap Tourisme Imagine », pour la période du 21 juin au 20 septembre 2017.

Site : 79, avenue d'Embrun - GAP (05).

Puissance : 100 W.

Fréquence : 106.9 MHz.

Porteuse RDS : Oui.

Code PS : TOURISME.

Code PI : F34E.
