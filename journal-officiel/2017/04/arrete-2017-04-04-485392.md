Le ministre de l'agriculture, de l'agroalimentaire et de la forêt, porte-parole du Gouvernement,

Vu le code rural et de la pêche maritime, notamment ses articles D. 661-1 à D. 661-11 ;

## Article 3

Est prolongée, pour une durée de cinq ans à compter du 1er janvier 2017, l'inscription au Catalogue officiel des espèces et variétés de plantes cultivées en France, dont les semences peuvent être commercialisées en France (liste A), des variétés désignées ci-après :

Graminées fourragères :

- Brome sitchensis : Hakari ;

- Dactyle fourrage : Ludac, Luflor, Lupre, Medly, Topaze ;

- Fléole des prés : Aurora, Presto ;

- Fétuque des prés : Paradisia ;

- Fétuque élevée fourrage : Centurion, Exella, Gardian ;

- Ray-grass anglais fourrage : Alfan, Azur, Cabriolet, Carillon, Defender, Eiffel, Fleuron, Graal, Ketarion 1, Macarena, Malambo, Pastoral, Rodrigo, Samsara, Sures, Twymax ;

- Ray-grass d'Italie alternatif : Andy, Bartigra, Speedyl ;

- Ray-grass d'Italie non alternatif : Antonia, Avensyl, Clorofyl, Jericho, Libeccio, Oscar, Silor ;

- Ray-grass hybride : Crucial, Splenda, Tonuss ;

- X Festulolium (F. arundinacea × L.multiflorum) : Lueur ;

- X Festulolium (F. pratensis × L. multiflorum) : Achilles.

Légumineuses fourragères :

- Luzerne : Exquise, Galaxie, Marshal, Midi, Rachel ;

- Pois fourrager de printemps : Gali ;

- Trèfle blanc : Alice, Avalon, Crusader, Lustar, Milagro ;

- Trèfle violet : Diadem, Merian ;

- Vesce commune d'hiver : Spinelle ;

- Vesce commune de printemps : Amethyste ;

- Vesce velue : Savane.

Graminées à gazon :

- Agrostide ténue : Allure, Orient ;

- Fétuque ovine : Mentor, Nordic ;

- Fétuque rouge demi-traçante : Musette ;

- Fétuque rouge gazonnante : Bardiva, Blenheim, Raisa ;

- Fétuque rouge traçante : Lambada, Lisamba ;

- Fétuque élevée gazon : Izella, Bardavinci, Meandre, Divyna ;

- Paturin commun : Sabrena 1 ;

- Ray-grass anglais gazon : Berlioz 1, Carinus, Concerto, Dylan, Escapade, Eterlou, Fandango, Sirtaky.

## Article 4

Est prolongée pour une durée de cinq ans à compter du 1er janvier 2017 l'inscription au Catalogue officiel des espèces et variétés de plantes cultivées en France, dont les semences peuvent être multipliées en France en vue de leur exportation (liste B), des variétés désignées ci-après :

Graminées fourragères :

- Ray-grass anglais fourrage : Inoval ;

- Ray-grass d'Italie alternatif : Melmondo.

## Article 5

Sont radiées du Catalogue officiel des espèces et variétés de plantes cultivées en France, dont les semences peuvent être commercialisées en France (liste A), à échéance du 31 décembre 2016, les variétés désignées ci-après :

Graminées fourragères :

- Brome cathartique : Atout, Rosabel ;

- Dactyle fourrage : Accord, Bartour, Cabrett, Cristobal, Diceros, Ereva ;

- Fétuque élevée fourrage : Bariane, Emeraude, Flexy, Tuscany ;

- Ray-grass anglais fourrage : Barelan, Bargloria, Barmondo, Barmoric, Bazil, Blog, Cantalou, Elital, Essor, Herbal, Magistral, Sadonne, Split, Vidalia ;

- Ray-grass d'Italie alternatif : Barcomet, Barspirit, Daxus ;

- Ray-grass d'Italie non alternatif : Altria, Andain, Prestyl.

Légumineuses fourragères :

- Luzerne : Andela ;

- Trèfle violet : Jonas, Mistral.

Graminées à gazon :

- Agrostide ténue : Bardot ;

- Fétuque élevée gazon : Amalia, Calvada, Cannavaro, Elisa, Greenbrooks ;

- Fétuque rouge gazonnante : Carioca, Morellino ;

- Fétuque rouge traçante : Bossanova ;

- Ray-grass anglais gazon : Aiken, Barsunny, Blazer 4, Greenfair, Leclair, Melbourne, Ragtime, Ritmo.

Usage non fourrager et non gazon :

- Dactyle : Bacchus ;

- Fétuque rouge gazonnante : Eurocom ;

- Ray-grass anglais gazon : Averto.

Ces variétés peuvent être commercialisées jusqu'au 30 juin 2019.

## Article 6

Sont radiées du Catalogue officiel des espèces et variétés cultivées en France, dont les semences peuvent être multipliées en France en vue de leur exportation (liste B), à échéance du 31 décembre 2016, les variétés désignées ci-après :

Graminées fourragères :

- Dactyle fourrage : Darsena, Efendi ;

- Ray-grass d'Italie non alternatif : Ansyl, Thales.

## Article 7

Dans les arrêtés modifiés susvisés du :

- 1er avril 1964, à l'article 1er, pour la variété Assas ;
