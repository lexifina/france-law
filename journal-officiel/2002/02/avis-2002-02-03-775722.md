# Avis de clôture des émissions de tickets de loterie instantanée de La Française des jeux dont les mises et les lots sont en francs et abrogation des règlements des jeux correspondants

- Nature : Avis
- Publication : 2002-02-03
- JO n° : 0029
- NOR : ECOZ0299025V
- Ministère : MINISTERE DE L'ECONOMIE, DES FINANCES ET DE L'INDUSTRIE
- Origine : JORF n°29 du 3 février 2002
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000775722

## Article

Article 1er

Les émissions de tickets des jeux de loterie instantanée de La Française des jeux dénommés Astro, Banco, Super Bingo, Black Jack, Goal, Jeu de l'oie, Millionnaire, Morpion, Pile, Face, Safari, Saint Valentin, Sprint, Solitaire, Tac o Tac TV, Vegas, Saga et XIII la BD culte, dont les mises et les lots sont en francs, qui n'auraient pas déjà été clôturées à ce jour, sont clôturées le 17 février 2002 à minuit au plus tard. En conséquence, le droit de revendication des lots pour ces émissions sera prescrit le 19 mars 2002.

A ce titre, sont notamment clôturées les émissions mentionnées ci-dessous :

- l'émission n° 3 code jeu n° 64103 du jeu dénommé Astro ;

- l'émission n° 7 code jeu n° 65107, l'émission n° 8 code jeu n° 65108, l'émission n° 9 code jeu n° 65109 du jeu dénommé Banco ;

- l'émission n° 1 code jeu n° 61101, l'émission n° 2 code jeu n° 61102 du jeu dénommé Black Jack ;

- l'émission n° 7 code jeu n° 58107, l'émission n° 8 code jeu n° 58108, l'émission n° 9 code jeu n° 58109 ;

- l'émission n° 10 code jeu n° 58110 du jeu dénommé Goal ;

- l'émission n° 1 code jeu n° 74101 du jeu dénommé Jeu de l'oie ;

- l'émission n° 2 code jeu n° 71102 du jeu dénommé Millionnaire ;

- l'émission n° 5 code jeu n° 57105, l'émission n° 6 code jeu n° 57106, l'émission n° 7 code jeu n° 57107 du jeu dénommé Morpion ;

- l'émission n° 1 code jeu n° 79001, l'émission n° 2 code jeu n° 79102 du jeu dénommé Pile, Face ;

- l'émission n° 1 code jeu n° 37101 du jeu dénommé Safari ;

- l'émission n° 4 code jeu n° 63104 du jeu dénommé Solitaire ;

- l'émission n° 1 code jeu n° 80101 du jeu dénommé Sprint ;

- l'émission n° 2 code jeu n° 73102 du jeu dénommé Tac o Tac TV ;

- l'émission n° 4 code jeu n° 68104 du jeu dénommé Vegas.

Article 2

Les règlements des jeux de loterie instantanée de La Française des jeux dénommés Astro, Banco, Super Bingo, Black Jack, Goal, Jeu de l'oie, Millionnaire, Morpion, Pile, Face, Safari, Saint Valentin, Sprint, Solitaire, Tac o Tac TV, Vegas, Saga et XIII la BD culte, dont les mises et les lots sont en francs, qui ont été publiés au Journal officiel jusqu'au 20 décembre 2001, sont abrogés le 20 mars 2002.
