# Délibération relative à une autorisation temporaire

- Nature : Deliberation
- Publication : 2015-08-13
- JO n° : 0186
- NOR : CSAR1519333X
- Origine : JORF n°0186 du 13 août 2015
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000031014767

## Article

Par délibération en date du 6 juillet 2015, le comité territorial de l'audiovisuel de Nancy a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Radio Campus Lorraine à diffuser un service de radio par voie hertzienne terrestre dénommé Radio Campus Lorraine, pour la période du 18 septembre 2015 au 18 juin 2016.

Site : 6, rue d'Aquitaine, bâtiment Lavoisier, 54500 Vandœuvre-lès-Nancy

Puissance : 100 W.

Fréquence : 99,6 MHz.

RDS Code PI : F37C

RDS Code PS : CAMPUS

Site : Résidence Saulcy, île du Saulcy, 57010 Metz.

Puissance : 100 W.

Fréquence : 106,1 MHz.

RDS Code PI : F37C.

RDS Code PS : CAMPUS.
