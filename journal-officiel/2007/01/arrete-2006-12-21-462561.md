## Article

Agréments

Par arrêtés du ministre de l'agriculture et de la pêche en date du 21 décembre 2006 :

Est agréée sous le numéro N 2868 l'Union de coopératives agricoles terres comtoises, dont le siège social est à Besançon (département du Doubs).

Cette société relève du type :

U1 Collecte-vente ;

U3 Approvisionnement ;

U4 Services.

Est agréée sous le numéro N 2869 l'union de coopératives agricoles Terres de France, dont le siège social est à Boves (département de la Somme).

Cette société relève du type : U4 Services.

Est agréée sous le numéro N 2870 l'union de coopératives agricoles Coopenergie Picardie, dont le siège social est à Laon (département de l'Aisne).

Cette société relève du type : U4 Services.

Est agréée sous le numéro N 2871 l'union de coopératives agricoles Oxalliance, dont le siège social est à Toulouse (département de la Haute-Garonne).

Cette société relève du type :

U1 Collecte-vente ;

U2 Administrée directement par AG ;

U3 Approvisionnement ;

U4 Services.

Est agréée sous le numéro N 2872 l'union de coopératives agricoles Unio, dont le siège social est à Vic-Fezensac (département du Gers).

Cette société relève du type :

U1 Collecte-vente ;

U2 Administrée directement par AG ;

U3 Approvisionnement ;

U4 Services.

Est agréée sous le numéro N 2873 l'union de coopératives agricoles Blasons de Bourgogne, dont le siège social est à Chablis (département de l'Yonne).

Cette société relève du type :

U1 Collecte-vente ;

U4 Services.

Est agréée sous le numéro N 2874 l'union de coopératives agricoles Grap'Sud, dont le siège social est à Cruviers-Lascours (département du Gard).

Cette société relève du type :

U1 Collecte-vente ;

U2 Administrée directement par AG ;

U3 Approvisionnement ;

U4 Services.

Est agréée sous le numéro N 2875 la société coopérative agricole Laitnaa, dont le siège social est à La Capelle (département de l'Aisne).

Cette société relève du type :

1 Collecte-vente ;

5 Approvisionnement ;

6 Services.

La circonscription territoriale est la suivante :

- les arrondissements d'Avesnes, de Cambrai et de Valenciennes dans le département du Nord ;

- les arrondissements de Laon, de Saint-Quentin et de Vervins dans le département de l'Aisne ;

- les cantons de Château-Porcien et de Chaumont-Porcien dans le département des Ardennes.
