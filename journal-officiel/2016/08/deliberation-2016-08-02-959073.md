# Délibération relative à une autorisation temporaire

- Nature : Deliberation
- Publication : 2016-08-02
- JO n° : 0178
- NOR : CSAR1621368X
- Origine : JORF n°0178 du 2 août 2016
- Légifrance : https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000032959073

## Article

Par délibération en date du mardi 28 juin 2016, le Comité territorial de l'audiovisuel de Caen a décidé, en application de l'article 28-3 de la loi du 30 septembre 1986 modifiée relative à la liberté de communication, d'autoriser l'association Papa's Production à diffuser un service de radio par voie hertzienne terrestre dénommé Ouest Track Radio, pour la période du 19 septembre au 23 octobre 2016.

Site : 55, rue du 329e-RI.

76620 LE HAVRE.

Puissance : 20 W.

Fréquence : 95.9 MHz.

RDS Code PI : F3B6.

RDS Code PS : OUESTRAK.

---

Fait à Caen, le 28 juin 2016.

Pour le comité territorial de l'audiovisuel de Caen :

Le président,
