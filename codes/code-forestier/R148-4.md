# Article R*148-4

L'autorisation prévue par l'article L. 148-11 du présent code est donnée par arrêté du ou des préfets intéressés.

Les articles R. 148-1 à R. 148-3 du présent code ainsi que les articles R. 166-1 et R. 166-2 du code des communes sont applicables aux syndicats mixtes de gestion forestière.
