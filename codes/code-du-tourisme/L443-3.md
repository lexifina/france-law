# Article L443-3

Les règles relatives aux personnes assujetties à la taxe de séjour dans les communes de Mayotte sont prévues au II de l'article L. 2572-58 du code général des collectivités territoriales.

NOTA :

L'article L. 2574-10 du code général des collectivités territoriales est devenu l'article L. 2572-58 du même code (se reporter à l'article 2 de l'ordonnance n° 2007-1434 du 5 octobre 2007).
