# Article 828

Les huissiers et les greffiers présentent ce répertoire au visa du fonctionnaire compétent de l’enregistrement de leur résidence, qui le vise et qui énonce dans son visa le numéro du dernier acte inscrit. Cette présentation a lieu :

Pour les huissiers, les 1er, 6, 11, 16, 21 et 26 ;

Pour les greffiers, les 1er et 16 de chaque mois.

Si le jour fixé pour le visa est un jour férié, le visa est apposé le lendemain.
