# Article 1755 bis

Dans le cas d’information ouverte par l’autorité judiciaire sur la plainte de l’administration fiscale, en matière d’impôts directs et de taxes assimilées, cette administration peut se constituer partie civile.

NOTA :

Créé par l'article 1er du décret n° 51-1446 du 15 décembre 1951 portant incorporation dans le code général des impôts de divers textes modifiant et complétant certaines dispositions de ce code ; JORF du 19 décembre 1951, p. 12529.
