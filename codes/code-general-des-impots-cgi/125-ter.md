# Article 125 ter

Les intérêts des sommes inscrites sur les livrets de caisse d’épargne sont exonérés de la taxe proportionnelle exception faite lorsqu’ils figurent dans les recettes provenant de l’exercice d’une profession industrielle, commerciale, artisanale ou d’une exploitation minière.

NOTA :

Ancien article 125 bis du code général des impôts transféré vers l'article 125 ter. Article 1er du décret n° 51-1446 du 15 décembre 1951 portant incorporation dans le code général des impôts de divers textes modifiant et complétant certaines dispositions de ce code ; JORF du 19 décembre 1951, p. 12529.
