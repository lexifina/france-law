TPS - Taxe sur les salaires - Base d'imposition

Le présent titre consacré à la base d'imposition de la taxe sur les salaires
aborde successivement :

- les principes généraux (Chapitre 1,
BOI-TPS-TS-20-10) ;

- les exonérations spécifiques à la taxe sur les salaires (Chapitre 2,
BOI-TPS-TS-20-20) ;

- les cas particuliers (Chapitre 3,
BOI-TPS-TS-20-30).
