# Article 1

Les communes de :

- Langon (Loir-et-Cher) ;

- Saint-Elix (Gers) ;

- Les Moulins (Côtes-d'Armor) ;

- Lisle-en-Rigault (Meuse) ;

- Saulmory-et-Villefranche (Meuse) ;

- Berville (Seine-Maritime) ;

- Hérouville (Val-d'Oise) ;

- Fresnes (Aisne),

prennent respectivement le nom de :

- Langon-sur-Cher ;

- Saint-Elix-d'Astarac ;

- Plémet ;

- L'Isle-en-Rigault ;

- Saulmory-Villefranche ;

- Berville-en-Caux ;

- Hérouville-en-Vexin ;

- Fresnes-sous-Coucy.
