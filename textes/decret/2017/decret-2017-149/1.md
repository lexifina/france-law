# Article 1

Les communes de :

- La Génétouze (Vendée) ;

- Clara (Pyrénées-Orientales) ;

- Sainte-Marie (Pyrénées-Orientales) ;

- Faverolles (Indre) ;

- Sévrier (Haute-Savoie) ;

- Le Gault-Perche (Loir-et-Cher) ;

- Pronville (Pas-de-Calais) ;

- Bouloc (Tarn-et-Garonne),

prennent respectivement le nom de :

- La Genétouze ;

- Clara-Villerach ;

- Sainte-Marie-la-Mer ;

- Faverolles-en-Berry ;

- Sevrier ;

- Le Gault-du-Perche ;

- Pronville-en-Artois ;

- Bouloc-en-Quercy.
