# Article 2

Des emplois permanents à temps non complet peuvent être créés pour les personnels relevant des corps suivants :

1° Sages-femmes des hôpitaux ;

2° Psychologues ;

3° Diététiciens ;

4° Masseurs-kinésithérapeutes ;

5° Orthophonistes ;

6° Orthoptistes ;

7° Pédicures-podologues ;

8° Ergothérapeutes ;

9° Psychomotriciens.
