# Article LEGIARTI000042235021

- Algérie ;

- Argentine ;

- Arménie ;

- Bolivie ;

- Bosnie-Herzégovine ;

- Brésil ;

- Chili ;

- Colombie ;

- Costa Rica ;

- Guinée équatoriale ;

- Inde ;

- Israël ;

- Kirghizstan ;

- Kosovo ;

- Koweit ;

- Liban ;

- Madagascar ;

- Maldives ;

- Mexique ;

- Moldavie ;

- Monténégro ;

- Oman ;

- Pérou ;

- Qatar ;

- République dominicaine ;

- Serbie ;

- Territoires palestiniens ;

- Turquie.
