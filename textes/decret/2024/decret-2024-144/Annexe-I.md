# Article Annexe I

- Filet ;

- Faux filet ;

- Rumsteck ;

- Entrecôte ;

- Aiguillette baronne ;

- Bavette d'Aloyau ;

- Onglet ;

- Hampe ;

- Bifteck ;

- Basse côte ;

- Paleron ;

- Flanchet ;

- Steak ;

- Escalope ;

- Tendron ;

- Grillade ;

- Longe ;

- Travers ;

- Jambon ;

- Boucher/Bouchère ;

- Charcutier/Charcutière.
