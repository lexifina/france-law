# Article 3

Le canton n° 2 (Bernay) comprend les communes suivantes : Bernay, Caorches-Saint-Nicolas, Corneville-la-Fouquetière, Courbépine, Fontaine-l'Abbé, Malouy, Menneval, Mesnil-en-Ouche, Le Noyer-en-Ouche, Plainville, Plasnes, Saint-Léger-de-Rôtes, Saint-Martin-du-Tilleul, Saint-Victor-de-Chrétienville, Serquigny, Treis-Sants-en-Ouche, Valailles.

Le bureau centralisateur de ce canton est le bureau centralisateur de la commune de Bernay.
