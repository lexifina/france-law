# Article 22

Le canton n° 21 (Vincelles) comprend les communes suivantes : Andryes, Charentenay, Coulangeron, Coulanges-la-Vineuse, Courson-les-Carrières, Druyes-les-Belles-Fontaines, Escamps, Escolives-Sainte-Camille, Etais-la-Sauvin, Fontenoy, Fouronnes, Gy-l'Evêque, Les Hauts de Forterre, Irancy, Jussy, Lain, Lainsecq, Levis, Merry-Sec, Migé, Mouffy, Moutiers-en-Puisaye, Ouanne, Sainpuits, Saint-Sauveur-en-Puisaye, Saints-en-Puisaye, Sementron, Sougères-en-Puisaye, Thury, Treigny-Perreuse-Sainte-Colombe, Val-de-Mercy, Vincelles, Vincelottes.

Le bureau centralisateur de ce canton est le bureau centralisateur de la commune de Vincelles.
