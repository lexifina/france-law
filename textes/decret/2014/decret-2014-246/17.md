# Article 17

Le canton n° 16 (Le Mortainais) comprend les communes suivantes : Barenton, Beauficel, Brouains, Chaulieu, Le Fresne-Poret, Gathemo, Ger, Mortain-Bocage, Le Neufbourg, Perriers-en-Beauficel, Romagny Fontenay, Saint-Barthélemy, Saint-Clément-Rancoudray, Saint-Cyr-du-Bailleul, Saint-Georges-du-Rouelley, Sourdeval, Le Teilleul.

Le bureau centralisateur de ce canton est le bureau centralisateur de la commune de Mortain-Bocage.
