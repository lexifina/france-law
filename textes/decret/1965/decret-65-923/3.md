# Article 3

Le corps des agents de services comprend les grades ci-après désignés :

- agent spécialiste ;

- agent chef de deuxième catégorie ;

- agent de première catégorie.

NOTA :

Décret 2003-977 du 9 octobre 2003 art. 3 : Le décret 65-923 est abrogé en tant qu'il concerne le grade d'agent spécialiste.
