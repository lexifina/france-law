# Article 1

Toute personne tenue d'émettre un bordereau de suivi des déchets dangereux en application de l' article R. 541-45 du code de l'environnement utilise le formulaire CERFA n° 12571 (1), sauf, d'une part, pour les déchets dangereux contenant de l'amiante pour lesquels le formulaire CERFA n° 11861 (1) est utilisé et, d'autre part, pour les déchets de fluides frigorigènes pour lesquels le formulaire CERFA n° 15497 (1) est utilisé.

NOTA :

(1) Le formulaire et ses annexes peuvent être consultés sur le site internet : http://www.ecologie.gouv.fr.
