# Article 3

Les insignes de grade des agents techniques de l'environnement sont définis comme suit.

Les galons sont portés sur des pattes d'épaule de couleur grise selon les modalités suivantes :

- agent technique classé C2 : trois galons argent en V renversé ;

- agent technique classé C3 : un galon trait argent avec un fil de soie gris foncé.

Les insignes portés sur le képi par les agents techniques sont les suivants : fausse jugulaire argent et soutache argent à fil gris.
