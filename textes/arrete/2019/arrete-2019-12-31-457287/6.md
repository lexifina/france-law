# Article 6

Les technologies critiques mentionnées au 1° du III de l'article R. 151-3 du code monétaire et financier sont :

1° La cybersécurité ;

2° L'intelligence artificielle ;

3° La robotique ;

4° La fabrication additive ;

5° Les semi-conducteurs ;

6° Les technologies quantiques ;

7° Le stockage d'énergie ;

8° Les biotechnologies ;

9° Les technologies intervenant dans la production d'énergie renouvelable.

NOTA :

Conformément à l’article 5 de l’arrêté du 10 septembre 2021, ces dispositions entrent en vigueur à compter du 1er janvier 2022.
