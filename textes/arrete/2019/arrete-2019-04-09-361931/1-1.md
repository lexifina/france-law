# Article 1.1

Aménagement.

Le préfet peut, en application de l'article L. 512-10 du code de l'environnement et dans les conditions prévues à l'article R. 512-52 du code de l'environnement, adapter par arrêté préfectoral aux circonstances locales :

- les prescriptions du présent arrêté, pour l'ensemble des installations du département ;

- les différentes prescriptions du présent arrêté, installation par installation.
