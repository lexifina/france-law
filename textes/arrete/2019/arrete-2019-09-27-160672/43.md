# Article 43

L'équivalence de loyer L pour chacune des catégories de personnes mentionnées à l'article D. 842-16 du même code est égal à :

1° Pour les étudiants logés en chambre :

a) 95,12 euros euros lorsqu'il s'agit d'une personne seule ;

b) 148,11 euros euros euros lorsqu'il s'agit d'un couple ;

2° Pour les étudiants logés dans une chambre ayant fait l'objet d'une réhabilitation :

a) 192,32 euros euros lorsqu'il s'agit d'une personne seule ;

b) 298,90 euros lorsqu'il s'agit d'un couple ;

3° Pour les personnes mentionnées au 3° :

a) 233,33 euros lorsqu'il s'agit d'une personne seule ;

b) 362,59 euros lorsqu'il s'agit d'un couple ;

4° Pour les autres personnes :

a) 192,32 euros lorsqu'il s'agit d'une personne seule ;

b) 298,90 euros lorsqu'il s'agit d'un couple.

NOTA :

Conformément à l’article 3 de l’arrêté du 28 septembre 2026 (NOR : VLOL2620735A), ces dispositions, dans leur rédaction issue de l'article 1er de l'arrêté précité, sont applicables aux prestations dues à compter du 1er octobre 2026.
