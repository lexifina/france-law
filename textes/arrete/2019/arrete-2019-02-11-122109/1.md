# Article 1

Sont classés sur la liste I des substances vénéneuses les produits suivants sous toutes leurs formes :

- abémaciclib ;

- apalutamide ;

- argipressine ;

- axicabtagène ciloleucel ;

- binimetinib ;

- brexpiprazole ;

- caplacizumab ;

- encorafenib ;

- éravacycline ;

- érénumab ;

- lanadelumab ;

- métréleptine ;

- nératinib ;

- talazoparib ;

- tidrakizumab ;

- tisagenlecleucel ;

- vestronidase alfa ;

- vonicog alfa.
