# Article 1

Sont classés sur la liste I des substances vénéneuses les médicaments à usage humain sous toutes ses formes :

- aviptadil ;

- damoctocog alfa pégol ;

- doravirine

- galcanezumab ;

- immunoglobuline équine anti-thymocytes humains ;

- mogamulizumab ;

- naldemedine ;

- filtrat acellulaire de protéines antigéniques de Bacillus anthracis ;

- tezacaftor ;

- vaborbactam ;

- virus chimériques fièvre jaune/dengue ;

- voretigene neparvovec.
