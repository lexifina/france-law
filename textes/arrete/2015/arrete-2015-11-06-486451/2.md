# Article 2

Le programme d'indemnisation approuvé en application de l'article 1er concerne les communes reconnues zones contaminées par arrêté préfectoral dans les départements suivants :

- Ardèche (07) ;

- Corrèze (19) ;

- Haute-Corse (2B) ;

- Dordogne (24) ;

- Drôme (26) ;

- Gard (30) ;

- Lot (46) ;

- Pyrénées-Atlantiques (64) ;

- Var (83).
