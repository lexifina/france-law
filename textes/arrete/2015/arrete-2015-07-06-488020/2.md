# Article 2

L'agrément prévu à l'article L. 211-4 du code du sport est accordé à nouveau, pour une période de quatre ans, aux centres de formation relevant des personnes morales suivantes :

SASP Bourges Basket (F) ;

SEMS ALM Evreux basket (M) ;

Association BC Maritime Gravelines Dunkerque (M) ;

Association Basket Landes (F) ;

Association ESSM Le Portel Côte d'Opale (M) ;

SASP SCP Limoges (M) ;

Association ASVEL Basket (M) ;

Association Nantes Reze basket (F) ;

SASP Paris Levallois (M) ;

Association Roanne Chorale basket (M) ;

SAEMSL Strasbourg Illkirch Graffenstaden Basket (M).
