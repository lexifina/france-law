# Article 1

Sont classés sur la liste I des substances vénéneuses les produits suivants sous toutes leurs formes :

- céritinib ;

- cystéamine ;

- gemtuzumab ;

- idébénone ;

- lenvatinib ;

- nivolumab ;

- [177Lu] -DOTA0-Tyr3-octréotate ;

- ozogamicine ;

- pembrolizumab ;

- pitolisant ;

- sultiame ;

- tizanidine.
