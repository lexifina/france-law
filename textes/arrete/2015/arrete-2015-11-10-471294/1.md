# Article 1

Sont classés sur la liste I des substances vénéneuses les produits suivants sous toutes leurs formes :

- afamélanotide ;

- aprémilast ;

- cangrélor ;

- crisantaspase (asparaginase d'Erwinia chrysanthemi : L-asparaginase d'Erwinia) ;

- dalbavancine ;

- dasabuvir ;

- éliglustat ;

- liraglutide ;

- naloxégol ;

- ombitasvir ;

- oritavancine ;

- ospémifène ;

- paritaprévir ;

- safinamide ;

- sécukinumab ;

- tédizolid ;

- témocilline ;

- vorapaxar.
