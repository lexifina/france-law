# Article 2

Sont classés sur la liste II des substances vénéneuses les produits suivants sous toutes leurs formes :

- acamprosate calcique ;

- acéclofénac ;

- dexkétoprofène trométamol ;

- ébastine ;

- fexofénadine ;

- fosfestrol ;

- liothyronine ;

- mésalazine ;

- morniflumate ;

- oxétorone ;

- toltérodine.
