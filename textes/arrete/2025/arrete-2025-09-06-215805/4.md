# Article 4

Le coût environnemental est calculé par référence à un type de produit donné, auquel correspond un nombre de jours théoriques d'utilisation. Les types considérés sont notamment les suivants :

1° Boxer, slip ;

2° Caleçon ;

3° Chaussettes ;

4° Chemise ;

5° Jean ;

6° Jupe, robe ;

7° Maillot de bain ;

8° Manteau, veste ;

9° Pantalon, short ;

10° Pull ;

11° T-shirt, polo.
