# Article 1

Les départements mentionnés à l'article 4 du décret du 27 juin 2024 susvisé sont les suivants :

- Aude ;

- Deux-Sèvres ;

- Côtes d'Armor ;

- Gers ;

- Haute-Corse ;

- Haut-Rhin ;

- Isère ;

- Loiret ;

- Martinique ;

- Mayotte ;

- Meurthe-et-Moselle ;

- Nord ;

- Réunion ;

- Rhône ;

- Seine-Maritime ;

- Tarn ;

- Var ;

- Vendée ;

- Yonne ;

- Yvelines.
