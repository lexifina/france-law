# Article 1

Les montants unitaires de l'aide aux petits ruminants en Corse pour la campagne 2025 sont les suivants :

- le montant unitaire de base pour les femelles éligibles ovines est fixé à 23,41 euros par animal primé ;

- le montant unitaire de base pour les femelles éligibles caprines est fixé à 16,25 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles ovines est fixé à 46,82 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles caprines est fixé à 32,51 euros par animal primé.
