# Article 1

Les montants unitaires de l'aide aux petits ruminants en Corse pour la campagne 2025 sont les suivants :

- le montant unitaire de base pour les femelles éligibles ovines est fixé à 22,23 euros par animal primé ;

- le montant unitaire de base pour les femelles éligibles caprines est fixé à 15,43 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles ovines est fixé à 44,47 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles caprines est fixé à 30,88 euros par animal primé.
