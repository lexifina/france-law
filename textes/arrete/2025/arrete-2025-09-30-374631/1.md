# Article 1

Les montants unitaires de l'aide aux petits ruminants en Corse pour la campagne 2025 sont les suivants :

- le montant unitaire de base pour les femelles éligibles ovines est fixé à 25,00 euros par animal primé ;

- le montant unitaire de base pour les femelles éligibles caprines est fixé à 17,36 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles ovines est fixé à 50,00 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles caprines est fixé à 34,72 euros par animal primé.
