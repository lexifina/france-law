# Article 8

Tous renseignements complémentaires peuvent être obtenus :

- sur internet à l'adresse suivante :

- pour le concours interne : https://recrutement.ecologie.gouv.fr/concours/officier-ere-port-capitaine-port-du-2e-grade-op-concours-interne ;

- pour le concours externe : https://recrutement.ecologie.gouv.fr/concours/officier-ere-port-capitaine-port-du-2e-grade-op-concours-externe ;

- par courriel auprès du pôle en charge des concours interne et externe pour le recrutement d'officiers de port (capitaines de port de 2e classe :

- pour le concours interne : concours.op-int@developpement-durable.gouv.fr ;

- pour le concours externe : concours.op-ext@developpement-durable.gouv.fr
