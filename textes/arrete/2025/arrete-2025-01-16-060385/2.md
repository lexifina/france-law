# Article 2

Pour application de l'article R. 4111-13-8-4 du code de la santé publique, pour la profession de médecin, les spécialités pour lesquelles le ressort géographique de la commission compétente dans l'examen des demandes d'attestation d'exercice provisoire est régional sont les suivantes :

Anesthésie-réanimation ;

Chirurgie orthopédique et traumatologique ;

Chirurgie viscérale et digestive ;

Gériatrie ;

Gynécologie obstétrique ;

Hépato-gastro-entérologie ;

Médecine cardiovasculaire ;

Médecine d'urgence ;

Médecine générale ;

Neurologie ;

Pédiatrie ;

Pneumologie ;

Psychiatrie ;

Radiologie et imagerie médicale.
