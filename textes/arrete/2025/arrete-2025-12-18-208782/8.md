# Article 8

Tous renseignements complémentaires peuvent être obtenus :

- sur internet à l'adresse suivante :

- pour le concours interne : https://recrutement.ecologie.gouv.fr/concours/officier-ere-port-adjoint-e-lieutenant-e-port-opa-concours-interne ;

- pour le concours externe : https://recrutement.ecologie.gouv.fr/concours/officier-ere-port-adjoint-e-lieutenant-e-port-opa-concours-externe ;

- par courriel auprès du pôle en charge des concours interne et externe pour le recrutement d'officiers de port adjoints (lieutenants de port) :

- pour le concours interne : concours.opa-int@developpement-durable.gouv.fr ;

- pour le concours externe : concours.opa-ext@developpement-durable.gouv.fr
