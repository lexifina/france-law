# Article 2

Le tarif de l'entretien d'évaluation est de 40 euros, facturable avec le code EEP.

Le tarif d'une séance d'accompagnement psychologique est de 30 euros, facturable avec le code APS pour les séances réalisées en présentiel et avec le code PSS pour les séances réalisées à distance par vidéotransmission.

Un psychologue ne peut effectuer annuellement plus de 20 % de son activité conventionnée à distance.
