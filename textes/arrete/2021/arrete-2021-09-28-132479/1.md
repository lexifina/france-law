# Article 1

Sont classées sur la liste I des substances vénéneuses les substances suivantes sous toutes leurs formes :

- acalabrutinib ;

- avapritinib ;

- crizanlizumab ;

- dapivirine ;

- entrectinib ;

- filgotinib ;

- glasdégib ;

- imlifidase ;

- léfamuline ;

- luspatercept ;

- remdésivir.
