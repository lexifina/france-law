# Article 3

Le préfet, lorsque le projet porte sur un immeuble de grande hauteur, ou le maire, dans les autres cas, affecte aux demandes un numéro d'enregistrement de 13 caractères suivant les lettres AT.

La structure du numéro d'enregistrement est la suivante :

― le numéro de code géographique INSEE du département (trois chiffres) ;

― le numéro de code géographique INSEE de la commune (trois chiffres) ;

― les deux derniers chiffres du millésime de l'année de dépôt de la demande (deux chiffres) ;

― le numéro de dossier composé de cinq caractères : le premier de ces cinq caractères est réservé au service instructeur ; les quatre autres caractères sont utilisés pour une numérotation en continu.
