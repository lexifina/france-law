# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération française démocratique du travail (CFDT) : 31,18 % ;

- La Confédération générale du travail (CGT) : 30,49 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 20,95 % ;

- L'Union Régionale 974 (UR 974) : 17,38 %.
