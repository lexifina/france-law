# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération générale du travail (CGT) : 35,09 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 29,07 % ;

- La Confédération française démocratique du travail (CFDT) : 23,37 % ;

- La Confédération française des travailleurs chrétiens (CFTC) : 12,47 %.
