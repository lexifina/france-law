# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- la Confédération générale du travail (CGT) : 39,19 % ;

- la Confédération générale du travail-Force ouvrière (CGT-FO) : 22,96 % ;

- la Confédération française démocratique du travail (CFDT) : 21,55 % ;

- la Confédération française des travailleurs chrétiens (CFTC) : 12,20 % ;

- la Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 4,10 %.
