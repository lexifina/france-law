# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération générale du travail (CGT) : 61,62 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 15,63 % ;

- L'Union nationale des syndicats autonomes (UNSA) : 12,70 % ;

- La Confédération française des travailleurs chrétiens (CFTC) : 10,05 %.
