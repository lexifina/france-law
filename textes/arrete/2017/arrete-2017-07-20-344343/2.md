# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- la Confédération générale du travail (CGT) : 40,06 % ;

- la Confédération française démocratique du travail (CFDT) : 23,69 % ;

- la Confédération générale du travail-Force ouvrière (CGT-FO) : 22,72 % ;

- la Confédération française des travailleurs chrétiens (CFTC) : 13,26 % ;

- la Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 0,27 %.
