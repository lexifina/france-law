# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- L'Union syndicale Solidaires (SOLIDAIRES) : 37,67 % ;

- La Confédération générale du travail (CGT) : 27,75 % ;

- La Confédération française démocratique du travail (CFDT) : 22,87 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 11,70 %.
