# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- la Confédération générale du travail (CGT) : 30,41 % ;

- la Confédération française démocratique du travail (CFDT) : 22,67 % ;

- la Confédération française des travailleurs chrétiens (CFTC) : 17,61 % ;

- la Confédération générale du travail-Force ouvrière (CGT-FO) : 17,47 % ;

- l'Union nationale des syndicats autonomes (UNSA) : 10,25 % ;

- la Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 1,60 %.
