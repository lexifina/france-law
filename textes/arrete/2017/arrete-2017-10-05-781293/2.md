# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

La Confédération générale du travail (CGT) : 51,28 % ;

La Confédération française démocratique du travail (CFDT) : 15,76 % ;

La Confédération française des travailleurs chrétiens (CFTC) : 15,61 % ;

La Confédération générale du travail-Force ouvrière (CGT-FO) : 12,73 % ;

La Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 4,61 %.
