# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- la Confédération générale du travail (CGT) : 41,47 % ;

- la Confédération française démocratique du travail (CFDT) : 25,99 % ;

- la Confédération générale du travail-Force ouvrière (CGT-FO) : 16,58 % ;

- l'Union syndicale Solidaires (SOLIDAIRES) : 15,96 %.
