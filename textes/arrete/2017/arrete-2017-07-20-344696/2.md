# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 36,44 % ;

- La Confédération française démocratique du travail (CFDT) : 20,66 % ;

- La Confédération générale du travail (CGT) : 19,54 % ;

- La Confédération française des travailleurs chrétiens (CFTC) : 12,01 % ;

- La Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 11,33 %.
