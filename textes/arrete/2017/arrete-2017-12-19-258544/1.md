# Article 1

A compter du 1er novembre 2017, sont inscrits sur la liste des sportifs des Collectifs nationaux, les sportifs dont les noms figurent en annexe du présent arrêté et relevant des fédérations françaises suivantes :

- Athlétisme ;

- Aviron ;

- Badminton ;

- Baseball, softball et cricket ;

- Billard ;

- Boxe ;

- Course d'orientation ;

- Cyclisme ;

- Danse ;

- Equitation ;

- Escrime ;

- Etude et sports sous-marins ;

- Football ;

- Football américain ;

- Force athlétique ;

- Golf ;

- Gymnastique ;

- Haltérophilie ;

- Handisport ;

- Judo-jujitsu kendo et disciplines associées ;

- Karaté et disciplines associées ;

- Lutte ;

- Montagne et escalade ;

- Natation ;

- Parachutisme ;

- Pelote basque ;

- Pentathlon moderne ;

- Pétanque ;

- Roller sports ;

- Rugby ;

- Rugby à XIII ;

- Sauvetage et secourisme ;

- Savate, boxe française et disciplines associées ;

- Ski nautique ;

- Sport adapté ;

- Sport automobile ;

- Sport boules ;

- Sports de glace ;

- Squash ;

- Surf ;

- Taekwondo et disciplines associées ;

- Tennis ;

- Tennis de table ;

- Tir ;

- Vol libre ;

- Volley-ball.
