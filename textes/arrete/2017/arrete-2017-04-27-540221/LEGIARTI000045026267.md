# Article LEGIARTI000034540244

ANNEXE

Liste des Etats où l'envoi par courrier sécurisé du passeport est autorisé :

- les Etats membres de l'Union européenne ;

- Argentine ;

- Australie ;

- Brésil ;

- Canada ;

- Chine ;

- Etats-Unis ;

- Japon ;

- Norvège ;

- Nouvelle-Zélande ;

- Russie ;

- Suisse.
