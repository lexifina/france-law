# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

La Confédération générale du travail (CGT) : 39,84 % ;

La Confédération générale du travail-Force ouvrière (CGT-FO) : 21,36 % ;

La Confédération française démocratique du travail (CFDT) : 20,97 % ;

L'Union syndicale Solidaires (SOLIDAIRES) : 17,82 %.
