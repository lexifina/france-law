# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- la Confédération française démocratique du travail (CFDT) : 41,87 % ;

- la Confédération générale du travail (CGT) : 27,54 % ;

- la Confédération française des travailleurs chrétiens (CFTC) : 18,32 % ;

- la Confédération générale du travail-Force ouvrière (CGT-FO) : 12,27 %.
