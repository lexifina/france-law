# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération française démocratique du travail (CFDT) : 35,84 % ;

- La Confédération générale du travail (CGT) : 29,91 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 24,58 % ;

- L'Union nationale des syndicats autonomes (UNSA) : 9,67 %.
