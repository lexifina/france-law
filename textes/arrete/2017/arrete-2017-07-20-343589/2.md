# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération française démocratique du travail (CFDT) : 38,37 % ;

- La Confédération générale du travail (CGT) : 31,65 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 19,24 % ;

- La Confédération française des travailleurs chrétiens (CFTC) : 10,74 %.
