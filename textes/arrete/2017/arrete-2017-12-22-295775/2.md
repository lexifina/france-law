# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération générale du travail (CGT) : 33,02 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 21,52 % ;

- La Confédération française démocratique du travail (CFDT) : 19,07 % ;

- La Confédération française des travailleurs chrétiens (CFTC) : 14,63 % ;

- La Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 11,77 %.
