# Article 1-1

Une période transitoire s'achevant le 31 décembre 2022 est accordée dans le cadre de l'article 15, point 4 du règlement (UE) n° 1151/2012 susvisé, aux opérateurs suivants :

- le GAEC des normandes (SIRET : 38531072700016) ;

- le GAEC des Quesnel (SIRET : 41022988400011) ;

- le GAEC du chalet (SIRET : 34005162200017) ;

- le GAEC de la cour des mares (SIRET : 34897314000026) ;

- le GAEC du hameau (SIRET : 38259121200016) ;

- le GAEC du petit flot (SIRET : 43783781800016) ;

- l'EARL des clôtures (SIRET : 51075733900013) ;

- le GAEC du Clos Roset (SIRET : 48310227300016) ;

- le GAEC de la Ronchette (SIRET : 49754563200018) ;

- le GAEC du Village Culot (SIRET : 83180144400017).
