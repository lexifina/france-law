# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- la Confédération française démocratique du travail (CFDT) : 28,41 % ;

- la Confédération générale du travail (CGT) : 28,06 % ;

- la Confédération générale du travail-Force ouvrière (CGT-FO) : 20,41 % ;

- la Confédération française des travailleurs chrétiens (CFTC) : 15,21 % ;

- la Confédération française de l'encadrement-Confédération générale des cadres (CFE-CGC) : 7,91 %.
