# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

- La Confédération générale du travail (CGT) : 33,96 % ;

- La Confédération générale du travail-Force ouvrière (CGT-FO) : 27,61 % ;

- La Confédération française démocratique du travail (CFDT) : 18,28 % ;

- L'Union nationale des syndicats autonomes (UNSA) : 10,26 % ;

- La Confédération française des travailleurs chrétiens (CFTC) : 9,89 %.
