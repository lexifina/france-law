# Article Annexe III

L'épreuve de secourisme vise à vérifier que le candidat a reçu une formation aux premiers secours spécifiques au taxi.

Le programme de l'épreuve portera sur les thèmes suivants :

- les grands principes de secourisme :

- protéger ;

- alerter ;

- secourir ;

- les dégagements d'urgence :

- bilan et surveillance ;

- les hémorragies ;

- l'inconscience ;

- l'arrêt ventilatoire ;

- l'arrêt cardio-ventilateur ;

- les malaises ;

- les plaies et brûlures ;

- les fractures.
