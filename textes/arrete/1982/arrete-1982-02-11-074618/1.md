# Article 1

Par dérogation exceptionnelle aux dispositions des articles 2 et 3 du décret du 16 septembre 1958 modifié relatif à la pêche fluviale, la pêche des écrevisses est interdite pendant l'année 1982, par quelque mode que ce soit, dans les eaux et pour les espèces ci-après désignées :

Département des Hautes-Alpes.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses.

Département de l'Ariège.

Sur tous les cours d'eau ou parties de cours d'eau des deux catégories pour toutes les espèces d'écrevisses. Département de l'Aude.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses, sauf pour l'écrevisse américaine dans les canaux du domaine public. Département de la Charente-Maritime.

Sur tous les cours d'eau ou sections de cours d'eau de la 1ère catégorie pour toutes les espèces d'écrevisses. Département de l'Indre.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour les écrevisses autres que les écrevisses américaines.

Département du Jura.

Sur tous les cours d'eau ou sections de cours d'eau de la 1ère catégorie pour toutes les espèces d'écrevisses et sur tous les cours d'eau ou sections de cours d'eau de la 2ème catégorie pour les écrevisses autres que les écrevisses américaines. Département des Landes.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses.

Département de la Loire.

Sur tous les cours d'eau ou sections de cours d'eau de la 1ère catégorie et de la 2ème catégorie pour les écrevisses autres que les écrevisses américaines.

Département du Pas-de-Calais.

Sur les cours d'eau la Slack et le Wimereux pour toutes les espèces d'écrevisses. Département des Hautes-Pyrénées.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses. Département de Saône-et-Loire.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour les écrevisses autres que les écrevisses américaines.

Département de la Haute-Savoie.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses, sous réserve des règlementations particulières concernant les lacs Léman et d'Annecy. Département de Tarn-et-Garonne.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses.

Département de Vaucluse.

Sur tous les cours d'eau ou sections de cours d'eau de la 1ère catégorie pour toutes les espèces d'écrevisses et sur tous les cours d'eau ou sections de cours d'eau de la 2ème catégorie pour les écrevisses autres que les écrevisses américaines.

Département de la Vienne.

Sur tous les cours d'eau ou sections de cours d'eau de la 1ère catégorie pour toutes les espèces d'écrevisses et sur tous les cours d'eau ou sections de cours d'eau de la 2ème catégorie pour les écrevisses autres que les écrevisses américaines.

Département des Vosges.

Sur tous les cours d'eau ou sections de cours d'eau des deux catégories pour toutes les espèces d'écrevisses. Département de l'Yonne.

Sur tous les cours d'eau ou sections de cours d'eau de la 1ère catégorie pour toutes les espèces d'écrevisses.
