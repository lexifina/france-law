# Article ANNEXE II, 4

Dimensions de l'élément

Pour les essais 3 a et 3 b, l'élément d'essai doit présenter les dimensions les plus grandes compatibles avec les dimensions des fours existants. Ces dimensions ne doivent jamais être inférieures à 3,70 mètres X 3 mètres (surface exposée).

Pour les essais 3 c (essais additionnels), l'élément peut être de plus petites dimensions.
