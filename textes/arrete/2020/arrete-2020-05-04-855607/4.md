# Article 4

Les données d'identification des candidats sont :

- l'identifiant unique du candidat ;

- le nom de famille du candidat ;

- le nom d'usage du candidat ;

- le premier prénom à l'état civil du candidat ;

- le sexe du candidat ;

- la date de naissance du candidat ;

- le libellé du pays de naissance du candidat ;

- le code du département de la commune de naissance pour les candidats nés en France ;

- le libellé de la commune de naissance pour les candidats nés en France ;

- la 1re ligne de l'adresse du candidat ;

- la 2e ligne de l'adresse du candidat ;

- la 3e ligne de l'adresse du candidat ;

- le code postal de la commune de résidence du candidat ;

- le libellé de la commune de résidence ;

- le libellé du pays de résidence du candidat ;

- l'adresse de courrier électronique ;

- le numéro de téléphone du candidat ;

- l'état de validation de l'inscription du candidat par l'autorité organisatrice du recrutement.
