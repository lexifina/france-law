19. Alliages de cuivre pour les produits métalliques du groupe D

En sus des alliages mentionnés aux points précédents de la présente annexe, les alliages respectant les conditions suivantes peuvent être utilisés pour les produits du groupe D :

- cuivre, zinc, silicium, étain, phosphore : pas de restriction ;

- aluminium, fer, manganèse : ≤ 3,0% (m/m) ;

- plomb : ≤ 3,5% (m/m) ;

- nickel : ≤ 3,0% (m/m) ;

- arsenic, antimoine : ≤ 0,25% (m/m) ;

- autres éléments : ≤ 0,1% (m/m).
