# Article LEGIARTI000041742657

ANNEXE

LISTE DES DONNÉES À CARACTÈRE PERSONNEL ET DES INFORMATIONS ENREGISTRÉES DANS LE TRAITEMENT « ORFIM »

I. - Données relatives aux données d'identification des personnes :

1° Nom ;

2° Prénom(s) ;

3° Date et lieu de naissance ;

4° Sexe ;

5° Photo ;

6° Numéro de téléphone ;

7° Adresse principale domicile ;

8° Adresse électronique personnelle ;

9° Identifiant défense (NID).

II. - Données relatives à la vie professionnelle :

1° Fonction/poste occupé ;

2° Nom de la société ;

3° Nom du service ;

4° Adresse électronique professionnelle ;

5° Numéro de téléphone professionnel ;

6° Expériences ;

a) Postes précédents ;

b) Diplômes civil et militaires ;

c) Curriculum vitae ;

d) Scolarité ;

e) Formations ;

f) Attestation de formations/certifications ;

g) Contrat de travail pour les formateurs ;

h) Heures travaillées pour les formateurs ;

i) Permissions, autres congés, motif pour les formateurs.
