# Article Annexe 2

Annexe 2 : Disciplines, domaines, options

Le diplôme d'Etat de professeur de musique est délivré dans les disciplines suivantes :

- enseignement instrumental ou vocal ;

- domaines :

- classique à contemporain (options : instruments concernés) ;

- musique ancienne (options : instruments concernés) ;

- musiques traditionnelles (options : aires culturelles, instruments concernés) ;

- jazz et musiques improvisées (options : instruments concernés) ;

- musiques actuelles amplifiées (options : instruments concernés) ;

- formation musicale ;

- accompagnement (options : musique, danse) ;

- direction d'ensembles (options : instrumentaux, vocaux) ;

- culture musicale ;

- écriture ;

- création musicale contemporaine (options : composition instrumentale et vocale, composition électro-acoustique sur support et temps réel, musique mixte, improvisation instrumentale ou vocale).
