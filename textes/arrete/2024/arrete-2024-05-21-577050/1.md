# Article 1

Pour l'année 2024, en fonction de l'option tarifaire choisie en application des dispositions de l'article R. 314-164 du code de l'action sociale et des familles, les valeurs annuelles du point mentionnées à l'article R. 314-162 du même code sont les suivantes :

1° Pour les établissements ayant opté pour le tarif global et ne disposant pas de pharmacie à usage intérieur : 13,29 € ;

2° Pour les établissements ayant opté pour le tarif global et disposant d'une pharmacie à usage intérieur : 14,00 € ;

3° Pour les établissements ayant opté pour le tarif partiel et ne disposant pas de pharmacie à usage intérieur : 11,30 € ;

4° Pour les établissements ayant opté pour le tarif partiel et disposant d'une pharmacie à usage intérieur : 11,97 €.

Les valeurs annuelles du point des tarifs plafonds sont majorées de 20 % dans les départements d'outre-mer comme suit :

1° Pour les établissements ayant opté pour le tarif global et ne disposant pas de pharmacie à usage intérieur : 15,95 € ;

2° Pour les établissements ayant opté pour le tarif global et disposant d'une pharmacie à usage intérieur : 16,80 € ;

3° Pour les établissements ayant opté pour le tarif partiel et ne disposant pas de pharmacie à usage intérieur : 13,56 € ;

4° Pour les établissements ayant opté pour le tarif partiel et disposant d'une pharmacie à usage intérieur : 14,36 €.
