# Article LEGIARTI000049381014

Dans le cas de sources d'alimentation internes, le nombre maximal de points est 22. Note pour ce sous-critère = (nombre de points obtenus/22) × 10.

Dans le cas de sources d'alimentation externes, le nombre maximal de points est 20. Note pour ce sous-critère = (nombre de points obtenus/20) × 10.
