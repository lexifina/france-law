# Article LEGIARTI000049381010

Dans le cas de sources d'alimentation internes, le nombre maximal de points est 12. Note pour ce sous-critère = (nombre de points obtenus/12) × 10.

Dans le cas de sources d'alimentation externes, le nombre maximal de points est 9. Note pour ce sous-critère = (nombre de points obtenus/9) × 10.
