# Article 1

Les montants unitaires de l'aide aux petits ruminants en Corse pour la campagne 2024 sont les suivants :

- le montant unitaire de base pour les femelles éligibles ovines est fixé à 24 euros par animal primé ;

- le montant unitaire de base pour les femelles éligibles caprines est fixé à 16,67 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles ovines est fixé à 48 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles caprines est fixé à 33,33 euros par animal primé.
