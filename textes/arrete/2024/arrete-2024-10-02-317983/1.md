# Article 1

Les montants unitaires de l'aide aux petits ruminants en Corse pour la campagne 2024 sont les suivants :

- le montant unitaire de base pour les femelles éligibles ovines est fixé à 21,31 euros par animal primé ;

- le montant unitaire de base pour les femelles éligibles caprines est fixé à 14,82 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles ovines est fixé à 42,61 euros par animal primé ;

- le montant unitaire supérieur pour les femelles éligibles caprines est fixé à 29,65 euros par animal primé.
