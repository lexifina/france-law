# Article 3

Les listes de candidatures devront comporter :

a) Pour le collège des maires des communes de moins de 20.000 habitants dénommé Premier collège : douze noms de titulaires auxquels correspond pour chacun un nom de suppléant ;

b) Pour le collège des maires des communes de 20.000 habitants et plus dénommé Second collège : douze noms de titulaires auxquels correspond pour chacun un nom de suppléant ;

c) Pour le collège des présidents de conseil général dénommé Troisième collège : huit noms de titulaires auxquels correspond pour chacun un nom de suppléant ;

d) Pour le collège des présidents de conseil régional dénommé Troisième collège : huit noms de titulaires auxquels correspond pour chacun un nom de suppléant.
