# Article 13

Lors d'une demande d'immatriculation principale, les renseignements relatifs à la personne contenus dans la demande sont justifiés par les pièces énumérées ci-dessous ;

Pour les personnes physiques, dans l'annexe n° 1 ; Pour les sociétés de droit français, dans l'annexe n° 2 ;

Pour les sociétés étrangères, dans l'annexe n° 3 ;

Pour les groupements d'intérêt économique, dans l'annexe n° 4 ; Pour les établissements publics français ainsi que les représentations ou agences commerciales des Etats, collectivités ou établissements publics étrangers, dans l'annexe n° 5 ;

Pour les autres personnes morales non commerçantes, dans l'arrêté particulier qui les régit.
