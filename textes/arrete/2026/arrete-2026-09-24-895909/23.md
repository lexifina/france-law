# Article 23

En cas de perte du code de vote transmis par l'ENSAP, l'électeur conserve la possibilité de le consulter et de le télécharger à nouveau sur son compte personnel ENSAP.

En cas de perte du code de vote transmis par voie papier, l'électeur contacte le service des ressources humaines de proximité qui lui a initialement remis son code de vote pour qu'il effectue un réassort avec un nouveau code de vote papier.
