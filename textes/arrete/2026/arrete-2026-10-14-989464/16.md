# Article 16

En application de l'article R. 211-553 du code général de la fonction publique, les moyens d'authentification comprennent un identifiant de vote, un mot de passe, ainsi qu'un code de vote (code PIN) crée par l'électeur. Ils sont nécessaires aux opérations de vote.

Au moins quinze jours avant le premier jour du scrutin, les agents détenant un compte sur l'Espace numérique sécurisé de l'agent public (ENSAP) reçoivent, via cet espace, leur carte électeur sur laquelle figure leur identifiant. Les agents reçoivent également un mail contenant un lien pour se connecter à l'espace d'électeur et contenant leur mot de passe provisoire. En cas d'oubli ou de perte de ce dernier, les électeurs auront toujours la possibilité d'obtenir un nouveau mot de passe.

Les agents ne disposant pas d'un compte ENSAP reçoivent leur identifiant par courrier postal, par courriel ou en main propre. Ils peuvent également récupérer leur identifiant via la plateforme « FranceConnect », disponible sur la page d'accueil du portail de vote.

A la première connexion au portail d'électeur, l'électeur crée un code PIN à quatre chiffres. Ce code doit être saisi à chaque vote afin de valider son vote.

En cas de perte ou d'oubli du code PIN, une procédure d'attribution d'un nouveau code PIN est accessible dès l'ouverture du portail d'électeur dans l'espace «  Mon compte  », via l'option «  Demander la modification de mon code de validation (PIN)  ».
