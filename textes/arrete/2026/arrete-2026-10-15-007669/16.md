# Article 16

L'authentification sur la plateforme de vote se fait par la saisine de deux authentifiants communiqués à l'électeur sur deux canaux sécurisés distincts et individuels.

Le premier authentifiant est constitué d'une connexion via ProConnect ou d'un code temporaire envoyé sur demande de l'électeur sur son courrier électronique professionnel.

Le deuxième authentifiant est constitué d'un code temporaire envoyé à la demande sur le numéro de téléphone professionnel de l'électeur ou du code déposé sur l'espace Numérique Sécurisé de l'Agent Public (ENSAP) de l'électeur ou, pour les électeurs n'ayant pas de compte ENSAP, d'un code envoyé par courrier postal.
