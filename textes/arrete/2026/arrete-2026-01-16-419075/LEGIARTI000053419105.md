# Article LEGIARTI000053419105

Annexe 2

Disciplines

Le certificat d'aptitude aux fonctions de professeur de musique est délivré dans les disciplines suivantes :

- enseignement instrumental ou vocal :

- domaines :

- classique à contemporain (options : instruments concernés) ;

- musique ancienne (options : instruments concernés) ;

- musique traditionnelle (options : aire culturelle, instruments concernés) ;

- jazz et musiques improvisées (options : instruments concernés) ;

- musiques actuelles amplifiées (options : instruments concernés) ;

- formation musicale ;

- accompagnement ;

- direction d'ensembles (options : instrumentaux, vocaux) ;

- culture musicale ;

- écriture ;

- création musicale contemporaine (options : composition instrumentale et vocale, composition électroacoustique sur support et temps réel, musique mixte, improvisation instrumentale ou vocale).
