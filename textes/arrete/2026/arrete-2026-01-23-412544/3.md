# Article 3

Cet agrément est limité aux expérimentions pratiquées dans les conditions suivantes :

Domaines d'activités :

Recherche fondamentale ;

Recherche médicale humaine ;

Mise au point, production, essai de qualité, d'efficacité ou d'innocuité de médicaments, d'aliments pour animaux et d'autres substances ou produits ;

Recherche appliquée ;

Expertises.

Espèces animales utilisées :

Souris (Mus musculus) : différentes souches ;

Lapins (Oryctolagus cuniculus) : différentes races ;

Porcs (Sus scrofa domesticus) : différentes races.

Types de procédures mises en œuvre :

Examens cliniques sur animaux vigiles ;

Examens cliniques sur animaux anesthésiés ;

Administration de substances sur animaux vigiles ;

Administration de substances sur animaux anesthésiés ;

Prélèvements sur animaux vigiles ;

Prélèvements sur animaux anesthésiés ;

Interventions chirurgicales ;

Conditionnement, apprentissage ;

Evaluations du comportement ;

Enregistrements physiologiques ;

Imagerie ;

Euthanasies d'animaux.
