(1) Types de présentations :

BM = (belly meat), chair de l'abdomen.

DWT = (dressed weight), poids paré (éviscéré, étêté, sans branchie et nageoires coupées).

FIL = (fillet weight), poids fileté.

GGWT = (gilled and gutted), éviscéré, sans gonade et sans branchie (équivalent du code GUG).

GWT = (gutted weight), éviscéré, sans gonade (équivalent du code GUT).

OT = (other), autre présentation.

RWT = (round weight), poids arrondi du poisson entier (toutes les statistiques de capture sont établies en poids arrondi) (équivalent du code WHL).
