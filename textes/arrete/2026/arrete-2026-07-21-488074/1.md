# Article 1

Pour l'année universitaire 2026-2027, le nombre maximal de places pour les collectivités mentionnées à l'article 1er du décret n° 2023-960 du 19 octobre 2023 susvisé est fixé à 36 places selon la répartition suivante :

- pour la Guadeloupe : 10 ;

- pour la Guyane : 9 ;

- pour la Martinique : 10 ;

- pour Saint-Martin : 5 ;

- pour Saint-Pierre-et-Miquelon : 2.

Les places qui ne pourraient pas être pourvues selon cette répartition peuvent être réattribuées.

Le nombre d'étudiants retenus lors de l'année universitaire précédente pour entamer un cursus d'enseignement complet dans le cadre de l'expérimentation est sans incidence sur ces nombres maximaux de nouvelles places ouvertes pour 2026.
