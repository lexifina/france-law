# Article 3

Le numéro du passeport est constitué du code ISO de la France (FR) suivi d'un code alphanumérique unique, conformément à l'article 71 du règlement délégué (UE) 2019/2035 modifié susvisé et à l'annexe I du règlement d'exécution (UE) 2026/705 susvisé. Le code alphanumérique contient le code identifiant de l'éditeur constitué de deux lettres puis d'un numéro unique composé de huit chiffres.

Le numéro de passeport est imprimé sur la première de couverture et sur chacune des pages avec hauteur minimale de 2 millimètres.
