# Article 2

Le nombre maximum de places offertes aux concours, au titre de l'année 2026, dans les Instituts nationaux des sciences appliquées (INSA) est fixé comme suit :

Formation d'ingénieurs

a) Accès en première année :

- INSA Centre-Val de Loire : 250 places ;

- INSA Hauts-de-France : 220 places ;

- INSA de Lyon : 917 places (6) ;

- INSA de Rennes : 270 places(7) ;

- INSA de Rouen : 285 places ;

- INSA de Strasbourg : 224 places ;

- INSA de Toulouse : 480 places.

Total : 2 646 places ;

b) Accès en deuxième année :

- INSA Centre-Val de Loire : 12 places ;

- INSA Hauts-de-France : 10 places ;

- INSA de Rennes : 24 places ;

- INSA de Rouen : 35 places (8) ;

- INSA de Strasbourg : 30 places ;

- INSA de Toulouse : 60 places.

Total : 171 places ;

c) Accès en troisième année :

- INSA Centre-Val de Loire : 250 places (9) ;

- INSA Hauts-de-France : 171 places (10) ;

- INSA de Lyon : 560 places (11) ;

- INSA de Rennes : 172 places (12) ;

- INSA de Rouen : 336 places (13) ;

- INSA de Strasbourg : 285 places (14) ;

- INSA de Toulouse : 270 places (15).

Total : 2 044 places.

d) Accès en quatrième année :

- INSA Centre-Val de Loire : 12 places ;

- INSA Hauts-de-France : 76 places (16) ;

- INSA de Lyon : 65 places ;

- INSA de Rennes : 20 places ;

- INSA de Rouen : 16 places ;

- INSA de Strasbourg : 55 places (17) ;

- INSA de Toulouse : 55 places (18).

Total : 299 places.

Formation d'architectes à l'INSA de Strasbourg

a) Accès en première année : 36 places ;

b) Accès en quatrième année (concours sur titres) :

- étudiants ingénieurs issus de 3e année du double cursus architecte-ingénieur de l'INSA de Strasbourg (240 ECTS validés) : 20 places ;

- candidats titulaires d'un diplôme d'ingénieur et du diplôme d'études en architecture conférant grade de licence : 4 places ;

- candidats titulaires d'un diplôme d'architecte étranger : 4 places.

Total : 64 places.
