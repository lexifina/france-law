# Article 1

Le cantonnement de pêche du golfe de Beauduc devant la commune des Saintes-Maries-de-la-Mer est renouvelé sans limitation de durée à compter de la date de publication du présent arrêté.

Cette zone est délimitée par une ligne reliant les points suivants (système de coordonnées WGS84) :

Point A :

- latitude : 43°2633.81 N ;

- longitude : 4°3232.22 E.

Point B :

- latitude : 43°2612.82 N ;

- longitude : 4°3334.44 E.

Point C :

- latitude : 43°2448.38 N ;

- longitude : 4°3236.04 E.

Point D :

- latitude : 43°258.56 N ;

- longitude : 4°3132.21 E.
