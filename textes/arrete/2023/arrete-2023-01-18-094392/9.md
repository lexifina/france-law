# Article 9

I. - La décision d'agrément mentionne :

- la dénomination sociale de l'organisme agréé ;

- l'adresse de l'établissement principal de l'organisme agréé ;

- le numéro d'agrément ;

- la date d'expiration de l'agrément ;

- le cas échéant, les conditions limitatives dans lesquelles l'agrément est délivré ;

- le cas échéant, les adresses des établissements inclus dans le périmètre géographique de l'agrément de l'organisme agréé.

II. - Pour une première demande, l'agrément est délivré par décision de l'Autorité de sûreté nucléaire pour une période maximale de deux ans.

III. - Pour un renouvellement, l'agrément est délivré par décision de l'Autorité de sûreté nucléaire pour une période maximale de cinq ans.
