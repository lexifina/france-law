# Article Préambule

Pour les agents biologiques, les groupes 1 à 4 considérés dans les présentes annexes sont ceux définis à l'article R. 4421-3 du code du travail.

Pour les organismes génétiquement modifiés, les groupes I à IV considérés dans les présentes annexes sont ceux définis à l'article D. 532-2 du code de l'environnement.
