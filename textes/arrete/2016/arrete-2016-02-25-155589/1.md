# Article 1

Sont classés sur la liste I des substances vénéneuses les produits suivants sous toutes leurs formes :

- alirocumab ;

- asfotase alfa ;

- ceftolozane ;

- complexe de coordination de citrate ferrique ;

- dinutuximab ;

- germanium (68Ge) ;

- isavuconazole ;

- lévosimendan ;

- sonidégib.
