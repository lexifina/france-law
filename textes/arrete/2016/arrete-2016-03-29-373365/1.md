# Article 1

A compter du 1er avril 2016, sont inscrits sur la liste des sportifs de haut niveau, les sportifs dont les noms figurent en annexe du présent arrêté et relevant des fédérations françaises suivantes :

- basket-ball ;

- cyclisme ;

- équitation ;

- escrime ;

- football ;

- golf ;

- gymnastique ;

- handball ;

- handisport ;

- hockey ;

- judo, jujitsu kendo et disciplines associées ;

- karaté et disciplines associées ;

- lutte ;

- montagne et escalade ;

- natation ;

- pelote basque ;

- roller sports ;

- ski ;

- sports de glace ;

- sport automobile ;

- squash ;

- surf ;

- taekwondo ;

- tennis ;

- tennis de table ;

- tir ;

- voile ;

- volley-ball.
