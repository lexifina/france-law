# Article 2

Sont radiées du Catalogue officiel des espèces et variétés de plantes cultivées en France, dont les semences peuvent être soit certifiées en tant que « semences de base » ou « semences certifiées », soit contrôlées en tant que « semences standards » (liste A), à échéance du 31 décembre 2015, les variétés désignées ci-après :

- asperge déclarée hybride : Andreas ;

- aubergine déclarée hybride : Adria ;

- betterave rouge déclarée hybride : Monorhizov1 ;

- carotte déclarée hybride : Melostar, Osiris, Poseidon ;

- chicorée frisée/chicorée scarole : Gargantua ;

- chou cabus déclaré hybride : Alsior, Bouldor ;

- concombre/cornichon déclaré hybride : Lassie ;

- courgette déclarée hybride : El Greco, Espada, Falali, Kompass, Mostra ;

- haricot : Cabri, Ducato, Rocky, Selecta, Soleil ;

- laitue : Abruzia, Admiration, Angie, Bellastar, Bisbale, Brasero, Cedrine, Flamenco, Hamac, Kitare, Loira, Loula, Mariola, Miriel, Shetlandia, Stromboli, Tuttifree ;

- mâche : Sapiana ;

- maïs potager : Code609, Hbantam 78, Katana ;

- melon déclaré hybride : Aubrac, Calibro, Cyro, Fangio, Gaspar, Meauzac, Merrylon, Ronsard, Rubens, Saladino, Sofia, SV7559MC ;

- piment/poivron déclaré hybride : Anibal, Eolo ;

- pois potager : Abador, Bayard, Orlando ;

- radis : Clipo ;

- tomate déclarée hybride : Cristal, Erifiz, Gorgol, Hymar, Luminoso, Pasionata, Zircon.

Ces variétés peuvent être commercialisées jusqu'au 30 juin 2018.
