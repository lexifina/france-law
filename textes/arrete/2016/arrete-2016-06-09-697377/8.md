# Article 8

Les procédures d'évaluation de la conformité mentionnées à l'article 5-13 du décret du 3 mai 2001 susvisé sont les suivantes :

1° Le module B, suivi soit du module D, soit du module F, dont les modalités sont précisées à l'annexe XIV. Toutefois, le module B n'est pas obligatoire pour les instruments qui n'utilisent pas de dispositif électronique et dont le dispositif mesureur de charge n'utilise pas de ressort pour équilibrer la charge. Pour les instruments non soumis au module B, le module D1 ou le module F1, dont les modalités sont précisées à l'annexe XIV, s'appliquent ;

2° Le module G, dont les modalités sont précisées à l'annexe XIV.
