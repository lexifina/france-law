# Article 2

Dans cette branche, pour la négociation des accords collectifs en application de l'article L. 2232-6 du code du travail, le poids des organisations syndicales représentatives est le suivant :

La Confédération générale du travail (CGT) : 40,82 % ;

La Confédération française démocratique du travail (CFDT) : 26,02 % ;

La Confédération française des travailleurs chrétiens (CFTC) : 11,22 % ;

L'Union nationale des syndicats autonomes (UNSA) : 11,22 % ;

La Confédération générale du travail-Force ouvrière (CGT-FO) : 10,71 %.
