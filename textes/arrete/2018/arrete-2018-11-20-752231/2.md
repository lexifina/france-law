# Article 2

Les catégories de données à caractère personnel enregistrées dans le traitement mentionné à l'article 1er sont :

1. Pour les artistes, collectifs et architectes :

1. Données d'identification : civilité, Nom, Prénom, Nationalité des artistes ;

2. Vie professionnelle : adresse, courriel, téléphone, fax, biographie de l'artiste ;

3. Informations d'ordre économique et financier : coût des œuvres achetées ou commandées, honoraires des artistes et des agences d'assistance aux projets ;

2. Pour les représentants des agences d'assistance aux projets et des maîtrises d'œuvre et d'ouvrage :

1. Données d'identification : civilité, Nom, Prénom ;

2. Vie professionnelle : adresse, courriel, téléphone, fax.

3. Pour les galeristes :

1. Données d'identification : raison sociale, Nom, Prénom ;

2. Vie professionnelle : adresse.

4. Pour les utilisateurs :

1. Données d'identification : nom, Prénom ;

2. Vie professionnelle : courriel ;

3. Données de connexion : nom d'utilisateur (login).
