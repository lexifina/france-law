# Article 1

Sont classés sur la liste I des substances vénéneuses les produits suivants sous toutes leurs formes :

- atézolizumab ;

- cariprazine ;

- cénégermine ;

- glécaprévir ;

- guselkumab ;

- niraparib ;

- ocrelizumab ;

- patiromère ;

- pibrentasvir ;

- télotristat ;

- tivozanib ;

- trastuzumab ;

- trientine ;

- velpatasvir ;

- voxilaprévir.
