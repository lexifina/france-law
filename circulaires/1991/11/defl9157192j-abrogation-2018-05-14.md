1. GÉNÉRALITÉS.
Les principes régissant la codification de la position des personnels de réserve de l'armée de l'air sont
identiques à ceux employés pour les personnels d'active.
Cette codification a pour but de permettre le traitement automatisé des informations relatives aux droits et aux
existants. Elle constitue le lien entre ces deux fichiers pour tout traitement informatique.
Elle permet, en outre, de déterminer la position du personnel de réserve lors de consultations :
- des situations automatisées (gestion et administration du personnel) ;
- des documents individuels (fascicules de mobilisation et documents de rappel) ;
- des données sur les matériels informatiques (console et micro).
2. PRÉSENTATION DU SYSTÈME DE CODIFICATION.
 2.1. Principes.
La position de mobilisation est exprimée par un groupe codé de sept caractères.
Ce code permet de définir sans ambiguïté la position de tout réserviste, qu'il relève :
- de l'effectif global mobilisé (EGM) : affecté de mobilisation en unité ;
- d'un volant régional ;
- du volant général ;
- du bureau central d'incorporation et d'archives de l'armée de l'air (BCIAAA).
 2.2. Format général du code.

2.2.1. Premier sous-groupe.
Composé de 5 caractères, il définit soit :
- l'unité d'affectation, pour le personnel affecté de mobilisation appartenant à l'effectif global mobilisé
(EGM) ;
- le volant régional (VR), qui concerne le personnel dans les cadres de réserve sans affectation
particulière et mis à la position de la région aérienne de rattachement ;
- le volant général (VG), pour le personnel dans les cadres de réserve ou placé en position « hors
cadres » et n'appartenant pas à l'EGM ou à un VR ;
- le BCIAAA, pour le personnel rayé des cadres de réserve de l'armée de l'air.
2.2.2. Deuxième sous-groupe.
Composé de 2 caractères, il définit soit :
- le code de mission guerre de l'unité d'affectation pour l'EGM ;
- la position du réserviste dans les autres cas.
 2.3. Expression des différents sous-groupes.
2.3.1. Premier sous-groupe.
a). Réserviste appartenant à l'EGM.
Les 5 caractères forment le numéro de l'unité d'affectation.
b). Réservistes en volant régional.
Les 2 premiers caractères définissent le volant régional et les 3 suivants forment le numéro de la
région aérienne gestionnaire :
- VR 011 : région aérienne Nord-Est.
- VR 012 : région aérienne Méditerranée.
- VR 013 : région aérienne Atlantique.
c). Autres personnels.
La position « en volant général » est codifiée VG 222.
La position « BCIAAA » est codifiée BCIAA.
2.3.2. Deuxième sous-groupe.
a). EGM.

Les 2 caractères représentent le code de mission guerre de l'unité d'affectation.
b). Volant régional.
Les réservistes constituant les volants régionaux doivent être reconnus et disponibles. En
conséquence, seuls les personnels non titulaires d'une position particulière définie en annexe 1
peuvent être placés ou maintenus en volant régional. Dans le cas contraire, ils sont placés en volant
général, soit au BCIAAA.
Le code 00 leur est donc attribué.
c). Volant général et BCIAA.
Les positions particulières des réservistes sont codifiées sur 2 caractères conformément à l'annexe 1.
Dans les autres cas, le code 00 est affecté par défaut. Des exemples de codification sont donnés en
annexe 2.

ANNEXE 2.
EXEMPLES DE CODIFICATIONS.
Premier exemple.
Code : 05107/XY.
Il s'agit d'un réserviste :
- affecté à l'unité 05.107 (contrôle local d'aérodrome Villacoublay) ;
- le code de mission guerre de son unité d'affectation est XY.
Deuxième exemple :
Code : CF123/WZ.
Il s'agit d'un réserviste :
- affecté à l'unité CF.123 (section aérienne du territoire Orléans) ;
- le code de mission guerre de son unité d'affectation est WZ.
Troisième exemple :
Code : VR011/00.
Il s'agit d'un réserviste :
- placé en volant régional Nord-Est ;
- reconnu et disponible 00.
Quatrième exemple :
Code : VG222/60.
Il s'agit d'un réserviste :
- placé en volant général : VG 222 ;
- domicilié outre-mer dans les départements, territoires d'outre-mer et collectivités territoriales : 60.
Cinquième exemple :
Code : BCIAA 96.
Il s'agit d'un réserviste militaire du rang issu du contingent :
- versé au BCIAAA 01.510 : BCIAA ;
- dont le critère de valeur est la lettre C.
