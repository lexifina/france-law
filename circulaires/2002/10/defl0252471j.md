Référence de publication : BOC, p. 7983.
L' instruction 1473 /DEF/DCMAA/ED/P du 18 juin 2002 est modifiée comme suit :
1. Dans le point 2.2.2. Les commissions externes de modification.
Remplacer dans le premier alinéa :
« Pilotées par la DCMAA/sous-direction des établissements (SDET), ces commissions sont composées : »,
Par :
« Pilotées par la DCMAA/sous-direction des opérations logistiques (SDOL), ces commissions sont
composées : »
2. Dans le point 4.2. L'administration des données.
Dans la phrase :
« Cette banque de données se présente sous la forme d'un « catalogue global des données logistiques du
SMAA » (CAG 100) »,
Supprimer : « (CAG 100) ».
3. Dans le point 4.3.2. Pour le personnel non-informaticien.
Remplacer dans le premier alinéa : « le centre d'informatique générale de l'armée de l'air (CIGAA) ».
Par : « le centre informatique de gestion de l'armée de l'air (CIGAA) ».
