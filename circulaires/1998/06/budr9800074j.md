instituée par le décret n° 65-845 du 4 octobre 1965 relative au paiement sans ordonnancement préalable

de codes reste subordonnée à l’accord préalable du Bureau M1 de la Direction.

ANNEXE N° 2
MOIS DE NAISSANCE : il peut prendre les valeurs suivantes :
de 20 à 30, ou 50, 51.... s'agissant de personnes dont le mois de naissance est inconnu.
31 à 42 (janvier à décembre) s'agissant de personnes nées en métropole ou dans un DOM inscrites dans le
répertoire au vu d'une pièce ne comprenant pas la totalité des éléments de l'état civil mais comportant le
mois de naissance.
LIEU DE NAISSANCE :
PERSONNES NEES EN METROPOLE :
les 2 premiers chiffres : département de naissance
les 3 chiffres suivants : commune dans le département
PERSONNES NEES DANS LES DOM ou DANS LES TOM :
Les 2 premiers caractères : 97 : DOM ; 98 : TOM
Les 3 caractères suivants :
- un caractère identifiant le pays
1 - Guadeloupe
2 - Martinique
3 - Guyane
4 - Réunion
- 2 caractères identifiant la commune dans le DOM ou le TOM.
PERSONNES NEES A L'ETRANGER :
Le lieu de naissance est codifié 99 suivi d'une lettre repérant le continent :
1 = Europe ; 2 = Asie ; 3 = Afrique ; 4 = Amérique ; 5 = Océanie ;
les 2 chiffres suivants désignent le pays dans le continent.
Cf le répertoire officiel géographique de l'INSEE.
EXCEPTIONS SUR LA COMPOSANTE LIEU DE NAISSANCE :
COMMUNE : commune fictive :
 990 pour les pupilles de l'Etat
999 pour les personnes dont le lieu précis de naissance n'est pas
connu
commune d'extension : lorsque plus de 999 personnes du même sexe sont nées dans le
même lieu, le même mois de la même année.
Exemples :
Paris 14 : code principal : 75114, code extension : 75214
Lyon tous arrondissements : code extension : 69323.

501 à 599
99-99-99-99
Personnel rémunéré sous forme d'indemnités
Pour ces agents, l'imputation budgétaire d'un traitement brut fictif - ainsi
que des "éléments fixes" de ce traitement - sera indiquée par des 9 dans
la grille de ventilation budgétaire. L'indemnité qui doit leur être payée
sera seule ventilée, à partir de l'imputation indiquée dans la table. Si
deux ou plusieurs indemnités, de même code indemnité, doivent être
imputées différemment pour des agents d'un même ministère rémunérés
sous forme d'indemnités, il y aura lieu d'ouvrir un code VB distinct par
imputation budgétaire.
*
* *
Dans chaque ministère, des codes VB 501 et suivants seront utilisés
pour la codification des agents qui ne perçoivent qu'un traitement
indemnitaire. Le code VB ne fait donc pas référence, dans ce cas, à
l'imputation budgétaire du traitement principal qui n'est pas payé. Il
permet seulement d'imputer correctement la ou les indemnité(s)
payée(s) à ces agents. Si une indemnité payée à des agents différents a,
pour cette raison, des imputations budgétaires différentes, il sera
nécessaire de créer divers codes VB pour pouvoir imputer correctement
cette indemnité pour les différents agents.
Pour le code VB 501 et suivants les tables de ventilation budgétaire
seront établies normalement pour la seule partie "indemnités". La partie
"Eléments fixes du traitement" ne comportera l'imputation budgétaire
normale que pour les éléments du traitement à imputer budgétairement.
Pour les autres éléments de traitement, l'imputation budgétaire sera
fictive et égale à 9999 9999. Ceci permettra, pour le cas où un code VB
501 ou suivant serait attribué à tort à un agent percevant un traitement
principal, de voir apparaître la consommation de crédit erronée au bas
de l'état de ventilation budgétaire avec l'imputation budgétaire 9999
9999.
Il serait également possible d'attribuer à ces agents :
- soit le code VB qui serait le leur s'ils percevaient un traitement
principal ;
- soit un code VB quelconque comportant dans la table VB l'imputation
à donner à l'indemnité payée à cet agent.
Dans ce cas, le contrôle visuel envisagé en cas d'erreur sur le code VB
ne serait pas possible.
N.B. - Pour le ministère 106, seuls les codes VB 501 à 549 sont laissés à
la disposition des services liaison-traitements.
