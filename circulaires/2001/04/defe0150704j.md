L' instruction 14770 /DEF/DCSSA/RH/ MINOC/1 du 22 septembre 1994 est modifiée comme suit :
1. Article 8, alinéa 8.1.
Au lieu de :
« Infirmiers principaux » ,
Lire :
« Infirmiers principaux et directeurs d'école paramédicale. »
2. Annexe IV.
Modifier le tableau de l'annexe IV ainsi qu'il suit :
Dans la colonne relative aux grades.
Ajouter avant les termes : « Aide-soignant de classe supérieure », les termes « Aide-soignant de classe
exceptionnelle ».
3. Annexe V.
Modifier le tableau de l'annexe V ainsi qu'il suit :
Dans la ligne relative aux grades.
Ajouter dans la troisième colonne du tableau, après les termes : « Infirmier principal de 2e classe », les termes
: « Directeur d'école para-médicale ».
Supprimer dans la quatrième colonne les termes : « Directeur d'école paramédicale ».
Dans la ligne relative aux appellations.

Ajouter dans la troisième colonne, après les termes : « Madame ou monsieur l'infirmier principal », les termes
: « Madame ou monsieur le directeur d'école paramédicale ».
4. Annexe VI.
Modifier le tableau de l'annexe VI ainsi qu'il suit :
Dans la ligne relative aux grades.
Ajouter dans la deuxième colonne du tableau, après les termes : « Secrétaires médicaux », les termes : «
Aides-soignants ».
