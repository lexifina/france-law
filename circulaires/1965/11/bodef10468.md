TERMES DE L'ACCORD (TDEA).
CODE DE COULEURS POUR L'IDENTIFICATION DES RAVITAILLEMENTS LARGUES.
BUT.
 1. 
Standardiser un code des couleurs à porter sur les colis du ravitaillement largués, afin de permettre aux forces
armées de l'OTAN d'identifier rapidement leur contenu.
MODALITÉS DE L'ACCORD (MDEA).
CODE DE COULEURS POUR L'IDENTIFICATION DES RAVITAILLEMENTS LARGUÉS.

ACCORD.
1. Les pays participants conviennent d'utiliser les couleurs suivantes sur la surface extérieure de leurs
emballages, plateaux ou plates-formes de livraison par air afin de donner une identification de leur
contenu :
a). Rouge : munitions et armement ;
b). Bleu : carburants et lubrifiants ;
c). Vert : vivres et eau ;
d). Jaune : matériel de transmissions ;
e). Blanc (ou croix rouge sur fond blanc) : ravitaillement sanitaire.
2. Les colis de ravitaillement d'autre nature ne portent pas de couleur particulière.
3. Tout procédé peut être employé pour indiquer les couleurs définies ci-dessus (peinture, craie,
papier de couleur, bande adhésive, etc…) ; aucune dimension particulière ni aucune forme n'est
prescrite, sous réserve que le procédé permette une identification à une distance de 200 mètres. Ce
marquage doit être réalisé sur les quatre faces latérales de chaque fardeau ou colis.
4. Si des lampes sont employées pour identifier de nuit ces ravitaillements, leurs couleurs doivent, si
possible, être conformes au code ci-dessus.
MISE EN APPLICATION.
5. Ce stanag sera considéré comme appliqué lorsque les prescriptions des modalités de l'accord
(paragraphe 1 à 4 ci-dessus) seront incorporées dans les ordres permanents ou les règlements
nationaux.
Nota.
Ce marquage d'ensemble qui permet une identification rapide, n'empêche pas le marquage plus détaillé de
chaque colis selon des normes OTAN ou nationales (type de munitions ou de ravitaillement sanitaire, numéros
de spécification, etc…).
