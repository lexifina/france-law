L’instruction 97-095-K1-B-M du 13 août 1997 a présenté aux comptables une application permettant la
consultation du Répertoire des Guichets Permanents par Minitel.
Celle-ci propose actuellement au réseau une consultation par établissement et par localité.
Afin d’améliorer la procédure en vigueur, un complément permettant la consultation à partir des codes
interbancaires a été réalisé ; aussi un accès est-il désormais possible à partir du code banque et du code
guichet.
La présente instruction a donc pour objet d’exposer aux comptables le troisième volet de cette application
qui est d’ores et déjà disponible.
Les modalités techniques de consultation, dont les codes d’accès demeurent inchangés [36-13, code
TRES1*MAO ] sont décrites dans le guide utilisateur joint en annexe auquel les comptables devront se
référer.
Toutes difficultés d’application devront être soumises à la Direction Générale sous le timbre des Bureaux
3A-7C.

ANNEXE (suite)
Choix
3
: LISTE PAR CODES BANQUE
Cette nouvelle fonctionnalité s’ajoute à celles déjà existantes.
Une liste de codes interbancaires s’affiche automatiquement à l’écran dès lors que l’on a choisi cette option
et deux possibilités sont alors offertes :
a) choisir un des codes interbancaires de la liste grâce au numéro.
b) choisir d’autres codes en entrant le code banque et le code guichet.
a) CHOIX D’UN DES CODES INTERBANCAIRES FIGURANT SUR LA LISTE
Pour sélectionner le guichet d’un établissement, il suffit d’entrer le numéro correspondant dans la liste.
L’écran suivant affiche les coordonnées bancaires telles qu’elles figurent actuellement au Répertoire des
Guichets Permanents :
- Localité
- Code établissement
- Code guichet
- Code géographique
- Code recouvreur
- Code localité de compensation
- Immatriculation du guichet
- Comptoirs Banque de France (chargés de l’acheminement des opérations)
La touche « suite » peut éventuellement être utilisée après le premier écran ; cependant son intérêt dans ce
cas est limité.

ANNEXE (suite et fin)
b) CHOIX D’UN GUICHET
EN ENTRANT TOUT OU PARTIE DES CODES INTERBANCAIRES
Lors de l’affichage de la première liste, il est proposé d’entrer de 3 à 10 caractères des codes interbancaires
de l’établissement recherché.
Une liste va alors s’afficher, plus ou moins large selon le nombre de caractères entrés :
Ç Si l’on entre moins de 5 caractères, une liste de différents établissements et guichets, sélectionnés sur
la base des caractères entrés, va s’afficher ; il conviendra de choisir un guichet de la liste grâce au numéro,
ou de faire « SUITE. ».
Ç Si l’on entre la totalité du code établissement, soit 5 caractères, va alors s’afficher la liste de tous
les guichets de cet établissement ; il conviendra là encore de choisir un numéro correspondant à un guichet,
ou de faire « SUITE. ».
Ç Si l’on entre le code établissement et une partie du code guichet, une liste plus restreinte encore va
s’afficher, pour laquelle il conviendra de choisir, au moyen du numéro, le guichet souhaité.
Ç Si l’on entre les codes établissement et guichet en totalité, l’écran suivant affiche directement les
coordonnées bancaires :
- Localité
- Code établissement
- Code guichet
- Code géographique
- Code recouvreur
- Code localité de compensation
- Immatriculation du guichet
- Comptoirs Banque de France (chargés de l’acheminement des opérations).
