## Résumé

La circulation a pour objet de détailler la procédure d'instruction pour demander un agrément de l'autorité de tutelle visé à l'article L.533-3 du code de la recherche ou L.762-3 du code de l'éducation dans le cadre de délégation d'activités édictées à l'article L.533-2 du code de la recherche ou L.123-5 du code de l'éducation vers une structure de droit privé.
